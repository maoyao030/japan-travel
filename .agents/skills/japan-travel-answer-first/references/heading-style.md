# 標題與 SEO 規範

從好材誌 `building-materials-tw-heading-optimizer` 的標題規範移植，換成旅遊例子。好材誌是上線後逐篇給 Darren 確認；本站把同一套規則放進自動化流程，在寫作階段由獨立的標題檢查 agent 執行，不必逐篇等 Darren 確認（2026-10-16 Darren 決定）。SEO 規範沿用好材誌，2026-10-18 從 `voice-and-seo.md` 併入本檔最後一節；作者寫作時只需記住寫作指南第 1 條，細則由標題檢查 agent 對照。

## 標題的角色

- 標題是讀者掃讀用的導覽，也是搜尋引擎辨識頁面主題的骨架。只讀 H 樹就要看出這一頁在回答什麼、各節在講哪個地點或問題。
- 標題命名本節的「對象」或「讀者真的會問的問題」；判斷、理由、順序提醒與操作細節留在正文。
- 不把標題當排版工具，不為湊數新增標題。

## H1 與 SEO Title

- 一頁一個 H1，自然保留主要查詢的核心詞（例如「禮文島交通」「稚內住宿」）。
- SEO Title 與 H1 回答同一件事；可以相同，也可以各自表達，不能為了點擊暗自改題。
- 不用冒號（`:` 或 `：`）切開主題與說明，改成問句、逗號或完整句。
  - 合格：「禮文島交通，巴士班次、觀光巴士預約與沒車怎麼去景點」「利尻山怎麼爬？登山口、時間與下山後的交通」
  - 不合格：「禮文島交通：完整攻略」「稚內住宿懶人包」
- 不用「完整指南」「懶人包」「重點整理」「先看結論」「TL;DR」「攻略大全」這類制式標籤。

## 層級與分工

- H1 → H2 → H3 逐級展開，不跳級、不重複。
- H2 是主要分章；只讀 H2 就看得出文章怎麼完成讀者的任務。
- H3 只細分所屬 H2 下的地點、路線、步驟或子問題；同一父題下的 H3 粒度相近。
- 不把所有內容攤成同一層 H2，也不把沒有父子關係的內容硬塞成 H3。

## 地名與主題辨識

- 每個正文 H2 都帶本頁地名，例如「禮文島路線巴士的三條路線」「禮文島觀光巴士怎麼預約？」；問句 H2 的句首也帶地名。
- H3 在父題已帶地名時可以省略（「澄海岬怎麼去？」放在「禮文島沒車怎麼去…」底下），單獨讀不出對象時才補。
- 次要查詢（頁面規格的 `secondaryQueries`）要出現在某個 H2 或 H3。
- 「交通方式」「注意事項」「推薦」「價格」單獨出現不合格，補上地點或改成具體問題。
- 標題承諾的內容，下文必須提供。
- `## 常見問題` 與 `## 資料來源` 是固定名稱，不加地名、不改名。

## 問句與直接回答

- 讀者真的會問的問題可以當 H2／H3，寫成完整問句、以全形「？」收尾，下一段第一句就是答案。
- 不要求所有標題問句化；已清楚的主題名不必硬改。
- 不能把正文提醒加上問號就當問句標題。

## 標題與正文各司其職

不把正文提醒升成小標。判斷的是整句的用途，不是有沒有特定字詞。

| 不合格 | 問題 | 改法 |
|---|---|---|
| 先訂船票再訂旅館 | 順序提醒 | 稚內到禮文島的船票預約 |
| 別錯過末班巴士 | 提醒式小標 | 禮文島巴士的末班時間 |
| 冬天不要走步道 | 正文的警告 | 禮文島步道的冬季封閉 |
| 觀光巴士才是最好的選擇 | 結論式小標 | 禮文島觀光巴士的路線與季節 |

常見的正文式句型：「先做 A，再做 B」「別只看 A」「A 不等於 B」「A 才是關鍵」「一定要 A」「不要急著 A」。

仍然合格、不要誤改的：地名與景點名 H3、步驟名（「網路預約」「電話預約」）、真實完整問句（「澄海岬怎麼去？」）。

## 改動的節制

- 只改有明確缺陷的標題；同義字選擇不算缺陷。
- 每個改動都要能說出對應哪一條；說不出理由就不改。
- 標題檢查只改標題文字，不改正文、不新增或刪除標題、不改層級。層級本身有問題時寫成結構備註，交回作者在下一輪處理。

## SEO（沿用好材誌規範）

- **主要查詢要完整出現**：主要查詢的完整詞組（例如「禮文島交通」）至少在開頭兩段裡自然出現一次，不能只靠拆散的「禮文島」「交通」。H1 自然保留它的核心詞。
- **次要查詢**：規格的 `secondaryQueries` 要自然出現在 H2 或 H3，以及該節正文。
- **問句緊接回答**：讀者真的會問的問題才作問句標題，下一段第一句就是答案。
- **常見問題**：從同搜尋意圖頁、Google「其他人也問了」與 `mustAnswer` 找出正文還沒直接回答的問題，放在 `## 常見問題`。不把正文換成問句再寫一次；沒有合格問題就不設，研究記錄寫原因。
- **看競爭頁**：研究階段實際開啟 3～5 篇同搜尋意圖的繁中頁，記下它們的 H 樹、回答了什麼、漏了什麼。本頁要回答它們漏掉的，H 樹要比它們清楚。
- **不追密度**：不設關鍵字密度、固定 H2 數量，也不把所有 H2 改成問句。
