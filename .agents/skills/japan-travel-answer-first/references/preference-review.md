# 偏好審查：拿 Darren 講過的話逐句審（Darren 2026-11-26）

Darren 看〈禮文島天氣〉樣本的開頭後說：「我覺得你可以參考一下我前兩個範例我對他要求的偏好。」那份樣本當時已經過了事實查核與五次讀者驗收，但拿他在住宿頁、地點主頁講過的要求逐句對，還有 23 處不合：摘要一句塞五件事、條件用逗號帶過的筆記句、換個地方也成立的話、照日文句子搬過來的詞。

讀者驗收看的是「讀者卡不卡」，抓不到「Darren 會不會退」。所以多一位只做這件事的審查者，不要等他再講一次。

作者那一面是 [每一頁都一樣的寫法](core-style.md)（2026-11-26）：同一套標準，寫成「要寫成什麼樣」，作者動筆前讀；這一份是審查者逐句問的題目。

目前用在：天氣頁（`content-automation/weather-writer.md`）。地點主頁有自己的吸引力審查（`place-entry-hook-review.md`），住宿頁有自己的編輯。之後做其他頁型的範本時，從這一關開始用。

## 審查者是誰

不是作者、不是事實查核者、不是協調者。Opus 5.5。只讀成品（`reader-preview.md`、`publication.json` 的 `excerpt` 與 `seoTitle`），不讀作者的說明。只讀不改稿。

## 標準只有 Darren 講過的話

審查者先把下面幾份讀熟，裡面標了 Darren 原話或「Darren 某月某日」的就是他的要求：

1. `place-entry-hook-review.md`：五個問題與他確認過的例子。
2. `place-entry-page.md`「最上面三樣」：大標題的結構、摘要不唸清單、序言一段只講一兩件事。
3. `stay-page.md`「句子」「用語」「編輯怎麼看」，以及最後「住宿專門頁」那幾條。
4. `examples.md` 第 6 節：他親手改的句子（6-5 說話的語氣、6-6 碎句接成一口氣而且條件跟著主詞走）。
5. `writing-guide.md` 第 17 條、`sentence-rhythm.md`。
6. 這種頁型的寫法檔（天氣頁是 `weather-page.md`），包含他對這種頁型講過的話（開頭先介紹這個地方再帶進主題）。
7. 一篇他親口說可以當範本的整篇文章（`page-models/`），感受他認可的句子長什麼樣；結構不用比。

**每一條意見都要對得到他的某一句話**，寫出是哪一句。審查者與協調者自己覺得的不算。

## 逐句問

大標題、摘要、每一段每一句、表格的定調與穿法格子，每一處問：

| 問題 | Darren 的話 |
|---|---|
| A. 換成別的地方，這句還能用嗎？ | 「大標題跟第一段還有兩個序言都很空泛」 |
| B. 放的是不是最讓讀者有感、最要緊的那一件事？ | 「必比登才是重點」 |
| C. 寫的是讀者得到什麼、會怎樣，還是只有資料或動作？ | 「剝好當場吃感覺好無聊」 |
| D. 一段是不是把一兩件事講完整？有沒有四五件事各半句？ | 「這些斷點好快喔」 |
| E. 句子是不是說話的語氣、把話講完整？條件有沒有用逗號帶過？ | 他把「第一次去、沒打算租車，住香深最省事。」改成「如果是第一次去並且沒有打算租車的話，住在香深最為省事。」 |
| F. 有沒有贅字、事實後面多補的總結？提醒是不是接在具體事實後面？ | 住宿頁「句子」第 2、3 點 |
| G. 開頭有沒有先介紹這個地方，再帶進主題？每節開頭有沒有讓讀者知道在回答他的什麼問題？ | 「先介紹這個地方，然後再帶入這個主題」 |
| H. 用語是不是台灣人平常講話的說法？ | 「檢討」不是台灣用語 |
| I. 大標題是不是他挑過的結構？ | 利尻島、禮文島天氣都是他從候選裡挑的 |

還沒有定案的大標題，審查者另外提 3 個候選（風格各不同），說他比較可能挑哪個、為什麼。

## 不要做的

- 不因為句子平實就判沒過；寫清楚的事實不是空話。
- 不要求加形容詞。
- 不改事實、不要求加事實表沒有的內容。可以示範一種改法，但事實、數字、條件一個都不能動，條件要跟著原本的主詞走。
- 表格格子本來就是短句，不審成長句。
- Darren 已經親口說可以的地方不再挑（大標題、他看過說可以的開頭）。

## 交什麼

`preference-review.md`，每一輪往下加一節：

1. 一張表，一處一列：位置｜原句｜違反哪一條（附 Darren 的原話或他改過的例子）｜改的方向。
2. 大標題的判斷與候選（還沒定案時）。
3. 沒問題、不要動的好句子（5 句左右，免得作者改壞）。
4. 結論：`通過` 或 `退回作者（N 處）`。

## 在流程裡的位置

事實查核之後、讀者驗收之前。退回作者改，最多 3 輪；第 3 輪還剩的，只差一兩個詞就套用審查者示範的改法，要改段落的照「停放」處理。

**改語氣會改到強度**：樣本裡作者照審查改完，事實複查抓到 4 處強度變了（「最接近」變「最剛好」、「推播」變「馬上收到通知」、條件「冷夏的時候」掉了）。所以每一輪改完都要送事實查核複查；審查者示範的改法由協調者套用時也一樣要查。

## 這份清單怎麼變好

Darren 之後每挑出一種新的毛病，就加一題、附他的原話。只有 Darren 挑出來的才加。不分頁型的，同時在 [core-style.md](core-style.md) 補上「要寫成什麼樣」，作者才不會等到審查才知道。
