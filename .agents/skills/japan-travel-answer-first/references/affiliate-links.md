# 分潤連結與推廣工具

本站的收入主要來自 Trip.com 與 Agoda 的聯盟分潤（讀者透過本站連結訂房或買票，平台付一部分佣金給本站，讀者價格不變）。住宿是主力，但不限住宿頁：只要跟主題有關、讀者讀到那裡正好要訂，任何頁型都可以放。這份檔案說明 Trip.com 聯盟計畫的規則、各頁型可以放什麼，以及文字連結、橫幅、搜尋框的用法。寫任何會提到訂房、訂票、租車、接送的段落，或填 `bookingChannels` 時讀。

Agoda 的規則還沒整理，查好後補在本檔「Agoda」一節。

## Trip.com 聯盟計畫的規則

查核日期 2026-10-24。官方說明頁寫明規則會調整，新規則從通知後的下個月生效；申請到帳號後以後台為準，數字有變就改這一節並更新日期。

### 佣金

| 產品 | 佣金 |
|---|---|
| 住宿 | 每月完成 0–199 筆 5%、200–999 筆 6%、1000 筆以上 7% |
| 國際機票 | 0–299 筆 0.5%、300 筆以上 0.8% |
| 機票＋住宿 | 2%–2.5% |
| 火車 | 2% |
| 一日遊、體驗 | 4% |
| 景點門票、表演 | 1.5% |
| 租車、機場接送 | 5% |

- 只算住完的訂單：旅館要退房後才算，取消與沒入住不算。
- 讀者用折扣碼、Trip Coins、禮物卡折掉的部分不算佣金。
- 住宿佣金以含稅金額計算。
- 追蹤期限：第三方聯盟目錄多寫網頁 30 天、App 7 天，以最後一次點擊計算。官方頁沒有寫，申請後以後台為準。

### 付款

- 銀行匯款，幣別選美元或港幣。
- 累積滿 200 美元（或 1,500 港幣）才付，不到就累積到下個月。
- 時程：訂房當月 → 下個月 5 日左右審核 → 再下個月 10 日左右入帳，約 40 到 60 個工作天。
- 收款銀行會扣手續費，實拿比報表少。

### 禁止的推廣方式

- 不買「Trip.com」品牌字或變體的搜尋廣告。
- 不用臉書廣告推分潤連結。
- 不寫成「Ctrip」（Trip.com 的中國品牌名）。
- 本站只靠文章的自然搜尋流量，不買任何廣告推連結。有一個第三方聯盟目錄把「SEO」也列為禁止，官方頁沒有這條；申請時在條款裡確認，確認結果記在 `PROJECT_STATUS.md`。

### 工具

- **Link Builder**：把任何 Trip.com 網址轉成帶本站帳號編號的追蹤連結。
- **橫幅**：固定圖片的橫幅（Static Banner），和內容會變動的橫幅（Dynamic Banner，例如輪播特價）。
- **搜尋框**（Search Box）：讓讀者在本站直接輸入日期搜機票、旅館、火車，按下後跳到 Trip.com。在後台建立後複製嵌入程式碼。
- **Promotion Center**：熱銷旅館與優惠清單。只當參考，不拿來決定寫哪些旅館；旅館要不要寫，照頁面規格與研究結果。
- 第三方目錄另外列了資料串接（Data Feed、API）與折扣碼。本站不放折扣碼（見下面「文字連結」）。

工具的實際名稱與選單位置會依地區與帳號不同，申請到帳號後照後台實際看到的更新這一節。

## 各頁型可以放什麼

原則：放在讀者讀到那裡正好要訂的位置，而且 Trip.com 或 Agoda 真的賣那樣東西（研究時實際搜過）。沒賣的不放，也不為了放連結去寫本來不該寫的段落。

| 頁型 | 可以放 | 佣金 | 位置 |
|---|---|---|---|
| 住宿頁、地點主頁的住宿節 | 每間旅館自己的訂房頁 | 住宿 5%–7% | 該旅館段落 |
| 交通頁 | 火車票（JR 周遊券、新幹線）、租車、機場接送 | 火車 2%、租車與接送 5% | 講到怎麼買票、要不要租車的段落 |
| 景點、體驗頁 | 門票、一日遊、觀光巴士 | 一日遊 4%、門票 1.5% | 講到怎麼買票、要不要預約的段落 |
| 天氣、季節頁 | 該地點的旅館清單頁（城市頁） | 住宿 5%–7% | 結尾「接下來安排住宿」那類段落，一處就好 |
| 美食頁 | 通常不放；附近住宿已經有住宿頁負責 | — | — |
| 共用教學頁 | 教學主題本身是訂票、租車時才放 | 依產品 | 教學步驟裡 |

- **交通與規則的事實照樣只用經營者官方**（例如 JR 北海道、宗谷巴士）。分潤連結是「另一個購買管道」，不是事實來源；官方有賣票就照樣先寫官方，Trip.com 列成另一個選擇，並寫清楚兩邊差在哪（例如官方只有日文、Trip.com 有中文介面）。
- 國際機票佣金只有 0.5%–0.8%，不特別放。
- KKday 有上架的團體行程可以走 KKday 分潤（2026-10-15 交接文件），規則另外整理。

## 文字連結

### 哪些旅館放分潤連結

- 研究時實際在 Trip.com 台灣站（`tw.trip.com`）搜到這間旅館，`bookingChannels` 有 `trip.com`，才放 Trip.com 連結。Agoda 同理。
- 只有官網或 Jalan 能訂的，放官網連結，不收錢。不為了分潤把這類旅館寫得比較不好，也不因為有分潤就把旅館往前排；排法照讀者的需求（位置、班次、含餐）。
- 同一間兩個平台都有，兩個都列，不只放佣金比較高的那個。官網能訂的也照樣列官網。

### 連結寫法

- 住宿段落的連結指向那間旅館自己的 Trip.com 頁，例如 `https://tw.trip.com/hotels/wakkanai-hotel-detail-<編號>/`，不連城市清單頁。只有天氣、季節頁可以連城市清單頁（見上表）。票券、租車連那個商品自己的頁。
- 帳號還沒申請前，正文先放旅館頁的一般網址。申請到帳號後，上稿前用 Link Builder 換成追蹤連結；換連結不改文字，不算改稿。
- 連結文字寫讀者要做的事：「在 Trip.com 查空房與價格」「Agoda 訂房頁」。不寫「最低價」「最優惠」「限時」這類平台沒保證、本站也查不到的話。
- 價格照旅館官網寫。Trip.com 上看到的房價會依日期變動，不寫進正文當事實。
- 評分與評論數照 [評論與人氣](reviews-and-popularity.md)：寫平台名稱與查核日期。
- 不放折扣碼。折扣碼會讓那部分訂單不算佣金，也常過期。
- 分潤連結屬於讀者要用的連結，放在那間旅館的段落文字裡，不放在 `## 延伸資料` 與 `## 資料來源`。
- 網站的表格（Sanity `contentTable`）格子只能放純文字，放不了連結。住宿表的「訂房管道」格只寫管道名稱（官網、Trip.com、Agoda、僅 Jalan），連結寫在表格下面或該旅館的段落。

## 橫幅與搜尋框

網站文章目前只支援文字、表格、圖片三種區塊，還不能放橫幅與搜尋框。申請到帳號、看得到後台實際的嵌入程式碼後，再做網站的「推廣區塊」（Sanity 新區塊類型與顯示元件）。做之前，寫作時只在研究記錄的文章計畫列「推廣區塊候選」：放哪一節、放什麼（橫幅或搜尋框、哪個產品），正文不放。

網站元件做好後照這些規則用（2026-10-24 暫定，Darren 可改）：

- **一頁最多一個**橫幅或搜尋框，文字連結不算在內。
- **不放在開頭**：第一個 H2 之前不放，也不插在回答讀者核心問題的段落中間。放在相關段落結束後。
- **跟主題對得上**：住宿頁放旅館搜尋框、預設好地點；交通頁放火車或租車；景點頁放門票。不放跟本頁無關的特價輪播。
- **優先用固定橫幅或本站自己做的卡片**（純圖片加連結，網站自己顯示），比較快，也不會載入 Trip.com 的程式。會變動的橫幅與搜尋框通常要載入對方的程式（JavaScript 或 iframe，就是在本站頁面裡開一個 Trip.com 的小視窗），會拖慢頁面，對方也可能放 Cookie；要用之前先跑頁面速度檢查，並更新隱私權政策。
- **標示**：區塊角落寫「分潤」或「訂房推廣」，讓讀者分得出這不是本站內容。
- 不用彈出視窗、不用蓋住內文的浮動橫幅。

## 揭露

- 網站的 [關於頁](../../../../src/pages/about.astro)「訂房連結與合作揭露」與隱私權政策已說明分潤，這是全站的揭露。
- 有分潤連結的文章，在第一個分潤連結所在的段落或表格前，寫一句：「下面的 Trip.com 與 Agoda 連結含有本站的訂房分潤，房價不會因此改變。」平台名稱照這篇實際有的寫，只出現一次，不放在文章開頭，也不每段重複。（2026-10-24 暫定，Darren 可改）
- 網站對 `trip.com` 與 `agoda.com` 的連結自動加上 `rel="sponsored"`（告訴搜尋引擎這是有收錢的連結，Google 要求這樣標），程式在 `src/lib/portableText.ts`，寫作時不用另外處理。
