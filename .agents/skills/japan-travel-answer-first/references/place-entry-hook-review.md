# 地點主頁的吸引力審查（Darren 2026-11-24 決定）

Darren 看利尻島主頁時，一次一次挑出「看了不會想去」「太空泛」「好無聊」的句子。作者看不出自己寫的句子空不空，協調者有自己的偏見，所以流程裡多一位只做這件事的審查者。

審查者不是作者、不是事實查核者、不是協調者。他只讀成品，不讀規格與作者的說明。

## 審查者是誰

一個還沒決定要不要去的台灣讀者。他不查班次、不訂旅館，只想知道：這個地方有什麼值得我專程去？

## 看哪些地方

只看讀者第一眼會看到、決定要不要往下讀的字：

1. 大標題
2. 摘要（`publication.json` 的 `excerpt`）
3. 兩段序言
4. 「是什麼樣的地方」整節
5. 「有什麼好玩、好吃的」每個小標題與小段第一句

其他節（幾月去、怎麼排、住哪一區）不審，那些是給決定用的，不靠吸引力。

## 每一處問五個問題

| 問題 | 沒過的樣子 | Darren 的原話 |
|---|---|---|
| 1. 換成別的地方，這句還能用嗎？ | 能，就是空話 | 「大標題跟第一段還有兩個序言都很空泛」 |
| 2. 這裡放的是不是這個東西最厲害的那一件事？ | 放了做法、規格，把得獎、唯一、名產上的那個東西漏掉 | 「必比登才是重點」「選一個真的引人入勝的」 |
| 3. 寫的是讀者得到什麼，還是他要做的動作？ | 只寫動作 | 「剝好當場吃感覺好無聊」「新鮮海膽現場直接吃，這樣不是更有爆點嗎」 |
| 4. 這一段是不是把一兩件事講完整？ | 四五件事各半句，像唸清單 | 「這些斷點好快喔」 |
| 5. 讀完有沒有畫面？ | 只講交通、位置、行政區 | 「是什麼樣的地方也沒說多少，看了不會想去玩啊」 |

第 2 題要對照事實表與子頁：審查者先翻一遍同地點子頁的稿，列出每個看點「最厲害的那一件事」的候選，再看主頁有沒有用上。主頁用的比候選弱，就是沒過。

## 不要做的

- 不因為句子平實就判沒過。寫清楚的事實不是空話；空話是換個地名也成立的話。
- 不要求加形容詞（絕美、夢幻、必吃）。吸引力來自具體的東西，不是形容詞。
- 不拿自己的喜好當標準。「一次看」「攻略」這類台灣讀者看慣的詞可以用；標準只有上面五題。
- 不改稿、不寫替代句。只指出哪一處、哪一題沒過、為什麼，以及子頁裡有哪個更強的事實可以用（附來源稿的原句）。

## 交什麼

`hook-review.md`，一處一列：

| 位置 | 原句 | 哪一題沒過 | 為什麼 | 可以改用的事實（來源稿原句） |
|---|---|---|---|---|

最後一行寫結論：`通過` 或 `退回作者（N 處）`。

## 在流程裡的位置

作者寫完、`check-voice.mjs` 通過之後，事實查核之前。沒過就退回作者改，改完再審，最多三輪；三輪還有沒過的，那一處照預設處理：找不到更強的事實就把那個看點併進別項或拿掉，不拿空話上線。審查通過後才送事實查核（改過的句子都要查）。

自動跑時不停下來問 Darren；每一輪審查的結果留在封包裡，他事後看得到。

## 這份清單怎麼變好

Darren 之後每挑出一種新的毛病，就加一題、附他的原話。只有 Darren 挑出來的才加，審查者與協調者自己覺得的不加。

## Darren 確認過的例子（禮文島，2026-11-24）

協調者在給 Darren 看之前先猜了九處，Darren 說「對，你在意的有問題」。這九處吸引力審查四輪都放行了，之後照這些例子審：

- 序言或小段的結尾只剩位置：「再往北，禮文島的最北端是須古頓岬。」（第 1、5 題）一個名字出現在序言，就要帶著想去的理由，不然不要提。
- 摘要用規格收尾：「從1994年起就列入日本保護的『國內希少野生動植物種』」。（第 2 題）
- 賣點後面接規格：久種湖「日本最北的湖」之後寫繞一圈幾分鐘、難度幾顆星。（第 2、3 題）小段每一句都要審，不只第一句。
- 撐不起一項的看點：薄雪之湯除了望得到利尻山，剩下是三溫暖、全年無休。併進別處。
- 小標題放兩件事：「清晨的雲海與國家天然紀念物的花」。挑一件。
- 有名字的賣點沒用上名字：澄海岬的海色叫「禮文藍」。
- 小標題像菜單：「6月到8月，海膽丼與放了海膽、牡丹蝦的磯拉麵」。
- 候選表裡最強的賣點沒有成為看點：北方金絲雀公園是吉永小百合主演電影的外景校舍，卻只在節末帶過。審查者要拿自己的候選表對看點清單，最強的幾個沒列進去就是沒過。
- 大標題結尾像被截斷：「…與一日來回」。
