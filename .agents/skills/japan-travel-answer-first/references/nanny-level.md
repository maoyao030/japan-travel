# 保母等級檢查表

文章計畫階段用的檢查表。寫作時要記的只有寫作指南第 8 條：只寫這個地方特有的難處，每個錯過就麻煩的環節給具體備案，一般常識連到共用教學頁。查不到的不寫、也不向讀者交代沒查到，見寫作指南第 5 條。

讀者設定：去過東京、大阪自由行，會用 Google 地圖與翻譯 App，日文看不太懂，這次想去交通不方便的小地方。日本旅遊的一般常識不寫，例如整理券巴士怎麼搭、IC 卡是什麼、下車要按鈴、便利商店能領錢。

篇幅跟著事實走：主題頁通常 800～3,000 字，地點主頁 1,500～2,500 字。同一個條件在一頁裡只寫一次。

## 讀者擔心的事與文章要給的東西

| 擔心 | 文章要給的東西 |
|---|---|
| 看不懂日文網站，不會訂 | 訂票、訂房頁面的按鈕與欄位對照表：日文、意思、要選哪一個 |
| 到現場不知道往哪走 | 售票口、月台、巴士站牌的位置描述與標示上的日文 |
| 怕錯過班次 | 末班船、末班車時間，錯過之後的備案 |
| 怕天氣出狀況 | 停駛怎麼公告、去哪裡看、船票與旅館怎麼處理 |
| 不知道能不能刷卡 | 現金、信用卡、交通 IC 卡在當地哪些地方能用 |
| 不知道什麼時候做什麼 | 出發前一個月、前一週、當天各要完成的事 |
| 行李太多 | 寄物櫃、宅配、旅館寄放的位置與條件 |

不是每一頁都要有全部項目。依頁型與 `mustAnswer` 決定，但寫作前要逐項想過，在研究記錄註明哪些不適用。

## 寫法

### 按鈕與欄位對照表

```markdown
| 畫面上的日文 | 意思 | 要怎麼選 |
|---|---|---|
| 往路 | 去程 | 選稚內出發 |
| 片道／往復 | 單程／來回 | 依行程選 |
| 大人 | 成人 | 填人數 |
```

只列讀者會遇到的欄位，不翻譯整個網站。對照表內容要來自實際開啟的頁面，研究記錄保存頁面網址與查閱日期。

### 不寫日文教學

不寫「可以指給對方看的日文」「照著念的電話日文」這類句子清單（2026-10-16 Darren 決定）。讀者會用翻譯 App，日文教學不是本站要提供的東西。現場要認的日文招牌、站名、網站按鈕仍然寫出原文，那是讓讀者認得出來，不是教日文。需要打日文電話才能完成的事，寫明這點並給不用講日文的替代做法（網路預約、到窗口辦）。

### 台灣讀者照做時會卡住的三件事（2026-10-18 讀者任務測試）

讀者照渡輪頁排「當天來回禮文島、隔天利尻島住一晚」時，卡住的多半不是文字，而是內容沒寫：

- **時間是日本時間**：「搭船日兩個月前的0點開放預約」這類時間點，寫明是日本時間，台灣比日本晚1小時，日本0點是台灣前一天23點。
- **外國人的名字怎麼填**：只收平假名、片假名或全形的欄位，要查官方有沒有寫外國人怎麼填（英文介面、羅馬拼音、護照拼法）。查到才寫；查不到時寫「可以切換英文介面」這類查得到的事，不自己發明填法。
- **只能打日文電話的事**：例如開船前24小時內只能打電話改票，要寫出不會講日文時能做的事（例如官方寫了可以到窗口辦或用電子郵件聯絡），一樣要有事實或官方說明撐，不自己發明做法。

### 備案

每個「錯過就麻煩」的環節都要有備案：末班船、末班巴士、旅館入住截止時間、季節停駛。備案要具體，例如「末班船停航時，稚內港附近可住的旅館」，不是「請自行安排」。各地相同的操作連到共用教學頁，本篇只寫在地差異；重複寫同樣的整理券說明，會被搜尋引擎視為重複內容。
