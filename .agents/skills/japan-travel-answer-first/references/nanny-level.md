# 保母等級寫法

讀者設定：去過東京、大阪自由行，會用 Google 地圖與翻譯 App，日文看不太懂，這次想去交通不方便的小地方。

保母等級只寫**這個地方特有的難處**：船班少、會停航、末班時間、季節限定、只收現金、只有日文的訂票頁、沒車到不了的地方。日本旅遊的一般常識不寫，例如整理券巴士怎麼搭、IC 卡是什麼、下車要按鈴、便利商店能領錢；需要時連到共用教學頁，本篇一句帶過。

篇幅跟著事實走：主題頁通常 800～3,000 字，地點主頁 1,500～2,500 字。同一個條件在一頁裡只寫一次。

## 讀者擔心的事與文章要給的東西

| 擔心 | 文章要給的東西 |
|---|---|
| 看不懂日文網站，不會訂 | 訂票、訂房頁面的按鈕與欄位對照表：日文、意思、要選哪一個 |
| 到現場不知道往哪走 | 售票口、月台、巴士站牌的位置描述與標示上的日文 |
| 不會講日文 | 可以直接指給對方看的日文句子，附中文意思與使用時機 |
| 怕錯過班次 | 末班船、末班車時間，錯過之後的備案 |
| 怕天氣出狀況 | 停駛怎麼公告、去哪裡看、船票與旅館怎麼處理 |
| 不知道能不能刷卡 | 現金、信用卡、交通 IC 卡在當地哪些地方能用 |
| 不知道什麼時候做什麼 | 出發前一個月、前一週、當天各要完成的事 |
| 行李太多 | 寄物櫃、宅配、旅館寄放的位置與條件 |

不是每一頁都要有全部項目。依頁型與 `mustAnswer` 決定，但寫作前要逐項想過，在研究記錄註明哪些不適用。

## 寫法

### 按鈕與欄位對照表

```markdown
| 畫面上的日文 | 意思 | 要怎麼選 |
|---|---|---|
| 往路 | 去程 | 選稚內出發 |
| 片道／往復 | 單程／來回 | 依行程選 |
| 大人 | 成人 | 填人數 |
```

只列讀者會遇到的欄位，不翻譯整個網站。對照表內容要來自實際開啟的頁面，研究記錄保存頁面網址與查閱日期。

### 指給對方看的日文

```markdown
- 「この船は礼文島に行きますか？」：這班船會到禮文島嗎？上船前問工作人員。
```

句子要短、正確、有使用時機。驗收時會核對日文是否自然。

### 查不到就說

「旅館官網沒有寫是否接受信用卡，建議訂房時以電子郵件確認。」比猜測安全。查不到不是失敗，寫成確定才是。

### 備案

每個「錯過就麻煩」的環節都要有備案：末班船、末班巴士、旅館入住截止時間、季節停駛。備案要具體，例如「末班船停航時，稚內港附近可住的旅館」，不是「請自行安排」。

## 不要變成囉嗦

- 開頭照樣直接回答核心問題，細節放後面。
- 各地相同的操作連到共用教學頁，本篇只寫在地差異。重複寫同樣的整理券說明，會被搜尋引擎視為重複內容。
- 不寫泛用提醒，例如「出國要注意安全」「記得帶護照」。每一句都要和本頁的地點或操作有關。
- 不寫「建議提早規劃」這種沒有具體內容的句子；要寫就寫「船票在出發前兩個月開放預約」。
