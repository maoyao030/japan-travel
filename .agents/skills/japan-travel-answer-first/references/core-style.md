# 每一頁都一樣的寫法：Darren 要的內容長什麼樣

2026-11-26 整理。Darren：「共用的規則跟我在意的東西就不要再做錯事情了」「你應該最後有把它整理成一個適合撰寫的規則吧…你要知道我想要的內容大概是長什麼樣子」。

這一份給**作者**在動筆前第一個讀，也給做新頁型範本的人在提結構、寫樣本之前讀。住宿頁、地點主頁、天氣頁三種頁型定案的過程裡，他講過、而且不分頁型的要求，都改寫成「要寫成什麼樣」放在這裡。

- 這裡只收他講過的。作者、審查者、協調者自己覺得的不加。
- 每種頁型自己的結構（幾節、幾張表、多少字）看那種頁型的寫法檔：[住宿頁](stay-page.md)、[住宿專門頁](stay-topic-page.md)、[地點主頁](place-entry-page.md)、[天氣頁](weather-page.md)、[祭典頁](festival-page.md)。和這一份衝突時，以頁型檔裡他親口定的為準。
- 標點、譯名、連結格式這些細則照 [寫作指南](writing-guide.md)；這一份講的是指南講不出來的「整篇讀起來是什麼樣子」。
- 審查的那一面是 [偏好審查](preference-review.md)：同一套標準，寫成審查者逐句問的題目，附他的原話。

## 一句話

像一個熟這個地方的台灣朋友，把話好好講完整：這裡有什麼只有這裡才有的東西、適不適合你、會卡在哪裡、接下來怎麼做。不是在列資料，也不是在寫宣傳。

## 1. 一頁只做一件事，每一句都過同一個門檻

動筆前先寫下這兩行，寫不出來就還不能動筆：

- **這一頁的讀者是誰、他現在在決定什麼。** 住宿頁是決定訂哪一間並直接去訂；地點主頁是還沒決定要不要去的人，要讓他想去、排得出大方向；天氣頁是已經想去的人，要知道「我那個月去會怎樣」。
- **每一句的門檻：這句會不會改變他的決定？** 不會的不寫，或交給負責那件事的頁。

份量照這個門檻拿捏，太多和太少都不對：

- **賣點要寫出來**：這個地方、這間店有什麼別的沒有、會讓人想去的東西，講得出具體內容（自己盛的海鮮丼、門口就是機場巴士站、8月只像台北3月）。
- **規格要刪掉**：幾點到幾點、在幾樓、幾間、幾台、繞一圈幾分鐘。只有會讓人撲空或改變選擇的才留（一天只有兩三班、只做午餐、冬天不開）。
- 刪廢話刪的是規格，不是賣點。事實表有三個賣點、正文只用了一個，是太少。

## 2. 讀者第一眼看到的字

大標題、摘要、開頭、每一節的第一句、小標題，決定他要不要往下讀。這些地方用同一套寫法：

- **開頭先介紹這個地方，再帶進這頁的主題。** 第一段一兩句先講讓人想去的事，再講位置；第二段用事實接到主題。從搜尋直接點進子頁的人不一定認識這個地方。第一次出現的地名連回地點主頁，不另外寫「可以先看…」的句子。
- **放只有這裡才有的具體東西。** 寫完把地名換成別的地方再讀一次，還成立就是空話，換掉。
- **把脈絡講出來：這個東西為什麼會在這裡。**（Darren 2026-11-27 看冰瀑祭樣本時問：「冰瀑祭的背景其他人有說嗎」「祭典的話背景是不是很重要」「或是其實景點跟當地特色都是，甚至是美食可能也有這些脈絡？」）祭典、景點、當地特色、美食都一樣：讀者知道它是怎麼來的、為什麼只有這裡有，才會覺得值得去，看的時候也看得懂。用兩三句寫在介紹那樣東西的地方（祭典是誰、為了什麼開始辦的；景點是怎麼形成的；料理為什麼是這個地方的）。下面的界線是協調者的理解，他還沒逐條確認：只寫會讓讀者更想去或看得更懂的脈絡，不寫年表、主辦單位沿革、得獎清單；只用查證過的官方說法；人名沒有通行的中文寫法就不放名字。
  - 冰瀑祭原本只寫「冰是把河水噴在骨架上凍成的」，沒寫 1976 年商店街的年輕人為了讓冬天也有人來才開始辦。
- **挑最厲害的那一件事。** 得獎、日本唯一、名產包裝上的那座山。不放做法與規格。
  - `利尻拉麵｜用昆布熬的湯` → `利尻拉麵｜兩度拿下米其林必比登的味樂`
- **每一段先想：讀者讀完要感覺到什麼。講做法、工法、流程的段落最無聊。**（Darren 2026-11-27 看冰瀑祭樣本「值得專程去嗎」第一段：「這段講來幹嘛的，好無聊喔」。那一段寫的是 12 月開始噴水、花一個半月、哪裡用電鋸切。）要讓人想去的段落，帶讀者走進去：照他到了現場的順序，寫他會看到、走進、抬頭看到的東西；做法只留半句當原因。他說「走進冰裡面也可以試看看，我希望他可以過」，這種把讀者放進畫面裡的說法可以用，但要有事實撐（有隧道才能寫走進去），給查核者對過。
- **寫讀者得到什麼，不寫他要做的動作。**
  - `海膽｜自己剝開，當場吃` → `海膽｜新鮮海膽，現場直接吃`
- **一段只講一兩件事，講完整再換下一件。** 不要四五件事各半句，像在唸清單。
- **要有畫面。** 到了那裡會看到什麼、吃到什麼。畫面來自具體的東西，不是形容詞；只用查證過的事實，不寫成本站去過。
- **大標題**：地名＋類型詞（旅遊攻略、天氣攻略、住宿推薦）＋一串讀者會搜的具體名詞。可以用「攻略」「一次看」。不承諾頁面沒有的東西，不用冒號，結尾不要像被截斷。新頁型的第一個大標題，提三個風格不同的候選給他挑。
- **摘要**直接講這個地方，放兩三件事、各自講完整。不寫「這篇整理了」這種介紹文章自己的話。
- **每一節的開頭**讓讀者知道這一節在回答他的什麼問題。標題是問句時，下一段第一句就是答案。不寫「想知道○○的看哪一節」這種指路的句子，讀者自己會看標題。

## 3. 句子

- **把話講完整。** 每一句有主詞、有動詞，條件寫出來，不縮成掛在句尾的幾個字。
  - 「住客免費用」「先到先停」→「如果是住客就可以免費使用」「停車位是先到的人先停，不能預約」
- **說話的語氣，不是筆記。** 只灑「所以」「不過」不算，句子本身要像在跟人說話。
  - 「第一次去、沒打算租車，住香深最省事。」→「如果是第一次去並且沒有打算租車的話，住在香深最為省事。」
- **同一件事的短句接成一口氣，講完才下句號；因果和轉折寫出來。** 一句最多 4 個逗號，不相干的事不硬接，接完每個條件還掛在原本的主詞上。細節在 [句子節奏](sentence-rhythm.md)。
- **有先後順序的事，照順序一步一步講完。**（Darren 2026-11-27 看冰瀑祭樣本的回程那一段：「更大的問題是其實看不太懂」，改成照順序講之後說「好多了，這個應該不只在轉車會遇到，很多地方都要有這個」。）轉車、排一天的行程、訂票、進場、換季，只要讀者得照著做，就一步一句：從哪裡出發、幾點、到哪裡、接下來做什麼、最後會怎樣。每一步讀者不知道的前提先講（這班車只開到哪裡），讀者用不到的資訊不放（已經趕不上的那班車），最後一步把錯過的後果講出來。不要把三四個時刻擠在一句裡，讓讀者自己拼順序。
  - 「18:55的巴士19:25才到上川，上川站18:38那班普通車已經趕不上，要等將近1小時搭20:24的普通車，21:04的特急大雪號之後就沒有車了。」→「這班車不會直接回旭川，只開到上川站，19:25到站以後要在上川站等大約1小時，再搭20:24的JR普通車，21:22回到旭川。如果沒搭上20:24那班，後面還有21:04的特急大雪號，21:44到旭川，這是當天最後一班車，錯過就回不去了。」
- **兩個事實擺在一起，就把結論講出來。** 「因為9月底以前纜車6:00就開，但從旭川搭頭班巴士要08:54才到，住溫泉街才趕得上一早的纜車。」
- **數字要換成讀者身體記得的東西，才有感覺。**（Darren 2026-11-27 看冰瀑祭樣本「多冷」那一段：「這段的比較起來沒什麼感覺」；換成寒流之後說「有，這種比較才有感，其他地方也是」。）只把兩排數字擺在一起、再算差幾度，讀者不會有感覺。拿一個台灣人經歷過的基準來比（寒流、台北的幾月、搭一趟高鐵的時間），再照讀者會經歷的順序講。不分頁型，氣溫、距離、時間、大小都一樣；基準本身要有事實撐。
  - 「上川1月白天平均最高-4.3℃、早晚最低-13.8℃，台北1月是19.4℃跟14.2℃，白天差大約24度，早晚差大約28度。」→「台北寒流來的時候，最低溫大約是10℃，而冰瀑祭附近的上川在1月，連白天最暖的時候平均都只有零下4℃，入夜以後會降到零下14℃左右。」
- **事實講完就停。** 後面不補總結或評語。提醒只接在具體的事實後面（「兩邊一天都只有3班，記得先看好回程的時間」），不寫「避免撲空」這種沒有新資訊的話，也不是每段都用提醒收尾。
- **官方的普通事實直接寫成這個地方的事。** 不寫「官網列出」「清單列了」「官網寫的是」。
- **強度不比來源重。** 「都」「只有」「最」「每年」要逐筆對過才寫；來源說「多」就寫「多」，「有這樣的日子」不寫成每到那時候就會。改語氣時最容易把強度改掉，改完要重新查核。
- **不要每段長得一樣。** 同一個句型、同一句提醒不要一直重複；各間店、各個景點的第一句開頭要有變化。

## 4. 用字與名字

- **台灣人平常講話的說法。** 日文漢字詞換掉（検討寫評估、入浴寫泡湯、運休寫停駛或停航），不用中國用語（酒店、性價比、打卡），不要像翻譯的句子。拿不準的詞換成最平常的講法。
- **名字用台灣多數的叫法。** 新的專有名詞定案前，先開官方繁體中文頁，再看 3 篇以上台灣人寫的文章怎麼寫。第一次出現寫「中文（日文原名）」，之後只寫中文，標題與表格只寫中文。找法照 [日文資料](japanese-sources.md)「譯名表」。
- 不用「我」「小編」，不寫成去過。不用必去、必吃、絕美、夢幻這類字，推薦要講出推薦的是哪一樣東西。

## 5. 事實

- **查不到的不寫，也不交代哪裡沒查到。** 讀者真的會卡住的事，改寫成他能做的事。來源打不開、查核者重開不了的也不上線。
- **一件事只有一頁寫細節，同一頁裡只講一次。** 別頁負責的一兩句帶過；表格上已經有的數字，不再用句子唸一遍。
- **不寫會過期的。** 臨時維修不寫；只查到一季的日期就標年份，不寫成每年。
- 評論、住客的說法怎麼寫，照 [住宿專門頁](stay-topic-page.md) 最後一節：講內容、好壞都寫、達門檻而且讀者用得到的才留。

## 6. 照片、貼文與連結

- **該有圖的地方每一個都要有，不能有的有、有的沒有。** 用認得出本尊的實拍，照選圖 Skill 的來源順序（官方照片 → 免費圖庫 → 維基共享資源）。
- **找不到照片先找貼文，不要直接說沒有。** 用日文、多換幾組搜尋字，放慢、可以分次找，遇到機器人檢查就停。每種頁型能放幾則、能不能用遊客的貼文，看那種頁型的規定。
- **給讀者馬上用得到的連結**：店家與旅館的官網、Google 地圖、訂房頁。
- **連到別頁的連結**寫讀者什麼時候需要、那一頁有什麼具體的東西，不為了放連結硬接一句。

## 7. 還沒定成全站的，不要自己推廣

下面這些他只對某一種頁型講過。做新頁型的範本時，在結構提案裡列成題目**一次問完**，他說了才用：

| 這件事 | 現在只用在 |
|---|---|
| 連到子頁的連結拉出來單獨一行「看更多：…」 | 地點主頁、祭典頁（祭典頁是結構提案的預設，Darren 看過樣本沒有反對） |
| 小標題寫成「名字｜賣點」 | 地點主頁的看點、祭典頁的看點 |
| 每個 H2 先用一兩句讀者的情境開頭；比較頁開頭不先寫答案 | 住宿專門頁 |
| 每個看點、每間旅館各放 1 則貼文，遊客的公開貼文也可以 | 住宿頁、住宿專門頁、地點主頁（其他頁型一篇最多 2 個、只用官方） |
| 不寫價格 | 住宿頁（房價、餐點價格） |
| 和台北逐月的數字對照表 | 天氣頁（「數字要換成讀者有感的基準」是全站的，見第 3 節） |
| 幾節、多少字、幾張表、驗收幾題 | 每種頁型各自定 |
| 大標題帶當屆年份 | 祭典頁（Darren 2026-11-27：「要」） |
| 作者用 Sonnet 5.5、審查用 Opus 5.5 | 住宿頁、地點主頁、天氣頁、祭典頁；其他頁型做範本時照這個組合起步，比較後再請他定 |

## 8. 交稿前自己對一次

1. 這一頁的讀者是誰、看完能決定什麼，我寫得出來嗎？
2. 開頭有沒有先介紹這個地方，再帶進主題？
3. 大標題、摘要、每個小標題，把地名換掉還成立嗎？主角（祭典、景點、料理）為什麼會在這裡，有沒有用兩三句講出來？
4. 每個賣點是不是那個東西最厲害的一件事、寫的是讀者得到什麼？
5. 有沒有哪一段塞了四五件事各半句？
6. 每一句讀出來像不像在跟人說話？條件有沒有縮成幾個字？有先後順序的事，是不是照順序一步一步講、讀者不用自己拼？
7. 有沒有只是規格、拿掉也不影響決定的句子？有沒有事實表裡的賣點沒寫出來？
8. 「都」「只有」「最」「每年」有沒有逐筆對過？
9. 用字是不是台灣的說法？新名字有沒有查過台灣怎麼寫？
10. 該有圖的地方是不是每一個都有？

## 給協調者：流程上他在意的事

- **沒過關的稿不給他看。** 程式檢查、事實查核、偏好審查、讀者驗收都過了才給。問題回到造成它的那一步改，不手修單頁。
- **沒有範本的頁型，不叫作者開寫正式稿。** 先做範本：看線上哪裡不行 → 找別站文章給他挑 → 提結構 → 做樣本 → 他看過說可以才寫進規則。
- **寫法有疑問，先拿幾段做改前改後的對照給他看**，他說可以再改全部。
- **他要的是自動化，不要問他。**（Darren 2026-11-27：「我需要的是自動化，所以不要問我。」）寫法上的選擇自己判斷、自己試、過了關再給他看結果；不拿兩個版本問他「這樣可以嗎」「感覺對嗎」。
- **岔路要有保守的預設，不為小細節停下來問他。** 要他親口同意的只有：新頁型的格式、替已核准的群新增頁面、改已上線頁面的分工、用 AI 圖、改他親手改過的正文。
- **該拆頁、該新增頁，寫在回報的第一句**，不藏在預設做法裡。
- **協調者不改稿、不替查核者記通過。** 要改的退回作者，或只套用查核者給的最小改法；改過的句子都要再查核。
- **他每挑出一種新的毛病，兩邊都要補**：這一份寫成「要寫成什麼樣」，偏好審查寫成一題、附他的原話。能用程式擋的加進檢查程式。
