# 日文資料

## 來源優先順序

| 順序 | 來源 | 用途 |
|---|---|---|
| 1 | 旅館、店家、交通公司官網 | 房型、含餐、價格、營業時間、班次、票價 |
| 2 | 市町村、觀光協會 | 景點、祭典日期、地方交通、季節現象 |
| 3 | 觀光廳、氣象廳、日本政府觀光局、國稅廳、消費者廳 | 統計、平年值、免稅與消費規則 |
| 4 | 日文新聞 | 停辦、停駛、改建、價格調整 |
| 5 | Hot Pepper Gourmet Web 服務 | 店家營業資訊；使用時署名「Powered by ホットペッパーグルメ」 |
| 6 | Jalan、樂天 Travel、Tabelog、Google 地圖、Walkerplus | 只用來發現題目與核對，不當正文來源 |

中文或英文官方頁可以當補充，但同一事實以日文頁為準；兩者不一致時寫日文頁的內容，並在研究記錄註明差異。

## 容易翻錯的地方

| 日文 | 正確理解 | 常見錯誤 |
|---|---|---|
| 税込／税別 | 含稅／未稅 | 價格沒寫明是否含稅 |
| 令和○年 | 令和元年是 2019 年，令和 8 年是 2026 年 | 年號沒換算 |
| 〜頃、見頃 | 大約、最佳觀賞期 | 寫成確定日期 |
| 欠航、運休 | 停航、停駛 | 寫成延誤 |
| 期間限定 | 只在某段期間 | 寫成常態 |
| 要予約 | 必須預約 | 寫成建議預約 |
| 素泊まり | 不含餐 | 寫成含早餐 |
| 1泊2食付き | 含晚餐與隔天早餐 | 寫成含兩餐但未說明哪兩餐 |
| 現金のみ | 只收現金 | 省略 |
| 最終受付 | 最後受理時間 | 寫成關門時間 |

## 著作權

- 只取事實：數字、日期、條件、名稱。事實本身不受著作權保護，表達方式受保護。
- 不翻譯段落、不改寫評論、不照抄介紹文。研究記錄的原文摘錄只保存支持事實的最短片段。
- 不使用對方的照片，也不用對方網頁的分享預覽圖。圖片規則見 `$japan-travel-image-finder`。

## 譯名表

`content-planning/glossary.json` 保存全站譯名：

```json
{
  "items": [
    {"ja": "礼文島", "zh": "禮文島", "type": "place", "note": ""},
    {"ja": "香深港", "zh": "香深港", "type": "port", "note": "禮文島的主要港口"}
  ]
}
```

寫作時先查表，表裡有就沿用；沒有就新增，並在研究記錄說明譯名依據，例如官方繁中頁或通行譯名。
