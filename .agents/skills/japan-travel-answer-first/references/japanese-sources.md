# 日文資料

## 來源依內容分級

2026-10-16 Darren 決定：能用哪種來源，看這個事實是什麼內容，不是一律只用日文官方。

| 內容 | 正文可用的來源 | 要怎麼核對 |
|---|---|---|
| 交通與規則：班次、票價、路線、停駛、步道封閉、入園規定、禁止事項 | 只用經營者官方：交通公司、步道或設施的管理單位、市町村公告 | 經營者官方沒寫的不寫，不用平台或部落格補 |
| 季節與氣候：花期、祭典日期、平年值 | 市町村、觀光協會、主辦單位、氣象廳 | 「〜頃」寫成大約；未公布的年份寫明用的是哪一年 |
| 店家與旅館資訊：營業時間、公休、價格、房型、含餐 | 店家與旅館官網、官方社群帳號（Instagram、X、Facebook） | 用 Jalan、樂天 Travel、Tabelog、Google 地圖、Hot Pepper 交叉核對；不一致時寫官方的版本，並在研究記錄註明 |
| 人氣：榜單、得獎、評分、評論數 | 米其林、Tabelog 百名店、Tabelog Award 等榜單；平台上顯示的評分與評論數 | 數字附平台名稱與查核日期，例如「Tabelog 3.52（2026-10-16 查）」 |
| 評論常提到的特點 | 兩個平台以上、三則以上共同提到的內容 | 依 [評論與人氣](reviews-and-popularity.md) |
| 統計與消費規則 | 觀光廳、日本政府觀光局、國稅廳、消費者廳 | 寫明統計年份 |
| 變動：停辦、停駛、改建、價格調整 | 日文新聞找線索，再回經營者官方確認 | 官方沒有公告時寫「據報導」並附日期，不寫成確定 |

找候選可以用任何來源：Tabelog、Google 地圖、Walkerplus、部落格、新聞、PTT、Dcard。候選只是「這裡可能有東西」，寫進正文前要依上表找到可用的來源。Hot Pepper Gourmet Web 服務的資料在正文使用時要署名「Powered by ホットペッパーグルメ」。

## 讀不到的來源改用瀏覽器（2026-10-18 Darren 決定）

網頁讀取工具讀不到，不等於官方沒寫。常見情況與做法：

- **PDF 是圖片**（時刻表、樓層圖、地圖）：下載到暫存資料夾，用 Read 工具的 `pages` 參數當圖片讀。
- **網站要執行 JavaScript、擋讀取工具、內容要點開才出現**：在規劃 session 用內建瀏覽器實際打開頁面讀取。雲端 routine 沒有瀏覽器，這類來源在規劃階段就要讀完。
- **要登入才看得到**（例如 Instagram）：只在 Darren 已登入的瀏覽器裡閱讀，不替他登入或建立帳號。
- **遇到驗證碼或機器人檢查**（例如 Tabelog 的驗證畫面）：不繞過。改用其他可用來源，依規則這類平台本來就只做交叉核對。

用瀏覽器讀到的事實，一樣記來源網址、日文原文摘錄與查閱日期。

中文或英文官方頁可以當補充，但同一事實以日文頁為準；兩者不一致時寫日文頁的內容，並在研究記錄註明差異。

## 容易翻錯的地方

| 日文 | 正確理解 | 常見錯誤 |
|---|---|---|
| 税込／税別 | 含稅／未稅 | 價格沒寫明是否含稅 |
| 令和○年 | 令和元年是 2019 年，令和 8 年是 2026 年 | 年號沒換算 |
| 〜頃、見頃 | 大約、最佳觀賞期 | 寫成確定日期 |
| 欠航、運休 | 停航、停駛 | 寫成延誤 |
| 期間限定 | 只在某段期間 | 寫成常態 |
| 要予約 | 必須預約 | 寫成建議預約 |
| 素泊まり | 不含餐 | 寫成含早餐 |

| 現金のみ | 只收現金 | 省略 |
| 最終受付 | 最後受理時間 | 寫成關門時間 |

## 著作權

- 只取事實：數字、日期、條件、名稱。事實本身不受著作權保護，表達方式受保護。
- 不翻譯段落、不改寫單則評論、不照抄介紹文。研究記錄的原文摘錄只保存支持事實的最短片段。多則評論的共同特點依 [評論與人氣](reviews-and-popularity.md) 用自己的話歸納。
- 不使用對方的照片，也不用對方網頁的分享預覽圖。圖片規則見 `$japan-travel-image-finder`。
