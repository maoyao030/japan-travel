# 句子節奏：短句接起來，講完一件事才下句號

Darren 2026-11-18 看過〈旭川飯店早餐〉潤前潤後的對照後說「蠻不錯的，都加這個」。這一份是本站採用的部分，用自己的話整理；出處是開源規範 zh-tw-writing（LCY000，MIT 授權，https://github.com/LCY000/zh-tw-writing ）第一節。對照稿在 `content-experiments/zh-tw-writing-test-2026-11-18/`。

本份取代 2026-10-31「先刪再調」裡把每句逗號壓到 1.1～1.3 的做法：那樣潤出來的稿子句號太多，讀起來一頓一頓（早餐頁 115 句裡 23 句沒有逗號）。「先刪讀者用不到的規格」照舊。

## 怎麼做

1. **同一件事的連續短句用逗號接起來**，講完一個完整的意思才下句號。
   - 前：「早餐是1樓餐廳的日式和西式自助，早上7點開始。9點前要點餐。」
   - 後：「早餐是1樓餐廳的日式和西式自助，早上7點開始，9點前要點餐。」
2. **省略主語的句子不要用句號切開**。下一句沒有主語、主語在前一句，就併回同一句；要留句號就把主語補回來。
3. **因果、轉折、條件寫出來**：「所以」「不過」「如果…就」。這和寫作指南第17條（照 Darren 的語氣寫）是同一件事。
   - 前：「官網的連結是看飯店資訊用的，不能在網站上訂房。要訂房，從 Trip.com 或 Agoda 訂。」
   - 後：「官網的連結是看飯店資訊用的，網站上不能訂房，所以要從 Trip.com 或 Agoda 訂。」
4. **判斷太碎的方法是重讀一遍**：讀者要自己補上「因為、所以、雖然、如果」才看得懂兩句的關係，就該接起來。
5. **句子長短要有變化**，不要每句一樣長。

## 不要做過頭

- 不相干的兩件事不硬接。接的時候條件要跟著原來的主語走，不能接完變成別間飯店、別條路線的事。
- 一句最多 4 個逗號，再多就拆。
- 新加的「所以」「不過」同一段最多一個；只有真的有因果或轉折才加。
- 不到處加逗號：很短的主語後面、很短的時間地點後面不用逗號。
- 不追比例。每個句號前的逗號數只當參考：本站實用文大約 1.4～1.8（Darren 親手改的東川是 1.53），低於 1.2 多半太碎；不用拉到報告文體的 2.8。
- 事實、數字、名字、連結、標題、表格一個都不動；不新增原文沒有的資訊。

## 本站不採用的部分

- 中文和英文、數字之間加空格：本站全站不加（「OMO7旭川」「JR旭川站」）。
- 改成正式報告的語氣：本站是口語的導覽口吻。
- 那份規範附的檢查程式：沒有採用。標點與口吻仍用本站的 `check-voice.mjs`。
- 它的「AI 腔」用語清單可以當參考，但對本站文章幾乎抓不到東西；本站像套版的地方（每間飯店長得一樣、同一句提醒反覆出現）要靠讀者驗收抓。
