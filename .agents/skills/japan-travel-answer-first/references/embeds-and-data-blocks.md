# 嵌入與資料圖

2026-10-18 Darren 決定：文章可以嵌入影片與官方 Instagram 貼文，也用資料圖呈現季節、天氣、路線與時間。網站的嵌入區塊與資料圖元件還沒做好；做好之前，只在文章計畫列候選，不放進正文。

## 嵌入影片與 Instagram 貼文

照片只能看到一個畫面，影片看得到整段路、天氣和現場氣氛。用平台的嵌入功能放進文章，影片和貼文留在對方帳號，不下載。

**放在哪**：步道、景點、交通這類「看了才知道是什麼樣子」的段落。每篇最多兩個。

**挑選條件**（全部符合才用）：

1. 對方有開放嵌入，貼文或影片是公開的。
2. 近兩年拍的或發的。
3. 有章節、字幕或說明欄能確認內容對得上這一段。看不到畫面，所以對不上就不用。
4. 不是業配，或業配有明確標示且內容不誤導。
5. 觀光協會、自治體、交通公司等官方帳號優先；個人 vlog 符合以上條件才用。

**怎麼放**：

- 影片從相關章節的時間點開始播。
- 下方寫拍攝或發布年份與頻道名，加一句「實際資訊以本文為準」。
- 正文要完整，不能依賴嵌入才看得懂：Google 讀不到影片內容，對方刪除或關閉嵌入時畫面也會消失。
- 研究記錄記下網址、頻道、年份、確認對題的依據（哪個章節或字幕）。上線後由 routine 定期檢查是否還在。

## 資料圖

用網站元件從事實資料畫出來，不做成圖片檔：Google 讀得到文字，事實重查更新後圖也會跟著改，也沒有圖片授權問題。

| 種類 | 用在 | 資料 |
|---|---|---|
| 季節日曆 | 主頁、景點、步道、祭典 | 開放期間、花季、盛產季、活動月份 |
| 天氣圖表 | 天氣頁 | 氣象廳平年值 |
| 路線圖 | 交通、渡輪 | 航線、班次、船程 |
| 行程時間軸 | 交通、主頁 | 搭哪班車、每站停多久 |
| 基本資訊欄 | 景點、步道 | 地址、開放時間、交通、費用 |

每個資料點都要對應事實編號，沒有事實編號的不畫。文章計畫列出要用哪種資料圖、放在哪一節、用到哪些事實。
