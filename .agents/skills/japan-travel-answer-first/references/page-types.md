# 頁型

## 地點條目

小地方一頁回答整趟安排。H2 依該地點讀者最在意的事排序（例如稚內是天氣與交通，禮文島是住宿與花季），常見的分章：

- 怎麼去：從主要城市或機場出發的路線、班次、所需時間、票券
- 島上或當地怎麼移動
- 住哪裡：旅館清單、房型、含餐、訂房管道、查核日期
- 看什麼、做什麼：景點、步道、祭典、特色料理
- 什麼季節去：各月氣候摘要（平年值）、花季、雪、停駛期間
- 錯過與停駛的備案
- 常見問題

不是每個地點都需要每一節；沒有內容的分章不硬寫。

## 面向頁

組合詞夠大而單獨成頁的題目，例如銀山溫泉住宿、函館住宿、北海道12月天氣。只深入這個面向，其他面向簡述後連回地點條目。

- 住宿面向頁：每間旅館的房型、含餐、接駁、訂房管道、查核日期；不寫成飯店排行。
- 天氣月份頁：該月平年值（平均、最高、最低氣溫、降水量、日照）、與台灣同月比較、穿著建議、該月的季節活動。

## 主題頁

與單一地點無關的題目，例如日本櫻花季、御朱印。說明通則，再用地點條目當例子。

## 共用教學頁

各地相同的操作。用逐步說明、按鈕對照、實際範例；不放特定地點的班次或價格，那些留在地點條目。
