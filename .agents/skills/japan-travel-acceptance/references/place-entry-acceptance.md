# 地點主頁的讀者驗收八題（2026-11-25）

地點主頁（`place-entry`）的讀者驗收照這八題，取代 [讀者驗收規則](reader-acceptance.md) 裡給一般頁型的判斷表；讀者設定、只讀不改、寫位置與原因這些通則照舊。題目與標準從利尻島主頁改版的兩次驗收（`content-production/rishiri-island/acceptance-place-entry.md`）整理出來，寫法依據是寫作 Skill `references/place-entry-page.md`。

## 讀者設定

聽過這個地方、正在想要不要排進北海道（或那一區）行程的台灣旅客，去過東京、大阪自由行，日文看不太懂。他還沒要查班次、訂旅館，只想知道值不值得去、幾月去、排幾天、跟哪裡一起排。

## 驗收者讀什麼

- 這篇的 `reader-preview.md` 與 `publication.json` 的 `excerpt`（摘要）。
- 寫作規格 `spec.md`（六節要回答什麼、交給子頁的事）。
- 寫作 Skill `references/place-entry-page.md`、`references/heading-style.md`。
- 第 8 題要讀：重寫時的舊版 `pre-place-entry/reader-preview.md`；新寫時同地點子頁的 `reader-preview.md`。
- 同頁型的範本（`node scripts/page-models.mjs --for=<articleId>` 列的檔案），做最後的「和範本比」。

不讀作者的說明與事實查核紀錄；事實對不對是查核者的事，這裡只看讀者讀起來的樣子。

## 八題

每題判「過」「過（有一處要改）」或「不過」，附證據（原句）。

| 題 | 看什麼 | 不過的樣子 |
|---|---|---|
| 1. 開頭兩段（含摘要） | 這是哪裡、為什麼有人專程去、幾月去、排幾天，各一句講到；摘要和序言連著讀順，不整句重複 | 少了其中一件；開頭列一串還沒介紹的地名；摘要寫「這篇整理了…」；一段塞四五件事各半句 |
| 2. 「是什麼樣的地方」 | 讀完會不會想去；寫的是看得到、吃得到的畫面 | 只講交通、位置、行政區；用絕美、夢幻這類形容詞撐場；和後面的看點前後說法對不上；寫成本站去過 |
| 3. 「有什麼好玩、好吃的」 | 每個 H3 是「名字｜賣點」，賣點是最讓人想去的那件事；小段第一句接住標題；只留會影響排不排的限制 | 賣點是做法或規格；標題承諾的正文沒有（例如兩個湖只有一個看得到倒影）；小段念規格（繞一圈幾分鐘、地址、門票）；和第 1 節重講同一個畫面 |
| 4. 「幾月去」「排幾天怎麼排」 | 先一句答案，月份表加一句不適合的月份；祭典只寫大約幾月、是什麼；每種排法照著走得通 | 祭典只寫「祭典變多」沒說是什麼；排法的時間接不上（逐站自己算一次：到港、接巴士、回港、末班船）；漏了會改變排法的交通選項（例如季節航班）；有要預約的環節沒提 |
| 5. 「住哪一區」「和鄰近地點怎麼一起排」 | 直接給判斷：住哪一帶、只能去一個選哪個、都去怎麼接 | 列旅館、寫家數或住宿稅；放班次表；只描述不判斷 |
| 6. 標題樹 | 照六節順序；H1 不用冒號、不是三連問、不承諾頁面沒有的；正文 H2 都帶地名；問句標題下一段第一句是答案；不跳級、不重複 | 有任何一項不符；標題承諾的內容正文沒有 |
| 7. 重複、連結句、空提醒、日期、用詞、日文 | 一件事全頁只講一次；連到子頁的連結是單獨一行的「看更多：頁名｜那一頁有什麼」（留在判斷句或指示裡的連結除外），不是接在段落最後的一句話；提醒接在具體事實後面；沒有今年或明年的具體日期；台灣說法；括號外沒有日文 | 同一件事講兩三次（住幾晚、哪個港有船、住哪裡看日出最常見）；「否則會很麻煩」這類空提醒；「天候」這類日文漢字詞 |
| 8. 有沒有不該消失的內容 | 重寫：舊版有、新版沒有的內容，子頁有沒有寫到；新寫：子頁裡會影響去不去、幾月去、排幾天、跟哪裡排的結論，主頁有沒有帶到 | 會改變判斷的事消失了（例如只寫一個機場，漏了台灣旅客最常用的那個）；只是時刻、票價這類細節移到子頁不算 |

最後加一項「和範本比」：哪一節比範本裡功能相同的節明顯空（讀者照著做會卡住）列一定要改，明顯囉嗦或每節一樣長列可改可不改。只比輕重與細度，不要求標題、順序或句子和範本一樣；和範本句子幾乎相同的反而列一定要改。

## 交什麼

`acceptance-place-entry.md`（第二次以後在同一個檔案往下加「第 N 次驗收」一節）：

1. 總判定：`acceptable`、`needs_revision` 或 `reject`。
2. 一定要改：每條寫位置、原句、哪一題、為什麼、最小改法（只指方向，不替作者寫整段）。
3. 可改可不改。
4. 逐題結果：題號、過或不過、證據。
5. 第二次以後：上次每一條「一定要改」解決了沒有（表格），再把八題重判一次。

八題全過、和範本比沒有一定要改的，才是 `acceptable`。驗收者只讀不改稿。
