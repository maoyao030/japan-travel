# 關鍵字來源與使用限制

## 不用 Ahrefs，改用 Google 自動完成

2026-10-16 Darren 決定不再用 Ahrefs。Ahrefs 對繁中小地方的詞幾乎都顯示 0 或 10，幫不上忙；本站又已經決定「每個地點 × 主題都成頁，搜尋量只決定先後」，不再需要搜尋量門檻。

| 要回答的問題 | 來源 |
|---|---|
| 這個地區有哪些地點、哪些地點常一起去 | 日文 Google 自動完成、觀光協會與市町村官網、モデルコース |
| 台灣讀者在問什麼、用什麼字 | 中文 Google 自動完成、搜尋結果頁的相關問題、PTT 日旅版、Dcard 旅遊版 |
| 先寫哪個區域 | 觀光廳宿泊旅行統計的台灣旅客分布、Google 趨勢 |
| 寫完之後成效如何 | Search Console |

## Google 自動完成怎麼查

端點（2026-10-16 測過可用）：

- 日文：`https://suggestqueries.google.com/complete/search?client=firefox&hl=ja&gl=jp&q=<查詢>`
- 中文：`https://suggestqueries.google.com/complete/search?client=firefox&hl=zh-TW&gl=tw&q=<查詢>`

查詢字串要做網址編碼。回傳是 JSON 陣列，第二個元素是建議詞清單。

- 日文用日文寫法查（`礼文島`、`稚内`），中文用繁中無空格寫法查（`禮文島`、`稚內船班`）。
- 除了地名本身，也查「地名＋空格」與「地名＋常見主題字」，例如 `礼文島 `、`禮文島 船`、`禮文島 住`，抓出更多組合。
- 一個地點查完的結果存進規劃檔，不要每次重查。查詢間隔至少一秒，不要大量連續查詢。
- 自動完成只告訴你「有人這樣搜」，不告訴你有多少人。排先後時，以出現的位置與在多少個查詢裡出現當參考。

## 證據怎麼記

每筆證據記下：

- `provider`：`Google autocomplete`（日文或中文寫在 `locale`：`ja-JP`、`zh-TW`）；實際看過搜尋結果頁的，另記一筆 `SERP observation`。
- `checkedAt`：查詢日期。
- `query`：送出的查詢字串。
- `suggestions`：回傳的建議詞（只存和本地點有關的）。
- `serpIntentConfirmed`：實際看過搜尋結果頁、確認是日本而非台灣同名地名後才填 `true`。

`ahrefsVerified` 一律 `false`。2026-10-16 以前用 Ahrefs 查到的紀錄（`content-planning/hokkaido/keywords-2026-10-16.json`）保留當參考，不再新增。

文章清單的驗證程式目前只接受 `Ahrefs MCP`、`Ahrefs browser UI`、`SERP observation` 三種來源，加入 `Google autocomplete` 是第二階段的工具工作；在那之前，進清單的頁面用 `SERP observation` 記錄。

## 繁中與日文用字

研究日文資料時，用日文寫法搜尋，不用繁中字：

| 繁中 | 日文 |
|---|---|
| 稚內 | 稚内 |
| 禮文島 | 礼文島 |
| 釧路濕原 | 釧路湿原 |
| 渡輪、船班 | フェリー、時刻表 |
| 住宿 | 宿泊、民宿、旅館 |
| 祭典、花火大會 | 祭り、花火大会 |
| 特色料理 | 名物、ご当地グルメ |
| 觀光協會 | 観光協会 |
| 建議行程 | モデルコース |

每個地點在規格裡保存一組 `japaneseNames` 與 `japaneseSearchTerms`，寫作研究時直接使用。

## 已知陷阱

| 詞 | 問題 |
|---|---|
| 岡山、松山、中山、板橋、豐原 | 台灣同名地名 |
| 川湯溫泉 | 流量來自台北北投的「川湯春天」溫泉會館 |
| 利尻昆布 | 多數搜尋是染髮劑品牌 |
| 余市 | 主要意圖是余市威士忌，旅遊意圖較小 |
| 東京天氣、大阪天氣 | 查預報，Google 天氣卡直接回答，不寫 |
| 稚內天氣 | 可能是查預報；天氣頁寫各月平年值與穿著，寫明不是預報 |
