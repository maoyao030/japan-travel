# 關鍵字來源與使用限制

## Ahrefs 只做兩件事

1. 確認地名本身的搜尋量，以及有沒有台灣同名或無關意圖的陷阱。
2. 判斷某個組合詞是否達到單獨成頁的門檻。

其他工作用下表的來源。這樣做一方面是 Ahrefs 對繁中小詞覆蓋不完整，另一方面是本站要發現的祭典、花火、特色料理，通常只有日文官方資料寫得完整。

| 要回答的問題 | 來源 |
|---|---|
| 先寫哪個區域 | 觀光廳宿泊旅行統計的台灣旅客分布、Google 趨勢 |
| 地點有哪些地方可寫 | 觀光協會與市町村官網、日本政府觀光局 |
| 讀者實際在問什麼 | Google 自動完成、搜尋結果頁的相關問題、PTT 日旅版、Dcard 旅遊版 |
| 地點之間的關係 | 地圖、鐵路與渡輪公司的路線 |
| 寫完之後成效如何 | Search Console |

## 使用 Ahrefs 的規則

- 市場用台灣（`country=tw`）。查詢用無空格寫法：「東京11月天氣」有 600，「東京 11月 天氣」只有 10。
- 一次查一批詞，避免逐字重查。先用「含地名的實際組合」找出真實組合，再補查固定面向清單。
- Ahrefs 顯示 10 的詞不當單獨成頁的依據；顯示 0 不代表沒人搜。兩者都保留在必答問題。
- 第一名實得流量明顯低於搜尋量時，通常是維基百科、地圖或 AI 摘要分走點擊，要看搜尋結果頁確認還有沒有位置。
- 每筆證據記下 `provider`、查詢日期、查詢字串、搜尋量與第一名實得流量；工具沒回傳的欄位記 `null`，不猜值。
- 已有可用紀錄就沿用並寫明原查詢日期，不重複消耗用量。
- 未實際呼叫 Ahrefs 時，`provider` 只能是 `SERP observation`，`ahrefsVerified` 為 `false`。文章清單的驗證程式會檢查這一點。

## 繁中與日文用字

研究日文資料時，用日文寫法搜尋，不用繁中字：

| 繁中 | 日文 |
|---|---|
| 稚內 | 稚内 |
| 禮文島 | 礼文島 |
| 釧路濕原 | 釧路湿原 |
| 渡輪、船班 | フェリー、時刻表 |
| 住宿 | 宿泊、民宿、旅館 |
| 祭典、花火大會 | 祭り、花火大会 |
| 特色料理 | 名物、ご当地グルメ |
| 觀光協會 | 観光協会 |

每個地點在規格裡保存一組 `japaneseNames` 與 `japaneseSearchTerms`，寫作研究時直接使用。

## 已知陷阱

| 詞 | 問題 |
|---|---|
| 岡山、松山、中山、板橋、豐原 | 台灣同名地名 |
| 川湯溫泉 | 流量來自台北北投的「川湯春天」溫泉會館 |
| 利尻昆布 | 多數搜尋是染髮劑品牌 |
| 余市 | 主要意圖是余市威士忌，旅遊意圖較小 |
| 東京天氣、大阪天氣 | 查預報，Google 天氣卡直接回答，不寫 |
| 稚內天氣 | 可能是查預報；先寫成條目裡的各月氣候段落 |
