# 文章研究記錄同步回地點事實表（2026-11-02）

Darren 2026-11-02 要求把各篇改正與新增的資料同步回地點事實表與維護資料庫。

## 做法

- `node scripts/article-facts-diff.mjs > .tmp/fact-report.json`：讀所有文章 `reference-review.md` 的事實表，和 `content-planning/hokkaido/places/<地點>/facts.json` 比對。
- `node scripts/article-facts-merge.mjs .tmp/fact-report.json --write`：同編號內容不同的視為更正，取查閱日期最新的一列（同日以本地點文章優先；跨地點引用只有日期較新才採用）；地點表沒有的編號視為新增，同編號不同內容的分成不同事實，用到最多篇的保留原編號，其餘發新號。新增與改號的事實加 `articleRefs`（例如 `sounkyo-weather:F481`），記錄它在各篇研究記錄裡的編號；文章本身的編號沒有改。
- 之後 `npm run planning:check` 通過，`node scripts/ops-facts.mjs sync` 登記到 D1。
