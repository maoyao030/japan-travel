# 自動化執行紀錄

routine 每輪結束前更新。只記事實：台北時間、這一輪的 action、文章或群、結果、停在哪一步、工具回報的錯誤重點、commit 短碼。不貼權杖、憑證或完整指令輸出。進度以 Sanity 與 D1 為準，本檔只給人看。

## 更新規則

1. 整段覆寫「最新一輪」。
2. 「有問題的項目」：本輪有文章停放、延後、判退、CI 失敗或 Sanity 衝突，就以文章 ID（或群 ID）更新或新增該列；問題解決後把狀態改成「已解決」並填日期，不刪列。
3. 在「執行紀錄」表格第一列插入本輪。
4. 結果欄只用：已開放索引、已暫存 noindex、判退、停放、延後、已補內連、已規劃、已重查、已同步、略過、失敗。
