## 2. 各篇的順序

**A 北海道官方特輯**
1. 開頭：道北面兩個海 → 四季各有什麼海鮮 → 帶一句章魚涮涮鍋 → 說本篇介紹平價店與在地居酒屋 → 酪農與冰淇淋
2. 目錄
3. うろこ亭：離車站走幾分 → 誰經營（魚店）→ 招牌丼與內容 → 另外不要錯過的（爐端烤蟹、季節限定海膽丼）→ 附設工廠可參觀
4. 源氏：先講稚內章魚（漁獲量、大小）→ 章魚涮涮鍋怎麼煮怎麼吃 → 才帶出店名與招牌沾醬 → 收尾麵
5. Ezo番屋（南稚內居酒屋）→ 冰淇淋工房（豐富町）→ 豐富溫泉羊肉 → 羽幌甜蝦拉麵 → 利尻沼邊小店
6. 文末地圖

**B 樂吃購 稚內完全指南**
1. 開頭：推薦稚內 → 一口氣列景點與三樣食物 → 「往下看」
2. 稚內是什麼地方（產業＋交通時間）→ 活動 → **美食 H2** → 景點 H2 → 利尻禮文
3. 美食 H2 底下四個 H3，每個 H3 標題是「食物名＋形容」：扇貝 → 海鮮丼 → 章魚涮涮鍋 → 稚內牛乳
4. 每段順序：為什麼這裡的好（海流、水溫、漁獲量）→ 怎麼吃（生吃、烤；涮幾下）→ 一句推薦。**完全沒有店名、地址、時間**

**C MATCHA 稚內美食 6 選**
1. 開頭（作者欄前後重複一次）
2. 海膽 → 昆布 → 稚內牛乳冰淇淋 → 車站內食堂的稚內丼 → 利尻拉麵 → 利尻乳酸飲料 → 小結（推薦夏天去）
3. 每段：食物為什麼特別 → 小編吃的感想 → 一句「不能錯過」。店名只在稚內丼、冰淇淋、拉麵出現，位置只說「在車站裡」「在利尻島」

**D Via 兩家店食記**
1. 開頭：問句「來稚內吃什麼」→ 預告兩家
2. うろこ亭：離車站不遠 → 兼賣特產 → 中午人氣海鮮丼（價格、內容）→ 晚上爐端燒套餐（價格、建議前一天預約）→ 套餐逐道 → 總結「中午吃 A、晚上吃 B」→ 店家資料框（時間、地址、電話、網站）
3. 源氏：問句「必吃是什麼」→ 章魚涮涮鍋 → 名人加持故事 → 這道菜怎麼來的 → 份量與價格 → 吃法步驟（先下菜、涮到捲起、沾醬、最後下麵當沾麵）→ 其他單點海鮮逐道 → 店家資料框

**E 大方 源氏食記**
1. 稚內強項是海鮮 → 店離車站走 5 分 → 在地人推薦但偏貴 → 一句列出會吃到什麼
2. 好不好找（離車站、離飯店幾分、雪天也走得到）→ 裝潢包廂 → 套餐價位帶、看不懂日文的提醒
3. 單點海鮮 → 章魚涮涮鍋（章魚多大 → 吃法步驟 → 兩人份價格 → 收尾麵）→ 其他單點 → 店名片

**F WalkerLand たからや**
1. **第一行就是店家資料（地址、電話、時間、公休）**，文末再放一次
2. 承接上一篇（道北多鹽味醬油）→ 這家的定位（最北的米其林拉麵、就在車站對面）
3. 位置（車站巴士月台旁）→ 歷史 → 在地人地位 → 營業時間只有兩小時半的提醒 → 菜單只有兩種
4. 碗、湯、麵、叉燒、筍乾、車麩逐項試吃

**G 稚內 WOW!50 伴手禮**
1. 稚內兩海域物產豐富 → 「稚內品牌」制度
2. 制度起源與件數 → 怎麼認商標 → 認證品有哪些（章魚、扇貝、黑牛、馬鈴薯；加工品舉例）→ **哪裡買（車站 KITAcolor、機場、市區、網路）**

## 3. 開頭怎麼寫

- A：先拉大到「整個道北的海」，再用四季列海鮮，第二段才落到「本篇要介紹什麼樣的店（平價、在地人去）」。讀者知道店的篩選標準。
- B：一句推薦地點 → 一長串名詞（景點＋三樣食物）→ 叫讀者往下看。資訊密，但沒有回答「去哪吃」。
- C：問句開場，接著預告「市區＋兩座離島」範圍與食物類別，最後一句俏皮收尾。
- D：問句＋「這篇帶你去兩間」，很快進店。
- E：一句定調「稚內最強是海鮮」，第二句就給店名與離車站幾分。
- 共通：沒有一篇在開頭就把「哪道菜去哪家」對起來。A、D、E 最快讓讀者拿到店名。本站 H1 已經把三樣食物寫進去，開頭可以直接用一兩句對上「章魚涮涮鍋→哪兩家、扇貝與海鮮丼→哪裡、麵→哪家」，這是競品都沒做到的。

## 4. 關鍵問題怎麼回答（mustAnswer：章魚涮涮鍋、扇貝、稚內拉麵在哪裡吃）

**章魚涮涮鍋**
- 五篇有寫的，順序幾乎一致：**先講稚內章魚（日本第一、很大）→ 章魚涮涮鍋是什麼、怎麼吃 → 才講店（源氏）→ 招牌沾醬 → 收尾下麵**。
- 吃法步驟三篇都寫（A、D、E）：昆布湯 → 先下蔬菜 → 章魚片涮到捲起或變波浪 → 沾醬 → 最後下麵沾醬吃。讀者顯然想知道「怎麼吃」。
- 店家只出現源氏一家（A、D、E）；うろこ亭有章魚涮涮鍋只有 A 的英文版搜尋摘要提到，中文競品沒人把うろこ亭當章魚涮涮鍋店。
- 價格都以「兩人份」或「一人」呈現，讀者在意份量是一人還是兩人。
- 沒有表格。

**扇貝／海鮮丼**
- B 把扇貝當成獨立美食，講「為什麼特別好吃（海流、水溫）→ 生吃或烤」，不給店。
- 海鮮丼的回答都落在うろこ亭（A、D）：**離車站多遠 → 魚店經營 → 招牌丼幾種料 → 季節限定的海膽丼 → 晚上另有爐端燒**。D 用「中午吃丼、晚上吃爐端燒」分時段。
- C 用車站內食堂的「稚內丼」（炸扇貝與蟹）回答「平價又方便」。
- 沒有人提副港市場的食堂。

**稚內拉麵**
- 中文競品沒有人把「稚內炒麵（チャーメン）」當主角；拉麵的代表是車站對面的老店たからや（F，米其林必比登），以及利尻島的味樂（C，但那是利尻）。
- F 的順序：**店家資料框先放 → 定位（最北、米其林）→ 在車站哪裡 → 營業時間很短的提醒 → 菜單只有兩種 → 試吃**。
- 讀者搜「稚內拉麵」時，可能期待的是「稚內有沒有一家代表拉麵店」，本站目前答的是チャーメン與ラーメン大王，兩者在競品裡都沒出現。

**稚內必買**
- 競品回答方式是「去哪買」多於「買什麼」：車站 KITAcolor、機場、宗谷岬紀念品店；單品只零星出現（稚內牛乳、烤魚真空包、到達證明書）。
- G 教讀者看「稚內品牌」商標認東西，這是唯一有「怎麼挑」的寫法。

## 5. 段落與句子的習慣

- 編輯站（B、C）一段 3～5 句，句子中長，形容詞多（鮮甜、肥厚、香醇），每段最後一句是推薦或「不能錯過」。數字很少，只有漁獲量第一、交通時間。
- 官方站（A）一店一段 4～6 句，第一句給位置（離車站幾分）或店的身分，數字放在第一、二句（步行分鐘、漁獲噸數）。
- 部落客（D、E、F）短句斷行、多驚嘆號；稱讀者「你」「大家」；店家資料集中在文末（或 F 文首）一個資料框：營業時間、地址、電話、網站，不散在正文。
- 轉場用時段（中午／晚上）、用問句（「必吃是什麼？」）、用「最後」帶到收尾麵。
- 全部沒有用表格比較店家；本站第一個 H2 的對照表在競品裡沒有對手，是本站獨有的資料。

## 6. 給作者的順序建議（標題不改）

**開頭（H1 下）**
1. 第一兩句直接對上三樣食物各去哪：章魚涮涮鍋→源氏或うろこ亭；扇貝與海鮮丼→うろこ亭、副港市場、野寒布岬；稚內炒麵→車站附近哪家。
2. 再一句說這些店大多在車站走路範圍（競品都用「離車站幾分」當第一個位置資訊）。
3. 最後放連回主頁的句子。

**H2 稚內美食有哪些？**
1. 讀者先想要一張「吃什麼、去哪家、離車站多遠、哪天休」的總覽。本站的對照表放這裡正好補競品空白。
2. 對照表前用一兩句說挑店的方式（平價、走得到、只做午餐或晚餐），像 A 開頭交代篩選標準那樣。

**H3 章魚涮涮鍋**
1. 先講稚內章魚為什麼有名（漁獲量第一、水章魚大）→ 為什麼適合涮（煮了不變硬）。競品全照這個順序。
2. 接著一句帶到市內很多店都有、本頁挑兩家。
3. 吃法步驟讀者明顯在意（先下菜、涮到捲起、最後下麵），但只能寫事實表撐得住的部分（收尾加麵有 F132）。

**H3 車屋源氏的章魚涮涮鍋**
1. 離車站走幾分 → 招牌鍋與價格 → 份量（競品都講幾人份；本站只能寫官網沒標份量、有一人份的御膳）→ 收尾麵。
2. 營業時段分午晚兩段與不定休，放在段末，像部落客的資料框但寫成句子。
3. 可刷卡與電子錢包放最後。

**H3 海鮮爐端Uroko亭**
1. 離車站走幾分 → 魚店（うろこ市）直營、同一地址 → 招牌丼 8 種料 → 也有章魚涮涮鍋。
2. 時段與週日休放後面；可補一句它和源氏的差別（連續營業 vs 午晚兩段），讀者在競品裡學到的就是「中午去 A、晚上去 B」。

**H3 扇貝與海鮮丼**
1. 先講宗谷扇貝為什麼好吃（小但緊實、甜）——B 的順序。
2. 再給去哪吃：副港市場（魚常的平價海鮮丼）→ 野寒布岬漁師の店（現烤扇貝）→ 源氏的扇貝菜。
3. 野寒布岬的冬季休業與交通（巴士 10 分）放在該店那句的尾巴。

**H3 生海膽丼的季節**
1. 先講幾月吃得到（讀者第一個問題），再講去哪家（ひいらぎ軒、樺太食堂、源氏時價）。
2. 預約方式與休業月份放最後。

**H3 稚內拉麵與稚內炒麵**
1. 讀者搜「稚內拉麵」，先用一句說稚內在地的代表是炒麵（チャーメン）是什麼樣子（煎麵＋勾芡），再講起源一句。
2. 再給去哪吃：車站內ふじ田（最近）→ ラーメン大王（車站走 4 分、週三休、只收現金）→ 副港市場兩家 → 晚上才開的よしおか、広宣。依「離車站近→遠」或「白天→晚上」排，不照事實編號。
3. 收尾帶 Dormy Inn 早餐。

**H3 宗谷黑牛**
1. 是什麼（最北牧場、赤身）→ 哪裡吃（Vin 的米其林星、源氏鐵板燒）。

**H2 稚內必買的伴手禮**
1. 先講「在哪買」：車站 KITAcolor 裡的ワッカナイセレクト（時間）、副港市場魚店、うろこ市——競品都先回答地點。
2. 再講買什麼：馬鈴薯餅乾、冰烤布丁（冷凍、要帶回旅館的提醒放這句）、稚內牛乳的冰淇淋與優酪乳、扇貝等稚內品牌海產。
3. 可一句提「稚內品牌」商標幫讀者認東西（需先有事實）。

## 7. 他們有、我們缺的（只列，不查）

- 章魚涮涮鍋的吃法步驟（先下蔬菜、涮到捲起、沾醬）與源氏的招牌沾醬（A、D、E 都寫）。
- 源氏章魚涮涮鍋的份量是幾人份（D、E 都以兩人份計價）。
- うろこ亭晚上的爐端燒套餐與是否需要預約（D）。
- うろこ亭附設工廠可參觀（A；事實表 F213 有「加工場免費參觀」，可確認是否要寫進）。
- 車站對面的拉麵老店たからや（F，米其林必比登、營業時間很短），讀者搜稚內拉麵最可能找的店。
- 車站內ふじ田的「稚內丼」（炸扇貝與蟹，C）；事實表 F211 只有ふじ田的海鮮炒麵。
- 稚內牛乳的特色（低溫殺菌、非均質）與在哪喝得到（B、C、F 都提，C 當成獨立一道美食）。
- 南稚內的居酒屋 Ezo番屋（A）、Google 地圖區塊排前三的海鮮居酒屋竹ちゃん、迴轉壽司花いちもんめ（Tripadvisor、hamoni 排行常見）。
- 「稚內品牌」認證商標怎麼認、認證品清單（G）。
- 稚內機場伴手禮店與 KITAcolor 裡便利商店可買的在地食品（ANA FESTA、Facebook 粉專）。
- 宗谷黑牛做的漢堡排等加工伴手禮（G）。
- 稚內公園的山白竹冰淇淋（B，屬景點頁範圍，提醒分工）。
