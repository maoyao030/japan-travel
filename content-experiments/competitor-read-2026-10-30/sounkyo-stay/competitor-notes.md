## 2. 各篇的順序

**A Mimi韓**
1. 開頭：國立公園裡的祕境 → 四季 → 預告 5 間
2. 為什麼選層雲峽溫泉（景觀、泉質、一天怎麼玩）
3. 交通（旭川→JR 上川→巴士，再提接駁、租車）
4. 住宿區域與預算：高台 vs 溫泉街中心／溪邊的優缺點 → 預算三層 → 建議訂一泊二食
5. 逐間（朝陽亭、層雲閣、朝陽度假、大雪、觀光）：介紹段 → 速查條列（交通、房型、價格、適合誰、訂房連結）→ 實住心得優缺點
6. FAQ：接駁 → 多早訂 → 親子 → 冰瀑祭 → 要不要含餐
7. 總結

**B 喵爸喵媽**

**C marktrip**

## 3. 開頭怎麼寫

- 清單型（A、C、D）都用同一套：先說層雲峽在大雪山國立公園、溫泉有名，再用四季（紅葉、冰瀑祭）證明值得住一晚，最後預告「幾間推薦」。開頭都沒回答「要住哪一區」。
- B 先給答案（最推哪兩間），再用預算問題轉到本篇主角；是唯一一開頭就幫讀者做選擇的。
- C 開頭點名旅客類型，讓讀者對號入座。
- 本站開頭不需要四季鋪陳（主頁負責「值得去嗎」，有內連句），可以學 B：開頭直接講住宿分在哪幾塊、多數人住哪裡。

## 4. 關鍵問題怎麼回答

**① 住溫泉街還是上川站**
- 沒有一篇正面比較溫泉街與上川站。上川站在競品裡只是轉車點（A、C、F），D 完全沒提上川站。
- A 把「區域」理解成溫泉街內部：高台（景觀好、上坡、冬天路滑）vs 中心或溪邊（離巴士站近、景觀普通），照「重景觀還是重方便」分流。
- 意思是：讀者心中的第一層分界其實是「溫泉街裡高處還是低處」，上川站是本站獨有的題目。

**② 有哪些旅館、各在哪**
- 清單都只收 5 間大型飯店（朝陽亭、層雲閣、朝陽度假、大雪、觀光，順序大致固定），小旅館、民宿、背包客棧只有 B 寫一間。
- 每間的順序：名稱與一句特色 → 浴池／景觀 → 位置（巴士站走幾分，或高台、纜車旁）→ 餐食 → 訂房。位置多半放在條列裡、排在中段，不放第一句。
- 位置的說法統一用「從層雲峽巴士站走幾分」；高台會加註上坡。纜車距離只在小旅館（B）當賣點。
- C、D、E 各有一張比較表或總整理格，放在逐間介紹之前（C、D）或之後（E）。

**③ 從旭川、札幌出發的旅館接駁巴士**
- A、C、E 放在 FAQ 一題，只說「有些飯店有、要預約、出發前查官網」，沒有時刻。
- D 是唯一以接駁為主軸的：先表格列哪幾間有、免費或付費 → 逐間寫出發地 → 車資 → 預約方式與幾天前截止；時刻都沒寫，只叫讀者看官網。
- 讀者順序：哪幾間有 → 從哪裡上車 → 幾點、多少錢 → 怎麼預約、幾天前 → 什麼季節有。競品普遍停在前兩步，本站有完整時刻與預約期限（F280、F302、F303、F283），是可以壓過他們的地方。

**④ 冬天要不要訂含晚餐**
- 只有 A 正面回答：先講結論（建議一泊二食），理由是溫泉街餐廳少、冬天常休，放在區域節與 FAQ 最後一題。
- 其他篇都把晚餐寫成各館的特色（螃蟹吃到飽、會席、自助），沒有談「不含餐能去哪吃」。
- 讀者順序：要不要含 → 為什麼（外面晚上能吃的少）→ 不含的話的退路。

**⑤ 訂房管道**
- 每篇在每間飯店後面放訂房按鈕（Agoda、Booking、Klook、Trip.com、樂天、Jalan 混用），都是分潤連結，沒有一篇講官網訂房或電話預約。
- 沒有一篇講「哪幾間平台訂不到」或「小旅館只能打電話」。這是本站的差別（F296、F297、F286、F307）。
- 價格：A、B、C 都把價位放在每間的前段（本站不寫價格，不學）。

## 5. 段落與句子的習慣

- 部落客句子長，逗號一路串；條列句短，常是名詞片語。本站照自己的導覽編輯口吻，不學長串句。
- 稱呼讀者用「你」「大家」，常見「如果你…」「想…的人可以…」分流句；C 的「依需求挑選」、A 的「重景觀還是重方便」這種二選一句很好懂。
- 數字放在條列：「巴士站走 X 分」固定放在交通那一行；價格放每間最前面（本站不寫）。
- 轉場常用「不過」「但要提醒」接缺點；A、B 都會寫每間的缺點（上坡、大廳舊），讀者信任度高。本站缺點只能寫客觀狀況（高台要上坡），店家評價維持「評論常提到」。
- 好運日本行的條目：先位置、再景觀浴池、再餐食；句子短、形容詞多；資訊欄用標籤加值。

## 6. 給作者的順序建議（標題照大綱不改）

**H2 層雲峽住宿選溫泉街還是上川站？**
1. 先一句講結論：多數旅館在溫泉街，住溫泉街；上川站只有 3 間，適合什麼人（搭火車晚到、早上要搭車）。
2. 接著講溫泉街晚上能吃的少、住上川站每天有幾班車到溫泉街，一句連交通頁。
3. 再帶溫泉街內部的分別：高台（大雪、朝陽亭）景觀好但要上坡；纜車與巴士站附近的小旅館走路方便。讀者心裡「高處或低處」的問題，在這節先點出來。

**H2 層雲峽住宿推薦，溫泉街的大型溫泉飯店**
1. 競品讀者熟悉的 5 間（朝陽亭、層雲閣、朝陽リゾート、大雪、觀光）放這節，順序可以照讀者熟悉度，不必照官方清單。
2. 每間固定順序：一句是什麼樣的飯店 → 位置（高台、離巴士站或纜車）→ 浴池特色 → 有沒有接駁（一句，細節在接駁節）。
3. 若有表格，放在逐間之前，欄位用區域、營業期間、訂房管道（不放價格）。

**H2 層雲峽溫泉街的小旅館、民宿與背包客棧**
1. 開頭先講這類的共同點與誰適合（一個人、不含餐、離纜車近）。
2. 每間先位置（離纜車或巴士站幾分），再特色（源泉、相連黑岳の湯、只有純住宿），最後營業季節或訂法有限制的寫出來（ホステル冬天不開、とだて只純住宿、銀河只能打電話）。

**H2 層雲峽溫泉街外與上川站的住宿**
1. 先上川站 3 間（離車站幾分 → 含不含餐 → 訂法），再清川、愛山溪。
2. 愛山溪先講「沒有公車、只開 5～10 月」，再講特色，讓讀者先判斷去不去得了。

**H2 從旭川、札幌到層雲峽旅館的接駁巴士**
1. 先列哪幾間有、什麼季節（一句或一張表）。
2. 再逐間：上車處 → 時刻 → 車資 → 預約方式與截止日（照 D 的順序，但補上 D 缺的時刻與上車處）。
3. 最後一句：沒接駁的旅館搭路線巴士，連交通頁；朝陽亭可從巴士站叫免費車。

**H2 冬天住層雲峽要不要訂含晚餐？**
1. 開頭先給結論（照 A 的位置），再用冬天晚上還開的店家數撐。
2. 接著不含餐的退路：還開的店與時間、24 小時便利商店。
3. 最後哪些住宿本來就沒附餐（とだて、KAMIKAWA HOTEL）、哪些有純住宿方案。

**H2 層雲峽住宿的訂房管道**
1. 先講大型飯店官網、Trip.com、Agoda 都訂得到。
2. 再講小旅館與上川站的限制：只能電話、只有 Jalan、官網表單。
3. 住宿稅一句連旭川住宿。

## 7. 他們有、我們缺的（只列，不研究）

- 各飯店從層雲峽巴士站走幾分（競品每間都寫；我們只有 5/16 間有官方數字，大型飯店沒有）。
- 高台飯店的上坡、冬天路滑（A 寫；我們只有「高台」，沒有坡度或冬季路況的官方資料）。
- 各大型飯店晚餐形式（自助、會席、螃蟹吃到飽）；我們只有觀光飯店的晚餐時間（F284）。
- 日歸泡湯（不住宿泡湯）的時間（大雪飯店）。
- 多早要訂房（A 的 FAQ）；冰瀑祭期間是否特別難訂。
- 親子、家族適合哪間（A、C 的 FAQ）；包租湯屋（C 的 FAQ）。
- 刺青入浴規定、能否寄放行李（好運日本行條目的 FAQ 型問題）。
- 層雲峽 La Vista（旭岳附近）等被競品歸到「層雲峽住宿」的非溫泉街旅館，以及 Mount View Hotel（我們已記 F300，不寫）。
