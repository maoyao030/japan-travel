# 導覽編輯口吻（草案，2026-10-18）

Darren 2026-10-18 的要求：寫出像好運日本行（GLTJP）那種旅遊網站的調性，但不要像是本站自己去過。本草案是研究競品後整理的寫法，試寫與比對結果見同資料夾的 `README.md`。**Darren 確認前不取代寫作 Skill 的 `voice-and-seo.md`。**

## 一句話

**像一位熟悉當地的導覽編輯，把查證過的事實講成「值得去的理由」和「怎麼去最順」。** 有畫面、有推薦，但每個畫面和推薦背後都有事實；不講自己的經歷。

## 和現行「旅行手札」的差別

| | 旅行手札（現行） | 導覽編輯（草案） |
|---|---|---|
| 對誰說話 | 寫給之後要去的自己，省略主語 | 介紹給讀者，偶爾用「大家」，多數句子省略主語 |
| 段落開頭 | 先記重點與條件 | 先說這個地方是什麼、為什麼有名，再給條件 |
| 畫面 | 不描寫風景 | 可以描寫，但只用官方或資料寫過的畫面，並寫出條件（晴天、傍晚、季節） |
| 推薦 | 很少 | 用「推薦」「建議」「不妨」「適合」給明確建議，附理由 |
| 提醒 | 「記得」「別忘了」 | 保留，但改成「建議先…」「出發前可以…」，每節最多一兩句 |
| 實用資訊 | 表格與條件 | 不變。這是本站贏競品的地方 |

## 競品學到的（要學）

1. **景點段落的固定節奏**：身分或「最」→ 看點 → 時機 → 一句實用資訊 → 連到細節。讀者掃一眼就知道要不要去。
2. **用條件句寫畫面**：「天氣晴朗時，可以看到…」「傍晚時…」。畫面屬於地方，不屬於寫的人。
3. **把印象歸給地方或一般遊客**：「被列為北海道遺產」「是拍電影和廣告的熱門地點」。
4. **推薦有方向**：「想多看一點，不妨排 5 小時的那班」「適合沒有開車的人」。
5. **開頭與結尾有溫度**：開頭一個招牌畫面，結尾把讀者帶到下一步。
6. **問句標題當鉤子**：讀者真的會問的才用。

## 競品的缺點（不要學）

1. **只有形容詞、沒有事實**：「絕美」「夢幻」「必去」單獨出現。本站的形容詞，同一段要有事實撐住。
2. **實用資訊缺很多**：沒有開放時間、末班車、季節封閉。本站照保母等級寫齊。
3. **標題與開頭的套話**：「超嚴選」「一篇搞定」「本篇為大家介紹」「相信一定能…」。
4. **翻譯腔與錯字、前後矛盾**。

## 寫法規則

### 景點或段落的節奏（100～250 字）

1. **一句定位**：這是什麼、為什麼有名。用事實型的「最」（日本最北、北海道遺產）或身分（電影外景地）。
2. **兩三個看點**：具體的東西（長度、數量、形狀、看得到什麼），來自事實表。
3. **時機**：季節、時段、天氣條件、開放期間。
4. **一句實用資訊**：怎麼去、要多久、開不開。細節在負責頁的，用內連表的連結句帶過去。
5. 選用：一則小知識（電影、地名由來、歷史），一樣要有事實編號。

### 寫畫面但不寫成去過

- 用條件句：「晴天時」「傍晚」「6 月下旬」。
- 用地方當主詞：「白色道路在綠色丘陵間延伸約 3 公里」。
- 印象要有出處：官方怎麼形容、被列為什麼、是什麼的外景地。
- 不寫：「我」「小編」「親自」「實際走過」「去的時候」「讓人感動」「彷彿置身…」這類把感受寫成本站經歷的句子。
- 不預測讀者的感受：不寫「相信一定會愛上」「保證不虛此行」。

### 推薦與提醒

- 推薦用：推薦、建議、不妨、適合、可以把握、比較順。每個推薦後面接理由（因為…／這樣…）。
- 提醒用：建議先…、出發前可以…、要留意…。每節最多一兩句。
- 不用：必去、必吃、一定要、絕對不能錯過、超嚴選。

### 形容詞

- 可以用：壯觀、遼闊、醒目、少見、安靜、熱鬧、潔白、清澈。**同一段要有對應的事實**，例如「壯觀」的同段有「57 座風車」。
- 少用：絕美、夢幻、療癒、震撼。一頁最多一次，而且要有事實。
- 驚嘆號與「～」：全文最多一個，只在開頭或結尾。

### 開頭（answer-first 不變）

1. 第一句：招牌畫面或身分（事實）。
2. 第二句：核心答案，讀者最想知道的那件事（值不值得去、怎麼去、要多久）。主要查詢自然出現在開頭兩段。
3. 第三句（選用）：最重要的條件（季節、班次少、要預約）。

不寫「本篇為大家介紹」「以下整理」「先看結論」。

### 結尾

最後一節照常寫內容，不另開「總結」。最後一段一兩句：把讀者帶到下一步（下一個景點、交通頁、住宿頁），用內連表的連結句。

## 第 1 輪盲測後補的規則

1. **身分句不用冒號標籤**：寫成「○○是／位於…」，不寫「○○：…」，也不用一串數字或經緯度開頭。
2. **畫面用字貼近官方原文**：官方寫「40km以上先」就寫「40 多公里外」，官方寫「強風」就寫「風很強」，不放大。
3. **推薦寫成由事實推出的判斷**：「想 A 的話，B 最從容，因為 C」，並寫出季節、休館、營業日的限制，免得讀者照著排卻撲空。
4. **建議與規定標出是誰說的**：「稚內市建議」「觀光協會的說明是」。不像去過，也比競品可信。
5. **交通工具照來源原文寫**：路線巴士、接駁巴士、觀光巴士不混用；來源互相矛盾或沒公布時，寫出來並給確認的窗口。

## 第 2 輪盲測後補的規則

1. **每個景點一句有出處的外觀描寫**：顏色、形狀、規模，用官方怎麼形容（例如觀光協會稱白色道路是「美しい道」）。地點研究時就要把官方的外觀說明記進事實表，沒有就不寫。
2. **每節最多一句輕柔的建議收尾**：「不妨把 A 和 B 排在同一個下午」「不妨先在案內所問清楚」。不預測感受、不誇張。
3. **說法不能比來源更確定**：「建議預約」和「要預約」不同、「北極星一角」和「北極星造型」不同；寫「沒有公布」「沒有」這類否定句，事實表要有對應的紀錄。
4. **實用段落把編輯判斷放進表格**：例如排法表的「適合」欄，比只列時刻更有用。

## 不變的規則

- answer-first、SEO 規範、標題規範、保母等級、評論統整、客觀狀況直接寫、事實編號，全部照舊。
- 地名先中文；不用公文腔（以下是、如下、請參閱、依據、本站整理）。
- 沒有來源的風景與感受不寫。
