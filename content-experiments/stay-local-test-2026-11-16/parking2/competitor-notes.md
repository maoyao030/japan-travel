- 三個查詢重複出現的都是泛「旭川住宿推薦」長文（車站周邊飯店推薦、TOP7 到 TOP15、車站直通），加上 JR Inn 旭川單店開箱文。沒有一篇專寫「旭川自駕住宿」或「旭川飯店停車」。

## 三、各篇結構與內容類別

### 1. FunTime
- H2 快速導覽（依旅客類型的 2 欄表）→ H2 車站飯店（3 間）→ H2 平價飯店（3 間）→ H2 親子飯店（2 間）→ H2 總整理表（4 欄，無停車欄）→ H2 Q＆A（6 題）。
- 開頭：先建立旭川是中繼站、附近有景點美食，最後才帶到「有的附停車場」；不先談飯店。
- 每間固定版型：圖 → 導言 → 評價 → 交通 → 附近景點 → 「停車場」欄 → 房價與比價連結。停車欄只寫有無與一天多少錢，位置、進出、預約幾乎沒有。
- 資料前後不一（標題與結尾間數不同、欄位寫未提供但另有提示框補充）。

### 2. 多多北海道
- 開場 → H2 房價問題（房價趨勢圖）→ H2 推薦清單（10 間，每間：亮點、缺點、兩則旅客回饋、入住建議、訂房資訊）→ H2 常見問題（4 題，訂房時機、交通、退房）→ H2 總結。
- 開頭先點出讀者「怎麼選」的困擾，再說明依需求（交通、親子、性價比）整理，最後點出有資料來源。
- 沒有停車段落、沒有停車欄；停車散在亮點、旅客回饋與 FAQ，寫成感受而不是費用或位置；多數飯店完全沒提。
- 沒表格；句子短、口語、有語氣詞與 emoji。

### 3. Vivian Explore
- 開頭用粗體痛點（雪地拖行李）→ 依需求快速跳轉清單 → H2 如何選（站前與買物公園兩區的優缺比較）→ H2 清單表（評分）→ H2 9 間逐間（H3）→ H2 優惠連結 → H2 常見問題（3 題）→ H2 總結（三類各推一間）。
- 區域分兩區（先選區），這是本批裡唯一先講「住哪一區」的。
- 停車只放在每間「交通」行的一句話；有使用限制的（例如停好後無法中途進出）寫進缺點。
- 每間固定順序：價格、訂房連結、交通、親子規定、特色條列、作者心得、缺點。
- 比較表只有一張，欄位是飯店名、推薦理由、評分，沒有停車欄。

### 4. 喵爸喵媽
- 先講旭川當據點的位置與價格比較 → 一間飯店的四個亮點 → 旭川美食 → 優惠連結。
- 停車只有一句（飯店與室內停車場相連，適合自駕）。
- 第一人稱體驗，輕鬆口吻、表情符號、每節後面附訂房連結。

### 5. 許傑，旅行圖中（JR Inn 單店）
- 目錄 → 飯店位置與外觀（停車資訊放在這一節）→ 大廳 → 客房 → 衛浴 → 旁邊的商場 → 延伸閱讀。
- 這篇是五篇裡停車寫得最完整的：誰能用、怎麼登記與付款、能停的時段、入住期間能不能進出、停車場在哪、從哪個門進飯店；沒寫是否要預約。
- 第一人稱、第二次來、冬天經驗，口語、驚嘆號與括號。

## 四、共同點

1. **標題**：「旭川住宿推薦」加年份、間數、「車站」「親子」「溫泉」。「自駕」「停車」只出現在 FunTime 的標題，其他篇沒有。
2. **間數與分區**：2 到 10 間；分區用旅客類型（車站、平價、親子）或價位；只有一篇用地理區（站前與買物公園）。
3. **每間飯店必有**：交通（離車站幾分鐘）、評價或評分、訂房連結。多篇有：房價、早餐、大浴場、親子規定。
4. **停車的寫法**：作為欄位或附帶一句，通常只寫有無與每晚多少錢；位置、能否自由進出、是否要預約、車高、冬天雪況、離市區景點與租車還車點的取捨，幾乎都沒寫。
5. **結論與結尾**：多數用「依需求各推一間」收尾，加優惠連結、相關文章；FAQ 問訂房時機與交通，不問停車。
6. **語氣**：口語、驚嘆號、emoji、「超方便」「CP 值」，作者自稱小編或第一人稱。

## 五、讀者決定的順序

多數文章：先選「住不住車站旁」→ 看一張清單或表 → 逐間看（交通、評價、早餐）→ 訂房。自駕與停車幾乎不在順序裡，要讀者自己去每間找一句。
本站自駕讀者的順序應該是：先選區（站前、市區、郊外）→ 依「停車」這件事篩出幾間 → 看停車怎麼停（位置、進出、預約、車高；費用有官方寫才寫）→ 才看房型與早餐 → 訂房。競品順序和這個順序相反。

## 六、給作者的順序建議（標題由大綱決定，這裡只給每節內部的資訊順序）

- 開頭先答「旭川自駕該住市區哪幾間、哪些有停車場、哪些要先確認」，不要先講旭川的地位或景點。
- 先選區：站前與車站周邊、市區其他區、郊外（層雲峽、美瑛方向）之間的取捨，和停車好不好停掛在一起。
- 每間飯店，停車放最前：停車場在哪（飯店自有／合作／商場共用）→ 能不能自由進出 → 要不要預約或先登記 → 有沒有車高或車種限制 → 最後才是離車站幾分鐘與訂房管道。這些都得回官方查到才寫。
- 比較表欄位：區域、停車方式、能否自由進出、是否要預約、訂房管道；表放在逐間介紹之前。
- 冬天雪況與租車還車的相鄰決定，一兩句帶過並連到交通頁；不展開。
- 不放 FAQ、優惠碼、行程推薦、房價。

## 七、他們有、我們缺的（只列出，不寫進文章）

- 每晚停車費金額（多篇寫、各篇不一致）：官網有寫才寫，沒有就不寫。
- 室內立體停車場、與購物中心共用的登記方式。
- 停車時段（幾點到幾點、入住期間能否進出）。
- 距離車站步行時間與有沒有特約停車場。
- 這些都得回官方查到才寫；價格一律不寫（住宿頁規則）。

## 八、競品空缺（確實看到的）

- 沒有任何一篇把「停車」做成篩選條件，只當欄位。
- 沒有一篇比較各家的進出自由度、預約、車高限制。
- 沒有一篇提冬天自駕與停車的實際問題。
- 沒有一篇處理「旭川住宿與租車、還車、往美瑛富良野的路線」的取捨。
- 各篇對同一間飯店的停車說法互相矛盾，且多為舊資料。
