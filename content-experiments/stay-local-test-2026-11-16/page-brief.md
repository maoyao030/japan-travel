# 為什麼自動寫會出問題，要補哪一步（草稿，2026-11-16）

Darren 2026-11-16：「現在的重點是要找到可以讓它自動化寫作，然後不會出問題的原因。」這份只整理原因與要補的步驟，還沒寫進正式規則。

## 今天 Darren 挑出來的問題，各出在哪一步

| Darren 說的 | 出在哪一步 | 寫作流程（作者→查核→編輯）抓得到嗎 |
|---|---|---|
| 整篇 1.9 萬字，讀者拿不到資料 | 寫之前沒有定這一頁寫幾間、每間寫多少 | 抓不到，他們照任務寫 |
| 很多是挑飯店用不到的資訊 | 任務沒有「這一行會不會影響選擇」的門檻 | 加進任務之後，查核每次都抓得到 |
| 應該切成主題群集 | 寫之前沒有查讀者分成哪幾種問法 | 抓不到 |
| 「依需求挑」要先帶情境 | 任務沒有規定這一節的寫法 | 抓不到 |
| 「要小心」讀起來很怪 | 用語 | 加進檢查程式就抓得到 |
| 自駕頁只講車，沒有基本介紹 | 任務把這一頁定成「只寫停車」，沒想到讀者是從搜尋直接進來的 | 抓不到 |
| 次標題沒有人這樣問 | 標題是規劃的人自己分類再改成問句，沒有查搜尋詞；細寫的飯店也挑錯 | 抓不到 |

## 原因

七個問題裡，五個出在**寫作之前的那份任務說明**（這一頁是什麼、標題、寫哪幾間、每間寫什麼），不是出在寫的人。

- 作者、查核、編輯三步是照任務說明做事的。事實錯誤、念規格、住客說法撐不住，查核每一輪都抓到 19 條上下，這一段是穩的。
- 任務說明是我憑判斷寫的，沒有憑據，也沒有人檢查它。任務說明錯了，後面三步會把錯的東西寫得很確實。
- 所以現在唯一會檢查「這一頁的方向對不對」的人是 Darren。自動化之後沒有他，這些問題就直接上線。

## 要補的步驟

### 1. 任務說明要有憑據（寫作前）

每一頁寫之前先產生一份「頁面規格」，每一項都要附憑據，沒有憑據的不能寫進去：

- **讀者從哪個搜尋詞進來**：用固定的一組查詢查中文自動完成，結果存檔。
- **每個次標題對應到哪一個查到的搜尋詞**：對不到的不能當標題，改成段落裡的內容。
- **細寫哪幾間**：有人直接搜「飯店名＋這個主題」的一定細寫；其餘挑最能回答標題問題的。
- **每間的版面與字數**：照頁型的固定版面，不每頁重新發明。

### 2. 規格要有人檢查（寫作前）

一位沒看過規劃過程的讀者 agent，只拿到搜尋詞和這份規格的標題與飯店名單，回答固定的幾個問題：

1. 這些標題，你會這樣問嗎？哪一個不會？
2. 你從搜尋直接進到這一頁，只看這一頁，能不能決定訂哪一間、能不能直接去訂？還缺什麼？
3. 你搜的那間飯店，這一頁有沒有寫？
4. 哪一節你用不到？

另外用程式擋：每個次標題有沒有填對應的搜尋詞、有人搜的飯店有沒有在細寫名單。

沒過就改規格，不進寫作。

### 3. 寫完再用同一位讀者的立場看一次（寫作後）

現在的流程在編輯之後就結束了，沒有讀者驗收。補一位只拿到搜尋詞和成品的讀者 agent，回答同樣四個問題。

### 4. Darren 改過的，回填成檢查的問題

Darren 每挑出一個方向上的問題，就加一條到第 2 步的問題清單或檢查程式裡。今天的七條已經對應進去了。

## 怎麼知道有沒有用

用還沒寫的溫泉頁測：整頁照上面的步驟跑，我不動手調任務說明。跑完給 Darren 看，數他挑出幾個方向上的問題（不算個別字句）。自駕頁兩版各被挑出一個；目標是零。零不了的話，看挑出來的那一條是哪一步漏的，再補。

# 第二輪檢討：為什麼溫泉頁還是沒有一次到位（2026-11-17）

Darren 2026-11-17：「現在在檢討流程，我要一次到定位。」溫泉頁照新流程跑了兩版，讀者驗收兩次都說不能上線。下面只整理流程哪裡漏，不談單篇怎麼修。

## 兩次驗收挑出來的問題，漏在哪一步

| 問題 | 漏在哪一步 | 為什麼前面沒擋住 |
|---|---|---|
| OMO7 有沒有溫泉答不出來 | 研究 | 查問法時就知道有人搜這句，但沒有人回頭確認事實表答不答得出來 |
| 訂房連結點不下去、旅館沒有任何連結 | 研究 | 寫之前沒有確認每一間的訂房頁網址 |
| 沒有開放時間、刺青規定、出湯號時刻表 | 研究＋任務說明 | 讀者選擇時要用到什麼，沒有先列清單；本站已有的規則（4 班以下列時刻表）沒有程式擋 |
| 比較表少連結欄、日文原名放錯、小表放錯節、比較表混了三種旅館 | 任務說明 | 任務說明是我每次重寫的，寫完沒有人檢查；讀者只檢查了標題，沒檢查表格欄位和每節放什麼 |
| 五間同一個模子、「適合」重講 | 任務說明 | 版面是我臨時定的，不是固定範本 |
| 驗收每次都挑十幾條、沒有說可以了 | 驗收 | 沒有過關標準，問的是開放題 |
| 還沒過關的稿就拿給 Darren 看 | 我 | 沒有規定「沒過關不給 Darren」 |

## 原因

1. **研究做在最前面、而且只做一次。** 事實表是為主頁查的，專門頁要回答的問題不一樣，缺的事實要到驗收才發現，那時候只能繞著寫。
2. **任務說明每頁重寫、沒人檢查。** 兩版各有錯是我寫任務說明時造成的。
3. **檢查都排在寫完之後。** 寫完才發現方向或事實不夠，就只能改稿，改一次冒出新的。
4. **驗收沒有過關標準，也沒有規定沒過關不能交給 Darren。**

## 一次到位的流程

寫作之前把會出問題的地方全部擋掉，寫作之後只剩確認。

1. **查問法**（已有）。
2. **讀競品**（已有）。
3. **讀者列問題**（新）：一位只拿到搜尋詞的讀者助手，列出「我要決定訂哪一間、並且直接訂，這一頁一定要回答我什麼」。加上頁型固定要有的：每一間的訂房連結、官網與地圖、被點名搜的飯店的直接答案、班次 4 班以下的時刻表。
4. **對事實、補研究**（新）：問題清單一條一條對事實表。答不出來的回去查官方；查完還是沒有的，明寫「這一頁不回答」和原因。缺口沒清完不進下一步。
5. **大綱與任務說明用固定範本產生**（改）：版面、表格欄位、訂房行、原名、查核日期置底都寫在頁型範本裡，不每頁重寫。這一頁只填：標題與搜尋詞、細寫哪幾間、每節回答問題清單的哪幾條。
6. **寫作前檢查**（改）：讀者助手檢查整份任務說明（不只標題），加上程式檢查：每個標題有搜尋詞、問題清單每一條都有對到某一節、被點名搜的飯店有細寫、每一間有訂房連結。沒過就改任務說明，不寫。
7. **作者 → 查核 → 編輯**（已有）。
8. **程式檢查**（已有，加上這次漏的幾項）。
9. **讀者驗收用過關標準**（改）：只問四題，每題過或不過。能不能決定訂哪一間；能不能從這頁直接訂；每個搜尋詞進來的人第一段或該節第一句有沒有直接答案；有沒有前後矛盾。四題都過就是過關，字句意見另外列、不擋。沒過就退回出問題的那一步，最多退兩次，再不過就停放、記原因。
10. **過關才交給 Darren。** 沒過關的稿不給他看。

## 怎麼驗證

用還沒寫的早餐頁照這十步從頭跑，中間不找 Darren。交給他的時候同時交：過關的成品、四題的結果、哪一步退回過幾次。他挑到的方向問題數就是成績，目標零。
