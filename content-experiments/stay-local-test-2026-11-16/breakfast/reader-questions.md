# 旭川飯店早餐：寫之前，讀者要這一頁回答的問題

只依據 `queries.md`（中文 Google 自動完成，2026-11-17）。扮演台灣讀者：不懂日文、沒去過旭川、從 Google 直接進來，沒看過本站其他頁。本站不寫房價與早餐價格的數字，但可以寫早餐含不含在房價、能不能現場加購。

身分：
- **A**：搜「旭川飯店早餐推薦」，還沒決定住哪間。
- **B**：已經訂了或快訂某一間，回頭查那間的早餐（搜「OMO7旭川 早餐」「旭川 AMANEK 早餐時間」「旭川JR飯店早餐」「站前永安國際 早餐」這類）。
- **C**：搜「旭川 早餐」，不確定要吃飯店還是外面。

標記：**必要**＝沒有就沒辦法決定；**加分**＝有會更好。

## 2. 第一個畫面就想看到的

- 一兩句直接回答：旭川早餐比較有特色的是哪幾間、各自為什麼（例如「想吃海鮮看這間、想吃得精緻看那間、要趕早車看這間」）。
- 緊接著一句說明：每間早餐含不含在房價、能不能現場加購，下面的表都有寫；價格會變，所以看訂房網站。
- 已經訂好飯店的人（B）要能馬上跳到自己那一間：表格或飯店名清單就在開頭附近，最好點名就能跳過去。
- 舊名也要看得到：「KOKO HOTEL旭川站前（舊名站前永安國際飯店）」。

## 3. 比較表的欄位（最多六欄，手機看得下）

| 欄 | 為什麼要這欄 |
|---|---|
| 飯店 | 中文名（必要時附舊名），點了跳到那一間 |
| 早餐時間 | B 最常搜的就是時間 |
| 自助或套餐 | 決定值不值得選 |
| 特色 | 一句話：海鮮、鮭魚卵、湯咖哩、地產食材之類 |
| 含早／加購 | 「可選含早方案、可現場加購」這種寫法，不寫價格 |
| 離旭川站 | 走路幾分鐘，早上趕車用得到 |

訂房連結不放比較表（會擠爆手機畫面），放在每間飯店那一節的最後一行。

## 4. 我不需要、寫了會滑過去的

- 「北海道食材豐富」「早餐是旅行的一大樂趣」這類開場與客套話。
- 每間飯店的房型、大浴場、停車場、接駁車介紹（跟早餐無關，除非直接影響吃早餐，例如要走到別棟）。
- 長長的菜單清單，每道菜都列；我只要知道有沒有招牌的、跟別間差在哪。
- 旭川的歷史、城市介紹、景點介紹。
- 外面早餐店的大篇幅介紹（我搜的是飯店早餐，外面的一兩句帶過就好）。
- 「營養均衡」「健康美味」這種沒有資訊的形容詞。
- 日文菜名一大串、沒有中文說明。
- 寫作者假裝自己去吃過的心得。
- 「價格請以官網為準」重複出現好幾次；講一次就好。
