# 讀者驗收：旭川溫泉飯店推薦（2026-11-16）

讀者身分：下個月去旭川住兩晚，想住有溫泉的飯店，不懂日文、沒去過旭川，從 Google 搜「旭川溫泉飯店推薦」點進來，沒看過本站其他頁。只讀 `final.md` 與 `queries.md`。

## 1. 標題像不像台灣人會問的話

| 標題 | 判斷 |
|---|---|
| H1 旭川溫泉飯店推薦，哪幾間是天然溫泉？ | 像。前半就是我打的字，後半也是我會想問的。 |
| 旭川有溫泉嗎？ | 像，是自動完成裡的原話。 |
| 旭川溫泉飯店比較表 | 可以，看得懂是什麼。 |
| 旭川市區有天然溫泉的五間飯店 | 可以，清楚。 |
| OMO7旭川、JR Inn旭川有溫泉嗎？ | 前半像（有人搜「omo7旭川有溫泉嗎」），但把 JR Inn 硬塞進同一句問句，我不會這樣問兩間。 |
| OMO7旭川有溫泉嗎？（H3） | 像，但和上一層 H2 幾乎同一句，重複。 |
| JR Inn旭川的大浴場（H3） | 意思懂，不過和旁邊的 H3 一個是問句、一個是名詞，不成對。台灣人會搜「jr inn旭川大浴場」，所以字是對的。 |
| 旭川溫泉旅館與附近的溫泉街 | 像，「旭川溫泉旅館」「旭川溫泉街」都是我會打的字。 |

不像台灣人講的只有「OMO7旭川、JR Inn旭川有溫泉嗎？」這種兩間並列的問句。

## 2. 只看這一頁能不能決定、直接去訂

大致可以縮到兩三間，但沒辦法「直接去訂」。

- 我會選 **Hotel WBF Grande旭川**：我搭 JR 進旭川，它離東口走路約 2 分鐘，又有露天浴池和三溫暖，是唯一「站前＋露天」兩個都有的。官網不能線上訂，文章也說從 Trip.com 或 Agoda 訂比較方便。
- 第二選擇是 Dormy Inn旭川（露天、1,200 公尺深的天然溫泉），但要拖行李走 15 分鐘，冬天我會猶豫。

卡住的地方：
- **每一間下面的「Trip.com｜Agoda」是純文字，點不下去**，只有官網有連結。文章自己說 WBF 要從 Trip.com 或 Agoda 訂，結果我找不到連結，只能自己再去搜。這是最直接的阻礙。
- 沒寫大浴場開放時間（深夜、早上能不能泡）。
- 刺青規定只寫了 Dormy Inn 和高砂溫泉，其他幾間沒寫，我會以為其他間都可以。
- 沒有飯店等級的感覺（商務飯店、還是比較高級的），不寫價格可以理解，但我分不出 WBF 和 CABIN 是同一個檔次還是差很多。
- 台灣人講到 Dormy Inn 常想到的宵夜拉麵、冰棒，這頁完全沒提，我會懷疑寫的人到底熟不熟這間。（只是讀者期待，不是錯誤。）

| omo7旭川有溫泉嗎 | 找得到，但答案不直接。H3 第一句是「泡湯設施是三溫暖和32到33度的低溫浴池」，**沒有一句直接說「沒有溫泉」**，要自己推。第二節「旭川有溫泉嗎？」也間接提到。 | 要滑過比較表和五間飯店，接近全文三分之二的位置，滿遠。 |

| 旭川溫泉旅館 | 找得到，最後一節標題就是。但第一句「市區外圍的旅館，官網寫天然溫泉的是龍乃湯溫泉…」很長，三間擠在一段裡。 | 要滑到最底，幾乎是最後。 |

## 4. 會滑過去的段落與讀起來怪的句子

會滑過去的：
- CABIN 的「早餐在14樓的景觀餐廳，主打在地食材。」和「適合」一段又講一次早餐景觀餐廳，重複。
- Super Hotel 的「早餐是每天換菜色的自助式，主打當季有機蔬菜做的沙拉和現烤麵包。」我在找溫泉，這句像飯店文宣。
- 「適合」幾乎每一間都在重講上面已經說過的條件，五間我都會跳過。
- 資料來源那段的查核方式說明。

讀起來怪、卡的句子：
- 「Hotel WBF Grande旭川離旭川站東口走路約2分鐘，是館內就有天然溫泉大浴場的飯店。」──整頁都在講有溫泉的飯店，這句等於沒說。
- 「不過有大浴場，不代表就是溫泉，OMO7旭川、JR Inn旭川…館內有的是大浴場或三溫暖。」──「館內有的是」讀起來卡，要讀兩次。
- 「如果是住客，住宿期間可以不限次數免費泡，不過這裡也開放給外面來泡湯的客人。」──「不過」前後的關係沒講出來，是說會比較擠嗎？
- 「想住在北口旁邊泡天然溫泉，又會從官網訂房、拿到免費早餐的人。」──「又會從官網訂房」不像在講適合誰，像在講條件。
- 「天然溫泉大浴場是男女照時段輪流使用，同一個時段只開給男生，或只開給女生。」──後半句是把前半再解釋一次。
- 「想住在站前，泡從飯店自己溫泉井抽上來的天然溫泉，早餐也想在景觀餐廳吃在地食材的人。」──太長，條件疊三層。
- 「下表把有泡湯設施的飯店和旅館放在一起比，『泡湯設施』這一欄寫天然溫泉的才是溫泉，其他只是館內有大浴場或三溫暖，官網資料的查核日期是2026年11月12日。」──一句塞三件事。
- 「扇松園的大浴場也不是溫泉，是把冷礦泉加熱。」──我看不懂冷礦泉加熱算不算溫泉，也不知道為什麼要提一間不是溫泉的旅館。
- 開頭和第二節反覆出現「官網寫的是天然溫泉」「都是官網寫的天然溫泉」，讀起來像在撇清責任，讓我反而懷疑是不是真的。

## 5. 順序、長度、比較表

- 順序大致對：先答有沒有 → 比較表 → 五間 → 不是溫泉但常被問的兩間 → 市區外。不過比較表放在五間介紹之前，14 列我一開始看不完；我會希望先看五間、表放後面當總整理，或表先只放五間天然溫泉的。
- 長度：五間的介紹剛好；比較表太長。
- 比較表看不懂或卡的地方：
  - 「到JR旭川站」一欄寫法混在一起：「走路3分」「東口走路約2分」「和車站相連」「從JR東旭川站走10分」「計程車約15分」「開車約10分」，有的有「約」有的沒有，後三列根本不是到 JR 旭川站。
  - 「—」是「沒有」還是「沒查到」？分不出來。
  - 「其他」一欄什麼都放：「官網不能線上訂房」「泉水有加水、加溫」「正面就是巴士乘車處」，我不知道哪個是缺點、哪個是優點。「泉水有加水、加溫」是不好嗎？
  - 「人工溫泉大浴場」（露櫻旭川站前一條通）沒有解釋什麼是人工溫泉。
  - Y's Hotel旭川站前、露櫻旭川站前一條通、HOTEL AMANEK旭川、Art Hotel旭川在表裡出現，但內文沒有介紹，我不知道為什麼列進來、要不要考慮。
  - 7 欄在手機上一定要橫滑。

## 6. 像不像熟旭川的台灣朋友

不太像，比較像整理得很仔細的資料頁。
- 五間都是同一個模子：一句位置 →「溫泉」→「適合」→「要注意」→「看房價與訂房」，連「有住客說／提到／覺得」都是每間一句、放在同一個位置。
- 「適合」每一句都是「想…的人」開頭。
- 朋友會直接說「你搭 JR 就住 WBF，從機場搭巴士就住 Dormy Inn」，這頁開頭有一點這個意思，但被一長串飯店全名和日文括號淹掉。
- 比較像人的地方：「冬天就要拖著行李走這一段」「比價的時候記得把早餐費算進去」這兩句有朋友提醒的感覺。

## 7. 前後不一致、讓人懷疑的地方

- 第二節說「大浴場或三溫暖」的是 OMO7、JR Inn、AMANEK、Art 四間，但比較表還有 Y's Hotel 和露櫻一條通也不是天然溫泉，內文沒提。
- 開頭說想泡露天只有 Dormy Inn 和 WBF 兩間，但 JR Inn 有「半露天」、龍乃湯也有露天，沒有說清楚「市區、天然溫泉、露天」三個條件同時成立才只有兩間。
- Dormy Inn 說「在市中心」，又說走到車站要 15 分鐘，我會疑惑市中心不是在車站附近嗎。
- 高砂溫泉表格寫「大浴場，不是天然溫泉」，扇松園寫「大浴場，不是溫泉」，用字不一樣，是有差別還是只是寫法不同？
- 刺青只有 Dormy Inn 和高砂寫了，其他沒寫，會讓人以為其他間沒限制。
- 表格標題是「旭川溫泉飯店比較表」，但裡面一半以上不是溫泉。

## 方向上的問題

1. 每間的「Trip.com｜Agoda」沒有連結，讀者沒辦法直接去訂；WBF 還明說要從這兩個網站訂。
2. 「OMO7旭川有溫泉嗎」沒有一句直接回答「沒有天然溫泉」，而且這個被點名搜的問題放在很下面。
3. 比較表太雜：14 間混了天然溫泉、普通大浴場、市區外旅館，「旭川溫泉飯店比較表」名不副實。建議只放五間天然溫泉，或分成兩張；Y's、露櫻一條通、AMANEK、Art 四間如果留，內文要有一句說明為什麼列。
4. 缺少選擇時會用到的資訊：大浴場開放時間、每間的刺青規定、飯店等級（商務／較高級）。
5. 「OMO7旭川、JR Inn旭川有溫泉嗎？」H2 把兩間擠成一個問句，H3 又和 H2 重複；JR Inn 的 H3 和 OMO7 的 H3 一個問句一個名詞，不成對。
6. 五間飯店的版面一模一樣、「適合」都在重講前面，讀起來像套範本；「適合」可以拿掉或只在真的有新資訊時寫。
7. 開頭塞了五間全名加日文括號，最重要的那句「搭 JR 選 WBF、從機場搭巴士選 Dormy Inn」沒有講出來。
8. 「旭川溫泉旅館」一節三間旅館擠在一段，龍乃湯、高砂、扇松園的差別看不出來；扇松園不是溫泉，為什麼要介紹沒講。
9. （讀者期待）Dormy Inn 台灣人熟悉的宵夜拉麵等特色沒提。

13. 「高砂溫泉…大浴場，不是天然溫泉」與「扇松園…大浴場，不是溫泉」用字不一致。

## 總評

方向對、資料紮實，搜「旭川有溫泉嗎」「dormy inn旭川天然溫泉」的人能很快找到答案；但訂房連結點不下去、OMO7 沒有直接回答、比較表太雜，這三件改好之前不建議上線。
