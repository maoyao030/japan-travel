# 盲測改寫：共同說明

繞路筆記是給台灣讀者的日本旅遊站。站長 Darren 看了旭川住宿的試寫後說「文字段落都不太好讀」。這次把同樣兩段文字交給很多位寫手，各用不同的方法改寫，Darren 會在不知道誰寫的情況下挑他覺得最好讀的。所以請獨立完成，照你拿到的那份「方法」認真做。

## 你會拿到的檔案（都在 `content-experiments/blind-test-2026-11-15/`）

- `source.md`：要改寫的兩段原文（第一題是「想泡溫泉或大浴場，選哪幾間？」一節，第二題是 OMO7旭川這一間飯店的段落），以及它們在文章裡的位置。
- `facts.md`：這兩題能用的全部事實（飯店官網的事實 F，住客評論統計 R）。
- 你的方法說明：`briefs/` 底下指定給你的那一份。

除了這些檔案與方法說明裡點名的檔案，不要讀別的東西。不要打開或列出 `out/` 資料夾，也不要讀暫存資料夾：那裡是別的寫手的版本，看了就不獨立了。不上網。

## 不管哪一種方法都要守的

1. 只能用 `facts.md` 裡的事實。不能加料，不能用你對這些飯店或連鎖品牌的印象補細節。可以捨掉事實，不能改事實。
2. 評論（R）只有 4travel 一個平台，寫的時候要讓讀者知道那是住客的說法，不是本站的結論。評論和官網對不上時以官網為準：OMO7旭川官網沒有寫天然溫泉，不能寫成天然溫泉；露櫻旭川站前一條通是人工溫泉；高砂溫泉的大浴場用地下水。
3. 我們沒有住過。不用「我」「小編」，不寫成自己住過。
4. 繁體中文、台灣說法。日文只能放在括號裡（飯店名第一次出現可以附原名，也可以不附）。
5. 不寫房價與早餐價格。
6. 飯店的中文寫法照 `source.md` 與 `facts.md`。

## 輸出

用 Write 工具寫到指定給你的輸出檔，內容只有這樣，不要加說明、筆記或事實編號：

```
## 第一題

（你改寫後的「想泡溫泉或大浴場，選哪幾間？」這一節。不用再寫這個標題。）

## 第二題

（你改寫後的 OMO7旭川段落。）
```

可以用 Markdown（粗體、條列、表格），用不用看你的方法說明。只能新增你那一個輸出檔，不改別的檔案，不 commit。
