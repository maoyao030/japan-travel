## 第一題
| 原句 | 哪裡怪 | 台灣人會怎麼講 |
|---|---|---|
| 官網寫有天然溫泉的有五間，其中露天和三溫暖都有、評論裡最多人誇的是Dormy Inn旭川 | 「寫有…的有」連兩個「有」，後半又用頓號硬塞兩個條件，要重讀才斷得開 | 官網標明有天然溫泉的共有五間，其中露天和三溫暖都有、評論裡也最多人誇的，是Dormy Inn旭川 |
| 不過有刺青的人不能入浴。 | 「入浴」是日文詞，台灣講泡湯 | 不過有刺青的人不能泡湯。 |
| 只有一位住客說外客多的尖峰時段會很擠 | 「外客」是日文的縮法，台灣不這樣講 | 只有一位住客說，外來泡湯客多的尖峰時段會很擠 |
| 不過水有加水、加溫，還經過循環過濾。 | 「水有加水」詞重複，讀起來卡 | 不過溫泉有另外加水、加熱，還經過循環過濾。 |
| 溫泉是直接從飯店腹地內的井抽上來的 | 「腹地內」是日文「敷地內」的語感，台灣講飯店範圍或自己的井 | 溫泉是直接從飯店自己的井抽上來的 |
| 不過浴場不算大，外客和運動團體多的時候會很擠 | 又是「外客」 | 不過浴場不算大，外來泡湯客和運動團隊多的時候會很擠 |
| 所以把它當成三溫暖設施比較準確 | 「比較準確」像翻譯稿下定義，不像在跟人講話 | 所以與其說是溫泉，不如說是來洗三溫暖的 |
| （整段）不過有刺青…／不過評論幾乎…／不過水有加水…／不過浴場不算大…／不過男女是輪流…／不過三溫暖要另外… | 九條裡有六條用「不過」轉折，句型一直重複 | 換掉幾個：「但有刺青的人不能泡湯」「只是男女是輪流使用的」「三溫暖要另外加收100日圓」（直接講，不用轉折） |

## 第二題
| 原句 | 哪裡怪 | 台灣人會怎麼講 |
|---|---|---|
| 有乾式和低溫霧氣兩種 | 「低溫霧氣」少了名詞，像筆記 | 有乾式三溫暖和低溫的霧氣三溫暖兩種 |
| 如果是住客就可以免費使用 | 「如果是…就可以」繞一圈，囉嗦 | 住客可以免費使用 |
| 早上只開到9點就關了，晚上則是下午3點半開到半夜12點。 | 先講早上關門、再講下午開，順序倒過來，「晚上則是下午」也打架 | 開放時間是下午3點半到半夜12點，隔天早上再開到9點。 |
| 也有住客稱讚這班接駁車，另外還有飯店的滑雪房，裡面有乾燥架和打蠟區。 | 前面沒有別人稱讚卻用「也有」；「滑雪房」看不懂是客房還是放雪具的地方 | 住客對這班接駁車評價不錯；飯店另外有放雪具的滑雪室，裡面有乾燥架和打蠟區。 |
| 1樓的自助餐是和洋菜色 | 「和洋」是日文詞 | 1樓的自助餐有日式也有西式 |
| 還有海鮮配山葵的丼飯，不過住客要另外加購。 | 「不過」接在菜色後面講要加購，轉折不對；「住客要另外加購」像筆記 | 還有海鮮配山葵的丼飯。早餐沒有含在房價裡，要另外加購。 |
| 如果想吃得從容，就早點下去。 | 「吃得從容」太書面 | 不想排隊的話，就早點下去吃。 |
| 大廳、三溫暖和早餐都很擠 | 「早餐很擠」怪，擠的是餐廳 | 大廳、三溫暖和早餐的餐廳都很擠 |
| 泡湯和吃早餐要避開大家集中的時段 | 「大家集中的時段」繞，台灣講尖峰 | 泡湯和吃早餐最好避開尖峰時段 |
| 停車位是先到的人先停，不能預約 | 「先到的人先停」拖長，有現成說法 | 停車位先到先停，不能預約 |

## 整體印象
整體讀起來已經像台灣人在講話，口氣自然，沒有明顯的中國用語。最明顯的問題是日文詞沒換掉（入浴、外客、腹地內、和洋），以及第一題「不過」用太多、第二題有幾句順序倒過來或像筆記（早上只開到9點、住客要另外加購）。
