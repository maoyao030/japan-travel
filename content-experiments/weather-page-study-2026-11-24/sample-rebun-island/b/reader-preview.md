# 禮文島天氣，最熱的8月只像台北3月，冬天船常整天停航

只有7月到9月的禮文島，天氣才像台北的2月到3月，過了9月就一路冷下去，到了冬天，白天也只在零度上下。

想要晴天多，9月比6月、7月好排，不過11月到2月常有整天沒有船的日子，那段時間去，回程後面最好多留一天。

## 禮文島各月氣溫，和台北差多少？

一整年只有7月、8月、9月的白天比台北最冷的1月暖，其他九個月都比那個月還冷。

|---|---|---|---|---|
| 1月 | −2.7℃ | −6.5℃ | 19.4℃ | 14.2℃ |
| 2月 | −2.1℃ | −6.4℃ | 20.3℃ | 14.4℃ |
| 3月 | 1.7℃ | −2.4℃ | 22.7℃ | 16.0℃ |
| 4月 | 6.6℃ | 1.8℃ | 26.4℃ | 19.3℃ |
| 5月 | 11.6℃ | 6.0℃ | 29.7℃ | 22.6℃ |
| 6月 | 15.9℃ | 10.3℃ | 32.7℃ | 25.1℃ |
| 7月 | 20.4℃ | 14.9℃ | 34.8℃ | 26.6℃ |
| 8月 | 22.6℃ | 17.3℃ | 34.2℃ | 26.4℃ |
| 9月 | 20.5℃ | 14.5℃ | 31.5℃ | 25.0℃ |
| 10月 | 13.9℃ | 8.4℃ | 27.6℃ | 22.4℃ |
| 11月 | 6.1℃ | 1.2℃ | 24.8℃ | 19.7℃ |

7月跟9月的白天與早晚，差不多是台北2月的樣子。5月跟10月的早晚平均都在10℃以下，6月的早晚也只比10℃高一點，台北的最低溫降到10℃或以下就叫寒流，所以這幾個月的早晚，冷的程度大概就是台北寒流來的時候。8月最熱的時候，禮文島白天也比同一個月的台北低11度多。

## 禮文島四季怎麼穿、要注意什麼？

禮文島夏天一天之內溫差小，6月到9月的白天跟早晚只差5到6℃，一套衣服大致能穿一整天。春天跟秋天的早晚比夏天冷，衣服要能一層一層加減。晴天也可能突然變冷或天氣變壞，也有早晚需要開暖氣的日子，所以7月、8月也要帶一件外套。冬天最要緊的是風，西海岸冬天會吹到強烈的西風，外層要選擋得住風的。

| 時期 | 一句定調 | 怎麼穿 | 要注意什麼 |
|---|---|---|---|
| 12月到3月 | 船常整天停開的雪季 | 比台北寒流來的時候穿得更多，白天也在零度上下，要穿整天都夠暖的 | 西北季風很強，多數步道冬季封閉 |
| 4月到5月 | 花季才剛要開始的春天 | 4月要比台北寒流時穿得更厚，5月跟寒流時一樣厚，外層要擋風 | 5月平均風速是一年裡最大的 |
| 6月到7月 | 花開得最多、還有機會看到雲海的涼夏 | 7月像台北2月，6月早晚要再多一件 | 6月霧特別多，6月跟7月日照是夏天最少 |
| 8月到9月 | 最暖的8月，接著天氣穩定的9月 | 8月像台北3月，9月早晚加外套 | 大雨多在夏末，也有熱到30℃的年份 |
| 10月到11月 | 冷得很快的秋末 | 早晚要穿台北寒流時的厚度，11月再加一件 | 多數步道陸續冬季封閉，11月起整天沒有船的日子變多 |

4月、5月跟9月晴天多，不過4月白天還不到7℃，花又要等5月下旬才開，想把晴天跟花一起顧，5月下旬最接近。冬天去的話，旅館有沒有開要先確認，[禮文島住宿](/places/rebun-island/stay/)列了每家的營業期間。還沒決定要不要排禮文島，可以先看[禮文島值得去嗎](/places/rebun-island/)。

## 禮文島幾月渡輪容易停航？

整天沒有船的日子大多落在11月到隔年2月，2023到2025年三年共52天，就有38天在這四個月。下表是Heartland Ferry（ハートランドフェリー）公布的利尻・禮文航路整天沒有船的天數，只有部分班次停開的日子不算在內。

| 月份 | 2023年（天） | 2024年（天） | 2025年（天） |
|---|---|---|---|
| 1月 | 3 | 6 | 3 |
| 2月 | 2 | 2 | 2 |
| 3月 | 0 | 1 | 3 |
| 4月 | 3 | 0 | 1 |
| 5月 | 0 | 1 | 0 |
| 6月 | 0 | 0 | 0 |
| 7月 | 0 | 0 | 0 |
| 8月 | 0 | 0 | 0 |
| 9月 | 0 | 0 | 1 |
| 10月 | 2 | 1 | 1 |
| 11月 | 7 | 2 | 3 |
| 12月 | 6 | 0 | 2 |
| 全年 | 23 | 13 | 16 |

11月、12月、1月、2月每個月都至少有一年停過，1月跟2月更是三年每年都有。6月到8月這三年一天都沒有，不過天候急變的時候，還是可能臨時停航，或改到別的港停靠。

想在停航的時候自動收到消息，可以把LINE官方帳號加為好友，停航跟臨時加開船班的時候都會推播，出發前先加好。預約的船班停航了，要重新預約，改票的做法在[稚內到利尻島、禮文島渡輪](/places/wakkanai/ferry/)有整理。

## 禮文島的霧與雲海

6月是禮文島霧特別多的月份，陰天、雨天也多，開花的季節裡，被海上升起的濃霧籠罩的日子也不少。霧多的日子，桃岩展望台這類高處強風跟濃霧都不少見，景色可能被擋住。不過清晨在那裡，一片白跟清楚的景色有時會很快輪流出現，不用太早放棄。

### 禮文島雲海要什麼條件、在哪裡看？

霧層壓在標高200公尺以下的時候，站在比它高的地方就能俯看雲海，桃岩展望台（225公尺）、燕山（ツバメ山，233公尺）跟禮文林道從元地口進去約1.1公里處（200公尺）都看得到。霧多的6月前後比較有機會碰上雲海。不過要當天早上起霧、風弱才行，而且要在氣溫上升之前去。前一天先看天氣預報有沒有霧、風弱不弱。

夏季稚內第一班船要8:25才到香深，已經不是一大早，想看雲海就前一晚先住在島上。想在清晨走上桃岩展望台看雲海，[禮文島健行](/places/rebun-island/hiking/)有每條步道要走多久、從哪裡上去。

## 出發前怎麼查禮文島的天氣？

出發前幾天到氣象廳宗谷地方的預報頁，在「市町村選択」選禮文町，就看得到禮文町的預報。船班停不停，出發當天早上看一下LINE有沒有推播就好。
