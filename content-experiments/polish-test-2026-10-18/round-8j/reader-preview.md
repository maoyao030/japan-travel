# 稚內到利尻島、禮文島渡輪，班次、票價與網路訂票

從稚內前往利尻島與禮文島，搭的是Heartland Ferry（ハートランドフェリー）經營的渡輪。船從稚內港出發，分別開往利尻島的鴛泊港與禮文島的香深港，兩座島之間也有船互通。班次多寡依季節而定。照2026年的時刻表，6月到9月稚內往兩島一天各有3個來回，1月到4月27日與11月到12月減為2個。稚內到鴛泊約1小時40分，直航香深則是1小時55分左右，2等大人單程含稅分別為3,590日圓與3,950日圓。還沒決定要不要排稚內，可以先看稚內值得去嗎。

當天來回的行程，島上能停留多久，取決於回稚內的末班船。禮文島香深的末班船夏天是17:10，其他季節17:05。利尻島鴛泊的末班船夏天與春秋都是16:40，冬天反而晚一點，到17:30才開。一旦錯過，當天就沒有船回稚內。船票可以上網預約，2等自由席也包括在內，搭船日兩個月前的同一天0點開放。網路上只訂乘客的話，開船前24小時會收到乘船QR code，搭船當天到渡輪站乘船口出示，可以直接上船。遇到颱風或低氣壓時船可能停航，開不開原則上在清晨5點到5點半決定。

## 稚內船班怎麼挑，各季稚內渡輪時刻

2026年的時刻表從1月1日用到12月31日，全年依季節分成三種。

- **夏季**，6月1日到9月30日，班次最多，還多了沓形港往返香深的船。
- **春秋**，4月28日到5月31日與10月，稚內往香深有一個來回會停靠鴛泊。
- **冬季**，1月1日到4月27日、11月1日到12月31日，稚內往兩島各只有2個來回。

航線共分三段，除了稚內往禮文島、稚內往利尻島，兩島之間也有船，各段的航程時間整理如下。

| 航段 | 航程 |
|---|---|
| 稚內→鴛泊（利尻島） | 約1小時40分 |
| 稚內→香深（禮文島）直航 | 約1小時55分 |
| 稚內→鴛泊→香深 | 約2小時50分 |
| 鴛泊→香深 | 約45分 |

除了定期班次，有需要時每天最多會加開2班臨時船。加開與停航的消息都放在官網的運航狀況頁，頁面上也列出每一班的船名。

## 稚內到利尻島、禮文島的船票預約

Heartland Ferry的船票可以透過網路或電話預約，沒訂位的話，只要還有空位，當天也能到窗口購買。2等自由席從2024年12月起開放網路預約，目前除了特別室以外，各艙等都能在網路上訂。這一節說的網路預約，都是只訂乘客、沒有帶車上船的情況。

- 搭船日兩個月前的同一天，網路預約在日本時間0點開放，換算台灣時間是前一天23點，電話預約則從同一天上午9點開始。
- 開船前24小時，乘船QR code會寄到註冊的信箱，網站上自行改票也在這個時間截止。
- 開船前3小時，網路預約截止。

### 用 Heartland Ferry 網站訂票

網路訂票的入口是渡輪公司的WEB予約頁，介面有日文與英文可以選。第一次使用時先註冊會員，日文畫面的姓名欄註明要填全形平假名。不會打平假名的話，建議改用English畫面註冊。那裡的姓名欄只分First name與Last name，各限14個字以內。訂票時會用到乘客姓名、電話、電子郵件與信用卡。登入後依序選搭船日、航段與人數，再挑班次與艙等，最後用信用卡一次付清票款。信用卡刷不過時，還是可以當天到窗口用現金或信用卡買票，只是客滿就搭不上。

網路一次最多訂14人。15人以上算團體，不能在網路上訂，要打電話給渡輪公司，團體票一般大人小孩都打9折。

回程或繞兩島的行程同樣可以在網路上訂，只不過每一段都要等到該班的兩個月前才開放，還沒開放的航段，之後再回來補訂。往前推兩個月如果沒有同一天，像4月30日往前推會碰到不存在的2月30日，這時就從3月1日開放。訂票過程中會遇到的日文按鈕與欄位，整理在下表。

| 畫面上的日文 | 意思 | 要怎麼做 |
|---|---|---|
| お客様情報登録 | 會員註冊 | 第一次使用先按這裡 |
| お客様名称（全角ひらがな） | 姓名，全形平假名 | 姓和名分開填 |
| ログイン | 登入 | 輸入註冊的電子郵件與密碼 |
| 乗船日 | 搭船日 | 在月曆上點選日期 |
| 行程 | 航段 | 選例如「稚内→利尻島」 |
| ご予約人数 | 人數 | 大人是12歲以上，小人是6歲以上未滿12歲，幼児是未滿6歲 |
| 利用規約に同意する。 | 同意使用條款 | 按下後再按「次へ」 |
| ○／數字／× | 可預約／剩少數座位／客滿 | 點選想搭的那班與艙等 |
| WEB予約は締め切りました | 網路預約已截止 | 已過開船前3小時，改打電話或到窗口 |
| この内容で予約する | 用這個內容預約 | 確認日期與班次後按下 |
| 確定 | 確定付款 | 填完信用卡資料按「次へ」，再按這個鈕 |

付款途中不要按瀏覽器的上一頁，停在未付款的狀態超過2小時，預約會被取消。訂1等可以在網路上自己選位，選位畫面上用框線圈起來的就是靠窗座位。

### 打電話訂

特別室只能打電話預約，1等也可以用電話訂，未滿15人的2等則不接受電話預約。電話預約從搭船日兩個月前同一天的上午9點開始，號碼是0162-23-3780，接聽時間9:00到17:00。預約時需要提供姓名與聯絡電話。不方便講日文電話的話，1等改在網路上訂也可以。

回程或兩島之間的船只要在去程算起14天內，打電話時就能跟去程一起訂下，不必等各段分別開放。當天才預約的話，只能訂11點以後開出的班次，開船前2小時截止。

### 改日期、改班次或取消

只訂乘客的網路預約，在開船24小時前都可以自己上網更改人數、日期、班次、艙等與座位，不收手續費。航線則無法直接更改，想換航線得取消後重新預約。開船前取消不收取消費，開船後才取消會收全額，票款會退回付款的信用卡，可能需要2個月左右。

距離開船不到24小時，網站上就無法自行更改或取消，必須在開船前打電話處理，電話5:30到17:00有人接聽。不擅長講日文電話，又擔心行程有變的話，建議在開船24小時前先上網改好或取消，就不必打電話。

電話訂的票要更改或取消，在9:00到17:00撥打同一支號碼並告知預約號碼，取消一樣免費。

## 稚內渡輪搭船當天，從出門到上船

### 出門前確認開不開船

利尻、禮文航線原則上在清晨5:00到5:30決定當天開不開，結果會放在官網的運航狀況頁。也可以打電話詢問，5:30起有人接聽。建議搭船當天早上出門前再查一次。狀況頁與LINE通知都是日文，會出現的字眼與意思整理如下。

| 畫面上的日文 | 意思 | 要怎麼做 |
|---|---|---|
| 午前05時30分頃決定いたします | 還沒決定，各班顯示「ー」 | 5:30過後再看一次 |
| 平常通りの運航です | 照常開船 | 照原定時間前往渡輪站 |
| 運航 | 這一班照開 | 標在各班的船名旁邊 |
| 欠航 | 停航 | 訂好的票自動取消，不收取消費 |
| 運航見合わせ | 暫緩開航，還沒決定開不開 | 隔一段時間再看狀況頁，或等LINE通知 |
| 臨時便 | 加開的臨時船 | 開船時間看狀況頁 |

網路訂的票如果停航，通知會寄到註冊的信箱，除此之外渡輪公司不會另外聯絡。想在停航時收到訊息，可以把LINE官方帳號「ハートランドフェリー　利尻礼文運航情報」加為好友。這個帳號只在停航、暫緩開航與加開臨時船時發訊息，照常開船的日子不會發。加入方式是點官網頁首的LINE圖示，打開海報後用LINE掃描上面的QR code。

### 到渡輪站報到、拿 QR code 上船

稚內、香深、鴛泊三個渡輪站的售票櫃台都在1樓，上到2樓再走空橋上船。窗口大約在開船前1小時開始辦乘船手續，2等要在開船前40分鐘辦好，1等與特別室則是開船前20分鐘。1等與特別室超過這個時間還沒辦，預約可能會被取消。

網路訂票拿到乘船QR code的話，當天直接到2樓乘船口出示就能上船，不必到窗口排隊。在稚內港渡輪站，搭手扶梯或電梯上到2樓，乘船口1與乘船口2都在候船大廳裡。即使手上有QR code，一樣要在開船40分鐘前抵達渡輪站。需要紙本船票可以到窗口換，辦手續時出示QR code或報上9位數的預約號碼都可以。有指定座位的話，上船後也要出示QR code上的座位號碼。

機車與腳踏車無法預約，當天在渡輪站依到場順序受理，手續同樣要在開船40分鐘前辦好，腳踏車運費則列在後面的票價一節。載機車或腳踏車的話，最好早點到渡輪站，船上空間有限，滿了可能就上不了船。

### 沒訂位，到窗口或售票機買票

沒有事先訂位，只要還有空位也能搭船。但乘客不能排候補，客滿就搭不上，想確保搭到某一班，事先訂好比較保險。窗口可以用現金、信用卡或QR code支付，信用卡接受VISA、Master、JCB、AMEX、Diners等。

自動售票機只賣2等自由席的大人與小學生票，付款只收現金與有設密碼的IC晶片信用卡。售票機在稚內渡輪站有3台，鴛泊與香深各1台。信用卡沒設密碼、買幼兒票或使用折扣，都要到窗口購買。在旅行社買的船票兌換券，也是到渡輪站櫃台換成船票。

## 稚內渡輪船上的艙等與設施

### 挑選2等、1等或特別室

利尻、禮文航線共有三艘船，艙等配置不完全相同，像1等觀景座與免費行李間只有アマポーラ宗谷號才有。

| 船名 | 艙等 |
|---|---|
| アマポーラ宗谷 | 特別室、1等觀景座（アイランドビューシート）、1等和室、2等 |
| サイプリア宗谷 | 特別室、1等休息室（ラウンジ）、1等和室、2等 |
| ボレアース宗谷 | 特別室、1等休息室（ラウンジ）、1等和室、2等 |

2等是上船後自己找空位坐，票價也是各艙等裡最便宜的。アマポーラ宗谷號原本設有2等指定席，目前暫時當作2等自由席開放。想坐固定座位可以選1等，休息室、觀景座與和室都能指定座位。

多人同行想有自己的空間，可以包下特別室，這是一整間獨立的房間。サイプリア宗谷號與ボレアース宗谷號最多容納6人，アマポーラ宗谷號最多4人。

### 船上吃東西、行李與暈船

船上沒有餐廳。想買點吃喝，船上有飲料與冰淇淋販賣機，2026年5月1日到10月31日另有小賣部營業，也可以自己帶食物上船。船上沒有投幣置物櫃，アマポーラ宗谷號則有免費的行李間。三艘船都不借毛毯。

容易暈船的話，選下層、船身中段的位子比較不晃，アマポーラ宗谷號與サイプリア宗谷號也裝有減少搖晃的減搖鰭。渡輪站與船上都不賣暈船藥，有需要的話，要在上船前自己準備好。

上船後還有空位的話，可以在船上的服務處升等，付款只收現金。天氣許可時可以到甲板上，夏天到秋天有機會看到海豚或鯨魚。航行途中手機基本上收得到訊號，講電話則要到大廳或甲板。

船靠岸後，可能要等10分鐘左右才能下船，如果下船後接著搭觀光巴士或其他交通工具，最好把這段時間也算進去。到了鴛泊港之後怎麼移動，見利尻島交通。到了香深港之後怎麼移動，見禮文島交通。

## 稚內到利尻島、禮文島船票多少錢？

2等大人單程含稅，稚內到鴛泊3,590日圓、稚內到香深3,950日圓，利尻島到香深是1,800日圓。這份票價表從2026年1月1日用到12月31日。2022年7月起採用燃油附加費制度，附加費含在票價裡，每3個月可能調整一次。2026年票價表上這筆附加費是0日圓。從利尻島前往香深，不論在鴛泊或沓形上船，票價都一樣。

| 艙等 | 稚內～鴛泊 | 稚內～香深 | 利尻島～香深 |
|---|---|---|---|
| 2等 | 3,590日圓 | 3,950日圓 | 1,800日圓 |
| 1等休息室、觀景座、和室 | 6,610日圓 | 7,270日圓 | 3,290日圓 |

來回折扣與網路訂票折扣都只針對車輛，乘客買來回票並不會比較便宜。

### 帶小孩搭船怎麼買票？

小學生買半價票，金額算到10日圓、個位數四捨五入。換算下來，2等稚內到鴛泊1,800日圓、稚內到香深1,980日圓，利尻島到香深900日圓。1歲以上、還沒上小學的小孩，每位大人可以免費帶2名，不過小孩如果坐指定席等座位，就不在免費範圍內。

### 包特別室或帶腳踏車要另外付多少？

特別室的包房費另計，稚內航線每間每段20,000日圓，兩島之間每段10,000日圓，每位乘客另外還要買2等票。

帶腳踏車上船要付運費，稚內航線3,300日圓，兩島之間1,650日圓。折疊腳踏車如果裝進專用攜車袋、看不到座墊與輪胎，三邊合計2公尺以內、30公斤以下就免運費。但它會算成一件手提行李，連同其他行李達到3件以上，就得另付受託行李費，票價表上是每件1,100日圓。

## 稚內渡輪停航的機率與停航後怎麼辦

颱風或低氣壓接近時，如果風浪與風向不適合開船，渡輪就可能停航，遇到天氣急變也可能臨時停航，或改由其他港口出發、靠岸。

### 哪幾個月比較容易停航？

2023年到2025年這三年，整天停航的日子多半落在11月到隔年3月，6月到8月則一天都沒有。2023年全年整天停航23天，之後兩年是13天與16天。

| 月份 | 2023年 | 2024年 | 2025年 |
|---|---|---|---|
| 1月 | 3天 | 6天 | 3天 |
| 2月 | 2天 | 2天 | 2天 |
| 3月 | 0天 | 1天 | 3天 |
| 4月 | 3天 | 0天 | 1天 |
| 5月 | 0天 | 1天 | 0天 |
| 6月～8月 | 0天 | 0天 | 0天 |
| 9月 | 0天 | 0天 | 1天 |
| 10月 | 2天 | 1天 | 1天 |
| 11月 | 7天 | 2天 | 3天 |
| 12月 | 6天 | 0天 | 2天 |
| 合計 | 23天 | 13天 | 16天 |

這些天數只算所有班次都停開的日子，部分班次停航不算在內。冬天從島上回稚內後還得接飛機或特急的話，中間多留一天，萬一遇到停航也還有一天可以等。

### 停航後訂好的票怎麼處理？

預約的班次停航時會自動取消，不收取消費，網路訂的票款會全額退回信用卡，想改搭其他班次就自己重新預約。

如果訂的是來回或繞兩島的行程，自動取消的只有停航的那一班。同一趟裡其他照常開的班次，要自己在開船前取消或改期，一樣不收費。

回程停航或錯過末班船，當晚就得在島上過夜。香深港與鴛泊港渡輪站1樓都有觀光服務處（観光インフォメーション），可以到那裡詢問住宿。有需要時每天最多會加開2班臨時船，最好持續留意運航狀況頁。島上的住宿整理在利尻島住宿與禮文島住宿。

## 稚內、香深、鴛泊渡輪站的位置與站內設施

### 怎麼去稚內港渡輪站？

稚內港渡輪站位在稚內市開運2-7-1，從JR稚內站步行約15分鐘就能抵達。不想走的話也可以搭計程車，2分鐘左右就到，車資估計在610到720日圓之間。從稚內機場前往，搭巴士約35分鐘，大人800日圓、小孩400日圓。搭計程車約30分鐘，車資估計4,000到5,000日圓。JR稚內站、巴士總站與渡輪站之間怎麼走，整理在稚內交通。

| 項目 | 內容 |
|---|---|
| 日文名 | 稚内港フェリーターミナル |
| 地址 | 稚內市開運2-7-1 |
| 怎麼去 | JR稚內站走路約15分鐘 |
| 售票櫃台 | 1樓「発券カウンター」 |
| 乘船口 | 2樓「乗船口1」「乗船口2」 |
| 置物櫃 | 1樓，投幣式 |

1樓售票櫃台（発券カウンター）的同一排，還有觀光服務處與宗谷巴士的櫃台，城際巴士與島上觀光巴士的車票都在宗谷巴士櫃台購買。

### 稚內渡輪站的商店、置物櫃與停車場

等船時可以逛逛1樓大廳另一頭的商店Heart Land Shop，營業到當天最後一班船開出為止。投幣置物櫃在1樓廁所旁，2樓除了候船大廳，還有一間餐廳「シーサイドレストラン Yu～来」。

開車前往的話，渡輪站旁就有渡輪公司經營的停車場，車位90個左右。停一天的基本費用是1,000日圓，在島上住一晚、停兩天是2,000日圓。部分時期可能會停滿，繳費機設在1樓正面出入口旁。

### 香深港、鴛泊港與沓形港的渡輪站

禮文島的香深港渡輪站，位在禮文町公所沿海約800公尺處，1樓右側是售票櫃台，旁邊就是宗谷巴士服務台。利尻島的鴛泊港渡輪站，1樓大廳一樣設有售票櫃台、觀光服務處與宗谷巴士服務台。兩個站的正面出口外都有計程車招呼站，觀光巴士則是在建築側面上車。

沓形港的渡輪站沒有商店也沒有餐飲，從這裡搭船的話，食物最好在別處準備好。
