# 讀者任務測試：稚內渡輪頁（round-3 reader-preview）

讀者設定：第一次去北海道離島的台灣旅客，30多歲，不會日文，平常看 Funliday、好運日本行。
任務：2026年7月20日兩人（不帶車）從稚內當天來回禮文島；7月21日從稚內去利尻島住一晚；7月22日回稚內。要決定船班、最早訂票時間、網路怎麼訂（含姓名欄）、當天幾點到、停航怎麼辦。
只讀了文章本身，沒有開其他檔案，也沒有上網。

## 1. 任務結果

### 船班（7月是夏季班表，6月1日到9月30日）

| 日期 | 航段 | 班次 | 為什麼選這班 |
|---|---|---|---|
| 7/20（一） | 稚內→香深（禮文島） | 6:30→8:25 | 文章直接寫「想在禮文島玩一整天，夏季搭最早6:30那班去、17:10那班回」 |
| 7/20（一） | 香深→稚內 | 17:10→19:05 | 同上，是末班，錯過當天就回不了稚內 |
| 7/21（二） | 稚內→鴛泊（利尻島） | 7:15→8:55 | 文章建議夏季7:15去；要住一晚，所以這天不用趕回 |
| 7/22（三） | 鴛泊→稚內 | 16:40→18:20（猜的） | 文章只寫了當天來回怎麼排，沒講住一晚的第三天搭哪班。我選末班多玩半天；如果當晚要接飛機或火車，就改 12:05→13:45 或 8:25→10:05 |

全程都在鴛泊港上下船，不是沓形港（文章有提醒兩個港不同）。

艙等：2等自由席，不對號，上船自己找位子。
票價：大人2等單程，稚內～香深 3,950日圓、稚內～鴛泊 3,590日圓。兩人四段合計 (3,950×2 + 3,590×2)×2 = 30,160日圓。來回票沒有折扣，分開買一樣價錢。

### 什麼時候訂

網路預約從搭船日兩個月前的同一天0點開放，而且「每一段都在該班的兩個月前才開放」，所以要分三天訂：

| 開放時間 | 要訂的段 |
|---|---|
| 5/20 0:00 | 7/20 稚內→香深 6:30、7/20 香深→稚內 17:10 |
| 5/21 0:00 | 7/21 稚內→鴛泊 7:15 |
| 5/22 0:00 | 7/22 鴛泊→稚內 16:40 |

0點是日本時間還是台灣時間，文章沒寫。我猜是日本時間，所以台灣時間是前一天晚上23:00（猜的）。
7月夏季停航是0天、文章也沒說會不會客滿，我其實不確定要不要半夜搶，但照文章「想確定搭上某一班，預約比較保險」，我還是會早點訂。

### 怎麼在網路上訂

1. 打開渡輪公司的 WEB予約頁（延伸資料裡的 reserve.heartlandferry.jp），可以切英文。
2. 第一次用先按「お客様情報登録」註冊會員。
3. 姓名欄「お客様名称（全角ひらがな）」：姓和名分開填，用全形平假名。手機切日文鍵盤，照名字的讀音打羅馬拼音，會跑出平假名。我的名字要用中文讀音還是日文漢字讀音，文章沒說（猜的：用中文讀音，例如陳→ちん？還是ちぇん？我拿不準）。朋友的名字要不要也填、要不要跟護照一樣，也沒寫（猜的）。
4. 「ログイン」登入 →「乗船日」點日期 →「行程」選「稚内→礼文島」或「稚内→利尻島」→「ご予約人数」大人填2。
5. 「利用規約に同意する。」→「次へ」→ 看到 ○／數字／× 點想搭的班次與艙等 →「この内容で予約する」→ 填信用卡 →「次へ」→「確定」。
6. 付款途中別按上一頁；沒付款放兩小時以上會被取消。
7. 一次只訂一段單程，所以 7/20 去程和回程要訂兩次（我的理解，文章寫得有點模糊）。
8. 準備好乘客姓名、電話、電子郵件、信用卡。台灣手機號碼和台灣信用卡能不能用，文章沒寫（猜的：應該可以）。

開船24小時前會收到乘船QR code的email。這也是自己上網改票的最後時間。

### 當天幾點到哪裡

QR code 上船也要「在開船40分鐘前到渡輪站」，所以：

| 日期 | 開船 | 最晚到 | 地點 |
|---|---|---|---|
| 7/20 | 稚內 6:30 | 5:50 | 稚內港渡輪站（JR稚內站走路約15分鐘），直接上2樓乘船口出示QR code |
| 7/20 | 香深 17:10 | 16:30 | 香深港渡輪站，2樓乘船口 |
| 7/21 | 稚內 7:15 | 6:35 | 稚內港渡輪站2樓 |
| 7/22 | 鴛泊 16:40 | 16:00 | 鴛泊港渡輪站2樓 |

7/20 早上要從住處5點多出門，走15分鐘。出門前（5:00到5:30決定開不開之後）看官網的運航狀況頁。另外可以加LINE官方帳號「ハートランドフェリー　利尻礼文運航情報」，它停航時會發訊息。
第一天要寄放行李的話，稚內渡輪站1樓有投幣置物櫃。

### 遇到停航怎麼辦

- 7月過去三年全天停航都是0天，機率很低。
- 停航那一班自動取消、不收費、網路預約全額退回信用卡。改搭別班要自己重新預約。
- 其他沒停的段不會跟著取消，例如 7/20 去程停了，回程那段要我自己在開船前取消，不收費。
- 開船前24小時內網站不能自己改，要打電話 0162-23-3780（5:30到17:00）。但我不會日文，打電話是個問題，文章沒說有沒有英文或中文服務（猜的：只能硬打或請旅館幫忙）。
- 如果去了禮文島，17:10回程停航怎麼辦？會不會被困在島上、要自己找住宿？文章沒寫（猜的：要在島上住一晚）。
- 如果 7/21 利尻去程停了，已訂的利尻住宿怎麼辦？文章沒寫（猜的：自己聯絡旅館）。

## 2. 卡住的句子

1. 「日文畫面的姓名欄填全形平假名。手機切到日文鍵盤，照名字的讀音打羅馬拼音，就會出現平假名。」
   卡在台灣人的名字要照什麼讀音。中文讀音、日文漢字讀音、護照英文拼音都可能，選錯會不會上不了船？「日文畫面的」也讓我想問：切英文畫面是不是就能填英文？文章沒說。這是整個任務最卡的一步。

2. 「網路一次只訂一段單程，回程或繞兩島的行程也訂得到。」
   讀了兩次。前半說只能訂一段，後半說回程也訂得到，我一開始以為有來回選項。看到下一句「每一段都在該班的兩個月前才開放」才猜到意思是「一段一段分開訂」。

3. 「網路預約從搭船日兩個月前的同一天0點開放」
   0點是日本時間。台灣讀者會想知道要不要前一晚11點守在電腦前，文章沒講時差。

4. 「訂了來回或繞兩島的行程，只有停航那一班會自動取消。其他相關班次不會跟著取消」
   前面說網路一次只訂一段，那「訂了來回」是什麼？是指我自己分開訂的那幾段嗎？讀兩次才懂是指「你自己訂的其他段」。

5. 「開船前24小時內，網站上就不能自己改票或取消。這時改在開船前打電話，5:30到17:00有人接。」
   照做會卡在不會講日文。前面電話預約那節說「不方便講日文電話，1等改用網路預約也可以」，但停航改票時沒有網路替代方案，文章沒給不會日文的人一條路。

6. 「停航那一班的預約會自動取消，不收取消費……改搭其他班次，必須自己重新預約。」
   如果是當天停航，「重新預約」要用網路還是窗口？網路是開船3小時前截止，隔天的班也可能還在24小時內收不到QR code……我不確定停航後該走哪條路，最後猜「到窗口買」。

7. 「辦乘船手續時，出示乘船QR code或報上9位數的預約號碼都可以。」配上「收到乘船QR code的電子郵件，當天直接到2樓乘船口出示就可以上船，不必在窗口排隊」
   一下說辦手續、一下說不必去窗口，讀了兩次才確定：有QR code就直接上2樓，不用去1樓窗口。

8. 「兩個月前剛好沒有同一天的日期，就從一個月前那個月的1日開放，例如4月30日的船從3月1日開始訂。」
   「一個月前那個月的1日」讀了三次，靠例子才懂。對我的任務沒影響，但很拗口。

共 8 句。

## 3. 想跳過的地方

- 「稚內渡輪的船與艙等」三艘船的日文船名表開始想跳。我不帶車、選2等，船名跟我無關，片假名船名又記不住。
- 「兒童與幼兒票價」「特別室與腳踏車運費」整段跳過，跟我無關。腳踏車那段（折疊車三邊2公尺、30公斤）很細，但不是我要的。
- 停航統計表從1月讀到5月就想跳，直接找6月到8月是0天就夠了。表下面的「三年加起來多半集中在11月到隔年3月」一句就能取代整張表。
- 「窗口付款與自動售票機」「渡輪站的商店、置物櫃與停車場」「船上設施」快速掃過，只抓了置物櫃和暈船藥不賣這兩件事。
- 開頭第一段資訊很密（三季班數、四個末班時間），第一次讀會想跳；等看到下面的時刻表才回頭對。

想認真讀的是：時刻表、網路預約流程、日文按鈕對照表、停航那兩節。日文按鈕對照表最有用。

## 4. 讀起來像誰寫的

像「很認真的旅遊網站編輯整理官網資料」，一半像編輯、一半像官網公告的翻譯，不太像朋友，也不太像AI。

- 編輯感：「排當天來回時，回稚內的末班船決定了能在島上待到幾點。」有幫我抓重點，這句很好用。
- 官網公告感：「燃油附加費的制度從2022年7月開始，票價可能每3個月調整一次，目前的燃油調整金是0日圓。」「手續要在開船40分鐘前辦好，空間有限，滿了可能就上不了船」這種句子像官方規定直接轉成中文。
- 偶爾有朋友感：「付款途中別按瀏覽器的上一頁，可能會出錯。」「暈船藥渡輪站和船上都不賣，需要就在上船前自己備好。」這種很實際。

不像AI的地方是沒有空話和套話，每句都有具體數字。缺的是「站在台灣旅客角度」的提醒：時差、姓名怎麼拼、不會日文怎麼打電話。
