# round-7h 潤稿紀錄：只改段落形狀

起點：start-draft-tagged.md。標題、表格、條列、延伸資料、資料來源與三句大綱內連句都沒動。

## 整體

- 段落數 44 → 56。每段句數分布從「1句4段、2句14段、3句8段、4句7段、5句7段、6句4段」變成「1句30段、2句18段、3句7段、4句1段」。同一件事的事實、價格、但書接成一句講完，不同的事拆成新段，所以段落變短、句子變長，段落字數有長有短（例如特別室一段很長，「不方便講日文電話…」一句就成段）。
- 段落開頭改成讀者的處境或動作：「從稚內去利尻島或禮文島…」「排當天來回時…」「春秋搭稚內10:10或香深13:25開的船…」「利尻島與禮文島想排在同一趟…」「帶腳踏車或機車的話…」「一群人想包一間…」「一群人一起訂時…」「行程有變時…」「沒訂位時…」「到窗口買票…」「自駕時…」「等船時…」「怕暈船…」「上船之後…」。
- 轉場用說話者的口氣接：「至於坐多久、花多少」「另外」「至於取消」「至於利尻島另一個港口沓形港」「至於手機」「到了渡輪站」。
- 刪掉節尾的收尾或總結句的位置：「利尻島與禮文島想排在同一趟，行程就跟著這幾班兩島之間的船走」原本在節尾收尾，改放到節首當起頭。

## 各段改了什麼

- **開頭**：三段改四段。第一段併成兩句；末班船單獨一段一句講完；停航確認拆成一句一段；航程、票價、訂票、QR code 一段，最後順著行程推到渡輪站 1 樓買票、2 樓乘船口。
- **航線與各季船班**：刪掉交代範圍的開頭句「Heartland Ferry在這一帶有三段航線…」，改從讀者能坐的航線起頭再帶出三段航線。臨時船兩句併成一句，用「另外」接。
- **稚內⇄香深**：表前一句改成從讀者搭哪一班起頭。「想在禮文島玩一整天，夏天…春秋…冬天…」整篇只留這一處，併成一句。
- **稚內⇄鴛泊**：表前兩句併成一句。表後原本同句型的「想在利尻島玩一整天…」改成「在利尻島待得最久的搭法，夏天是…」換講法。
- **島間航線**：原本「兩島之間的船最少…」開頭、節尾收尾與冬天16:00那班，整理成一段從「想排在同一趟」起頭講完；沓形港的提醒單獨成段；表後不再寫收尾。
- **票價與兒童票**：刪掉「這裡的票價都是…」開頭，改從燃油附加費講起，含稅年份放後面一句。
- **船與艙等**：2等不對號與アマポーラ宗谷號的2等指定席併成一句；1等能指定座位併成一句；特別室一句。
- **船票**：表前一句改成先講讀者在意的「鴛泊還是沓形上船票價都一樣」。
- **兒童與幼兒**：小學生半價與算出的票價併成一段一句；幼兒免費與售票機另成一段。
- **特別室與腳踏車**：特別室一段（兩句）；腳踏車預約與到場拆成一段；運費與折疊車一段，用「但」接行李件數。
- **網路訂票與報到時間**：開頭兩句併成一句。
- **網路預約**：註冊、姓名欄、平假名打法併成一串；訂票準備與窗口備案一句接完；團體一句成段；分段開放與日期推算一段；「訂票畫面上會看到的日文，可以對照下表。」單獨成段；表後順著訂票流程，先講挑1等座位、再講付款。
- **電話預約**：改從「打電話能訂的是1等與特別室」起頭；號碼、開放時間、受理時間、要報的資料併成一句；「不方便講日文電話…」一句成段；14天內一起訂與當天預約一段。
- **改票與取消**：網路改票與航線限制併成一句；取消與退款用「至於取消」接成一句；電話改票一段不變。
- **報到時間與 QR code**：順著行程排，先講40分鐘前到站，再講 QR code 直接上2樓、紙本、預約號碼、座位號碼；1等與特別室20分鐘一句成段；沒訂位與兌換券一段，兌換券用「另外」接。
- **窗口付款與自動售票機**：窗口一段、售票機一段，各一句講完。
- **停航確認**：停航原因一段；整天停航天數一段；表後兩句併成一句。
- **停航當天怎麼確認、停航後的預約**：每段一兩句，LINE 帳號三句併成兩句。
- **渡輪站位置**：從 JR 稚內站、從機場兩種到法各一句；「三站都是1樓買票、2樓上船」移到第二段開頭，用「到了渡輪站」接；售票櫃台那排與上2樓順著動線講完。
- **商店、置物櫃、停車場**：用「等船時」「行李想寄放的話」「自駕時」起頭。
- **香深港與鴛泊港**：兩站一段；沓形港用「至於」另成一段。
- **船上設施**：用「上船之後」起頭；暈船一段；升等、甲板、手機一段，手機用「至於手機」接；靠岸與兩句內連句一段。

## 新推論句或換講法的地方（請意義比對確認）

- 「在利尻島待得最久的搭法，夏天是7:15去、16:40回，春秋6:45出發、回程一樣是16:40，冬天則是6:55去、17:30回。」：原文是「想在利尻島玩一整天，夏天搭…」。「待得最久」是從表格看出來的（各季最早去程與最晚回程），意思跟「玩一整天」相同，但說法更明確。「回程一樣是16:40」是跟夏天比較，表格可查。
- 「買好票搭手扶梯或電梯上2樓」：加了「買好票」當動線轉場；拿 QR code 的人不用買票，同一篇其他段已經寫了直接上2樓。
- 「從稚內機場直接過去」「等船時」「自駕時」「行李想寄放的話」「行程有變時」：只是加讀者處境當起頭，沒有加事實。
- 沒有新增事實沒有的建議或判斷。原本就有的建議（早點到渡輪站比較好、事先訂好比較保險、中間多留一天、上船前備好暈船藥）位置有動，內容沒改。
