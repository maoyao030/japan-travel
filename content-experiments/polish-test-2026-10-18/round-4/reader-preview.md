# 稚內到利尻島、禮文島渡輪，班次、票價與網路訂票

稚內到利尻島、禮文島坐的是Heartland Ferry（ハートランドフェリー）的渡輪。船從稚內港開往利尻島的鴛泊港與禮文島的香深港，兩座島之間也有船互搭。船班多寡跟著季節走，2026年的時刻表裡6月到9月稚內往兩島一天各有3個來回，1月到4月27日與11月到12月只剩2個。還沒決定要不要排稚內，可以先看稚內值得去嗎。

排當天來回時，回稚內的末班船決定了能在島上待多久。禮文島香深開出的末班船夏天是17:10，其他季節是17:05。利尻島鴛泊的末班船夏天與春秋是16:40，冬天反而晚一點，是17:30。錯過了，當天就沒有船回稚內。遇到颱風或低氣壓時船可能停航。開不開原則上在清晨5點到5點半決定，搭船那天早上出門前查一次。

從稚內坐到利尻島的鴛泊港約1小時40分，直航禮文島的香深港1小時55分左右。坐2等的話，大人單程含稅到鴛泊是3,590日圓、到香深是3,950日圓。搭船日兩個月前的同一天0點起就能在網路上訂票，現在連2等自由席也開放網路訂。只訂乘客不帶車，開船24小時前會收到乘船QR code，當天到渡輪站2樓的乘船口出示就可以上船。稚內港渡輪站離JR稚內站走路約15分鐘，售票櫃台在1樓。

## 稚內渡輪的航線與各季稚內船班

Heartland Ferry的航線有三段，稚內到禮文島、稚內到利尻島，再加上利尻島與禮文島之間的島間航線。2026年的時刻表從1月1日用到12月31日，一年分成三種班表。

- **夏季**，6月1日到9月30日，班次最多，還多了沓形港往返香深的船。
- **春秋**，4月28日到5月31日與10月，稚內往香深有一個來回會停靠鴛泊。
- **冬季**，1月1日到4月27日、11月1日到12月31日，稚內往兩島各只有2個來回。

| 航段 | 航程 |
|---|---|
| 稚內→鴛泊（利尻島） | 約1小時40分 |
| 稚內→香深（禮文島）直航 | 約1小時55分 |
| 稚內→鴛泊→香深 | 約2小時50分 |
| 鴛泊→香深 | 約45分 |
| 沓形→香深 | 約40分 |

有需要時每天最多會加開2班臨時船。停航與臨時船的消息都在官網的開航狀況頁（運航状況），每一班由哪艘船開也查得到。

### 利尻島與禮文島之間的島間航線

兩座島之間的船最少，春秋與冬天一天都只有1個來回。夏天鴛泊與香深之間有2個來回，沓形與香深之間另有一班只在6月到9月開的船。沓形港在利尻島西側，跟鴛泊港是不同的港，訂票與前往港口時都要看清楚是哪一港。

## 稚內渡輪的票價與兒童票

2026年的票價表從1月1日用到12月31日，金額都含消費稅。2022年7月起實施燃油附加費制度，票價可能每3個月調整一次，目前的燃油調整金是0日圓。

利尻、禮文航線由三艘船輪流開，各船的艙等不完全一樣。

從利尻島去香深，不管在鴛泊還是沓形上船，票價都一樣。下表是大人單程的含稅票價。

乘客買來回票沒有折扣，網路訂票的折扣也只給車輛。

### 兒童與幼兒票價

小學生半價，不到10日圓的尾數5日圓以上進位。算下來2等稚內到鴛泊是1,800日圓、稚內到香深1,980日圓、利尻島到香深900日圓。每位大人可以免費帶2名還沒上小學、1歲以上的小孩，但小孩要坐指定席等座位就不適用。學齡前的幼兒票自動售票機不賣，只在窗口賣。

### 特別室與腳踏車運費

一群人想包一間的話，可以訂特別室，每段每組另收20,000日圓，利尻島到香深這段是10,000日圓，每個人還要再付2等票價。サイプリア宗谷號與ボレアース宗谷號的特別室最多6人、アマポーラ宗谷號最多4人，只接受電話預約。

機車與腳踏車不能預約，當天在渡輪站照到場先後上船，手續要在開船40分鐘前辦好。空間有限，滿了可能就上不了船，帶腳踏車或機車時早點到渡輪站比較好。帶腳踏車上船，稚內航線的運費是3,300日圓，島間航線是1,650日圓。折疊腳踏車裝進專用攜車袋、把座墊與輪胎都蓋住，三邊合計2公尺以內、30公斤以下就不收運費。只是連同腳踏車在內的手提行李一共3件以上，要另付行李費。

## Heartland Ferry 稚內航線的網路訂票與報到時間

船票可以在網路、電話或當天到窗口買。2024年12月起2等自由席也開放網路訂票，現在除了特別室以外的艙等都能在網路上訂。

- 搭船日兩個月前的同一天0點，網路預約開放，電話預約是同一天上午9點開始。
- 開船24小時前，只訂乘客、不帶車的網路預約會收到乘船QR code，這也是自己在網站改票的截止時間。
- 開船3小時前，網路預約截止。
- 開船前約1小時，渡輪站的窗口開始辦乘船手續。
- 開船40分鐘前，2等乘客要辦好乘船手續，1等與特別室是20分鐘前。

### 網路預約

想在網路上訂，到渡輪公司的WEB予約頁，畫面可以切換成日文或英文。第一次用要先註冊會員，日文畫面的姓名欄得填全形平假名。用手機的日文鍵盤照名字的讀音打羅馬拼音，就會變成平假名。訂票時準備好乘客姓名、電話、電子郵件與信用卡，票錢在訂的當下就用信用卡一次付清。網路刷卡不順利，也可以當天到窗口用現金或信用卡買票，有空位就搭得上。

不帶車時，網路一次最多訂14人。15人以上的團體不能在網路上訂，要打電話給渡輪公司，團體票一般大人小孩都打9折。兩個月前剛好沒有同一天，就從一個月前那個月的1日開放，例如4月30日的船從3月1日開放。

回程或繞兩島的行程也可以在網路上訂，只是一次只訂一段單程。每一段要等到該班的兩個月前才開放，還沒開放的那段之後再回來訂。訂票畫面上的按鈕與欄位對照如下。

| 畫面上的日文 | 意思 | 要怎麼做 |
|---|---|---|
| お客様情報登録 | 會員註冊 | 第一次使用先按這裡 |
| お客様名称（全角ひらがな） | 姓名，全形平假名 | 姓和名分開填 |
| ログイン | 登入 | 輸入註冊的電子郵件與密碼 |
| 乗船日 | 搭船日 | 在月曆上點選日期 |
| 行程 | 航段 | 選例如「稚内→利尻島」 |
| ご予約人数 | 人數 | 大人是12歲以上，小人是6歲以上未滿12歲，幼児是未滿6歲 |
| 利用規約に同意する。 | 同意使用條款 | 按下後再按「次へ」 |
| ○／數字／× | 可預約／剩少數座位／客滿 | 點選想搭的那班與艙等 |
| WEB予約は締め切りました | 網路預約已截止 | 已過開船前3小時，改打電話或到窗口 |
| この内容で予約する | 用這個內容預約 | 確認日期與班次後按下 |
| 確定 | 確定付款 | 填完信用卡資料按「次へ」，再按這個鈕 |

付款途中別按瀏覽器的上一頁，沒付款放著2小時以上，預約會被取消。1等的座位可以在網路上自己挑，畫面上框線圍起來的是靠窗的位子。

### 電話預約

打電話能訂的是1等與特別室，未滿15人的2等客室不接受電話預約，特別室更是只能打電話訂。打0162-23-3780訂，從搭船日兩個月前同一天上午9點開始接受預約，訂的時候報上姓名與聯絡電話。網路訂的票收到QR code後想取消或想問當天開不開船，5:30起就可以打。不方便講日文電話，1等也可以改在網路上訂。

打電話訂時，回程與島間的船可以跟去程一起訂，條件是在去程搭船日起14天內。搭船當天才訂，只接受11點以後開的船，開船2小時前截止。

### 改票與取消

只訂乘客的網路預約在開船24小時前都可以自己上網站改人數、日期與班次、艙等與座位，不收手續費。航線不能直接改，想換航線得先取消再重訂。開船前取消不收取消費，開船後才取消就要付全額。退款會退回付款的信用卡，最久可能要2個月左右。

進入開船前24小時，網站上就不能自己改票或取消，要改成在開船前打電話，5:30到17:00有人接。電話訂的票改票與取消在9:00到17:00處理，取消也不收費，打去時報上預約號碼。

### 報到時間與 QR code 登船

收到乘船QR code的郵件後，當天直接到2樓乘船口出示就可以上船，不用排窗口，想要紙本船票也可以到窗口換。辦乘船手續時，出示QR code或報上9位數的預約號碼都行。有指定座位的話，上船後也要出示QR code上的座位號碼。手上有QR code，也一樣要在開船40分鐘前到渡輪站。

1等與特別室過了開船前20分鐘還沒辦好手續，預約可能被取消。沒訂位也能上船，只是客艙沒有候補，客滿就搭不上。想確定搭到某一班，事先訂好比較保險。在旅行社買了船票兌換券，當天要到渡輪站櫃台換成船票。

### 窗口付款與自動售票機

窗口收現金、信用卡與QR code支付，信用卡收VISA、Master、JCB、AMEX、Diners等。自動售票機只賣2等自由席的大人與小學生票，稚內渡輪站有3台，鴛泊與香深各1台。售票機只收現金與有設密碼的IC晶片信用卡，卡沒設密碼的話到窗口買就好。幼兒票與各種折扣也都在窗口辦。

## 稚內渡輪的停航確認與改票

颱風或低氣壓帶來的風浪與風向不適合開船時，渡輪可能停航。天氣急變時也可能臨時停航，或改在別的港口出發、靠岸。2023年全年有23天整天停航，之後兩年是13天與16天，6月到8月三年都是0天。

| 月份 | 2023年 | 2024年 | 2025年 |
|---|---|---|---|
| 1月 | 3天 | 6天 | 3天 |
| 2月 | 2天 | 2天 | 2天 |
| 3月 | 0天 | 1天 | 3天 |
| 4月 | 3天 | 0天 | 1天 |
| 5月 | 0天 | 1天 | 0天 |
| 6月～8月 | 0天 | 0天 | 0天 |
| 9月 | 0天 | 0天 | 1天 |
| 10月 | 2天 | 1天 | 1天 |
| 11月 | 7天 | 2天 | 3天 |
| 12月 | 6天 | 0天 | 2天 |
| 合計 | 23天 | 13天 | 16天 |

表裡只算所有班次都停開的日子，三年加起來多半落在11月到隔年3月。冬天從島上回稚內後要接飛機或特急的話，中間多留一天，遇到停航也還有一天可以等。

### 停航當天怎麼確認？

利尻、禮文航線原則上在當天清晨5:00到5:30決定開不開。結果放在官網的開航狀況頁，也可以打電話問。

用網路訂票，遇到停航會收到寄到註冊信箱的通知，其他情況渡輪公司不會另外聯絡。想主動收到消息，可以把LINE官方帳號「ハートランドフェリー　利尻礼文運航情報」加為好友。這個帳號只在停航、暫緩開航與加開臨時船時發訊息。官網頁首的LINE圖示連到一張海報，用LINE掃海報上的QR code就能加入。

### 停航後的預約怎麼處理？

訂好的那班停航會自動取消，不收取消費，網路訂的票款全額退回信用卡。想改搭其他班次，必須自己重新預約。訂了來回或繞兩島的行程，只有停航的那一班會自動取消。其他相關的班次要自己在開船前取消或改期，這樣做也不收費。

## 稚內、香深、鴛泊渡輪站的位置與售票櫃台

稚內、香深、鴛泊三個渡輪站都是1樓買票、2樓上船，從空橋直接登船。稚內港渡輪站在稚內市開運2-7-1，從JR稚內站走路約15分鐘，搭計程車2分鐘左右，車資估計在610到720日圓之間。從稚內機場搭巴士約35分鐘，大人800日圓、小孩400日圓。從機場搭計程車約30分鐘，車資估計4,000到5,000日圓。JR稚內站、巴士總站與渡輪站之間怎麼走，整理在稚內交通。

售票櫃台（発券カウンター）在1樓，同一排還有觀光服務處與宗谷巴士的售票櫃台，城際巴士與島上觀光巴士的票可以在那裡買。搭手扶梯或電梯上2樓，候船大廳裡有乘船口1與乘船口2。

### 稚內渡輪站的商店、置物櫃與停車場

1樓大廳另一頭有商店Heart Land Shop，開到當天最後一班船開出為止。投幣置物櫃在1樓廁所旁，2樓除了候船大廳還有餐廳「シーサイドレストラン Yu～来」。

渡輪站旁的停車場由渡輪公司經營，有90個車位左右。停一天基本1,000日圓，住一晚停兩天2,000日圓，有些時期可能停滿。停車費的繳費機在1樓正面出入口旁。

### 香深港與鴛泊港的渡輪站

香深港渡輪站離禮文町公所沿著海邊走800公尺左右，售票櫃台在1樓右側，旁邊是宗谷巴士服務台。鴛泊港渡輪站的1樓大廳也有售票櫃台、觀光服務處與宗谷巴士服務台。兩站正面出口外都有計程車招呼站，觀光巴士則在建築側面上車。利尻島另一個港口沓形港的渡輪站沒有商店與餐飲，從沓形搭船前，吃的得在別處準備好。

## 稚內渡輪的船上設施

船上沒有餐廳，有飲料與冰淇淋販賣機。2026年5月1日到10月31日另有小賣部營業，自己帶吃的上船也可以。船上沒有投幣置物櫃，アマポーラ宗谷號有免費的行李間。船上也不借毛毯。

怕暈船可以選下層、船身中段的位子，アマポーラ宗谷號與サイプリア宗谷號也裝有減搖鰭。渡輪站與船上都不賣暈船藥，需要就在上船前備好。有空位時可以在船上的服務處升等到較高艙等，只收現金。天氣許可時可以到甲板上，夏天到秋天有機會看到海豚或鯨魚。航行中手機大致收得到訊號，講電話請到大廳或甲板。

靠岸後下船可能要等10分鐘左右，要接觀光巴士或其他交通的話，把這段時間算進去。到了鴛泊港之後怎麼移動，見利尻島交通。到了香深港之後怎麼移動，見禮文島交通。
