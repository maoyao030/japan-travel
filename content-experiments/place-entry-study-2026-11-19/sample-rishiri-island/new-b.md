# 利尻島旅遊，值得去嗎、住幾晚、幾月去

利尻島在稚內外海，從稚內搭渡輪大約1小時40分就到。島的正中央是標高1,721公尺的利尻山，周圍沒有別的山相連，所以也叫「利尻富士」。想登日本百名山、在產地吃海膽，或者看島上特有的花，利尻島就值得專程排進北海道行程。

6月到9月最適合去，正是海膽的採收期，觀光巴士主要在5月下旬到9月行駛。不登山住一晚就夠，登山要住兩晚。

## 利尻島在哪裡，是什麼樣的地方？

從稚內出發的渡輪夏天一天3個來回，札幌丘珠機場也全年有飛機直飛，船班與飛機的細節在[利尻島交通](/places/rishiri-island/transport/)。還沒排好怎麼到稚內的話，走法整理在[稚內交通](/places/wakkanai/transport/)。

路線巴士沿著海岸繞一圈大約2小時。渡輪停在島北側的鴛泊港，西側的沓形港夏天也有船往返禮文島，從鴛泊搭路線巴士到沓形大約40分鐘。北海道名產白色戀人包裝上的那座山就是利尻山。

## 利尻島有什麼好玩、好吃的？

### 利尻山，不用登頂也看得到的日本百名山

> 照片位置：從鴛泊港望向利尻山的全景

利尻山是日本百名山由北往南數的第一座，沼面、岬角跟展望台都看得到它。鴛泊路線上山6小時、下山4小時，加上山頂休息天氣好也要11小時，要登頂得留一整天。

### 姬沼，原生林裡繞湖一圈

> 照片位置：姬沼的環湖步道與湖面

姬沼周圍大約1公里的步道穿過原生林，走起來很輕鬆，晚上也是看星空的地方。步道5月到10月開放。

### Otatomari沼，繞一圈看湖面映出的山

> 照片位置：Otatomari沼湖面映出利尻山的畫面

Otatomari沼（オタトマリ沼）是島上最大的湖，沿著步道繞一圈大約30分鐘，一路都看得到湖面映出的利尻山。5月到10月開放，旁邊還有伴手禮店跟食堂。

### 仙法志御崎公園，最南端的奇岩海岸

> 照片位置：仙法志御崎公園的熔岩奇岩與海面

仙法志御崎公園在島的最南端，海岸是利尻山古代噴發的熔岩形成的奇岩，海水清澈，看得到水裡的天然海膽跟昆布。6月到9月左右有斑海豹，園內可以餵牠們。

### Peshi岬，鴛泊港旁看日出

> 照片位置：從港邊望向Peshi岬的岩山輪廓

Peshi岬（ペシ岬）是鴛泊港旁大約90公尺高的岩山，天氣好的日子，從上面看得到利尻山、禮文島，一路望到稚內。步道又窄又陡，天氣不好不要上去，住在鴛泊的人清晨可以從港邊走上去看日出。

### 沓形的夕陽，神居露台面海看日落

> 照片位置：神居露台的觀景台與海面

島西側的沓形是看夕陽的地方，神居露台（カムイテラス）是面海的觀景台，開放期間大約是4月到11月。沓形岬公園看得到利尻山跟禮文島，傍晚當地人也會去看夕陽。

### 海膽與利尻拉麵，在產地吃的兩樣

> 照片位置：鴛泊港渡輪站食堂的海膽丼

當地人把蝦夷馬糞海膽叫做Ganze（ガンゼ），6月中旬解禁、採到9月，當季最常做成海膽丼。沓形的利尻拉麵味樂（利尻らーめん味楽）用利尻昆布熬湯，拿過米其林必比登推介，只做午餐，想吃就要排在中午前後。

### 萱草與利尻雛罌粟，初夏的花

> 照片位置：富士野園地成片的橘色萱草

6月下旬到7月中旬，海岸跟濕原會開滿橘色的萱草，富士野園地也長著一大片。利尻雛罌粟（リシリヒナゲシ）是日本唯一的野生雛罌粟，開在登山路線9合目附近的碎石地，花期是7月上旬到中旬，要登山才看得到。

沿著巴士繞島能看的景點在[利尻島景點](/places/rishiri-island/sights/)，吃的在[利尻島美食](/places/rishiri-island/food/)，登山路線與所需時間看[利尻山登山](/places/rishiri-island/hiking/)。

## 利尻島幾月去最好？

6月下旬到7月中旬最好，因為海膽正當季，萱草也在這段時間開花。如果錯過初夏，可以改排9月，海膽還在採收期內，觀光巴士也還在開。

| 月份 | 島上的狀況 |
|---|---|
| 5月 | 山麓還有殘雪，見返台園地一帶可以玩雪，湖沼步道開放 |
| 6月 | 中旬海膽季開始，下旬萱草開花 |
| 7月 | 上旬到中旬利尻雛罌粟開花，下旬利尻昆布漁解禁，下旬起祭典變多 |
| 8月 | 祭典排得最密的月份，也是一年裡最暖的月份 |
| 9月 | 海膽採收到9月，觀光巴士開到月底 |
| 10月 | 上旬山頂初冠雪，下旬平地飄雪，湖沼與岬角景點開到月底 |
| 11月到4月 | 多數景點與自行車道封閉 |

夏天不熱，依氣象廳的長年平均，沓形7月均溫18.0℃、8月19.9℃，不是預報，每個月穿多厚可以看[利尻島天氣](/places/rishiri-island/weather/)。想把行程對上煙火或祭典，日期整理在[利尻島祭典](/places/rishiri-island/festival/)。

11月到4月不太適合去，天候差的日子變多，渡輪也更常停航，這段時間上島的話，離島那天之後最好多留一天備用。

## 利尻島要排幾天，怎麼排？

不登山住1晚就夠，登山要住2晚，夏天不登山的話也可以當天來回。大致可以這樣排。

**夏天一日遊**：稚內7:15的船 → 8:55到鴛泊 → 9:05觀光巴士A路線繞姬沼、Otatomari沼、仙法志御崎公園 → 12:15回到鴛泊 → 16:40的船 → 18:20回稚內。

觀光巴士回到港口時，12:05的船已經開走了，所以回程只能搭傍晚那班。船8:55靠岸、巴士9:05就開，只隔10分鐘，要先上網預約並付款，下船直接上車。中間空出來的下午，可以搭13:00的路線巴士到沓形渡輪站下車，接13:45的觀光巴士B路線，16:15回鴛泊趕得上16:40的船。

**住一晚看日出**：稚內7:15的船 → 觀光巴士A路線 → 住鴛泊 → 隔天清晨Peshi岬看日出 → 搭船回稚內。不開車的話，清晨沒有計程車，要看Peshi岬日出就住鴛泊。

**登山兩晚**：稚內 → 鴛泊，當天看景點 → 住鴛泊 → 隔天清晨登利尻山 → 再住一晚 → 第三天離島。登山清晨出發、日落前下山，登山口靠旅館接送，接送不跨區，所以前一晚住鴛泊，挑有車送鴛泊登山口的旅館。大雨時町公所可能請登山者暫停，登山日最好排在行程前段，跟禮文島一起排的話，還能跟禮文島的日子對調。

完整的船班、環島巴士與觀光巴士時刻放在[利尻島交通](/places/rishiri-island/transport/)，船票怎麼訂看[稚內到利尻島、禮文島渡輪](/places/wakkanai/ferry/)。

## 利尻島住哪一區？

第一次上島、要登山或從稚內搭渡輪來回，住鴛泊最順，渡輪站跟登山口都在這一區。想看日本海的夕陽、夏天要從沓形港搭船去禮文島，就住沓形。冬天不少旅館休館，11月起大飯店都休館，能住的多半是小旅館，各區的旅館與營業期間整理在[利尻島住宿](/places/rishiri-island/stay/)。

## 利尻島和禮文島怎麼一起排？

只能去一個島的話，想登利尻山就選利尻島，想看花、走海岸步道就選禮文島，夏天大約有300種高山植物開花，所以叫「花之浮島」。兩座島夏天都能從稚內當天來回，不過利尻要登山、禮文要走8小時步道，就都得住一晚。

兩個都去的話，兩島之間有船，船程大約40到45分鐘，6月到9月一天3個來回，其中1個來回走沓形港，其他時間一天只有1個來回，所以跳島那天要照船班排。沓形港往禮文島的船只在6月到9月開，夏天可以從鴛泊上島、從沓形離島，不用走回頭路，10月到5月進出兩島都得走鴛泊港。搭飛機進出的話，把利尻島排在行程的頭或尾，回程要搭飛機的人，最後一晚住利尻島最順，當天不用趕船。

禮文島的排法在[禮文島旅遊](/places/rebun-island/)，從稚內怎麼接兩座島，看[稚內旅遊](/places/wakkanai/)。
