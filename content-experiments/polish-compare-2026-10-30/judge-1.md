# 盲測評審 1（2026-10-30）

評審身分：台灣資深旅遊編輯，只讀 `blind/` 資料夾的九個檔案，不知道 X、Y、Z 對應哪一種寫法。
口吻目標：好運日本行、MATCHA 中文版。熟悉當地的台灣編輯在跟朋友解釋怎麼排，不像資料表拆成句子、不像 AI、不是日文官網翻譯腔。

評分說明：
- 好讀程度 0～100：越高越順，一次讀懂、不用回頭。
- 像 AI 的程度 0～100：越高越像機器寫的（句型重複、修飾堆疊、贅詞、前者後者、被稱為、提供…服務之類）。

## 一、asahikawa-transport（旭川交通）

### 排名

1. **Z**：最像人在講話。句子短、句號多，每句只講一件事，口語動詞自然（坐、等、走、貴了250日圓、直接上車就好、最穩）。同一段先講讀者的狀況再給事實，讀起來有人在帶。缺點是有幾句日文「お願い」式語氣跑出來（「原則上請每人放1件」），以及一句乘車券的話擺錯位置。
2. **X**：段落切得短，資訊順序清楚，但不少句子是「名詞、數字、數字、數字」串起來，像時刻表拆成句子。整體乾淨，只是少了人味。
3. **Y**：把 X 的短段落全部黏成一大段，一段七八個逗號、一個句號，讀到後面會忘記前面在講什麼。特急那段（カムイ、ライラック、班次、えきねっと、彩繪車頭）塞在同一段，是三個版本裡最難讀的一段。

### 最怪的句子與改法

**X**

1. 「カムイ5節車廂、ライラック6節，兩種都是全車指定席，最快1小時25分抵達，普通車指定席正常價5,440日圓。」
   → 資料表拆句。改：「兩種都是全車指定席，最快1小時25分到，普通車指定席5,440日圓。カムイ5節、ライラック6節，座位數有差，連假前後想坐哪班要早點訂。」（若沒有後半句的事實，就只留前一句，車廂數放進括號。）
2. 「搭JR的話從新千歲機場站到札幌站約40分鐘，再轉最快1小時25分的特急，不算轉車時間約2小時10分起。」
   → 「約2小時10分起」不是台灣人會講的話。改：「JR從新千歲機場到札幌約40分鐘，再轉特急最快1小時25分，加起來兩個多小時，還沒算轉車等車的時間。」
3. 「從機場搭計程車到旭川站約6,000日圓，11月25日到3月31日的冬季還要再加2成，機場官網建議事先預約。」
   → 「機場官網建議事先預約」像公告。改：「搭計程車到旭川站約6,000日圓，11月25日到3月31日冬季加2成，想搭的話先預約比較保險。」
4. 「往層雲峽的道北巴士班次，見層雲峽交通。」
   → 孤零零一句，像佔位。改成跟前後段一樣的句型：「往層雲峽的道北巴士在8號上車，班次見層雲峽交通。」
5. 「從旭川機場進市區的機場專用巴士配合班機起降開，約30到40分鐘到旭川市區。」
   → 「配合班機起降開」三個版本都有，是日文「航空機に合わせて運行」直譯。改：「機場巴士照班機時間發車，到旭川市區約30到40分鐘。」

**Y**

1. 「札幌到旭川的主力是特急カムイ與特急ライラック，最快1小時25分抵達。前者5節車廂、後者6節，兩種都是全車指定席，普通車指定席正常價5,440日圓。札幌開往旭川方向的特急與快速一天約24班……」（整段）

2. 「往層雲峽的道北巴士在8號上車。往層雲峽的道北巴士班次，見層雲峽交通。」
   → 兩句重複主詞。改：「往層雲峽的道北巴士在8號上車，班次見層雲峽交通。」
3. 「沒預約たいせつライナー的話，也能在這裡5:45到21:00開放的現金售票機買票。」
   → 修飾語堆在名詞前。改：「沒預約たいせつライナー，也能在這裡的現金售票機買票，機器5:45到21:00都能用。」
4. 「搭國際線回台灣的旅客下車後，要從連絡通道走到國際線航廈。」
   → 「旅客」把讀者變第三人稱。改：「搭國際線回台灣，下車後走連通道到國際線航廈。」

   → 「不配合班機」沒說是誰不配合誰。改：「這幾條是一般路線巴士，不會等飛機，落地後要自己對時刻表。」

**Z**

1. 「行李艙原則上請每人放1件，長度2公尺、重量30公斤以內，體積不超過0.25立方公尺。」
   → 「原則上請」是日文公告口氣。改：「行李艙每人放1件，長2公尺、重30公斤、體積0.25立方公尺以內。」
2. 「沒預約的乘車券在旭川站前的巴士總合案內所售票機賣，從新千歲出發想搭這班車，先上網預約付款最穩。」
   → 這段在講從新千歲出發，卻說票在旭川站前賣，讀者會愣住。改：刪掉前半句（旭川那邊的售票機在後面案內所一節已經講），只留「從新千歲出發想搭這班車，先上網預約付款最穩。」

   → 「替誤點多留點時間」語意怪。改：「路線巴士和長途巴士不會等飛機，搭這些車去機場，時間要抓鬆一點。」
4. 「機場建議搭計程車先預約。」
   → 主詞受詞黏在一起。改：「要搭計程車的話，機場建議先預約。」
5. 「從旭川發車的特別快速大雪有12:38與19:05兩班」
   → 另外兩版寫「特急大雪」，這裡變成「特別快速」，疑似事實跑掉，不是語氣問題但要查。

### 每版最好的句子

- **X**：「趕時間的話選特急，想省錢就搭巴士。」／「落地後趕不上最後一班就改走JR。」
- **Y**：「兩者差在時間和價錢，高速巴士比特急便宜2,940日圓，夏天多花約40分鐘」（開頭先講取捨，是好的段首）。
- **Z**：「高速巴士比特急便宜2,940日圓，代價是夏天多坐40分鐘左右，12月到3月多坐1小時左右。」／「這是路線巴士，直接上車就好，不能訂位，上車抽整理券、下車再付錢。」

## 二、rebun-island-sights（禮文島景點）

### 排名

1. **Y**：三版裡最像編輯在帶路。句子切得短、一句一事，遇到讀者會卡的地方多補一句（「不會講日文的話，可以請住宿的旅館幫忙叫車」「打開後找日文地名『金田ノ岬』就看得到位置」「不去北方金絲雀公園就在這裡下車」）。段首常先講讀者的情況（「想早點回稚內」「沒有車」）再給做法。少數句子有點囉嗦，但不影響理解。
2. **X**：結構清楚，事實密度高，但不少句子是「位在……的……，同時望得見……」這種把修飾語堆在前面的寫法，像從日文觀光頁直譯。偶爾兩件不相干的事硬接在同一句。
3. **Z**：和 X 幾乎同一套文字，但把逗號拿掉、句子黏起來，變得更難讀（「改搭14:20的船回稚內的話島上約5小時」「想把景點一次看齊的話6月到9月最合適」）。前置修飾語也更長（「離香深港渡輪站走路約3分鐘的禮文島溫泉薄雪之湯，是……」）。

   → 「的話島上」中間沒停頓。改：「改搭14:20的船回稚內，島上約5小時；禮文A 12:30回到渡輪站，趕得上。」

## 三、rishiri-island-stay（利尻島住宿）

### 排名

1. **X**：三版裡最像台灣編輯寫的。句子短、句號多，段首先給結論再補事實（「想登山就住鴛泊。」「冬天能住的地方少了一截。」「住哪一區，大致跟著上島的港口與隔天的行程走。」）。鴛泊住宿用表格，不硬塞成一段。少數句子漏字（「登山計畫書的表格住宿裡就有」）。
2. **Z**：讀起來很順，但順是靠大量贅詞撐出來的：「提供…服務」「會」「都」「的話」「也就是說」「即使…也」「直接處理乾淨」，一段裡動不動四五個「的話」。這是典型的 AI 潤稿痕跡，而且開始用「你」「送你到」，跟其他段落的口吻不一致。「早上8點到下午17點」是贅述。
3. **Y**：把 X 的表格和短句壓成長段落，鴛泊住宿那段六家旅館擠在一起，讀者要自己拆。登山公告那句數字連發、沒有句號。「比對選區和季節時可以從りしぷら的住宿清單開始」這種段首像翻譯。

## 整體結論

三篇裡我各挑的第一名是 asahikawa-Z、rebun-Y、rishiri-X。它們不一定是同一套寫法，但共同特徵一致，這就是本站該追的風格：

1. **句子短、句號多。** 一句一件事，一句最多兩三個逗號。主詞換人或時間換段就下句號。最差的兩個版本（asahikawa-Y、rishiri-Y）都是把短句用逗號黏成一大段，讀者讀到第五個逗號就忘了主詞。
2. **段首先講讀者的狀況，再給事實。** 「想登山就住鴛泊。」「沒有車，最省事的是……」「想早點回稚內，可以改搭……」。資料表拆句的寫法是倒過來，先丟名詞和數字，讀者要自己判斷跟自己有沒有關係。
3. **修飾語放在主詞後面，不放前面。** 「桃台貓台在元地的高台上，看得到……」好過「位在元地的高台展望點桃台貓台，同時望得見……」。前置修飾是日文觀光頁直譯最明顯的痕跡，X 和 Z 的禮文島版都有。
4. **用台灣人會講的動詞和短語。** 坐40分鐘、直接上車就好、最穩、貴了250日圓、少了一截、趕不上就改走JR。不用「配合班機起降開」「提供接送服務」「被稱為」「變幻出」「展示著」「前者後者」「原則上請」。
5. **贅詞是 AI 的指紋。** rishiri-Z 讀起來最「順」，但順是靠「的話」「會」「都」「即使…也」「也就是說」「直接…乾淨」堆出來的，一眼就看得出是機器潤過。好讀不等於不像 AI；評分時兩個分數要分開看。
6. **會補讀者真的會卡的那一句。** rebun-Y 的「不會講日文的話，可以請住宿的旅館幫忙叫車」「打開後找日文地名『金田ノ岬』」是三篇裡最接近好運日本行、MATCHA 的地方：不是多講資料，是多講一句怎麼做。
7. **表格留給清單，正文不要把表格重講一遍。** rishiri-X 鴛泊住宿用表格、正文只講例外，Y 和 Z 把同樣內容壓回段落，馬上變難讀。

一句話：**短句、句號、先講讀者再講事實、修飾語放後面、台灣口語動詞、不加解釋腔贅詞。** asahikawa-Z 和 rishiri-X 最接近這個樣子，rebun-Y 則示範了「多補一句怎麼做」的價值。

附帶一提（不計入分數）：asahikawa-Z 有「特別快速大雪」「約2小時起」、rebun-Y 有桃岩展望台冬季只開到展望台一段、rishiri-Y/Z 有「便宜4,000圓」的比較，這幾處跟另外兩版的事實不完全一樣，交給事實查核確認。
