# 〈禮文島祭典〉第 1 輪改稿：改了哪些句子（原句→新句）

- 大標題：…島上一年只有一場的花火與7月小學生的神轎行列，日期、水產祭與回程一次看 → 禮文島祭典2027，看島上唯一的花火要住一晚，7月神轎遶境與水產祭一次看
- 開頭1：禮文島是稚內外海的離島，夏天的祭典不大，不過…島上的人都會出來，遊客下了船在香深港一帶走幾步路就遇得到。 → 禮文島夏天最出名的是花，島上大約有300種高山植物開花，被稱為「花之浮島」，位置在稚內外海。
- 開頭2：7月15日前後，小學生拿著弓和太刀走在神轎前面…水產祭…花火。最大的決定在花火，想看的話，那一晚就要住在島上。 → 花開之外，7月15日神轎會在香深的街上遶境，替神轎開路的是大約18位小學高年級生，手上拿著弓和太刀，跟在大人敲的太鼓後面。8月10日前後，島民、返鄉的人和觀光客會聚到香深港看花火，想看的話，那一晚就要住在島上。
- H2 1 第一段：7月中旬同一個禮拜有神轎行列和水產祭，…8月10日晚上則是島上一年只有一場的花火。 → 7月15日前後有神轎遶境和水產祭，兩個都在香深，同一趟就排得進去，8月10日前後則是花火與海峽祭，晚上看花火、傍晚逛海峽祭的攤位。
- 表（感謝祭）：在群生地辦的小活動，順便支持保護島上環境的緞帶計畫 → 會場賣以島上高山植物為圖案的緞帶計畫徽章，收益用在保護高山植物
- 表（水產祭日期）：7月18日到23日之間的週六，2018年起有紀錄的七屆都是 → 7月20日前後的週六
- 表（花火）：晚上8點開始的花火 → 傍晚起的美食攤，入夜後在港邊放的花火
- 表（神轎）：神轎行列在15日 → 神轎遶境在15日
- 表後：島北的船泊另有禮文神社祭，同樣是每年7月8日到10日。三個主角都在香深一帶，渡輪站到花火會場大約800公尺。照日曆推算…週四…週二。 → 島北的船泊還有禮文神社祭，日子也固定，是7月8日到10日。照日曆推算，…兩天都落在平日，要看的話得先排好假。
- 延期：花火近四屆有兩屆因為天候延到8月12日，… → 花火近四屆有兩屆比預定晚一兩天，到8月12日才放，2024年那一屆是因為天候不好，…
- 新增（利尻島）：兩座島一起排的話，利尻島祭典裡，鴛泊的北海島祭在8月3日、…鴛泊的海膽祭在8月11日，近年花火多在8月10日，海膽祭就在隔天。（原本在回程節最後一段）
- 嚴島 H3 第一段：走在最前面開路的是大約18位小學高年級生 → 走在前面的是大人敲的太鼓，替神轎開路的是跟在後面、大約18位的小學高年級生
- 嚴島 背景：這套行列叫…是禮文町指定的無形民俗文化財。／由小學生擔任，是因為這幾乎是島上小孩唯一能參加的傳統活動… → 嚴島神社是島上最古老的神社…；這套行列叫四箇散米舞（四ヶ散米舞），是17世紀松前藩創作的神樂舞曲，後來由神職帶到禮文，在島上已經有80年以上的歷史。這幾乎是當地小孩唯一能參加的傳統活動，又是每年由小學高年級生出場，所以參加的孩子和地方居民都很期待。
- 水產祭 H3 小標題：渡輪站旁現烤的海膽、螺和章魚 → 當季的現烤海膽，還能體驗剝海膽
- 水產祭 H3 內文：官方有公告的2022、2023、2025年，都辦在…週六11:00到14:00。… → 辦在渡輪站旁的停車場，會場賣當季的海膽。近年的公告都寫現烤的海膽、螺和章魚賣得比較便宜，2025年的公告還寫花魚試吃和剝海膽體驗免費，剝海膽是先到的100名。主辦的是禮文町產地協議會，香深與船泊的漁協和商工會也一起辦。
- H2 3 標題：禮文島花火大會，島上一年只有這一場 → 禮文島花火大會，島民、返鄉的人和觀光客一起看
- H2 3 內文：規格清單（第45屆、8點到8點半、町公所後面、800公尺、美食攤、1,500發）→ 先畫面（傍晚美食攤、天黑後港上放花火、2025年島民返鄉的人觀光客都來）；背景（主辦自稱島上唯一、疫情2020、2021只放花火、商家贊助改群眾募資）；會場近年都在香深港裡面
- 新增海峽祭一小段：近兩屆都辦在道道禮文島線上，2026年那天整段路封起來，擺美食攤、辦拔河。2025年海峽祭結束的晚上8點，町公所海側有往船泊、元地和知床的免費巴士。
- 回程第一段後：…往稚內的末班船17:10…所以看花火的人一定要住在島上。…住香深的話，會場離渡輪站大約800公尺…2025年散場後，主辦另外安排了…免費巴士 → 花火晚上8點才開始放，從利尻島過去的話，往鴛泊的末班船在15:30就開了，所以不管從稚內還是利尻島出發，都得住在島上。…住香深的話，會場離渡輪站大約800公尺（F963），走路就回得去，旅館整理在〔住宿頁連結〕。（免費巴士句刪除）
- 回程水產祭：從稚內搭06:30的船，08:25到香深…回程可以搭14:20或17:10… → 水產祭在14:00結束，14:20從香深開往稚內的船只隔20分鐘，待到最後的話要直接走去搭船，想逛久一點就搭17:10那班。（鴛泊 09:30／15:30 一句留）
- 表（水產祭幾點）：11:00到14:00 → 11:00到14:00（2025年的公告）
- 結尾：船票句與利尻島句拆開；三行「看更多」改成每節最多一行（天氣在 H2 1、渡輪在 H2 4，住宿與利尻島祭典改進句子）。
