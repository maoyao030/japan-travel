# 禮文島祭典，花火大會、神社祭與敦盛草感謝祭

禮文島的活動集中在5月到9月，8月的花火大會是島上唯一的花火，7月中旬嚴島神社祭有小學生帶頭的神轎行列，同一週還有水產祭可以吃花魚跟海膽。想知道禮文島整體怎麼玩，可以先看[禮文島值得去嗎](/places/rebun-island/)那一頁。

## 禮文島祭典與活動月曆

島上的活動從5月底的敦盛草感謝祭開始，一路辦到9月底的溫泉美食健行。下面是2026年的日期，每年的日期會由觀光協會跟禮文町公所公布。

| 活動 | 2026年日期 | 地點 |
|---|---|---|
| 敦盛草感謝祭 | 5月28日～29日 | 敦盛草群生地 |
| 最北花之馬拉松 | 6月6日 | Pisuka２１起跑 |
| 禮文神社祭 | 7月8日～10日 | 船泊地區 |
| 嚴島神社祭 | 7月14日～16日 | 香深地區 |
| 水產祭 | 7月18日 | 香深港特設會場 |
| 花火大會 | 8月10日 | 禮文町公所後面 |
| 海峽祭 | 8月12日 | 道道禮文島線 |
| 溫泉美食健行 | 8月1日～9月30日 | 香深渡輪站出發 |

遊客比較容易配合行程的是花火大會、水產祭跟嚴島神社祭，三個都在香深港一帶，不用特地移動。多數活動不用報名也不用門票，只有馬拉松要事先報名，溫泉美食健行要事先買方案。出發前記得到禮文町公所的活動公告頁確認當年的日子。

## 禮文島初夏的敦盛草感謝祭

敦盛草感謝祭（アツモリ感謝祭）是在禮文敦盛草群生地辦的小型活動，觀光協會也藉這個機會請大家支持保護島上環境的緞帶計畫（リボンプロジェクト）。近年都在5月底到6月初辦兩天，剛好跟禮文敦盛草（レブンアツモリソウ）的花期重疊，所以賞花跟活動可以一起排。

近幾年的會場都賣以禮文島高山植物為圖案的緞帶計畫徽章，收益用在自然公園修繕跟高山植物的保護。2024年還請大家喝了昆布茶。徽章在敦盛草群生地、高山植物園跟觀光案內所都買得到，不一定要在感謝祭當天才能買。

### 最北花之馬拉松，遊客也能報名嗎？

可以。最北花之馬拉松（最北フラワーマラソン）參加免費，分成3公里、5公里跟10公里，一般組是國中以上就可以報名。不過報名要在活動前一個月左右截止，而且當天不受理，所以如果初夏上島想順便跑的話，記得提早報名才行。2026年第33屆是6月6日，報名在5月6日就截止了。

報名用禮文町公所網站上的LOGO表單，也可以用電郵或郵寄。早上8:30受付、9:00開幕式、9:30起跑，起終點都在香深的Pisuka２１（ピスカ２１）。因為小孩參加的多，天氣不好的時候可能取消。各組前三名有獎狀跟獎牌，參加者都有完跑證明。

近年的馬拉松都辦在5月底到6月上旬的週六，2019年6月1日、2023年6月3日、2024年6月1日、2025年5月31日、2026年6月6日。而且這一天剛好是利尻島環島馬拉松的前一天，兩座島的馬拉松可以連著跑。2023年的報名大約3月初就開始了。

## 禮文島7月中旬的神社祭與水產祭

嚴島神社祭在7月14日到16日、水產祭近年在7月18到22日之間的週六，兩個活動只差幾天而且都在香深，可以一起排進行程。

### 嚴島神社祭，小學生帶頭的神轎行列

嚴島神社（厳島神社）源自江戶時代的辯天社，是禮文島上最古老的神社。每年7月15日本祭的時候，神轎會排成隊伍在香深地區巡行，帶頭的是小學高年級生大約18人組成的四箇散米舞行列（四ヶ散米舞行列），這個行列有80年以上的歷史，是禮文町指定的無形民俗文化財。不過天候不好的時候可能順延或取消。

嚴島神社從香深港渡輪站往桃岩隧道方向走路大約15分鐘。想看神轎巡行的話，不用特地去神社，巡行隊伍會經過香深地區的路上。

### 禮文神社祭在島北的船泊

禮文神社祭（礼文神社祭）辦在島北部的船泊地區，日期是7月8日到10日。禮文神社從香深港渡輪站開車大約30分鐘。

### 水產祭吃花魚、海膽，看抓章魚

水產祭（うめーべやフェスティバル）是禮文島的美食活動，油脂豐富的花魚、當季海膽、蝦這些島上的美食都會集中到會場來。重頭戲是抓章魚，不過只有女性能參加。

水產祭例年7月中旬，近年都辦在7月18日到22日之間的週六，2026年是7月18日在香深港的臨時會場。因為香深港就是渡輪靠岸的地方，所以當天上島也排得進去。

## 禮文島8月的花火大會與海峽祭

花火大會跟海峽祭同屬禮文故鄉祭（礼文ふるさとまつり），觀光協會說這是禮文最大的活動，2026年已經辦到第45屆了。近幾年花火大會多在8月10日前後，2026年8月10日晚上8點開始放花火，預定1,500發。2025年放了1,600發，島民、返鄉的人跟觀光客都來了。

花火會場在禮文町公所後面的香深港港灣設施，離香深渡輪站大約800公尺。傍晚5點起就有美食攤位，主辦說市區的主要街道也會擺滿啤酒花園跟便宜吃海鮮的攤位。不過夏季香深開往稚內的末班船是17:10，所以看完晚上8點的花火當天是回不了稚內的，要在島上住一晚。

### 海峽祭的美食攤與拔河

海峽祭（海峡祭り）是禮文故鄉祭的白天場，2026年實際在8月12日舉行。下午3點到晚上8點，有美食攤位跟拔河大賽。

2026年的會場是道道禮文島線的中島商店前到舊北野寫真材料店前，2025年在香深漁協到民宿香榮丸之間，2024年在薄雪之湯的海側綠地公園，所以會場每年都在香深港一帶，但確切位置會換。當天中午12點到晚上10點這段路會封閉。

### 花火大會遇到壞天氣會延期嗎？

會。2026年的公告寫天候惡劣最多延到8月12日，之後可能取消。海峽祭遇到壞天氣也會延期，或者改到Pisuka２１的室內。實際上2026年的海峽祭就比預定晚了一天，2024年也因為天候惡劣延到8月12日並改在室內辦。花火當天晚上7:30到8:30附近道路會交通管制。

## 禮文島8、9月的溫泉美食健行

溫泉美食健行（ONSEN・ガストロノミー）是全國性的活動在禮文島的場次，2026年是第5屆，從8月1日到9月30日。買了方案之後，拿著附的2,000日圓餐券到島上指定的店吃飯，走完步道再去薄雪之湯（うすゆきの湯）泡溫泉，免費借毛巾。3,000日圓的方案走禮文岳步道，4,000日圓的可以在7條步道裡任選。

起終點跟受付都在香深渡輪站1樓的觀光案內所。不過各方案限50人、額滿就截止，2026年已經額滿了。誰都能參加，國籍、年齡、性別不限，小學生以下要家長陪同。

## 禮文島看祭典的船票與住宿

看完花火或海峽祭當天回不了稚內，要在禮文島住一晚。渡輪在乘船日2個月前的同一天開放預約，所以打算8月上島看花火的話，6月上旬就可以先訂船票。渡輪的班次、訂票跟報到方式，可以看[稚內到禮文島的渡輪](/places/wakkanai/ferry/)那一頁。

2025年海峽祭結束後，晚上8點從禮文町公所海側有免費巴士分往船泊、元地跟知床三個方向，不住香深的人也能回去。不過2026年的公告沒有寫免費巴士，有沒有要看當年公告。

禮文島的住宿從香深到船泊都有，哪一家離渡輪站多遠、能從哪裡訂房，整理在[禮文島住宿](/places/rebun-island/stay/)那一頁。
