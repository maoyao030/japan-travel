## Round 4：語氣改寫

全篇敘述段落改寫為 Darren 的對話口吻（writing-guide 第17條）。表格、條列、延伸資料、資料來源不動。以下列出主要改寫模式與代表例子。

### 模式 A：與→跟

全篇替換，約 20 處。

- 旭岳**與**層雲峽常排 → 旭岳**跟**層雲峽常排
- 吃飯**和**領錢 → 吃飯**跟**領錢
- 銀行**與**郵局 → 銀行**跟**郵局
- 限定貼紙**與**大塚製藥 → 限定貼紙**跟**大塚製藥

### 模式 B：約→大約

約 12 處。保留表格裡的「約」不動。

- 約1,600公尺 → 大約1,600公尺
- 約24公里 → 大約24公里
- 約7小時 → 大約7小時
- 約1個半小時 → 大約1個半小時
- 約10分鐘 → 大約10分鐘

注意：「30分」「15分」等短時間保留「分」不加「鐘」，因為 check-benchmark 的數字比對會把「30分鐘」算成不同的 key。

### 模式 C：加 如果…的話 條件句

約 10 處。

- 只有一天、想搭纜車… → **如果**只有一天、想搭纜車…**的話**
- 打算在山上多待一晚 → **如果**打算在山上多待一晚…**的話**
- 還要從旭川機場搭出湯號 → **如果**還要從旭川機場搭出湯號…**的話**
- 想分兩天走 → **如果**想分兩天走**的話**
- 額滿就要改搭 → **如果**額滿**的話**就要改搭

### 模式 D：加 所以、不過、因為 等關係詞

約 15 處。

- 現金在出發前就要備齊 → **所以**現金在出發前就要備齊
- 兩條巴士路線都從…，接得順也將近4小時 → **不過**兩條巴士路線都從…，接得順也**要**將近4小時
- 建築有高度限制 → **因為**建築有高度限制
- 早起並沒有比較早到 → **所以**早起並沒有比較早到
- 光是兩地之間單程就要將近4小時 → **因為**光是兩地之間單程就要將近4小時

### 模式 E：加 記得、要注意 等提醒

約 5 處。

- 出發前要確認纜車與吊椅幾點開 → 出發前**記得**先確認纜車跟吊椅幾點開
- 縱走當天早上先看兩邊官網 → 縱走當天早上**記得**先看兩邊官網
- 9月下旬以後上姿見要帶保暖外套 → 9月下旬以後上姿見**記得**帶保暖外套
- 出發前看大雪Kamuimintara DMO → 出發前**記得**看一下

### 模式 F：加語助詞 了、的、就好、才行

散佈全篇，讓句尾不會全部乾脆收掉。

- 下車就是火口池 → 下車就是火口池**了**
- 領一張免費乘車券 → 領一張免費乘車券**就好**
- 兩者都要煮沸 → 兩者都要煮沸**才行**
- 末班車已經開走 → 末班車已經開走**了**
- 溫泉街還開著的餐廳不多 → 溫泉街還開著的餐廳不多**了**

### 模式 G：壓縮句拆開、補上關係

- 層雲峽溫泉街有餐廳可以挑 → 層雲峽溫泉街**就好多了**，有餐廳可以挑
- 到的時候已經是下午 → **不過**到的時候已經是下午**了**
- 趕上了18:34就到層雲峽 → **理論上**趕得上的話18:34就**能**到層雲峽
- 不要指望這班，排行程時直接抓18:25那班 → 不要指望這班**比較好**，排行程時直接抓18:25那班**就好**
