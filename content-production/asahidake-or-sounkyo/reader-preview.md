# 旭岳與層雲峽怎麼選、怎麼一起排，黑岳到旭岳縱走與兩地交通

旭岳是北海道最高峰，標高2,291公尺，從旭岳溫泉搭纜車就能一路上到約1,600公尺的姿見站。層雲峽是石狩川切出來的斷崖峽谷，綿延約24公里，谷底就是大雪山系最大的溫泉街。

這兩個地方常排在同一趟大雪山行程裡，搭大眾運輸都是從JR旭川站發車。兩地之間移動要先回旭川站前轉車，接得最順也要3小時53分；開車大約2小時30分。夏天還有一種走法，從黑岳那一側上山，一路走到旭岳纜車，黑岳纜車官網寫的是約7小時。

## 旭岳與層雲峽差在哪

兩地都能搭纜車上山，旭岳的纜車停得比較高，山腳下的溫泉地也大不相同。

| 項目 | 旭岳 | 層雲峽 |
|---|---|---|
| 從旭川站前的巴士 | いで湯號一天4班，約1小時48分 | 道北巴士直達一天7班，1小時59分 |
| 旭川站前發的末班 | 14:15發、16:03到 | 18:25發、20:24到 |
| 巴士單程車資 | 大人2,300日圓 | 大人2,140日圓 |
| 纜車 | 旭岳纜車，約1,100公尺上到約1,600公尺的姿見站，單程約10分 | 黑岳纜車，670公尺上到1,300公尺的五合目，約7分，再轉吊椅到1,520公尺的七合目 |
| 纜車大人來回 | 6/1～10/31 3,500日圓，11/1～5/31 2,800日圓，含稅 | 3,000日圓，含稅，到2027/5/31 |
| 山上散步 | 姿見の池散策路一圈約1小時、約1.7公里，6月～10月中旬 | 五合目一圈約30分，七合目單程約15分的步道 |
| 山腳下 | 沒有溫泉街，住宿分散在樹林裡 | 大雪山系最大的溫泉街，觀光協會列出11間住宿 |
| 吃飯與現金 | 遊客中心列出的只有纜車山麓站食堂、賣店與一家便利商店，周邊沒有ATM | 溫泉街有多家餐廳，冬天晚上還開的只剩3家左右 |

旭岳的纜車一下車就是高山。沿著姿見の池散策路走，可以看到冒著煙的地獄谷、舊火口姿見の池與夫婦池，運氣好還會遇到花栗鼠。層雲峽的黑岳纜車只到五合目，再往上要轉吊椅，山頂還得自己爬。從七合目登山口爬到黑岳山頂，上行約1個半小時。

山腳下的差別更大。旭岳溫泉沒有溫泉街，建築有高度限制，一棟棟隔著距離散在樹林裡。遊客中心列出的吃飯地點，只有纜車山麓站的食堂、賣店，加上ラビスタ大雪山的便利商店。周邊也沒有銀行與郵局，最近的ATM開車要30到40分鐘，現金最好出發前就備齊。層雲峽溫泉街有餐廳可以挑，日歸溫泉黒岳の湯5月到10月開到22:00。只不過到了冬天，晚上還開著的餐廳就剩少數幾家。旭岳一帶的設施與季節，見旭岳。層雲峽溫泉街與景點，見層雲峽。

### 只去一個的話選哪個

只有一天、又想站上大雪山的高處，選旭岳最省力，搭纜車約10分鐘就到姿見站。散策路一圈約1小時，不用登山也看得到火口池。散策路只在6月到10月中旬開放。2026年10月2日旭岳初冠雪，當天路面就有部分結冰、積雪。

如果想住在溫泉街、晚上有地方吃飯，或是下午才從旭川出發，就選層雲峽。往層雲峽的道北巴士一天7班，末班18:25才發車，往旭岳的いで湯號末班則是14:15。層雲峽也有不用爬坡的景點，銀河瀑布與流星瀑布都入選日本の滝百選，全年開放，也不收費。

## 旭岳與層雲峽的紅葉與雪季

大雪山的紅葉從山頂一路往下染，從黑岳山頂開始變色，到層雲峽溫泉街轉紅，前後差了將近一個月。

| 地點 | 紅葉時期 |
|---|---|
| 黑岳山頂附近 | 9月上旬開始變色 |
| 旭岳姿見一帶 | 9月中旬～下旬，之後一天天往下移到旭岳溫泉 |
| 赤岳銀泉台 | 9月中旬高峰，紅葉期有自用車管制 |
| 層雲峽溫泉街 | 2026年10月初轉紅，見頃到10月12日體育節連假前後 |
| 天人峽 | 10月初旬 |

想看高山紅葉，9月中旬可以去旭岳姿見一帶，或從層雲峽開車約50分鐘到赤岳銀泉台。只是遊客中心也提醒，姿見最漂亮的時候每年前後差很多。10月才出發，就以層雲峽溫泉街與峽谷為主。

到了雪季，兩邊都能滑雪。旭岳滑雪路線從12月開到5月，觀光協會說是全日本開放最久的。這裡也被稱為進階滑雪者的山岳滑雪聖地。旭岳溫泉另有約8公里、分成3條的越野滑雪路線，11月到5月都能用。黑岳滑雪場2026到2027年這一季預定12月1日開幕、5月5日結束，實際哪天開還要看積雪。不滑雪也可以去層雲峽看冰瀑祭，2027年是1月23日到3月7日。

2026年初冬兩邊的纜車都停駛整備，黑岳纜車11月9日到30日，旭岳纜車11月16日到12月10日。兩段重疊的11月16日到30日，兩邊都上不了山。

## 從旭岳到層雲峽怎麼移動

搭大眾運輸，兩地都從旭川站出發，往旭岳搭旭川電氣軌道的いで湯號，往層雲峽搭道北巴士。在兩地之間移動，要在旭川站前的巴士站バスタッチ轉車。いで湯號在9號乘車處上下車，道北巴士在8號乘車處上車，下車則在標著「降」的下車處。

開車約2小時30分，是旭岳纜車官網寫的時間。いで湯號的時刻，見旭岳交通。道北巴士的班次，見層雲峽交通。

## 旭岳與層雲峽一起排的天數

搭巴士一起排，至少要兩天一夜，光是兩地之間單程就要將近4小時。一天之內，只夠在其中一地待一個上午。最緊的排法是早上看旭岳、下午移到層雲峽住：從旭川站前搭7:15的いで湯號，9:03到旭岳。接著搭11:55的車回旭川，轉14:25的道北巴士，16:24到層雲峽。這段時間夠搭纜車上姿見站、走完一圈約1小時的散策路，但沒有時間登旭岳山頂。

反過來先住層雲峽，隔天搭10:10的巴士，14:03到旭岳，晚上住旭岳溫泉。到的時候已經是下午，2026年10月21日起纜車上行末班是15:40。夏天的營業時間比較寬，7月到9月的平日開到17:30。

想兩邊都搭纜車上山、又不想天天趕車，排三天兩夜會寬鬆許多，旭岳溫泉與層雲峽各住一晚。

- 第一天：旭川站前7:15或9:15搭いで湯號，9:03或11:03到旭岳，下午上姿見站，住旭岳溫泉。
- 第二天：旭岳9:55或11:55發，在旭川轉道北巴士，15:24或16:24到層雲峽，傍晚逛銀河、流星瀑布或泡黒岳の湯。
- 第三天：上午搭黑岳纜車與吊椅上七合目，下午搭13:30或14:40發的道北巴士回旭川，15:25或16:35到。

自己開車，兩天一夜也排得開。

## 黑岳到旭岳縱走

黑岳到旭岳的縱走是一日路線，從黑岳搭纜車、吊椅上到七合目，一路走到旭岳纜車的姿見站。從旭岳下到姿見的後半段，就是大雪山國立公園連絡協議會說的「大雪山主路線」。

要走多久，官方有兩個數字。黑岳纜車官網寫的是七合目登山口到姿見站約7小時。協議會公告的2026年回程巴士傳單，寫的則是黑岳⇔旭岳的標準路線時間8到9小時，並提醒時間抓寬一點。排行程時照長的8到9小時估，比較保險。

旭岳到姿見這一段是碎石坡，又是沒有遮蔽、強風直吹的風衝地，天氣一變，能見度很快就變差。起濃霧時從旭岳下山容易迷路，過去也發生過山難。

縱走要兩邊的纜車都在開。2026年黑岳吊椅的夏季營業是6月27日到10月15日。但大雪山10月初山頂一帶就會積雪、登山道被雪埋住，只帶夏季登山裝備能走的時間，大約只到9月。同一年黑岳纜車更換車廂，6月26日前停駛，協議會也提醒那段時間縱走改走別的路線。

夏季從黑岳出發，纜車6:00、吊椅6:30開始營業。吊椅單程15分，最早大約6:45到七合目。黑岳纜車與吊椅的時間，見層雲峽纜車與黑岳登山。

2026年兩邊的纜車合賣過一張「TAISETSU縱走PASS」，由大雪カムイミンタラDMO發行。6月27日到9月30日販售，一張4,600日圓含稅。內容是兩邊纜車的單程，外加限定貼紙與大塚製藥的補給品。黑岳這一側的單程連吊椅也包在內。照當年的價格分開買，旭岳纜車夏季單程2,200日圓加黑岳的纜車吊椅套票單程2,400日圓，合計也是4,600日圓。

價錢一樣，PASS的好處是天氣變差或身體撐不住時，可以改當其中一邊纜車的來回票用。只是它只收現金，任何情況都不退款，9月28日時部分販售處已經賣完。黑岳的纜車吊椅套票單程，2027年6月起會漲到2,800日圓。

### 縱走前要準備的事

出發前要向北海道警察提交登山計畫書，可以線上提交，到了登山口另外還有入林登記表（入林屆）要填。沒有常設廁所的地方要用攜帶式廁所，自然公園法有規範，不能把排泄物留在登山道上。登山計畫書與攜帶式廁所，見旭岳登山。

從黑岳出發，纜車五合目的黑岳站是最後一間廁所，吊椅的乘車處、下車處與七合目都沒有。途中的黑岳石室夏季有管理人，生質廁所每次付500日圓協力金。有人管理的期間一結束，廁所也跟著關閉，2025年是10月5日結束。

協議會建議帶上下分開的雨具、刷毛或羽絨保暖衣、紙本地圖、頭燈、熊鈴與防熊噴霧。夏季的水要1.5公升以上，輕冰爪與付廁所協力金的現金也要帶，地圖不能只靠登山App。大雪山到8月中旬都還有雪溪，9月隨時可能下雪，9月下旬日落約17點。旭岳遊客中心也提醒，10月到11月容易有人因為裝備不足而出事、遇上山難。2026年9月到10月，裾合平方向的登山道一帶還記錄到棕熊的糞。

想分兩天走，可以住黑岳石室，大人協力金2,000日圓，不接受預約，當天先到先住。石室不供餐、幾乎沒有手機訊號。水要用煮沸的雨水，不然就走到往返約30到40分鐘的北海澤取水。

### 縱走下山後怎麼回去

從黑岳走到旭岳，最後搭旭岳纜車約10分鐘下到旭岳溫泉。過去有人錯過下行末班，被別人報警，最後當成山難處理。要纜車在營業時間外緊急開一趟，除了車資還要另付費用。姿見站的下行末班，見旭岳纜車與姿見の池。

想從旭岳回層雲峽，路線巴士要經旭川轉車，最晚要搭旭岳14:55發的いで湯號。16:33到旭川後，再轉18:25的道北巴士，20:24到層雲峽。

反方向從旭岳走到黑岳也走得通，只是黑岳纜車公布的約7小時，是黑岳往旭岳的方向。這個方向下山後，搭路線巴士當天回不了旭岳溫泉。夏季旭岳纜車週末連假6:00、平日6:30開始營業。另一頭的黑岳吊椅營業到17:30、纜車到18:00。從層雲峽搭14:40或17:00的道北巴士，分別在16:35、18:55到旭川。可是旭川往旭岳的いで湯號末班是14:15發，當天接不上。這個方向走完，可以當晚住層雲峽，隔天搭10:10的巴士，14:03回到旭岳。

2026年夏天另外有免費的縱走回程巴士（縦走リターンBUS），由あさひかわ交通運行。行駛日是7月下旬到9月下旬的指定日，把走完全程的人從另一側的纜車載回出發地。要搭回程巴士，就在出發那一側的纜車窗口說「縦走バス利用」，領一張免費乘車券。窗口開門後收到早上8:00為止，名額20人，先到先登記。

走到另一側的纜車下山後，到指定乘車處搭16:00發的車，預定18:30回到出發地。巴士一律準時發車，沒到或打電話說會晚都不等。額滿就要改搭路線巴士，中途也不能下車。回程巴士和縱走PASS是不同的服務，PASS的票根不能當乘車券，買票時要另外說要搭回程巴士。

巴士16:00發車，窗口又只收到早上8:00，這一天的時間最好排得寬一點。PASS與回程巴士都是2026年夏季的做法。隔年辦不辦、怎麼賣，出發前看大雪カムイミンタラDMO的北海道まんなか觀光ナビ，或兩邊纜車的官網。
