## 2. 各篇的順序

**A（Funliday 10 大景點）**
- 開頭：島的位置與暱稱 → 有什麼可看（花、海岸、海鮮）→ 本文會整理什麼
- 前往禮文島：從稚內港搭船 → 怎麼訂 → 季節班次
- 景點 1～10：澄海岬、須古頓岬、金田之岬、高山植物園、桃岩展望台、北方金絲雀公園、禮文瀑布、元地海岸、桃台貓台、薄雪之湯。大致從北端往西岸、南部排，最後用溫泉收
- 每個景點：一段描述（看到什麼、為什麼有名）→ 條列資訊卡（地址、Map code、時間或開放季）
- FAQ 5 題：在哪、怎麼去、是不是日本最北、自然景觀、最佳季節

**B（Funliday 稚內交通與景點）**
- 開頭：稚內的位置 → 從旭川多遠 → 兩座島是來稚內的理由
- 船票：車站走到港口 → 訂票 → 季節班次 → 艙等與費用
- 禮文島交通：吃住集中在香深港附近 → 租車、一日券、觀光巴士三個選項，各自價格、限制、官方連結
- 禮文島景點：桃岩展望台、北方金絲雀公園、須古頓岬、金田之岬，每個一段描述加資訊卡
- 結尾：一天走完或住幾晚都可以

**C（日本國家旅遊局）**
- 開頭一段：位置與氣候 → 為什麼有這些植物 → 招牌步道與沿途亮點 → 行程時間、住宿、渡輪接駁
- 交通段：一段一段寫怎麼從本島到島上，每段附時間
- 業者資訊框：地址、所需時間、預約連結

**D（北海道觀光機構繁中行程）**
- 概要：風景、氣候、海鮮 → 提醒停靠點與菜單可能變動
- 停靠點索引（編號列表）
- 每天：每站前一行先寫「開車約幾分鐘、幾點左右」→ 標題與一句標語 → 描述 2～4 段 → 資訊框（地址、電話、時間、休息日、官網）→ 側欄小提醒

## 3. 開頭怎麼寫

- A、B、C 都先講「島在哪、為什麼有名」（最北、花之浮島），再一句帶到本文整理了什麼。交通與開放期間都要等到第二節以後。
- D 先寫景色與季節，再補一句提醒資訊可能變動。
- 共同點：開頭不給數字，用暱稱與畫面感起頭。本站開頭直接回答（景點數、開車多久、什麼月份開），順序上可以先一句點出南北兩區的分布，再接時間與開放月份，讀者不用等到第二節才知道怎麼排。

## 4. 關鍵問題怎麼回答

**各景點怎麼去**
- A：每個景點的交通藏在資訊卡最後，只寫地址與 Map code，很少寫從港口多久。沒有總表。
- B：先把「島上怎麼移動」獨立成一節（租車 → 一日券 → 觀光巴士），每個選項先講適合誰、再講價格與限制；景點段落只寫步行時間。
- D：每站前面先寫移動方式與時間，再介紹景點，讀者跟著時間軸讀。
- 共同點：沒有人做「景點 × 怎麼去」的總表。本站第一節的總表是差異點，保留。

**開放期間**
- A、B：寫在每個景點資訊卡的「營業時間」，月份範圍放在時間前面（先月份、再幾點到幾點、最後休館）。
- D：資訊框固定順序是地址 → 電話 → 時間 → 休息日。
- 沒有人把各設施的開放期間整理成一張表，也沒人提醒冬天哪些關。本站最後一節的表是差異點。

**觀光巴士**
- B：先講路線（A 上午、B 下午）→ 停哪些點 → 價格 → 要預約。
- 搜尋摘要裡的部落格順序是：A、B 兩條 → 配合渡輪 → 繞完可以吃飯再搭船。讀者在意的是「接不接得上船」。

## 5. 段落與句子的習慣

- Funliday 句子長、逗號多，常用驚嘆與「超」「絕對」，稱讀者「你」「大家」。轉場靠「首先」「除了…之外」「最後」。本站不學這種口吻與長句，只學順序。
- 北海道觀光機構繁中版：中長句，用「您」，常用「不妨」。時間數字放在每站最前面，像時間軸。
- 數字位置：價格與時間大多集中在條列資訊卡，正文段落只放步行時間或「約幾分鐘」。
- 沒有人用表格，全部用條列資訊卡。本站的基本資訊欄（表格）比較好掃，照舊。
- 景點描述的順序很一致：外觀或看得到什麼 → 為什麼有名（電影、最北、禮文藍）→ 一句建議（夕陽、帶外套）→ 資訊卡。

## 6. 給作者的順序建議

標題照現在的 `draft-tagged.md`，只調每節裡的資訊順序。

- **H1 下的開頭**：先一句南北兩區、離港口多遠 → 再講開放月份 → 最後內連句。
- **禮文島有哪些景點？**：先南北兩區的分布 → 總表 → 沒車的話最省事的是觀光巴士（停哪些點 → 哪些月份 → 怎麼買票）→ 路線巴士不停的三處 → 地圖上其他地點與步道內連。觀光巴士的價格與付款放在段落最後，不要排在停靠點前面。
- **禮文島景點一天怎麼排？**：先講搭哪兩班船、在島上待多久 → 時間軸表 → 船到港與觀光巴士只差 15 分鐘的提醒 → 想早回或晚到的替代 → 不搭巴士的走路、自行車、租車。讀者最在意「接不接得上船」，提醒放在表格後第一段。
- **薄雪之湯**：先離港口多近、適合等船時去 → 營業時間 → 看得到什麼 → 費用與一日券折扣。
- **南部的奇岩與觀景點，各 H3**：先外觀與為什麼有名 → 怎麼去（開車、巴士、走路）→ 注意事項（海岸線不通、強風濃霧、冬季步道）。目前地藏岩、桃岩展望台已是這個順序。
- **北方金絲雀公園**：先位置與離港口多遠 → 開放月份與時間 → 咖啡另有營業日 → 怎麼去。H3 電影外景地照「看到什麼 → 為什麼有名 → 建議先看電影」。
- **高山植物園**：先說它能補群生地花期 → 展示什麼 → 開放與門票 → 怎麼去。群生地的期間改用重查後的說法（5 月中旬～6 月上旬，2026 年 5/15 起開放）。
- **北部的岬，各 H3**：先看到什麼（禮文藍、弧形入江；海馬島、庫頁島）→ 怎麼去（開車、觀光巴士、路線巴士與步道）→ 店家或附帶資訊。須古頓岬不要寫成「日本最北端」，用 F562。
- **開放期間**：先一句「6 到 9 月最齊」→ 表 → 冬天還能做什麼。

## 7. 他們有、我們缺的

- **須古頓岬是不是日本最北端**：競品寫成「日本國土最北端」。北海道觀光機構寫它在宗谷岬南邊、稱「日本最北限の岬」，已加 F562。正文可以順帶澄清，但不寫成糾錯口吻。
- **澄海岬看到什麼**：競品寫弧形海灣與展望台。已加 F563（弧形大入江與斷崖）。競品寫的「有一小段階梯通往展望台」官方沒寫，不加。
- **金田之岬的海豹季節與位置**：競品寫初夏到初冬比較看得到。官方只有ぶらりMAP 的「海豹群」標示（F422），觀光協會網站今天打不開，查不到季節、位置與停車，不寫。
- **日本最北端到達證明書**：競品說須古頓岬的土產店賣得到。島の人官網沒寫，查不到，不寫。
- **一日券值不值得買**：B 寫班次少、要規劃好。一日券本身歸 `rebun-island-transport`，本頁不擴寫。
- **步道健行時間與難度**：A、C 寫了步道。歸 `rebun-island-hiking`，本頁照舊只帶過並連過去。
