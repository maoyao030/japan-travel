# 禮文島景點，澄海岬、北方金絲雀公園怎麼去與開放期間

禮文島景點分成南北兩區。南邊的地藏岩、桃岩展望台與北方金絲雀公園離香深港開車都在10分鐘以內，北邊的澄海岬約50分鐘，島最北端的須古頓岬約60分鐘。景點大多在戶外。有室內展示的設施只在春末到秋天開放，北方金絲雀公園是5月到10月，高山植物園是5月到9月。沒有車的話，6月到9月搭早班船抵達後接上8:40的觀光巴士禮文A，一個上午就能看完北部的澄海岬、須古頓岬，和南部的桃台貓台、北方金絲雀公園。

還沒決定要不要排禮文島，可以先看禮文島值得去嗎。

## 禮文島有哪些景點？

島上的景點大致分成南北兩區。南部的地藏岩、桃台貓台、桃岩展望台與北方金絲雀公園都在香深港附近，開車10分鐘以內就到。北部的高山植物園開車約30分鐘，澄海岬約50分鐘，須古頓岬約60分鐘。郭洛塔岬也在北部，位在連接這幾個岬角的巡岬步道上。

| 景點 | 位置 | 從香深港開車 | 不開車怎麼去 |
|---|---|---|---|
| 北方金絲雀公園 | 香深奮部 | 約5分鐘 | 觀光巴士禮文A |
| 地藏岩 | 元地海岸 | 約10分鐘 | 路線巴士元地線開往終點元地 |
| 桃台貓台 | 元地的高台 | 約10分鐘 | 觀光巴士禮文A，6月到9月另有觀光接駁巴士 |
| 桃岩展望台 | 桃岩周邊 | 約10分鐘 | 到渡輪站1樓的觀光案內所問走法 |
| 高山植物園 | 船泊村上泊 | 約30分鐘 | 不在禮文A路線上，到觀光案內所問走法 |
| 澄海岬 | 船泊西上泊 | 約50分鐘 | 觀光巴士禮文A、禮文B停靠 |
| 須古頓岬 | 島的最北端 | 約60分鐘 | 路線巴士禮文線②的終點 |
| 郭洛塔岬 | 巡岬步道上 | 可開車，停車場3台 | 路線巴士禮文線②到江戶屋站，再走約30分鐘 |

沒有車，最省事的是搭宗谷巴士的定期觀光巴士禮文A，一趟就繞過澄海岬、須古頓岬、桃台貓台與北方金絲雀公園。2026年的行駛期間是5月3日到5日、5月20日到9月30日，搭車日的2個月前開始接受預約。預約可以打電話、到窗口，或用巴士訂票網站Hassha Orai Net（発車オーライネット）。網路預約在線上付款後，收到的付款完成通知畫面就是車票；電話預約會拿到11位數的預約號碼，搭車當天到窗口付款取票。當天有空位也能直接上車，不過可能客滿，日子排好了就先預約比較穩。窗口在香深港渡輪站1樓下行手扶梯與電梯旁的「切符売場」，在這裡付款只收現金或PayPay，不收信用卡，沒在網路先付的話要準備現金。票價禮文A大人3,600日圓，禮文B大人3,300日圓。

不搭禮文A的話，桃台貓台在6月到9月另有觀光接駁巴士。

北部另外還有久種湖與日食觀測紀念碑。想把這些地點和禮文敦盛草群生地沿著步道走成一條路線，可以看禮文島健行，各條步道怎麼走、要走多久都整理在那一頁。

## 禮文島景點一天怎麼排？

從稚內當天來回，2026年6月到9月搭6:30的船去、17:10的船回，是在島上待最久的排法。上岸後接8:40的觀光巴士禮文A，一個上午就能繞完澄海岬、須古頓岬與桃台貓台，回程再經過北方金絲雀公園，下午留給泡湯或在港邊休息。地藏岩與桃岩展望台不在禮文A的路線上，下午想去地藏岩，可以搭路線巴士元地線。

| 時間 | 行程 |
|---|---|
| 6:30 | 稚內港搭渡輪出發 |
| 8:25 | 抵達香深港 |
| 8:40 | 搭觀光巴士禮文A，經澄海岬、須古頓岬、桃台貓台 |
| 11:45左右 | 6月到9月可在渡輪站中途下車，不去北方金絲雀公園就在這裡下車 |
| 12:30 | 經北方金絲雀公園回到渡輪站 |
| 下午 | 到渡輪站旁的薄雪之湯泡湯 |
| 17:10 | 香深港搭渡輪回稚內 |

船到港和觀光巴士發車只差15分鐘。宗谷巴士說有15分鐘以上就趕得上，不過船上人多時最好提早到下船口等。觀光巴士的乘車處在渡輪站側面，不在正門口的路線巴士站。回程搭2等艙的話，開船40分鐘前要在渡輪站辦好乘船手續。

想早點回稚內，可以改搭14:20的船。禮文A在12:30回到渡輪站，接這班船來得及。從稚內搭10:30那班過來，12:25才到，已經趕不上當天的禮文A，排南部的景點就夠了。下午14:15出發的禮文B也會繞到澄海岬與須古頓岬，但16:40才回到渡輪站，17:10那班船2等艙的報到時間已經過了。因此禮文B適合排在島上住一晚、隔天再搭船的行程。

觀光巴士沒開或客滿時，可以改租車。島上的租車在離渡輪站走路1分鐘的Toyota Rent a Lease（トヨタレンタリース），車不多，打算開車最好早點預約。不跟觀光巴士、想自己用路線巴士或租車排一天，可以看另外整理的禮文島交通，班次、一日券、租車和計程車都寫在那裡。

## 禮文島香深港旁的薄雪之湯

禮文島溫泉薄雪之湯離香深港渡輪站走路約3分鐘，等回程船時去泡最順路。4月到9月從12:00開到22:00，10月到3月是13:00到21:00，全年無休。這裡是源泉放流的溫泉，泡在露天風呂裡望得到利尻山，另外也有三溫暖。入浴費600日圓，出示當天用過的路線巴士一日券是500日圓。想包租家庭浴池要事先預約。毛巾可以付費租借。

## 禮文島南部的奇岩與觀景點

地藏岩、桃台貓台與桃岩展望台離香深港都不遠，開車大約10分鐘，停車場也都免費。

### 地藏岩

地藏岩是元地海岸上高約50公尺的奇岩，兩塊岩石彼此靠著，看起來像朝海合掌。這一帶以夕陽沉入西邊海面出名，旁邊的瑪瑙海岸還能看到瑪瑙原石。

從香深港開車大約10分鐘，有20個免費車位。路線巴士元地線從渡輪站開到終點元地，車資520日圓。想待到夕陽再走，回程可以叫島上的禮文計程車（礼文ハイヤー）或Ishido計程車（イシドウハイヤー）來接。不會講日文的話，可以請住宿的旅館幫忙叫車。

| 項目 | 內容 |
|---|---|
| 日文名 | 地蔵岩 |
| 怎麼去 | 香深港開車約10分鐘 |
| 路線巴士 | 元地線到元地，520日圓 |
| 停車場 | 20台，免費 |

### 桃台貓台

桃台貓台是元地高台上的觀景點，從這裡看得到形狀像桃子的巨大桃岩，和海上像一隻貓的貓岩，天氣好時還望得到遠方的地藏岩。觀光巴士禮文A會停這一站，搭禮文A就不用另外安排。

不搭禮文A的話，開車約10分鐘，停車場有20台。6月到9月另有觀光接駁巴士可搭。

| 項目 | 內容 |
|---|---|
| 日文名 | 桃台猫台 |
| 怎麼去 | 香深港開車約10分鐘 |
| 停車場 | 20台，免費 |

### 桃岩展望台

桃岩展望台在高台上，望得到形狀像桃子的巨大桃岩和海上的貓岩，周邊是一片高山植物群落。這片群落在2022年列為國家天然紀念物。視野和步道的通行狀況都會跟著天候變化，天氣不好的日子不一定看得清楚。

從香深港開車約10分鐘，停車場12台免費。想走步道上去，抵達時先到渡輪站1樓的觀光案內所問當天的路況。

| 怎麼去 | 香深港開車約10分鐘 |
| 停車場 | 12台，免費 |

## 禮文島的北方金絲雀公園

位在香深奮部的北方金絲雀公園離香深港開車約5分鐘，是離港口最近的景點。5月到10月每天9:00到17:00開放，11月到隔年4月左右休館。園內附設金絲雀咖啡，營業時間和公園不同，週二、週三公休。

觀光巴士禮文A回渡輪站前，最後停的就是這裡。自己開車前往，有10個免費車位。

| 項目 | 內容 |
|---|---|
| 日文名 | 北のカナリアパーク |
| 開放 | 5月～10月，9:00～17:00，無休 |
| 怎麼去 | 香深港開車約5分鐘，觀光巴士禮文A停靠 |
| 停車場 | 10台，免費 |

### 吉永小百合主演電影的外景地

園內保存的木造校舍，是2012年上映、吉永小百合主演的電影（北のカナリアたち）拍攝時用的「麗端小學校岬分校」。校舍裡重現了電影中的教室，也展示劇照與演員穿過的戲服。先看過電影再去，可以一一對照片中的場景。

## 禮文島高山植物園

錯過了禮文敦盛草群生地的花期，還可以到高山植物園看。群生地只在5月中旬到6月上旬開放，日期依開花狀況變動。植物園有控溫，禮文敦盛草能看到8月初左右。園內展示約50種、大約1萬株高山植物。

植物園5月到9月開放，時間是9:00到17:00。5月到8月無休，9月逢週日休館，門票大人310日圓、小孩160日圓。位置在北部的船泊村上泊，從香深港開車約30分鐘。植物園不在禮文A的路線上，不開車的話，可以到渡輪站1樓的觀光案內所問怎麼去。

## 禮文島北部的岬

北部的須古頓岬、郭洛塔岬與澄海岬，都在串起北部岬角的巡岬步道沿線。從香深港開車過去要50到60分鐘，觀光巴士禮文A與禮文B也都會繞到澄海岬與須古頓岬。

### 澄海岬

澄海岬位在船泊西上泊。從高台望下去，是一道畫成弧形的大入江，四周圍著斷崖。海水清澈，夏天隨光線變成藍綠色或翡翠色，這種海色有個名字叫禮文藍（レブンブルー）。觀光巴士路線表上的「スカイ岬」就是這裡，讀作Sukai Misaki（すかいみさき）。

開車約50分鐘，有20個免費車位。路線巴士沒有停澄海岬，不開車的話，搭觀光巴士禮文A或禮文B最省事。

| 項目 | 內容 |
|---|---|
| 日文名 | 澄海岬 |
| 怎麼去 | 香深港開車約50分鐘，觀光巴士禮文A、禮文B停靠 |
| 停車場 | 20台，免費 |

### 須古頓岬

須古頓岬是禮文島的最北端，正前方約1公里的海上是無人島海馬島，島上立著海馬島燈塔。天氣晴朗時，還能遠望海對面的庫頁島。岬角的位置比北海道本島最北端的宗谷岬偏南，所以有「日本最北限的岬」這個稱呼。岬上的土產店島之人（島の人）賣昆布霜淇淋，2026年的營業期間是5月11日到9月30日，時間是8:00到17:00。

開車約60分鐘，停車場20台免費。岬上就有巴士站，路線巴士禮文線②從渡輪站一路開到這裡，車資1,400日圓。巡岬步道也是從這一帶起步。

| 項目 | 內容 |
|---|---|
| 日文名 | スコトン岬 |
| 怎麼去 | 香深港開車約60分鐘，路線巴士禮文線②終點 |
| 車資 | 渡輪站出發1,400日圓 |
| 停車場 | 20台，免費 |

### 郭洛塔岬

郭洛塔岬是巡岬步道上標高176公尺的岬角。岬的另一側是圓石灘Teppu海岸（テップ海岸），可以在石頭間找找天然穿孔的貝殼（穴あき貝）。

停車場只有3台。搭路線巴士禮文線②在江戶屋站下車，再走30分鐘左右。從須古頓岬走過來，第一段的江戶屋山道是鋪面道路。

| 日文名 | ゴロタ岬 |
| 怎麼去 | 路線巴士禮文線②到江戶屋站，再走約30分鐘 |
| 停車場 | 3台，免費 |

### 金田之岬

金田之岬（金田ノ岬）是禮文島幾處斑海豹上岸的地點之一。2010年前後的調查中，這裡的斑海豹從6月上旬開始變多，11月上旬以後又減少。想找海豹的話，抵達香深港時到渡輪站1樓的觀光案內所問位置和怎麼去。

## 禮文島景點的開放期間

想把景點一次看完，6月到9月最合適，因為禮文A、禮文B兩條觀光巴士都有開，北方金絲雀公園與高山植物園也都開放。花的種類最多是在6月中旬到8月初。禮文敦盛草的群生地5月中旬到6月上旬開放，6月中旬以後還想看，就到高山植物園。

| 景點或設施 | 開放期間 | 時間 |
|---|---|---|
| 北方金絲雀公園 | 5月～10月，無休 | 9:00～17:00 |
| 高山植物園 | 5月～9月，9月週日休 | 9:00～17:00 |
| 禮文敦盛草群生地 | 5月中旬～6月上旬，依開花變動，2026年5月15日起開放 | |
| 薄雪之湯 | 全年無休 | 4月～9月12:00～22:00，10月～3月13:00～21:00 |
| 觀光巴士禮文A | 2026年5月3日～5日、5月20日～9月30日 | 8:40發車 |
| 觀光巴士禮文B | 2026年6月1日～9月30日 | 14:15發車 |

到了10月，觀光巴士停駛，北方金絲雀公園也在10月底休館。冬天到島上的話，薄雪之湯照常營業到晚上21:00，可以排在搭船前去泡。
