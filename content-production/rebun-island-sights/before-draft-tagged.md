# 禮文島景點，澄海岬、北方金絲雀公園怎麼去與開放期間

禮文島景點分成南北兩區，南邊的地藏岩、桃岩展望台與北方金絲雀公園離香深港開車都在10分鐘以內，北邊的澄海岬約50分鐘，島最北端的須古頓岬約60分鐘[F74, F425, F431, F73, F428, F39]。景點大多在戶外，有室內展示的設施只在春末到秋天開放，北方金絲雀公園是5月到10月，高山植物園是5月到9月[F433, F437]。沒有車的話，6月到9月搭早班船抵達後接上8:40的觀光巴士禮文A，一個上午就能把南北兩區繞過一輪[F405, F26]。

還沒決定要不要排禮文島，可以先看禮文島值得去嗎。

## 禮文島有哪些景點？

島上的景點大致分成南北兩區。南部的地藏岩、桃台貓台、桃岩展望台與北方金絲雀公園都在香深港附近，開車10分鐘以內就到[F74, F436, F425, F431]。北部的高山植物園開車約30分鐘，澄海岬約50分鐘，須古頓岬約60分鐘[F438, F73, F428]。郭洛塔岬也在北部，位在連接這幾個岬角的巡岬步道上[F429]。

| 景點 | 位置 | 從香深港開車 | 不開車怎麼去 |
|---|---|---|---|
| 北方金絲雀公園 | 香深奮部 | 約5分鐘 [F431] | 觀光巴士禮文A或接駁巴士，或騎自行車約15分鐘 [F26, F421, F410] |
| 地藏岩 | 元地海岸 | 約10分鐘 [F74] | 路線巴士元地線開往終點元地 [F201] |
| 桃台貓台 | 元地的高台 | 約10分鐘 [F436] | 觀光巴士禮文A，6月到9月另有接駁巴士，或從渡輪站走約1小時 [F26, F421, F409] |
| 桃岩展望台 | 桃岩周邊 | 約10分鐘 [F425] | 從渡輪站走約1小時 [F407] |
| 高山植物園 | 船泊村上泊 | 約30分鐘 [F438] | 接駁巴士，不在禮文A路線上 [F421, F26] |

| 須古頓岬 | 島的最北端 | 約60分鐘 [F428] | 路線巴士禮文線②的終點 [F120, F203] |

沒有車，最省事的是搭宗谷巴士的定期觀光巴士禮文A，一趟就繞過澄海岬、須古頓岬、桃台貓台與北方金絲雀公園[F26]。2026年的行駛期間是5月3日到5日、5月20日到9月30日，搭車日的2個月前開始接受預約[F26, F28]。當天有空位也能直接上車，只是可能客滿，排好日子就先預約比較穩[F242]。車票在搭車當天到香深港渡輪站1樓的「切符売場」買，位置在下行手扶梯與電梯旁，只收現金或PayPay[F234, F93, F307]。票價禮文A大人3,600日圓，禮文B大人3,300日圓[F26, F27]。

路線巴士不停桃台貓台、北方金絲雀公園與高山植物園，這三處只停接駁巴士，桃台貓台的觀光接駁巴士在6月到9月行駛[F421]。其中桃台貓台與北方金絲雀公園搭禮文A就會到，真正要靠接駁巴士的是高山植物園[F26]。接駁巴士的班次可以到渡輪站1樓的觀光案內所問，案內所在4月中旬到10月中旬開放[F115]。

地圖上另外還有元地燈塔、瑪瑙濱、海馬島展望台、久種湖畔展望台與禮文瀑布等地點，詳細的步道地圖可以在案內所拿到[F423, F424]。想把這些地點和禮文敦盛草群生地沿著步道走成一條路線，可以看禮文島健行，各條步道怎麼走、要走多久都整理在那一頁。

## 禮文島景點一天怎麼排？

從稚內當天來回，6月到9月搭6:30的船去、17:10的船回，島上能待大約8小時，是時間最長的排法[F405]。上岸後接8:40的觀光巴士禮文A，北部的岬角和南部的展望台一個上午就能繞完，下午留給散步或泡湯[F405, F26]。

| 時間 | 行程 |
|---|---|
| 6:30 | 稚內港搭渡輪出發 [F405] |
| 8:25 | 抵達香深港 [F405] |
| 8:40 | 搭觀光巴士禮文A，經澄海岬、須古頓岬、桃台貓台 [F26] |
| 11:45左右 | 6月到9月可在渡輪站中途下車，不去北方金絲雀公園就在這裡下車 [F233, F26] |
| 12:30 | 經北方金絲雀公園回到渡輪站 [F26] |
| 下午 | 走到桃岩展望台來回，或到薄雪之湯泡湯 [F407, F435] |
| 17:10 | 香深港搭渡輪回稚內 [F405] |

船到港和觀光巴士發車只差15分鐘，宗谷巴士說15分鐘以上就趕得上，不過船上人多時，最好提早到下船口等[F306]。觀光巴士的乘車處在渡輪站側面，不在正門口的路線巴士站[F70]。下午從渡輪站走1小時左右就到桃岩展望台，在展望台周邊散步1小時再走回來，時間剛好[F407]。回程搭2等艙的話，開船40分鐘前要在渡輪站辦好乘船手續[F46]。

想早點回稚內，可以改搭14:20的船，禮文A在12:30回到渡輪站，接這班船來得及，島上大約待5小時[F405, F26]。從稚內搭10:30那班過來，12:25才到，島上只剩4小時左右，排南部的景點就夠了[F406]。下午14:15出發的禮文B也會繞到澄海岬與須古頓岬，但16:40才回到渡輪站，這時17:10那班船2等艙的報到時間已經過了[F27, F46, F81]。搭禮文B適合在島上住一晚、隔天再搭船。

觀光巴士沒開或客滿時，南部可以用走的繞一圈。從渡輪站走到桃台貓台大約1小時，再走30分鐘左右到瑪瑙濱，從瑪瑙濱走回渡輪站也是1小時左右[F409]。島上的CAT ROCK與禮文飯店（ホテル礼文）有出租自行車，從渡輪站騎到北方金絲雀公園大約15分鐘[F416, F410]。離渡輪站走路1分鐘的Toyota Rent a Lease（トヨタレンタリース）只有6台車，打算開車最好早點預約[F415]。不跟觀光巴士、想自己用路線巴士或租車排一天，可以看另外整理的禮文島交通，班次、一日券、租車和計程車都寫在那裡。

## 禮文島香深港旁的薄雪之湯

禮文島溫泉薄雪之湯離香深港渡輪站走路約3分鐘，等回程船時去泡最順路[F435]。4月到9月從12:00開到22:00，10月到3月是13:00到21:00，全年無休[F435]。這裡是源泉放流的溫泉，泡在露天風呂裡望得到利尻山，另外也有三溫暖[F435]。入浴費600日圓，出示當天用過的路線巴士一日券是500日圓[F64, F97]。想包租家庭浴池要事先預約，毛巾可以付費租借[F435]。

## 禮文島南部的奇岩與觀景點

地藏岩、桃台貓台與桃岩展望台離香深港都不遠，開車大約10分鐘，停車場也都免費[F74, F426, F436, F425]。

### 地藏岩

地藏岩是元地海岸上高約50公尺的奇岩，兩塊岩石彼此靠著，看起來像朝海合掌[F74, F426]。這一帶以夕陽沉入西邊海面出名，旁邊的瑪瑙海岸還能看到瑪瑙原石[F74, F426]。

從香深港開車大約10分鐘，有20個免費車位[F74, F426]。路線巴士元地線從渡輪站開到終點元地，車資520日圓[F201]。從地藏岩往北經禮文瀑布到宇遠內的海岸線不能通行，看完要沿原路回去[F237]。想待到夕陽再走，回程可以叫島上的禮文計程車（礼文ハイヤー）或Ishido計程車（イシドウハイヤー）來接[F414]。不會講日文，可以請住宿的旅館幫忙叫車。

### 桃台貓台

桃台貓台是元地高台上的觀景點，從這裡看得到形狀像桃子的巨大桃岩，和海上像一隻貓的貓岩，天氣好時還望得到遠方的地藏岩[F436, F316]。觀光巴士禮文A會停這一站，搭禮文A就不用另外安排[F26]。

開車約10分鐘，停車場20台[F436]。6月到9月另有觀光接駁巴士[F421]。從渡輪站走路大約1小時，沿著步行路線還能接著走到瑪瑙濱[F409]。

### 桃岩展望台

桃岩展望台標高225公尺，起霧又微風的清晨，冷霧壓在200公尺以下時，從這裡看得到雲海[F442]。展望台一帶的高山植物群落在2022年列為國家天然紀念物[F425]。標高雖然不到300公尺，強風和濃霧並不少見，帶件防風外套比較保險[F36]。

從渡輪站走上去大約1小時，開車約10分鐘，停車場12台免費[F407, F425]。從桃岩登山口到展望台這段都是鋪面路[F87]。2026年10月20日起進入冬季，桃岩展望台步道只開放渡輪站到展望台這一段，近道全部封閉，其他區段請不要進入[F495]。

## 禮文島的北方金絲雀公園

北方金絲雀公園在香深奮部，離香深港開車約5分鐘，是離港口最近的景點[F431]。5月到10月每天9:00到17:00開放，11月到隔年4月左右休館[F433, F431]。9:00到17:00開放的是校舍和廁所，園內的金絲雀咖啡另有營業日，2026年只開到8月29日，8月只有21、22、28、29日這4天[F105, F434]。

觀光巴士禮文A回渡輪站前，最後停的就是這裡[F26]。自己前往的話，從渡輪站騎自行車大約15分鐘，這裡也是接駁巴士的停靠站[F410, F421]。開車有10個免費車位[F431]。

### 吉永小百合主演電影的外景地

園內保存的木造校舍，是2012年上映、吉永小百合主演的電影（北のカナリアたち）拍攝時用的「麗端小學校岬分校」[F310, F432]。公園在2013年7月27日正式開園，校舍從此對外公開[F310]。校舍裡重現了電影中的教室，也展示劇照與演員穿過的戲服，先看過電影再去，可以一一對照片中的場景[F431]。

## 禮文島高山植物園

錯過了禮文敦盛草群生地的花期，還可以到高山植物園看。群生地只在5月中旬到6月上旬開放，日期依開花狀況變動，植物園有控溫，禮文敦盛草能看到8月初左右[F441, F438]。園內展示約50種、大約1萬株高山植物[F438]。

植物園5月到9月開放，時間是9:00到17:00，5月到8月無休，9月逢週日休館，門票大人310日圓、小孩160日圓[F437]。位置在北部的船泊村上泊，從香深港開車約30分鐘[F438]。植物園不在禮文A的路線上，不開車就搭接駁巴士，班次可以到渡輪站的觀光案內所問[F26, F421, F115]。

## 禮文島北部的岬

北部的須古頓岬、郭洛塔岬與澄海岬，由全長約12.4公里的巡岬步道串在一起，一路往南通到濱中[F37]。從香深港開車過去要50到60分鐘，觀光巴士禮文A與禮文B也都會繞到澄海岬與須古頓岬[F73, F428, F26, F27]。

### 澄海岬

澄海岬位在船泊西上泊，從高台望下去，是一道畫成弧形的大入江，四周圍著斷崖[F73, F563]。海水清澈，夏天隨光線變成藍綠色或翡翠色，這種海色有個名字叫禮文藍（レブンブルー）[F427, F73]。觀光巴士路線表上的「スカイ岬」就是這裡，讀作Sukai Misaki（すかいみさき）[F86]。

開車約50分鐘，有20個免費車位[F73]。路線巴士沒有停澄海岬，從濱中站沿巡岬步道走過去約3.4公里，大約1小時30分，回程同樣要走這段[F313, F211]。巡岬步道2026年10月20日起冬季封閉，這段路只能在開放期間走[F495]。不想來回走3小時，就搭觀光巴士[F211, F26]。

### 須古頓岬

須古頓岬是禮文島的最北端，正前方約1公里的海上是無人島海馬島，島上立著海馬島燈塔[F308, F428]。天氣晴朗時，還能遠望海對面的庫頁島[F39]。岬角的位置比北海道本島最北端的宗谷岬偏南，所以有「日本最北限的岬」這個稱呼[F562]。岬上的土產店島之人（島の人）有賣昆布霜淇淋，2026年在5月11日到9月30日營業，時間是8:00到17:00[F448, F453]。

開車約60分鐘，停車場20台免費[F428]。岬上就有巴士站，路線巴士禮文線②從渡輪站一路開到這裡，車資1,400日圓[F120, F203]。巡岬步道也是從這裡起步[F37]。

### 郭洛塔岬

郭洛塔岬是巡岬步道上標高176公尺的岬角[F429]。岬的另一側是圓石灘Teppu海岸（テップ海岸），可以在石頭間找找天然穿孔的貝殼（穴あき貝）[F430]。

停車場只有3台[F429]。搭路線巴士禮文線②從渡輪站坐大約55分鐘到江戶屋站，下車再走30分鐘左右[F313, F429]。從須古頓岬走過來，第一段的江戶屋山道是鋪面道路[F439]。

### 金田之岬

金田之岬一帶有海豹群，觀光協會的Burari MAP（ぶらりMAP）在岬旁標著「アザラシの群れ」[F422]。這份地圖放在禮文島觀光協會網站上，打開後找日文地名「金田ノ岬」就看得到位置，4月中旬到10月中旬也能到渡輪站1樓的觀光案內所拿詳細的地圖[F422, F424, F115]。

## 禮文島景點的開放期間

想把景點一次看完，6月到9月最合適，禮文A、禮文B兩條觀光巴士都有開，北方金絲雀公園與高山植物園也都開放[F26, F27, F433, F437]。花的種類最多是在6月中旬到8月初，禮文敦盛草則在5月下旬到6月中旬開花[F443]。

| 景點或設施 | 開放期間 | 時間 |
|---|---|---|
| 北方金絲雀公園 | 5月～10月，無休 [F433] | 9:00～17:00 [F433] |
| 高山植物園 | 5月～9月，9月週日休 [F437] | 9:00～17:00 [F437] |
| 禮文敦盛草群生地 | 5月中旬～6月上旬，依開花變動，2026年5月15日起開放 [F441, F561] | |
| 薄雪之湯 | 全年無休 [F435] | 4月～9月12:00～22:00，10月～3月13:00～21:00 [F435] |
| 觀光巴士禮文A | 2026年5月3日～5日、5月20日～9月30日 [F26] | 8:40發車 [F26] |
| 觀光巴士禮文B | 2026年6月1日～9月30日 [F27] | 14:15發車 [F27] |
| 步道 | 2026年禮文瀑布步道10月1日起封閉，巡岬步道等其他步道10月20日起封閉；禮文林道照常通行，桃岩展望台步道只開渡輪站到展望台 [F33, F495] | |
| 觀光案內所 | 4月中旬～10月中旬 [F115] | |

到了10月，觀光巴士停駛，步道陸續封閉，北方金絲雀公園也在10月底休館[F26, F33, F495, F433]。冬天到島上，薄雪之湯照常營業，開到晚上21:00，可以排在搭船前去泡[F435]。
