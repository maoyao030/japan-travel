# 宗谷岬交通，稚內到宗谷岬巴士、計程車與自駕

宗谷岬在稚內市區往東32公里外，是北海道本島的最北端，大眾運輸只有宗谷巴士的路線巴士。宗谷岬交通最容易卡住人的是班次，這條路線一天只有4個來回，從岬上回稚內的末班車是15:20。錯過末班車，當天就沒有巴士回市區，16:12以後從稚內出發的車也都沒有回程車。

開車從JR稚內站過去約40到50分鐘，可以順路開上用扇貝殼鋪成的白色道路。沒有車也去得了白色道路，夏天在岬上租自行車、走步道到宗谷站搭巴士，或坐停靠宗谷丘陵的Active Bus都行。還沒決定要不要排宗谷岬，可以先看宗谷岬值得去嗎。怎麼先到稚內，見稚內交通。

## 稚內到宗谷岬巴士的班次與末班

往宗谷岬的車是宗谷巴士的「天北宗谷岬線」，坐往浜頓別或鬼志別方向的班次。從稚內站前巴士總站的1號乘車處上車，大約50分鐘到宗谷岬。全年用同一份時刻表，不分平日假日，目前是2023年10月1日改正的版本。

去程，稚內往宗谷岬

| 稚內站前巴士總站出發 | 到宗谷岬 |
|---|---|
| 9:30 | 10:20 |
| 13:30 | 14:20 |
| 16:12 | 17:02 |
| 19:30 | 20:20 |

回程，宗谷岬往稚內

| 宗谷岬出發 | 到稚內站前巴士總站 |
|---|---|
| 7:21 | 8:26 |
| 8:44 | 9:46 |
| 11:04 | 12:04 |
| 15:20 | 16:18 |

岬上7:21和8:44開的兩班，比稚內首班車抵達的10:20還早。從稚內當天來回，能搭的回程只有11:04和15:20。班次少到宗谷巴士自己也在路線頁提醒別誤了車。遇到惡劣天氣可能停駛，當天想確認有沒有開，可以打給宗谷巴士稚內營業所0162-33-5515。

### 宗谷岬當天來回的三種排法

從稚內出發當天來回，接得上的組合只有三種。

- **上午去、中午前回**：搭9:30的車，10:20到，搭11:04的車回，12:04回到稚內。
- **下午去**：搭13:30的車，14:20到，只能搭15:20的末班車回，16:18回到稚內。
- **待一整天**：搭9:30的車去，搭15:20的末班車回。

稚內市觀光導覽手冊的模範路線，在宗谷岬排30分鐘、宗谷丘陵排1小時。只想在最北端之地碑前拍照、看看海峽，上午去中午前回就夠了，12:04回到稚內，下午還能排市區的行程。想走上宗谷丘陵或騎白色道路，就搭9:30去、末班車回，搭下午那班去的話，到了只剩一班車能回。

### 宗谷岬巴士的票價、一日券與付款方式

稚內站前巴士總站到宗谷岬單程1,600圓，兒童800圓。只往返宗谷岬，在總站窗口買2,880圓的「紀念來回乘車券」最划算，比單程買兩次的3,200圓省320圓。稚內路線巴士一日券大人3,300圓，同樣只在總站窗口賣，搭天北宗谷岬線只能坐到宗谷岬。它比來回券貴420圓，適合同一天還要搭市內其他路線的行程。

宗谷巴士收現金或PayPay，信用卡和交通IC卡都不能用，部分票種也不收PayPay。車上換零錢只收千圓鈔，出發前把千圓鈔和零錢備齊最穩當。

### 宗谷岬站的上下車與回程候車

宗谷岬不是這條路線的終點，去程要自己按鈴下車。回程在同一個站等往稚內站前巴士總站的車，到總站大約1小時。在室內等車，司機可能沒注意到有人要上車，最好站在站牌附近等，站牌的位置也會隨季節稍微移動。岬上風很強，等車時穿好防寒防風的外套。

夏天的Active Bus在宗谷岬上下車的地點和路線巴士站牌不同。它停在國道238號旁停車場的公共廁所附近，兩種車不要在同一處等。

### 夏季的定期觀光巴士

宗谷巴士的定期觀光巴士「稚內A」，8:00從稚內站前出發、11:50回到站前，途中經過宗谷丘陵並停靠宗谷岬，大人3,600圓。宗谷丘陵這一段只從車窗看，不下車。下午出發的「稚內B」大人3,900圓。不開車又想在同一個上午看到丘陵和岬角，稚內A比自己搭路線巴士省事。

觀光巴士只在夏季行駛，2026年是5月3日到5日與5月20日到9月30日，今年度已經結束。採預約制，乘車日2個月前開始受理。

### 元旦的日出接駁巴士

宗谷岬每年元旦有迎接日出的活動，2026年的日出是7:12。2026年元旦稚內的路線巴士全面停駛，天北宗谷岬線照常行駛，但首班9:30從稚內出發、10:20才到，趕不上日出。

看日出要搭活動的接駁巴士，2026年是6:00從稚內站前巴士總站出發、6:50到宗谷岬。回程8:00離開岬上，經野寒布岬9:30回到站前。大人3,000圓、兒童1,500圓，車票從前一天起在總站窗口買。這是2026年的安排，2027年的活動預定在1月1日舉辦。

現場只有飲料販賣機，除夕宗谷岬附近的餐飲店和商店也不營業，吃的東西要在市區買好。跨年到元旦清晨，岬上的氣溫會降到零下10度左右。

## 稚內宗谷岬交通的其他方式，計程車與自駕

時間配不上一天4班的巴士，從稚內前往宗谷岬就只剩計程車或開車。

### 從稚內搭計程車去宗谷岬

稚內市區到宗谷岬單程32公里，開車40到50分鐘，計程車走的也是這段路。車資和繞去白色道路的包車方案，可以到JR稚內站旁「キタカラ」1樓的稚內市觀光案內所詢問。案內所10:00到18:00開，12月31日到1月5日休息。

### 從稚內開車去宗谷岬與白色道路

從JR稚內站開車到宗谷岬約35公里，稚內市的導覽手冊寫約50分鐘，北海道的觀光推廣頁寫約40分鐘。宗谷岬公園停車場有72個車位，免費。從宗谷岬再開約10分鐘就到白色道路。

稚內市建議從宗谷岬那一側的起點進入白色道路，往宗谷地區的方向開，但汽車導航常把路線排成反方向，從終點那一頭開進去。出發前對照地圖，確認入口在宗谷岬側。觀光協會另外拜託開車的人在宗谷岬一帶上好廁所、在白色道路上減速互讓、絕對不要開進牧草地。終點的宗谷地區是住宅區，經過時要慢慢開。

2026年5月到10月左右的平日8:00到17:00前後，拆除風車的大型車經過時，白色道路一帶由交通引導員指揮單線交替通行。一天最多約20次，每次大約等5到10分鐘。白色道路11月中旬到隔年4月下旬封閉，2026年是4月24日開通。白色道路的開放季節與風車工程，整理在宗谷岬值得去嗎。

### 冬天開車去宗谷岬的雪路

積雪的季節，從市區開到宗谷岬要1小時左右，夏天大約40分鐘，路上可能結冰、遇到暴風雪或視線不良。白色道路冬季封閉，宗谷岬公園內往高台的道路也會封閉，2026年春天是4月10日16點才解除。冬天開車前往，行程以岬角一帶為主。

## 宗谷岬白色道路沒車怎麼辦？

沒有車也能走一趟白色道路，夏天可以在宗谷岬租自行車騎過去，或沿著步道從宗谷岬走到宗谷站搭巴士。6月到9月另有Active Bus，途中會在宗谷丘陵的攝影點停約5分鐘。白色道路是用稚內特產扇貝殼鋪成的路，全長約3公里，被列為稚內步道的路線，官方也推薦騎自行車。

這些走法都集中在夏天，白色道路11月中旬到4月下旬封閉。2026年稚內市有棕熊的目擊情報，觀光協會提醒清晨、傍晚與夜間外出特別注意。騎車和走步道都排在白天比較安心。

### 夏季的 Active Bus 停靠宗谷丘陵

宗谷巴士夏季的「日本のてっぺんでアクティブバス」往返稚內機場、宗谷岬與JR稚內站，途中在宗谷丘陵的攝影點停約5分鐘。2026年的行駛期間是6月1日到9月30日，今年已經停開。

| 區間 | 第1班 | 第2班 |
|---|---|---|
| 稚內機場往宗谷岬 | 13:20發，14:10到 | 15:30發，16:20到 |
| 宗谷岬往稚內站前巴士總站 | 16:00發，17:00到 | 17:00發，18:00到 |

不用預約、自由入座，客滿時可能上不了車。稚內機場到宗谷岬1,500圓，宗谷岬到JR稚內站2,000圓，帶自行車加500圓，只收現金。從稚內市區出發的話，去程搭路線巴士，回程改搭16:00或17:00的Active Bus，就能比15:20的末班車晚走。車資比路線巴士多400圓。

### 在宗谷岬租自行車騎白色道路

Base-Soya是宗谷岬的觀光服務台，離宗谷岬巴士站走路約3分鐘。夏季在這裡出租自行車，有電動越野車、電動登山車與一般登山車。2026年只在6月1日到9月30日開設，10:00到16:00，租車受理到15:00，2026年的營業在9月30日告一段落。JR稚內站旁「キタカラ」1樓的觀光案內所也出租，9:30到17:00，受理到16:00。

| 方案 | 電動車 | 一般車 |
|---|---|---|
| 2小時 | 2,000圓 | 1,000圓 |
| 4小時 | 2,500圓 | 1,500圓 |
| 一天，當天17:00前還 | 3,000圓 | 2,000圓 |
| 過夜，隔天17:00前還 | 不提供 | 4,000圓 |

租車要出示身分證件，護照也可以，沒帶證件就租不到。這裡可以用現金、信用卡、行動支付或交通IC卡付款，跟巴士只收現金或PayPay不同。

搭9:30的巴士10:20到宗谷岬，租電動車騎白色道路，再回來趕15:20的末班車，不開車也能把白色道路排進一天的行程。電動車4小時方案2,500圓，只比2小時多500圓，10:20到15:20之間時間還夠，選4小時騎起來不用趕。路上請減速互讓，也不要騎進牧草地。

### 走宗谷丘陵步道再從宗谷站搭巴士回稚內

稚內步道的「宗谷丘陵路線」長路線從宗谷岬出發，終點是宗谷歷史公園，5月到10月左右可以走，冬季不能通行。官方的走法是去程搭路線巴士到「宗谷岬」，走完步道從宗谷歷史公園附近的「宗谷」站搭路線巴士回稚內站前巴士總站。宗谷歷史公園有廁所，離「宗谷」站走路約5分鐘。

| 往稚內方向，經過宗谷站 |
|---|
| 7:31 |
| 8:54 |
| 11:14 |
| 15:29 |

搭9:30的車10:20到宗谷岬才開始走，回程對準15:29那班，它也是當天最後一班，錯過就沒有巴士回稚內。宗谷丘陵展望休息設施離宗谷岬巴士站走路約15分鐘，可以免費休息，11月上旬到4月下旬休館。2026年5月到10月左右拆除風車期間，步道部分路段可能暫時管制，遇到引導員照指示通行。
