## 3. 開頭怎麼寫

- A：先給一個精確的地理事實建立可信度，接著一句畫面，第三句就把「只有一條巴士、班次很少」的限制丟出來。讀者讀完開頭就知道這頁要解決的問題。
- B：先釐清一個常見誤會，再帶到行程規劃。
- C、E：先講情感或景點，交通放後面（遊記型，本頁不學）。
- 共通點：交通型的文章（A、B）在開頭三句內就講到「班次少、回程末班」。本站現行開頭也是這樣，順序可以保留。

## 4. 關鍵問題怎麼回答

**mustAnswer 1：巴士班次與末班**
- A、B、C 都是：哪條路線、在哪上車 → 車程 → 一天幾班 → **回程末班幾點** → 錯過怎麼辦。
- 車資有兩種放法：A、E 放在班次之前（單程與來回票一起講），B 放在路線名之後。都是「單程價 → 來回票比較省」。
- 時刻表：A、B、C 都用文字逐一列時間，沒有用表格；本站已有去回兩張表，比競品清楚，保留。
- B 有一段專講「時刻表上有、但從稚內出發接不上的班次」，再給可行組合。本站現行稿也有（7:21、8:44 接不上），順序相同。
- 錯過末班：C 直接說只能叫計程車或住下來；A 在冬季段才提停駛與電話。讀者想先知道「錯過的後果」，再知道「備案」。

**mustAnswer 2：白色道路沒車怎麼辦**
- 競品幾乎都沒正面回答。B 直接說租車是唯一解；A 只說觀光巴士經過宗谷丘陵。D 只寫開車。
- 這是本站獨有的內容（Active Bus、Base-Soya 租車、步道走到宗谷站），要放在前面講清楚，不用學競品。
- D 的開車順序值得學：先講從哪一頭進去 → 沿路怎麼認 → 路窄要讓車 → 什麼時候封閉。

**表格**
- A 只在「交通方式比較」用表格，時刻表用文字。本站的時刻表、租車費用表維持表格。

## 5. 段落與句子的習慣

- 句長：A、B 中等偏長，常用「也就是說」「換句話說」把資訊轉成建議；條列與小標極短。本站照 writing-guide 寫短句，不學長逗號串。
- 稱呼讀者：A 很少用「你」，多用「建議」「……的話」；B 偶爾用「你」。本站維持不直接稱呼、從讀者處境起頭。
- 數字位置：A 把關鍵數字（車資、末班時間）放進小標或句首；B 數字放句中、單位緊跟。本站可以把「15:20」「1,600圓」放在段落第一句。
- 警示：A 用 ⚠️ 標記風險。本站不用符號，改成把風險放在段首。
- 轉場：B 用「另外」「此外」「相對的」。本站避免每段同一種轉場詞。

## 6. 給作者的順序建議

標題照現在的 `draft-tagged.md`，不改。

- **開頭兩段**：最北端 → 只有一條巴士、一天 4 個來回 → 回程末班 15:20 與錯過的後果 → 有車的走法 → 沒車的走法 → 內連句。現行順序已經符合，保留。
- **稚內到宗谷岬巴士的班次與末班**：路線與上車處 → 車程 → 去回時刻表 → 哪幾班從稚內接不上 → 停駛時怎麼問 → 錯過末班的備案（夏季 Active Bus、其他季節計程車）。
- **宗谷岬當天來回的三種排法**：先列三種排法，再講「待多久夠」的判斷（模範路線停留時間）。現行順序符合。
- **票價、一日券與付款方式**：單程 → 來回券比較省多少 → 一日券什麼情況才划算 → 付款只收現金或 PayPay → 車上只換千圓鈔。競品都把「不能刷 IC 卡」講得很重，付款這句可以提前到單程價之後的第二、三句。
- **宗谷岬站的上下車與回程候車**：不是終點要按鈴 → 回程站在哪、長什麼樣 → 要出來站牌旁等 → Active Bus 上下車處不同。B 建議下車時記下回程站牌位置，本站已寫「下車時順便看好回程站牌」，放在站牌描述後面即可。
- **夏季的定期觀光巴士**：適合誰 → 時間與價格 → 季節與預約。
- **元旦的日出接駁巴士**：日出時間 → 一般路線巴士趕不上 → 接駁巴士時刻與票價 → 現場沒吃的、很冷。
- **其他方式，計程車與自駕**：一句交代巴士配不上時的選擇。
- **計程車**：距離與車程 → 怎麼問車資與包車。
- **開車去宗谷岬與白色道路**：車程與停車 → 白色道路從哪一頭進（導航會排反）→ 路上的請求（廁所、讓車、不進牧草地）→ 風車工程管制（寫明是 2026 年 5 到 10 月左右）→ 封閉期。照 D 的「開車順序」。
- **冬天開車的雪路**：車程變多久 → 路況風險 → 公園內道路封閉（改用重查後的 F21：2026 年 10 月 31 日、11 月 3 日起封閉）。
- **白色道路沒車怎麼辦（H2 與三個 H3）**：先一句給三個答案（租自行車、走步道、Active Bus 只在丘陵停一下），再分節。每個 H3 都是「適合誰 → 什麼季節有 → 時間與費用 → 怎麼接回程巴士」。
