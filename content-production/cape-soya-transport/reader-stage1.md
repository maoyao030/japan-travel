# 讀者驗收第一階段｜cape-soya-transport（宗谷岬交通）

- 驗收者：讀者驗收 agent（非作者），2026-10-20
- 讀的檔案：大綱 `hokkaido-wakkanai-outline.json` 的本頁、`reader-preview.md`、`reader-acceptance.md`（讀者設定、第一階段）、`writing-guide.md`
- 這一階段沒有讀研究記錄、`reference-review.md`、`fact-check.json`、`heading-review.json`
- 背景不算缺點：標題照旅客動線排、不設常見問題 H2；分工歸別頁的事只帶過並連過去（目標頁尚未上線）

## 判斷

**需修改（revise）**。不判退。

開頭第三句就給出核心答案（一天4個來回、岬上末班15:20、16:12以後去就回不來），兩張時刻表加「三種排法」是別的中文站沒有的資料，口吻接近導覽編輯，不像公告。白色道路沒車的三條路（自行車、步道、Active Bus）都有寫，也有時刻與價格。

但照著文章實際走，有幾個環節會卡住：岬上的站牌在哪裡、錯過末班或停駛時怎麼辦、要查停駛只能打日文電話、白色道路入口認不出來、步道多長走得完嗎、自行車要在哪裡還。另外主要查詢「宗谷岬交通」沒出現在開頭兩段。共 8 條必修。

## 模擬情境

### 情境A：2027年7月中旬，兩人，不開車，住稚內，想騎白色道路

兩人自由行，住稚內市區兩晚，中間那天整天給宗谷岬，想騎白色道路再回市區吃晚餐，隔天早上搭JR離開。

| 步驟 | 照文章做 | 結果 |
|---|---|---|
| 到巴士總站 | 稚內站前巴士總站1號乘車處，搭往浜頓別或鬼志別的車 | 可以。總站與JR稚內站的位置關係沒寫，總站沒給日文原名（加分2） |
| 買票 | 單程1,600圓。回程想搭Active Bus就不買來回券 | 可以，文章有說來回券與一日券的差別 |
| 付款 | 現金或PayPay，車上只能用千圓鈔換零錢 | 可以 |
| 下車 | 10:20到，自己按鈴 | 可以 |
| 找Base-Soya | 「離宗谷岬巴士站走路約3分鐘」 | 方向、外觀、日文招牌都沒寫，要靠地圖。勉強可以（加分3） |
| 租車 | 護照，電動車4小時2,500圓 | 可以。但表格寫「一天，當天17:00前還」，Base-Soya卻是16:00關，不知道要在哪裡還（必修6） |
| 騎到白色道路 | 「從宗谷岬那一側的起點開進」 | **卡住**。起點在哪、從Base-Soya騎過去多遠、要不要爬坡、3公里騎完是回到岬上還是到宗谷地區，都沒寫。文章說4小時「時間也夠」，沒有路程撐這個判斷（必修4） |
| 回程 | 15:20路線巴士，或16:00、17:00 Active Bus | 可以。但期待「Active Bus停靠宗谷丘陵」，文章沒說哪一段才停，岬上往站前那段會不會停看不出來（必修7） |
| 錯過回程 | 17:00 Active Bus也錯過 | **卡住**。文章只說「當天就沒有巴士回市區」，沒有給計程車怎麼叫、岬上有沒有車可以叫（必修2） |

### 情境B：2026年12月下旬，三人家庭含一名小學生，不開車，隔天中午後要離開稚內

住稚內一晚，第二天上午排宗谷岬，下午要搭車離開稚內，所以一定要搭11:04的車回來。

| 步驟 | 照文章做 | 結果 |
|---|---|---|
| 選排法 | 「上午去、中午前回」，9:30去、11:04回、12:04到 | 可以，排法清楚 |
| 票價 | 大人來回券2,880圓×2，兒童800圓 | 兒童有沒有來回券沒寫，只能各買單程，可以（加分4） |
| 確認有沒有停駛 | 冬天、可能暴風雪，打0162-33-5515 | **卡住**。只有日文電話，沒有不用講日文的確認方式（必修1） |
| 冬天交通 | 白色道路、Active Bus、自行車、步道都停，只剩岬角 | 可以，文章有說冬天以岬角為主 |
| 回程候車 | 「站在站牌旁邊」「站牌的位置會隨季節稍微移動」 | **卡住**。整篇沒寫站牌在岬上哪裡、對面是什麼、日文寫什麼。冬天會移動卻不說移到哪，零下颳風時找不到站牌最麻煩（必修3） |
| 11:04停駛或錯過 | 下一班15:20，會趕不上下午離開 | **卡住**。沒寫備案，計程車只寫「到案內所問」，人已經在岬上了（必修2） |

## 必修

1. **停駛確認只有日文電話**
   - 位置：「稚內到宗谷岬巴士的班次與末班」第3段（第29行）
   - 原句：「想確認當天有沒有開，可以打電話到宗谷巴士稚內營業所（0162-33-5515）。」
   - 原因：讀者不會講日文，冬天最需要確認停駛。要補不用講日文的做法，例如到稚內站前巴士總站窗口或觀光案內所問、看宗谷巴士官網的運行資訊（有的話）。

2. **錯過末班或停駛時沒有備案**
   - 位置：開頭第1段（第3行）、第29行
   - 原句：「錯過這班，當天就沒有巴士回市區。」
   - 原因：後果寫了，人已經在岬上卻不知道接下來怎麼辦。計程車一節只說「到案內所問」，那是出發前才辦得到的事。要補岬上的備案，例如夏季還有16:00、17:00的Active Bus；計程車要不要事先預約、能不能請案內所或店家代叫；或建議出發前在案內所問好回程計程車。

3. **岬上的巴士站認不出來**
   - 位置：「宗谷岬站的上下車與回程候車」第1段（第49行）
   - 原句：「最好站在站牌旁邊。站牌的位置會隨季節稍微移動。」
   - 原因：全文沒寫宗谷岬站牌在哪裡（哪一側、靠近哪個紀念碑或商店、日文站名），又說會隨季節移動卻不說怎麼移。回程等不到車就回不了稚內，這是最不能卡的一步。要補位置描述與地標，冬季移到哪裡。「在室內等」也沒說是哪裡的室內。

4. **白色道路入口與自行車路程不清楚**
   - 位置：「從稚內開車去宗谷岬與白色道路」第2段（第79行）、「在宗谷岬租自行車騎白色道路」最後一段（第117行）
   - 原句：「出發前對照一下地圖，確認入口在宗谷岬這一側。」「10:20到15:20之間時間也夠，選4小時騎起來不用趕。」
   - 原因：說導航常排錯，卻沒給讀者認入口的方法（地標、路口、日文標示）。騎自行車的人也不知道從Base-Soya到入口多遠、要不要爬坡、騎完白色道路是到宗谷地區還要騎回岬上。「時間也夠」「4小時不用趕」沒有路程撐住。要補入口的位置描述、自行車一圈的路線與距離。

5. **步道長度與所需時間沒寫**
   - 位置：「走宗谷丘陵步道再從宗谷站搭巴士回稚內」（第121、130行）
   - 原句：「搭9:30的車10:20到宗谷岬才開始走，回程就是15:29那班，它也是當天最後一班，錯過就沒有巴士回稚內。」
   - 原因：最後一班15:29錯過就回不去，讀者卻不知道長路線多長、標準要走幾小時，判斷不了10:20出發趕不趕得上，也不知道有沒有短路線可選。要補距離與所需時間（有官方數字的話）。

6. **自行車一天方案的歸還時間與營業時間衝突**
   - 位置：「在宗谷岬租自行車騎白色道路」第1段與表格（第106、112～113行）
   - 原句：「時間是10:00到16:00，15:00以後就不再受理租車。」表格「一天，當天17:00前還」「過夜，隔天17:00前還」
   - 原因：Base-Soya 16:00就關，「當天17:00前還」要還去哪裡看不懂。讀者也會想知道能不能岬上租、站前還（Active Bus帶車加500圓暗示可以，但沒說）。要寫清楚表格是哪一處的價格、在哪裡還、能不能異地還；不能的話，帶車上Active Bus那句要說明用途。

7. **Active Bus在哪一段停宗谷丘陵沒寫**
   - 位置：「夏季的 Active Bus 停靠宗谷丘陵」第1段（第95行）、第102行
   - 原句：「往返稚內機場、宗谷岬與JR稚內站，途中在宗谷丘陵的攝影點停約5分鐘。」「去程搭路線巴士、回程改搭16:00或17:00的Active Bus」
   - 原因：這節放在「白色道路沒車怎麼辦」底下，讀者會以為搭回程那段就能看到丘陵或白色道路。停靠是在機場往岬的那段，還是岬往站前那段，從市區出發的人搭得到嗎？要寫清楚停在哪一段、停的地方是不是白色道路。

8. **開頭兩段沒有主要查詢完整詞組**
   - 位置：開頭第1、2段（第3、5行）
   - 原句：「宗谷岬是北海道本島的最北端，離稚內市區往東32公里，大眾運輸只有宗谷巴士的路線巴士。」
   - 原因：寫作指南第1條要求「宗谷岬交通」完整詞組出現在開頭兩段，目前只有「稚內交通」。可以自然帶進一句，例如「宗谷岬交通以巴士為主」。

## 加分

1. **時間相對用語會過期**：第57行「今年已經結束」、第91行「2026年也都在9月30日結束了」。明年讀者看不懂「今年」，也想知道每年大約幾月開。建議寫成「每年大約6月到9月，2026年是…」。
2. **巴士總站的日文原名與位置**：第9行「稚內站前巴士總站」第一次出現時加上「稚内駅前バスターミナル」，並說明與JR稚內站的位置關係。
3. **Base-Soya怎麼找**：第106行只寫「走路約3分鐘」，補方向或外觀（例如在展望台上、哪一側）。
4. **兒童來回券**：第43行只寫大人2,880圓，兒童有沒有來回券可補一句。「部分票種也不收PayPay」（第45行）若知道是哪些票種，寫出來讀者才知道來回券能不能用PayPay。
5. **空提醒**：第29行「宗谷巴士官網也提醒班次少，要抓好時間。」前面時刻表已經說明，可刪。
6. **白色道路冬季封閉講三次**：第81、85、91行各講一次，第85、91行可只留一處或縮成半句。
7. **H2 用詞**：「稚內宗谷岬交通的其他方式，計程車與自駕」讀起來像塞關鍵字，「其他方式」也偏泛稱，可考慮「從稚內搭計程車或開車去宗谷岬」。
8. **報告式句子**：第9行「目前用的是2023年10月1日調整後的時刻」、第63行「以上是2026年的安排」讀起來像備註，可併進前句或改成條件寫法。另第3行「32公里」與第77行「約35公里」數字不同（市區與JR站起點不同時請寫明），第二階段對照事實。
9. **稚內B的時刻**：第55行只有價格，下午出發幾點、幾點回來補上，讀者才能比較。
10. **站前租自行車的用途**：第106行提到キタカラ也有出租，但稚內站到宗谷岬32公里，讀者看不出站前租車怎麼用在這條路線上，可補一句用途或刪去。
