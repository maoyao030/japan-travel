- **B GLTJP**：開頭 → 稚內是什麼地方（最佳季節、各季穿著、怎麼去、市內怎麼移動：租車、計程車、定期觀光巴士）→ 景點 1～12（宗谷岬、宗谷丘陵、野寒布岬、稚內站、舊瀨戶邸、北防波堤、稚內公園、冰雪之門、水族館、科學館、北門神社、大沼）→ 一日行程 → 購物 3 處（副港市場、KITAcolor、道之驛）→ 住宿 3 家 → FAQ（美食、冬天景點）→ 結語。
- **C tsunagu**：開頭 → 10 個景點（每節：為什麼值得去 → 季節或注意事項 → 官網、地址）→ 租車連結。

## 3. 開頭怎麼寫

- A：先點出適合哪種旅客（怕人擠、想要特別回憶），再安撫「沒想像中冷」，最後一句交通便利帶到結尾邀請。
- B：先一句地理定位（本島最北的市），再預告這篇會講哪幾類資訊。
- C：地理定位加「難得來一趟要看完」，然後預告 10 個景點。
- D：用一個問句問讀者想去哪，再分成市區與離島兩條路。

都沒有在開頭回答「怎麼去、冬天能不能去」；本站現在的開頭直接講位置與冬天封閉，比競品實用，順序可以保留。

## 4. 關鍵問題怎麼回答

- **防波堤穹頂怎麼去**：A、B、C 都是「為什麼有名（形狀、高度長度、取景）→ 從車站走幾分鐘」。交通放在最後的資訊欄，正文只講外觀與歷史。點燈與夜景放在介紹段末尾。
- **野寒布岬怎麼去**：A、B 都是「名字由來或位置（最西端）→ 夕陽與利尻山 → 周邊水族館、燈塔 → 交通（巴士到「ノシャップ」站走 5 分）」。都沒有日落時間表；交通永遠在最後。
- **副港市場怎麼去**：A 把副港市場和港之湯拆兩節，但都是「裡面有什麼（海鮮、伴手禮、溫泉）→ 走路幾分鐘」。B 放在購物一章，強調吃、買、泡湯、問路一次解決。
- **冬天還能去哪**：A 只在氣候段提流冰與零下十度、港之湯冬天雪景。B 在 FAQ 一題回答，指向雪樂園一類的雪上活動；各景點資訊欄的冬季封閉與縮短時間分散寫。C 在各景點順帶冬天玩法（雪蠟燭、雪橇、樓梯滑）。沒有一篇整理成「冬天開／關」對照表。
- 表格：只有 A 的交通方式比較表；B 用條列資訊欄，不是表格。

## 5. 段落與句子的習慣

- 每個景點段 2～4 句，第一句講它是什麼、為什麼有名，數字（高度、長度、年份）放在第二句。
- 交通、時間、門票集中在每節最後的資訊欄，不在敘述句裡穿插。
- 稱呼讀者：B 用「推薦」「不妨」「記得」；C 用「您」；A、D 用「你」「大家」。都不用第一人稱以外的硬口語。
- 轉場靠「此外」「另外」「若有時間」「接下來」；景點之間幾乎沒有串場句，靠編號標題切開。
- 季節條件放在介紹段末尾（「冬天可以…」「夜間有點燈」），不放開頭。

## 6. 給作者的順序建議（標題照現在的 draft-tagged.md）

- **開頭段**：現在的「位置 → 野寒布岬 → 夏天觀光巴士 → 冬天封閉」順序比競品實用，保留；注意 Night & Light 2026 已結束（見重查）。
- **北海道稚內景點的位置與距離**：讀者第一個想知道「哪些走路就到、哪些要搭車」，接著「半天怎麼排」。現在就是這個順序。
- **稚內港北防波堤穹頂**：先講它是什麼、為什麼這樣蓋（擋風）→ 數字 → 下車就走得到；點燈放最後，而且要改成不綁 2026 年日期的寫法。
- **野寒布岬**：先夕陽與利尻、禮文 → 周邊水族館與燈塔 → 日落時間表與冬天幾點到 → 停車與機場距離。現在的順序跟競品一致。
- **野寒布寒流水族館**：競品先講看得到什麼（海豹、企鵝）再講時間；本站已補 F211，可以一句講看得到什麼，接著共通券與冬天哪幾個月進得去。
- **稚內副港市場**：先講裡面有什麼（餐廳、市場、溫泉、紀念館）→ 走路或開車多久 → 港之湯時間與費用 → 跟野寒布岬怎麼接。現在交通與港之湯混在一起，可以把「走路約13分鐘」提到前面。
- **稚內市樺太紀念館**：位置（副港市場2樓）→ 免費與時間 → 冬天休館日 → 雨天搭配港之湯。保留。
- **稚內公園與冰雪之門**：競品先講歷史意義與看得到庫頁島，再講交通與封閉。現在順序一致；封閉期間可以提早到第二段開頭，讓冬天去的人第一眼看到。
- **北方紀念館與開基百年紀念塔**：先展望室看得到什麼 → 開館與夏季延長 → 冬季休館 → 觀光巴士 B 線。保留。
- **北門神社與舊瀨戶邸**：兩處各一兩句，先神社（最北、搭巴士 5 分）再舊瀨戶邸（走路 5 分、冬天也開）。
- **北之櫻守公園與大沼**：先講「機場附近、離開那天順路」再講各自內容；宗谷 Fureai 公園的搭法放最後。現在順序可以，表格放尾端。
- **稚內溫泉童夢與西海岸**：先看得到什麼（利尻、禮文、夕陽）→ 車程 → 時間費用 → 沒車怎麼辦。保留。
- **稚內景點沒車怎麼去？**：競品只有 B 有這一節，順序是「租車 → 計程車 → 定期觀光巴士」。本站先講走路圈與市內線再講觀光巴士，比較符合沒車的讀者。付款只收現金或 PayPay 放在這節開頭是好的。
- **稚內定期觀光巴士**：先講「現在（2026 年）已停駛、什麼時候開」→ 預約方式 → 路線表 → 跟自己搭比較。2026 年度已結束，開頭要讓讀者知道是夏季限定，不要讀起來像現在就能搭。
- **搭市內線巴士到野寒布岬**：乘車處 → 班距與車資 → 整理券與找零 → 下車後走幾分鐘。保留。
- **稚內觀光案內所**：位置與時間 → 機場無人 → 該問誰。保留。
- **稚內冬天景點**：競品沒有對照表，本站的表是優勢。順序：12、1 月最少 → 對照表 → 2 月最多（雪樂園、水族館、犬橇大會）→ 風雪一句帶到天氣頁。
- **稚內與南極物語的太郎、次郎**：故事 → 南極祭 → 犬橇大會一句。保留，篇幅不要比實用節長。
