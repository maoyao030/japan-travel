# 層雲峽冰瀑祭 資訊順序（重寫 2026-11-02）

照 `competitor-notes.md`「給作者的順序建議」。研究者判斷現稿順序大致符合讀者期待，這輪只調整下面幾處。

- **開頭兩段**：維持「是什麼、規模與點燈 → 2027 日期 → 煙火在末班車之後、要住或開車 → 不過夜的當天來回」（筆記：現稿已是這個順序）。規模句加上日本夜景遺產（F531），競品三篇都在定位句寫，對讀者是「晚上值得看」的理由。
- **H2 日期與開放時間**：改成日期 → 平日與週末的時間差（平日白天不開）→ 標明是 2026 年的數字、2027 出發前看官網（筆記：年份提醒放在時間之後）。基本資訊表放說明之後，連結句收尾。
  - **H3 門票**：金額 → 怎麼買（官網連到 KKday）→ 會場另收費的滑道，原本就是這個順序。
  - **H3 煙火時間**：幾點 → 從哪裡打、有倒數 → 新加一句「這時巴士已收班，要住或開車」帶到交通（筆記：煙火接住宿的因果）。
- **H2 交通**：直達巴士（上車點、車程、車資、班數）→ 上川轉乘 → 下車走到會場 → 時刻年份提醒 → 連到交通頁（筆記：直達先講、年份提醒放最後）。上川班次多改寫成「直達時間對不上時改走上川」，給讀者用法。
  - **H3 看完煙火回得了旭川嗎？**：「回不去」→ 末班時間 → 住一晚或開車、旅館接駁 → 連到住宿頁 → 不看煙火的當天來回與時刻表（筆記：WaTabi 的因果順序）。刪掉重複出現「層雲峽交通」錨文字的那一句。
  - **H3 開車去**：交流道距離、時間、免費停車 → 冬季輪胎 → 封路與查路況，原本就是這個順序。
- **H2 會場**：主冰雕與展望台 → 最熱門拍照點 → 神社、寫真館 → 滑道、數位藝術、冰屋、舞台 → 休息處與吃喝（筆記順序）。刪掉遊客中心冬季觀察會一段（F530：只收住日本、會日語的人，台灣讀者不能參加；協調者決定）。
  - **H3 要穿什麼**：官方提醒 → 氣溫數字 → 會場買得到手套與止滑器 → 連到天氣頁，原本就是這個順序。
- **H2 夏天火祭與秋天點燈**：每個活動是什麼、在哪 → 日期時間 → 座位、接駁、停車 → 收在「都在晚上，住一晚比較實際」，原本就是這個順序。
