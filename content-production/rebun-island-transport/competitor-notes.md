## 各篇的順序

**1. Funliday 稚內渡輪＋兩島攻略**
- 稚內渡輪船票（票價、座位等級）
- 禮文島交通：先講抵達的港口與港邊有吃有住 → 三種交通方式並列：租車（建議從稚內把車帶上船）、路線巴士一日票（提醒班次少要先排）、觀光巴士半日遊（上午、下午兩條，配合船班）
- 禮文島景點 → 利尻島交通 → 利尻島景點 → 站內推廣

**2. Funliday 船票懶人包版**
- 和 1 幾乎同結構；禮文島交通標成「交通方式 1／2／3」，平行排列讓人比較
- 景點用統一版型：照片 → 條列地址、開放時間、交通
- 只有桃岩寫了從港口走幾分鐘到入口；須古頓岬、金田岬只給地址；澄海岬只出現在觀光巴士那段
- 計程車、自行車完全沒寫

**3. Funliday 禮文島 10 大景點**
- 開頭：島的別稱 → 自然景觀與美食 → 本文幫你排行程
- 「前往禮文島」：車站走到碼頭 → 買票 → 班次與最佳季節
- 景點 1～10：介紹段在前，地址／開放時間的條列在後，交通夾在介紹段裡，以「從香深港走幾分鐘」表達

**4. 日本觀光局 利尻島與禮文島**

## 開頭怎麼寫

- 1、2：先給地理位置（北海道最北），再給從大城市過去要多久，最後一句帶出兩座島，承諾「這篇幫你搞定」。
- 3：用島的別稱當記憶點，接景色與吃的，再承諾幫你排行程。
- 4：景色描寫起頭，交通放很後面。
- 共通點：競品開頭都在「為什麼要去」，沒有一篇在開頭直接回答「沒車怎麼移動」。本站這頁讀者已經決定去、要查怎麼移動，開頭直接回答「島上靠宗谷巴士，季節差很多」是競品沒做到的，保留。

## 關鍵問題怎麼回答

**① 三條路線與班次**
- 競品沒有一篇寫出島內路線巴士有幾條、往哪裡。只說「有一日票、班次少、要先排好」。
- 順序是：票（一日票）→ 提醒班次少 → 叫你自己排。先講票、後講班次，沒有時刻表、沒有表格。
- 讀者熟悉的入口是「一日票划不划算」與「班次很少」這兩個印象。

**② 觀光巴士預約與季節**
- 競品把觀光巴士寫成「半日遊」：先說有上午、下午兩條 → 再說配合渡輪時間 → 順帶經過的岬角。
- 沒有一篇寫怎麼預約、在哪買票、季節到哪天。
- 讀者熟悉的說法是「上午那條、下午那條」，而不是「A 線、B 線」。

**③ 沒車怎麼去群生地、澄海岬、地藏岩**
- 競品把交通放在每個景點介紹之後或之中，用「從香深港走幾分鐘」或「開車幾分鐘」。
- 澄海岬在競品裡只靠觀光巴士或開車到；沒有人寫路線巴士＋走路。
- 地藏岩、群生地的沒車去法競品都沒有。

**表格**：四篇都沒有表格，全用條列。本站的時刻表、車資表是競品沒有的資料，保留，但表格前要有一句話告訴讀者這張表要拿來做什麼決定。

## 段落與句子的習慣

- 句子偏長、用逗號串很多資訊，段落短；條列很多。本站不學長逗號句。
- 稱呼讀者用「你」「大家」，語助詞與驚嘆號多。本站照導覽編輯口吻，不學語助詞與驚嘆號。
- 轉場常用「另外」「不過」「最後一種是」「如果…的話」。「交通方式 1、2、3」這種平行列舉讓讀者容易比較，可以在總覽段用一句話把幾種方式並排。
- 數字放在句尾（「約 10 分鐘」「單日 X 日圓」），先講地點或動作，再給數字。
- 提醒語常放段尾：「班次少，一定要先排好」。本站可以把限制放在選項後面同一句，但不重複「一定要」。

## 給作者的順序建議

標題照現在的 `draft-tagged.md`，不改；以下只排每節裡的資訊順序。

- **開頭兩段**：先講沒車靠什麼（路線巴士＋夏季觀光巴士，都從渡輪站出發）→ 季節差多少（觀光巴士只到 9 月、冬天往北班次少）→ 沒車去景點的兩種方式。內連句照放。競品開頭講「為什麼要去」，本頁不學。
- **禮文島怎麼去？**：只有渡輪 → 船程多久 → 機場停用一句 → 連到渡輪頁。和競品「前往禮文島」一節同順序，但比競品短，細節歸渡輪頁。
  - **香深港渡輪站**：讀者下船後第一個問題是「巴士在哪搭」：先講出口前就是巴士站與計程車站 → 觀光巴士在停車場那側 → 樓層（乘船口 2 樓、服務台 1 樓）→ 有問題問誰。目前稿子先講樓層，可以把「出口前就是巴士站」往前提。
- **禮文島觀光巴士的路線與季節**：讀者心中是「上午那條、下午那條」：先一句說有兩條、一條上午約 4 小時、一條下午約 2.5 小時，都從渡輪站出發 → 表格 → 2026 年已跑完、2027 年等公告 → 怎麼接船（A 線接早班船當天來回，B 線適合住島上）。季節與「今年已結束」可以留在節首一句，但不要比路線說明更搶前面。
- **禮文島觀光巴士怎麼預約？**：競品完全沒寫，順序照讀者動作：要不要預約 → 幾時開放 → 用哪種方式（不會日文就網路）→ 當天空位。現在稿子順序已經合理。
  - **網路預約**：開放時間（換算台灣時間）→ 註冊 → 畫面對照表 → 付款 → 車票怎麼出示 → 取消。照操作先後，維持。
  - **電話與窗口預約**：打電話要報什麼 → 電話表 → 當天要去窗口換票、只收現金或 PayPay → 窗口在哪。維持。
- **禮文島路線巴士的三條路線與班次**：競品只講「班次少」，讀者想先知道「往我要去的地方是哪一條」：三條各往哪 → 路線表 → 往北最常用那條的車程 → 夏冬班表怎麼分。
  - **車資與一日券**：競品的入口是「一日票划不划算」。可以先講一日券價格與能搭什麼 → 跟單買比較（來回須古頓、來回濱中比較便宜，跑兩個方向才划算）→ 再給車資表與整理券付法。把「划不划算」的結論提前，車資表放在後面當查表用。
  - **刷卡或 Suica**：先回答「不行」→ 能用什麼 → 零錢怎麼準備。維持。
  - **大件行李**：限制 → 換算成多大 → 大行李寄放在哪 → 嬰兒車。維持。
  - **自由上下車區間**：哪些路段可以 → 怎麼舉手、怎麼下車 → 司機不停的地方 → 單側站牌。維持。
  - **冬季班表與末班**：讀者要的是「當天來回行不行」：先講冬天從稚內當天來回能去哪、要搭哪班 → 住島上的排法 → 再放時刻表 → 最後停駛日與假日班表。現在稿子就是這個順序，維持；時刻表前各加一句說這張表用在哪段行程。
  - **停駛去哪裡查**：先給電話 → 官網與 X → 什麼情況會停駛。維持。
- **禮文島沒車怎麼去景點與步道起點？**：競品把交通夾在景點介紹裡，讀者要的是一眼看到「搭哪條、在哪下、走多遠」：先一句說大多數景點有巴士＋步行的去法、但班次少要先排回程 → 冬季步道封閉狀況 → 總表。
  - 每個景點 H3：照「搭哪條車 → 在哪站下 → 走多遠多久 → 冬天怎麼辦」。競品習慣先講景點在哪再講交通，本頁是交通頁，景點介紹只留一句（例如地藏岩在元地海岸），直接進交通。
- **計程車、租車與自行車**：競品的順序是租車在前（甚至建議從稚內帶車上船），計程車沒寫。讀者沒車時想知道「哪種最實際」：先講冬天租車最實際的理由 → 租車店位置與營業時間 → 計程車兩家 → 自行車與夏季接送 → 表格。現在稿子把這個判斷放在節尾，可以考慮往前。
