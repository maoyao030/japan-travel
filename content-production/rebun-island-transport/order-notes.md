# 禮文島交通 資訊順序筆記（2026-11-01 重寫）

標題沿用網站上的版本，一字不改。以下是每節的資訊順序，以及照 `competitor-notes.md` 的哪一點。

- **開頭兩段**：沒車靠宗谷巴士（三條路線＋夏季觀光巴士，都從渡輪站出發）→ 季節差多少（觀光巴士10月起停、冬季往北4班）→ 沒車去景點的兩種方式，冬天要租車或計程車 → 內連句。照筆記「開頭兩段」，不學競品講為什麼要去。
- **禮文島怎麼去？**：只有渡輪 → 船程 → 機場停用 → 渡輪頁內連句。照筆記，維持短。
  - **香深港渡輪站**：改成先講出口前就是巴士站與計程車站 → 觀光巴士在停車場那側 → 樓層 → 有問題問誰。照筆記「把出口前就是巴士站往前提」。
- **禮文島觀光巴士的路線與季節**：節首一句兩條各是上午、下午與全程時間 → 2026年已跑完、2027年等公告（放在路線說明之後）→ 表格 → A線細節 → 接船（A線當天來回、B線接不上末班船適合住島上）→ 票與限制。照筆記「讀者心中是上午那條、下午那條」，並把怎麼接船提到票務規則之前。
- **禮文島觀光巴士怎麼預約？**：要預約、2個月前 → 當天空位與不候補 → 預約方式 → 不會日文用網路。照筆記「要不要預約 → 幾時開放 → 用哪種方式」。
  - **網路預約**：開放時間（換算台灣時間）→ 註冊 → 登入後選路線 → 畫面對照表 → 付款 → 車票 → 取消。照筆記，把「選定期観光バス」移到註冊之後，符合操作先後。
  - **電話與窗口預約**：維持（報什麼 → 電話表 → 當天換票、付款 → 窗口位置）。
- **禮文島路線巴士的三條路線與班次**：三條各往哪 → 去哪個景點搭哪條（新增一句）→ 路線表 → 往北車程 → 夏冬班表。照筆記「讀者想先知道往我要去的地方是哪一條」。
  - **車資與一日券**：一日券價格與能搭什麼 → 划不划算（單買來回須古頓、濱中較便宜，跑兩個方向才划算）→ 溫泉折扣 → 車資表 → 整理券付法。照筆記「把划不划算的結論提前，車資表放後面當查表用」。
  - **刷卡或 Suica**、**大件行李**、**自由上下車區間**：維持筆記建議的順序。
  - **冬季班表與末班**：適用期間 → 當天來回能搭哪班 → 住島上的排法 → 時刻表（前面加一句說去程、回程各看哪張；元地線與知床線表前加一句說用途）→ 停駛日與假日班表。照筆記「時刻表前各加一句說這張表用在哪段行程」。
  - **停駛去哪裡查**：維持。
- **禮文島沒車怎麼去景點與步道起點？**：大多有巴士站但班次少 → 冬季步道封閉（改寫成10月20日起還能走哪兩段）→ 總表。照筆記。
  - 各景點 H3：搭哪條 → 在哪下 → 走多遠 → 冬天怎麼辦。地藏岩補一句元地線冬天照常行駛，林道把香深井這端的走法排在渡輪站直走之前。照筆記「交通頁，景點介紹只留一句」。
- **禮文島的計程車、租車與自行車**：冬天租車最實際的理由 → 租車店位置、車少要早聯絡 → 營業時間 → 計程車兩家與夏季接送 → 自行車 → 電話表 → 觀光協會。照筆記「把判斷往前」。
