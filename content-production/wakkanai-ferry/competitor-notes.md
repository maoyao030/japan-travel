## 2. 各篇的順序

**A Funliday**
1. 開頭：稚內在哪、從旭川多久 → 稚內是去兩島的出入口 → 「這篇帶大家搭渡輪出發」
2. 渡輪船票 H3：渡輪站在車站哪個方向、走幾分 → 可以網路預約或現場買（窗口開船前 1 小時）→ 班次隨季節變、夏天最適合、一天約 3 個來回 → 兩島之間的港口與班次
3. 票價座位 H3：艙等名稱一口氣列完 → 帶車要另外付 → 票價只放官網截圖
4. 之後全是島上交通（公車一日券、觀光巴士 A／B 路線）與景點

**B 小氣少年**
1. 一句話：去利尻島大部分人坐渡輪，渡輪站也是去禮文島的地方
2. 從車站走過來多久 → 進門看到櫃台 → 旺季先網路訂、付好款 → 到櫃台出示預約郵件的條碼換票
3. 艙等分 1 等、2 等 → 為什麼選 1 等（怕暈船）→ 1 等是指定席要劃位 → 票價與航程
4. 站內設施：置物櫃、商店 → 2 樓餐廳賣什麼、郵局、紀念章 → 兩個乘船口各去哪座島
5. 船上：2 等座位樣子（不劃位、自己找）→ 優先席 → 商店、販賣機、行李放置區 → 1 等座位表與座位 → Wi-Fi、電視 → 天氣差不能上甲板
6. 抵達鴛泊：1 樓案內所、售票處 → 碼頭對面有餐廳、租車

**C sanjeff**
1. 去兩島除了飛機，主流是坐渡輪 → 官網有中文、可以直接訂票刷卡、付完寄 QR code 直接登船
2. 利尻有兩個港，千萬看清楚在哪上船；禮文只有香深
3. 2 等這趟：航程、票價 → 渡輪站小、上 2 樓驗票 → 船上從船頭走到船尾介紹（1 等和室、服務處、販賣機、2 等榻榻米區、甲板塑膠椅）→ 隔天那班 2 等滿席
4. 1 等和室那趟：航程、票價、小孩半價 → 好處是不用跟著排隊搶位 → 網路訂時可選位、名額少、出發兩週前就滿 → 位子有什麼（床墊、枕頭、衣架）

**D O2 Travel**
1. 去利尻有飛機與船兩種 → 為什麼選船（順路去宗谷岬）
2. 夏冬班次不同、以官網為準 → 車站走過去多遠
3. 渡輪站兩層：1 樓售票窗口、2 等售票機、商店；2 樓登船口、餐廳
4. **行前最煩惱：要不要先網路訂指定席**，夏天怕買不到 → 一早到發現不用排、順利買到
5. 站內逛：商店賣什麼 → 外面的人孔蓋、國際碼頭 → 船的介紹
6. 開船前約 15 分開始放人上船 → 2 等幾乎是臥鋪，要早排隊才挑得到角落 → 甲板座位是吸菸區

**E 明星花露雪**
1. 兩島為什麼有名 → 去的方法：飛機或渡輪 → 帶車運費很貴
2. 官網：要指定席在網路買；最便宜的 2 等在站內投幣買 → 時刻表、票價表
3. 站內超商 → **為什麼提早一小時到：排第一個，2 等臥鋪位有限** → 被旅行團插到前面的插曲 → 一再強調「買到票就去排隊」
4. 上船直奔 2 等 → 室外 2 等座位 → 航程、沒暈船 → 回程也提早 40 分排隊

## 3. 開頭怎麼寫

- 編輯站（A）從「稚內在哪、是去兩島的門戶」切入，一句帶到「這篇搭渡輪出發」，渡輪的實用資訊放進第一個 H2。
- 部落客（B、C、D、E）多半先講「去兩島只有飛機和船兩種」，再說為什麼選船，然後直接進到渡輪站。
- 沒有一篇在開頭就給班次、航程、票價三個數字；本站現在的開頭已經是一段給齊，這個優勢保留。

## 4. 關鍵問題怎麼回答

- **各季班次與航程**：A 只講「夏天一天約 3 班、隨季節變」；D、E 只說「夏冬不同、看官網」。都沒有時刻表文字。讀者期待的順序是：先「一天幾班、哪個季節多」→ 再「坐多久」→ 最後才是逐班時刻。
- **票價與小孩**：A、E 放官網截圖或寫舊價；B、C 在講自己選哪個艙等時順便講價錢。順序是「我選了哪一等 → 為什麼 → 多少錢」，價錢跟著艙等選擇一起出現，不是單獨一張表先出現。C 提到小孩半價，接在大人票價後面一句。
- **網路訂票與報到時間**：B、C 的順序是「先網路訂、付款 → 收到郵件條碼或 QR code → 當天出示就能上船」；A 只說「可網路或現場、窗口 1 小時前開」。沒有一篇寫訂票步驟或畫面按鈕。
- **要不要先訂**（讀者實際最煩惱的，D 明講）：D、E 的答案是「2 等可以現場買，但要早到排隊搶位置」；C 的答案是「1 等名額少，早訂」。都是從「搭什麼艙等」回推要不要訂。
- **停航怎麼知道、怎麼改**：5 篇都沒寫。
- **渡輪站櫃台在哪**：B、D 照樓層講：1 樓櫃台、售票機、商店 → 2 樓登船口、餐廳；B 加「兩個乘船口各往哪座島」。

## 5. 段落與句子的習慣

- 部落客句子很短，一句一張照片，常用「這裡」「來到二樓」當轉場，照走路的順序推進。
- 數字放在句尾或括號：「航程約 1 小時 40 分」「大人 ○○ 円」，很少一句塞兩個以上數字。
- 稱呼讀者用「大家」「你」；建議句用「建議」「一定要」，E 用重複句強調。
- 艙等用「1 等」「2 等」「自由席」「指定席」「和室」「臥鋪」「榻榻米」，讀者熟悉「臥鋪」這種說法描述 2 等。
- 港口一律寫中文港名＋「港」（鴛泊港、香深港、沓形港），強調「利尻有兩個港」時會單獨成一句提醒。

## 6. 給作者的順序建議

標題照現在的 `draft-tagged.md`，只排每節裡的順序。

- **開頭兩段**：保持「誰開船、去哪兩個港 → 一天幾班 → 坐多久 → 多少錢」；第二段當天來回的末班船之後，接「要不要先訂」的一句答案會比現在先講預約開放時間更貼近讀者（競品最常見的煩惱）。
- **稚內船班怎麼挑，各季稚內渡輪時刻**：先「哪個季節一天幾班」→ 航程表 → 臨時船一句放最後（現在順序已對）。
- **從稚內去禮文島香深港／從稚內去利尻島鴛泊港**：讀者先要「一天玩最久怎麼搭」，再看全表。可以考慮把「待最久的組合」移到表格前（注意每個標題底下第一段之後要留給嵌入，段落數不能少）。
- **在利尻島與禮文島之間坐船**：先「班次最少、春秋冬一天一個來回」→ 再「利尻有兩個港，看清楚」（C 的提醒放得很前面）→ 表格。
- **船票預約 H2**：讀者順序是「要不要訂 → 怎麼訂 → 訂完拿到什麼（QR code）→ 當天怎麼用」。現在 H2 開頭是三個時間點條列，可以先一句「2 等可以現場買但沒有候補、1 等與特別室建議先訂」再接條列。
- **用 Heartland Ferry 網站訂票**：順序「註冊 → 選班次 → 付款 → 收到 QR code」，畫面對照表維持放在步驟之後。
- **到渡輪站報到、拿 QR code 上船**：照樓層走：1 樓櫃台 → 2 樓乘船口 → 幾分前要到（競品都照走路順序）。
- **挑選2等、1等或特別室**：競品的順序是「2 等長什麼樣、要不要搶位 → 1 等好在哪、要早訂 → 特別室」。現在先講三艘船的艙等表，可以改成先講 2 等是地毯開放空間（F249），再接表格；表格段落數照 media 規定。
- **船上吃東西、行李與暈船**：小賣部寫成「5 月到 10 月才開」；毛毯句改成「不出借，1 等和室本身有床墊與毛毯」（F250）；Wi-Fi 一句（F251）可以放在手機訊號旁。
- **票價 H2**：維持「最常買的 2 等價格 → 表 → 來回不便宜」，小孩接在大人後面（競品也是這樣）。
- **停航 H2、渡輪站 H2**：競品沒寫，照現在順序。渡輪站一節照「怎麼到 → 進門 1 樓有什麼 → 2 樓有什麼」走。

## 7. 他們有、我們缺的

- **2 等室長什麼樣、要不要早排隊搶位置**（B、C、D、E 都寫）：已回官方查到 2 等室是地毯開放空間（F249）。「要提早排隊」「開船前 15 分放人上船」只有部落客經驗，官方沒寫，不寫。
- **1 等和室有床墊、毛毯**（C）：官方船舶介紹有寫（F250）。
- **船上 Wi-Fi**（B、C）：官方 FAQ 有寫（F251）。
- **兩個乘船口各往哪座島**（B）：官方樓層圖只標乘船口 1、2，沒寫固定對應哪座島，不寫。
- **1 等和室名額少、早就滿**（C）：官方沒公布名額，不寫。
- **甲板座位是吸菸區**（D）：事實表沒有，官方 FAQ 沒查到，不寫。
- **碼頭外的人孔蓋、2 樓郵局與紀念章**（B、D）：跟本頁主題無關，不寫。
