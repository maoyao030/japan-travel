# 層雲峽旅遊攻略，瀑布、纜車、紅葉與冰瀑祭排法一次看

層雲峽的秋天主角是紅葉，黑岳山頂一帶大約9月上旬就開始變色，被稱為日本最早的紅葉，之後一路往下染到溫泉街[F70, F415, F117]。冬天換成冰瀑祭，入夜的冰雕會場是日本夜景遺產認定的夜景[F600]。

從旭川搭巴士去層雲峽，單程1小時59分，當天來回搭得到纜車，不過直達末班車17:00就開走了[F13, F15]。想看煙火或趕一早的纜車，就要在溫泉街住一晚[F75, F403]。

## 層雲峽是什麼樣的地方？

層雲峽是沿著石狩川延伸大約24公里的斷崖峽谷，兩岸是一根根並列的柱狀節理岩壁[F93]。愛努人把這一帶的大雪山叫作Kamuimintara（カムイミンタラ），意思是眾神遊玩的庭院[F94]，谷底就是大雪山系最大的溫泉街[F95]。

秋天峽谷裡約七成是岳樺的黃葉，楓樹的紅混在裡面特別顯眼[F415]。葉子落光之後，10月下旬路面就有積雪的日子，到了4月積雪還有將近1公尺[F410, F167]。

溫泉街在標高600公尺以上的高地，朝陽亭蓋在高台上，頂樓大浴場望出去就是大雪山[F409, F617]。

## 層雲峽有什麼好玩、好吃的？

### 銀河瀑布與流星瀑布｜爬上雙瀑台，兩道日本瀑布百選同時入鏡

銀河瀑布跟流星瀑布分別從絕壁不動岩的左右兩側落下，爬上展望台雙瀑台，兩道瀑布就能同時入鏡[F618]。銀河瀑布落差120公尺，細白得像絲線，別名女瀑；流星瀑布落差90公尺，是一道粗壯的水流，別名男瀑，兩道都入選日本瀑布百選[F96, F412]。瀑布離溫泉街約3公里，沒開車的話要叫計程車或跟導覽團[F605, F471, F470]。想爬上雙瀑台看兩道瀑布同時入鏡，或想知道計程車與導覽團怎麼找，[層雲峽景點](/places/sounkyo/sights/)那一頁都有寫。

### 黑岳纜車｜日本最北的纜車

上到五合目只要7分鐘，不爬山也有正對黑岳的展望台「高松台」[F41, F404]。轉搭吊椅到七合目，單程約15分的步道終點看得到對岸的雨龍瀑布（あまりょうの滝）[F404]；想登頂的話，靠纜車跟吊椅，從七合目走到山頂約1個半小時[F51]。打算從七合目繼續登頂，或想先查好纜車與吊椅的票價，可以看[層雲峽纜車與黑岳登山](/places/sounkyo/hiking/)，營業時間和登山路線也都在裡面。

### 紅葉｜被稱為日本最早的紅葉，從山頂一路染到溫泉街

黑岳山頂一帶大約9月上旬就開始變色，赤岳銀泉台9月中旬到高峰，溫泉街往年在10月上旬到中旬最漂亮[F70, F116, F415]。溫泉街的紅葉谷走到底是紅葉瀑布（紅葉の滝），柱狀節理跟瀑布就在同一個畫面裡，這種景色本來要到小函才看得到，現在小函去不了[F620]。

### 層雲峽觀光飯店的峽谷大露天｜穿湯衣，全家一起泡

層雲峽觀光飯店的峽谷大露天「宇旅璃」（うたり）就在石狩川旁邊，穿飯店的專用湯衣，全家可以一起泡，小孩也有兒童湯衣[F621, F623]。這是這間飯店的浴場，想去別處泡的話，溫泉街還有町營的日歸溫泉黑岳之湯（黒岳の湯）[F477]。

### 冰瀑祭｜日本夜景遺產認定的冰雕夜景

層雲峽溫泉冰瀑祭在1月下旬到3月上旬舉辦，是日本夜景遺產認定的夜景[F71, F72, F600]。2026年的會場有大小約30座冰雕，最高超過10公尺，入夜打上七彩燈光，每晚20:30從冰雕後方放煙火[F406, F75]。想先知道煙火幾點放、會場怎麼走，[層雲峽冰瀑祭](/places/sounkyo/festival/)把日期、交通與煙火時間列在同一頁。

### 峽谷火祭｜上川愛努的貓頭鷹神事

夏天的峽谷火祭，主祭日是7月下旬的晚上，舞台上有貓頭鷹神事（フクロウ神事）跟上川愛努古式舞蹈，這兩項都是日本遺產的構成文化財，最後放煙火[F601, F602, F615, F614]。2026年主祭日之後到8月中旬，每晚都放夏季煙火[F601]。

### KAMIKAWA KITCHEN｜卡門貝爾起司拿下世界起司大賽金牌

上川站周邊的起司工房，招牌起司Kiyomi（カマンベール・キヨミ）在世界起司大賽（WCCC）2026拿到卡門貝爾組金牌[F153, F455]，2024年春天才開幕，用的生乳全是上川町產[F454]。溫泉街與上川站周邊的店，寫在下面層雲峽溫泉街與上川町美食那一節。

## 層雲峽幾月去最好？

10月上旬到中旬最值得排，溫泉街的紅葉在這時候到高峰，黑岳纜車跟瀑布也都還開著[F415, F403, F44, F98]。想看冰瀑祭，就排1月下旬到3月上旬[F71, F72]。

| 月份 | 層雲峽的狀況 |
|---|---|
| 4月到6月 | 4月最深積雪還有94公分，6月下旬起纜車進入夏季營業，清晨6:00就開 [F167, F476] |
| 7月到8月 | 白天最高約24度，也是雨最多的時候[F603]，7月下旬有峽谷火祭，2026年到8月中旬每晚放煙火 [F601, F602] |
| 9月到10月中旬 | 9月山上先紅，10月上旬到中旬輪到溫泉街 [F70, F116, F415] |
| 10月下旬到11月 | 葉子落光，溫泉街開始有路面積雪的日子 [F410] |
| 12月到3月上旬 | 12月初起黑岳滑雪場營業，1月下旬到3月上旬辦冰瀑祭，積雪在3月最深，平年126公分 [F611, F71, F72, F167] |

11月比較沒有主角，葉子已經落光，冰瀑祭要等到1月，2026年的黑岳纜車還在11月停駛整備了三個多星期[F410, F44]。要依月份抓穿著，[層雲峽天氣與楓葉](/places/sounkyo/weather/)有各月的氣溫、積雪與紅葉時期。

## 層雲峽要排幾天，怎麼排？

從旭川當天來回，夠搭纜車上五合目、逛溫泉街；想看冰瀑祭的煙火，或搭紅葉季一早的纜車，就要在溫泉街住一晚。

從旭川站前搭道北巴士（道北バス）直達，一天7班，單程2,140日圓[F1, F5]。在終點站下車，走5分鐘就到黑岳纜車[F469]。想先在網路買好車票，或要對照每一班的發車時刻，[層雲峽交通](/places/sounkyo/transport/)列了全部班次與網路票的買法。

### 不開車，從旭川當天來回

旭川站前9:55發 → 11:54到層雲峽 → 走5分鐘到纜車，7分鐘上五合目 → 17:00搭直達末班車 → 18:55回旭川站前[F1, F469, F41, F3]。

17:00是直達旭川的最後一班[F15]，下山的時間要照它排。錯過的話，18:55還有一班開往上川的車，19:25到上川再轉JR回旭川[F15, F4, F402]。

### 冬天看冰瀑祭，要看煙火就住一晚

住進溫泉街 → 傍晚入場看冰雕 → 20:30煙火 → 隔天6:20搭頭班巴士回旭川[F72, F75, F3]。

2026年的冰瀑祭，平日17:00才開場，煙火20:30才放，回旭川的直達末班17:00、往上川的末班18:55都早就開走了，所以想看煙火就得住一晚，或是自己開車[F72, F75, F15, F4]。只看冰雕的話，當天也回得了旭川，週末假日11:00就開場，平日17:00開場，再搭18:55的末班車轉JR回去[F72, F4, F402]。

### 秋天看紅葉，要搭一早的纜車就住前一晚

前一晚住溫泉街 → 6:00搭第一班纜車上山看山上的紅葉 → 下山逛溫泉街[F476]。

9月底以前纜車6:00就開，是看山上紅葉的時間，但從旭川搭頭班巴士6:55發、8:54才到，想一早上山的話，前一晚要住溫泉街[F476, F1]。溫泉街的紅葉谷要等到往年10月上旬到中旬才到高峰[F415]。銀泉台的紅葉9月中旬到高峰，那段時間有車輛管制，自己開車或搭上川町的包車都要事先預約[F116, F411, F472]。

### 自駕往道東，翻石北峠或三國峠

旭川走國道39號到層雲峽約66公里，開車約1小時30分，再往北見方向翻石北峠約90公里、約1小時30分，往帶廣翻三國峠約122公里、約2小時，都是夏天路況的參考時間[F19, F20]。

冬天遇到暴風雪或有雪崩之虞，石北峠跟三國峠都可能臨時封路，解除時間也說不準，2025年2月石北峠就封過32.5公里[F29, F30]。車子也要換冬季輪胎，夏季輪胎走山路非常危險[F32]。不開車的話，Sunrise號（サンライズ号）從層雲峽9:22跟14:37各有一班往北見、阿寒湖，一定要先預約[F22, F26]。

## 層雲峽住哪一區？

想泡溫泉、隔天一早搭纜車，就住溫泉街，住上川站周邊的話，比較適合火車很晚才到上川，或隔天一早要從上川站離開的行程，從上川站搭巴士到層雲峽要30分鐘[F608, F13]。冬天不開車的話，部分旅館有從旭川、札幌出發的接駁車，要先預約[F606, F607]。溫泉街的旅館離纜車多遠、哪幾家有接駁巴士，比較寫在[層雲峽住宿](/places/sounkyo/stay/)。

## 層雲峽和旭岳怎麼一起排？

只能去一個的話，想站上高處又不登山就選[旭岳](/places/asahidake/)，它是北海道最高峰，纜車約10分鐘上到標高約1,600公尺的姿見站，一圈約1小時的散策路看得到冒煙的地獄谷跟舊火口的姿見池（姿見の池），6月到10月中旬開放[F418, F421, F422, F612]。想住溫泉街，或下午才從旭川出發，就選層雲峽，因為旭岳溫泉沒有溫泉街，往旭岳的出湯號（いで湯号）最晚14:15就從旭川站前發車，往層雲峽的巴士最晚18:25還有車[F420, F424, F1]。

兩個都去的話，兩地之間要回旭川站前轉車，層雲峽10:10發、12:05到旭川站前，轉12:15的出湯號，14:03到旭岳，接得最順也要將近4小時，開車大約2小時30分[F3, F424, F609]。所以搭巴士的話至少排兩天一夜。夏天體力夠的人，也可以從黑岳七合目走到旭岳纜車（大雪山旭岳ロープウェイ）的姿見站，大約7小時，保險一點抓8到9小時[F51, F610]。

兩邊都想去、要決定先後或住哪一邊，[旭岳與層雲峽怎麼選](/places/asahidake/asahidake-or-sounkyo/)比較了兩地的差別，也寫了怎麼排在同一趟。從札幌或機場過來、想前一晚先住在轉車的城市，[旭川](/places/asahikawa/)那一頁整理了轉乘方式與住宿。

### 冬天晚上還開的店

冬天晚上在溫泉街吃飯的選擇很少。11月到4月，登山軒跟Tree Bird（ツリーバード）都休業了，Taisetsu Bakery也只開到18:00，所以晚上就只剩Beer Grill Canyon（ビアグリル・キャニオン）跟大雪山食堂[F149, F147, F450, F452, F148]。不過Canyon冬天也有開，冰瀑祭期間還推出過冬季限定菜單[F453]。

Canyon每週二、週三公休，大雪山食堂則是不定休，如果兩家剛好撞在同一天休息的話，溫泉街晚上就幾乎沒有地方吃飯了[F452, F148, F459]。冬天打算住溫泉街，又擔心晚上沒地方吃，[層雲峽住宿](/places/sounkyo/stay/)也談到要不要訂含晚餐的方案。

2026年冰瀑祭的煙火20:30才放，看完的時候Canyon已經過了最後點餐，大雪山食堂也打烊了，所以晚餐最好排在煙火前面[F75, F452, F148]。住在大雪飯店（ホテル大雪）的話，還有東館地下1樓的居酒屋大雪茶屋，開到24:00[F451]。再晚就只剩便利商店，從層雲峽觀光飯店走路大約5分鐘，有一家24小時營業的7-Eleven[F416]。
