## 3. 開頭怎麼寫

- A、B、E 都先講「層雲峽是什麼地方」（國立公園裡、柱狀節理峽谷、溫泉街），再一句帶到四季或主要景點，最後預告本文。
- D 不同：先拿一個具體的時間點當鉤子，馬上用轉折講限制（季節巴士、末班車），讀者第一段就知道「沒車會卡」。這最貼近本頁 H1「沒車怎麼去」。
- 幾篇都沒有在開頭就把景點分區。本站現在的開頭「景點分成三塊」是競品沒有的，可以保留，讀者一眼知道全貌。

## 4. 關鍵問題怎麼回答

- **有哪些景點、一天怎麼排**：A、E 只有清單沒有排法；A 的 Q&A 只說「半天到一天」。D 唯一有建議行程，而且先講「扣掉交通能用的時間」再講排不下什麼。順序是：可用時間 → 優先順序 → 排不下的放棄。沒有表格，用條列。
- **銀河瀑布、流星瀑布怎麼去**：C 先講兩瀑長怎樣（性格對比）→ 雙瀑台走多久 → 鞋子 → 交通。A 是描述 → 交通 → 走到雙瀑台多久。共通順序：**先描述兩瀑的差別，再講停車場就看得到，最後講雙瀑台的步行與裝備**。交通多半放在節末的資訊欄。
- **大函、紅葉谷**：大函在 D 是「位置（溫泉街往上游幾公里）→ 看什麼（柱狀節理岩壁）→ 怎麼去（巴士季節限定，其餘靠車）→ 封閉的步道」。紅葉谷在 A 是「步道長度與時間 → 難度 → 從巴士站走多久」。
- **溫泉街裡的景點**：B、D 的遊客中心都是「時間與休館 → 館內有什麼（模型、VR）→ 雨天可以去」。日歸溫泉在 D 是先講全年都能去的公共浴場，再列旅館；時間表用表格。
- **上川町的景點**：五篇都幾乎沒寫，D 只列上川站周邊幾家餐廳與轉車資訊。本站這節是競品缺的，順序照「從層雲峽回旭川順路停」的動線走即可。
- **沒車怎麼去**：D 最清楚：先否定（巴士不可靠）→ 季節巴士的期間與一天一班 → 改用計程車、租車或團。其他篇都只講到「搭巴士到溫泉街」，沒講溫泉街外面的景點怎麼去。A 寫巴士在瀧見台下車走到瀑布，沒有官方來源，本站不寫。
- **導覽團**：D 只提一個札幌出發的團，先講範圍（包含哪些點）再講限制。其他篇沒有。

## 5. 段落與句子的習慣

- 景點段落多是中長句，用逗號串兩三個分句；資訊欄與條列很短，一行一個值。
- 稱呼讀者：A、B、C 幾乎不直接稱呼，用「遊客」「建議」；D、E 直接用「你」。
- 轉場常用「此外」「除了…」「如果…的話」；D 多用「如果你想…就…」的條件句帶出不同讀者的選擇。
- 數字的位置：描述段幾乎不放數字，數字集中在每點最後的資訊欄（地址、時間、費用、交通）或表格。D 會把關鍵限制（停駛期間、末班）在開頭就用粗體點出來。
- 兩瀑一律用「對比」的寫法介紹（一細一粗、女瀑男瀑），讀者熟悉這個順序。

## 6. 給作者的順序建議

- **H2 層雲峽景點一天怎麼排？**
  1. 先講決定排法的條件：有沒有車、季節巴士已在 10/31 結束（現在去只能開車、計程車或團）。
  2. 再給有車的排法（上午峽谷沿線、下午溫泉街），最後是沒車的排法。
  3. 纜車、主頁的連結句放最後。
- **H2 從層雲峽溫泉街走得到的地方**：先講下巴士在哪、從那裡走得到哪些點，再講案內所能幫什麼。
- **H3 層雲峽遊客中心**：位置與免費 → 館內看什麼（影片、模型、VR，雨天也能看）→ 繁中導覽 → 時間表（11 月起週一休館放進表格，段落裡提醒一句）。
- **H3 紅葉谷散策道與紅葉瀑布**：步道長度與終點看什麼 → 從溫泉街怎麼走到入口、各段時間 → 裝備與棕熊 → 停車 → 秋天紅葉與連結句。開放期間到 11 月上旬，現在去要提醒。
- **H3 日歸溫泉黑岳之湯與寫真博物館**：泡湯放前面（全年可去）→ 費用 → 時間表；博物館 2026 年已閉館，放後面並寫明期間。
- **H2 銀河瀑布與流星瀑布**：兩瀑對比 → 停車場就看得到、免費 → 雙瀑台步行與裝備 → 秋天紅葉。
- **H2 大函與大雪水壩**：位置 → 看什麼 → 開放與停車 → 小函封閉、改看紅葉谷 → 大雪水壩。
- **H3 沒車怎麼去大函與瀑布？**：先一句結論（巴士只在 7～10 月、每天一班，瀑布只能靠車或團）→ 時刻表 → 計程車與怎麼叫車。
- **H2 上川町景點**：從層雲峽回旭川順路的順序（離上川站多遠）→ 各點。森のガーデン先講三區與餐廳，再講期間與票價（2026 年已結束，票價改用 2026 年版）。
- **H2 跟導覽團玩層雲峽**：先講溫泉街出發的團（自行車到瀑布，對沒車的人最有用）→ 泛舟 → 觀察會報不了。
