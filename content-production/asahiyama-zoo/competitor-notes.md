## 開頭怎麼寫

- Funliday：先講它的身世（開園年份、差點倒閉、靠理念翻身），用故事建立分量，最後一句列出本文涵蓋的主題。
- 兔兔安：先說它在當地很紅，接著一口氣點名幾種明星動物，再說園區大、設施齊全，以「推薦大家來」收。
- WaTabi：先丟一個反直覺說法（不是靠稀有動物紅的），用一兩個具體畫面舉例，再點出冬天的招牌活動，段尾把關鍵數字一次列出。
- 好運日本行：先給兩個硬事實（日本最北、每年多少人來），再一句定義行動展示，預告本文三個重點，最後直接對讀者說「請看到最後」。
- 蕃薯藤：先定位成「旭川必去」，再一句話鋪陳「不大但有故事」，用感嘆句收尾製造期待。
- 日本觀光局：從整體特色縮到一種動物（國王企鵝），由大到小。

觀察：沒有一篇第一段就回答「幾點開、票多少、怎麼去」；排名前面的都是先讓讀者知道「為什麼值得去」。我們的規則是開頭直接回答核心問題，所以可借的是「回答完核心問題後，用一句話交代它為什麼值得排進行程」，不必整段講歷史。

## 關鍵問題怎麼回答

**開放時間與休園日**
- Funliday：一句「時間依季節變」→ 表格（期間｜開園｜閉園｜特別活動）→ 提醒看官網。
- WaTabi：條列，依「期間 → 時間」的格式，冬期、特別開園、休園、夏期依日曆順序排。
- FUN! JAPAN：不用表格，按季節由長到短分段，每段一句裡嵌入時間。
- 共同：期間在前、時間在後；休園日多半夾在時間表裡，沒有單獨講「哪幾天不能去」。表格或條列都有，沒有人用整段文字寫完所有季節。

**企鵝散步**
- WaTabi：是什麼 → 期間 → 每天幾場 → 會被取消的原因 → 實用提醒（提早卡位、保暖）。
- 好運日本行：冬季代表活動 → 為什麼受歡迎 → 每天幾次、幾點 → 天候會變 → 三條觀看禮節（每條先講原因再講規範）。
- Funliday、兔兔安：放在企鵝館介紹裡，先講館的設計，最後才講冬天的散步。
- 日本觀光局：時間範圍 → 能多近看 → 澄清這不是表演、是讓企鵝運動 → 次數。
- 共同：期間與場次放前段；「不是表演、是運動」是多家都寫的意義說明；取消條件緊接在場次之後；觀看規矩放最後。只有 WaTabi 用條列。

**門票**
- WaTabi：入園費 → 年票 → 調價 → 去哪買 → 購票限制，從「多少錢」走到「怎麼買」。
- Funliday：表格（一日票、兩日票 × 年齡兩列），價格旁直接放購買管道。
- 兔兔安、蕃薯藤：票價 → 誰免費 → 套票或兩日票。
- 共同：先成人票價，再免費對象，再其他票種，最後才是購買方式。

**從旭川站搭公車**
- WaTabi（最完整）：先說有公車與自駕兩條路 → 條列：路線號、乘車處、車程、車資、班次間隔、能用什麼付錢 → 冬季末班 → 錯過時改搭計程車。
- FUN! JAPAN、日本觀光局：從哪站、幾號乘車處、幾號線、約幾分鐘，一句話寫完；日本觀光局多一句計程車比公車快多少。
- 兔兔安、蕃薯藤、好運日本行：一段文字，路線號＋車程，沒有車資與末班。
- 共同：上車地點 → 路線號 → 車程 → 車資 → 付款方式 → 末班與替代方案。機場出發都只是一句「另有直達」；札幌出發都是「先搭 JR 到旭川」一句，再接當天來回可行。

**逛多久**
- Funliday 問答：先給官方建議時數 → 再依腳程放寬成一個範圍。
- WaTabi：沒有獨立回答，改成建議住一晚、分兩天排。
- 兔兔安：只說玩一整天沒問題。
- 共同：給一個數字或範圍，不解釋怎麼算；逛的路線（從東門走下坡）常放在旁邊的「撇步」裡，不和時數放一起。

**冬季**
- 沒有一篇有完整的冬季節；WaTabi 用夏冬比較表（看點、開園時間、體感、順遊、人潮）處理「哪季去」。
- 冬季資訊散在三處：縮短的開園時間、企鵝散步、保暖提醒。夜間開園只有 WaTabi、蕃薯藤、日本觀光局提到，都是「哪幾天 → 開到幾點 → 晚上看起來什麼樣」的順序。

## 段落與句子的習慣

- 句子中等長，常用逗號串兩個子句；寫規定或提醒時改成短句加「請」「記得」。
- 稱呼讀者：編輯型（好運日本行、日本觀光局）用「您」「旅人」；部落客型用「大家」「你」，語尾加「喔」「呢」。WaTabi 用第一人稱下判斷，例如「我的建議是住一晚」這種講法。
- 轉場：「接下來」「另外」「不過」最常見。好運日本行介紹各館時，用上一館的位置帶出下一館（像是「旁邊就是…」），讀起來像跟著走。
- 數字位置：實用數字（時間、車程、價格）直接嵌在句子中段，例如「搭某號線約四十分鐘就到」；成堆的數字丟進表格或條列，不在段落裡一口氣列三個以上。
- 先動作後數字：交通句多半是「在哪裡上車 → 搭幾號 → 多久到」，數字在動作之後出現，不是先丟一個數字再解釋。
- 規定先講原因：好運日本行寫禁止閃光燈時，先說動物怕光，再說請不要拍；讀者比較不覺得被命令。
- 澄清式的一句：「這不是表演，是讓企鵝運動」這種先否定常見誤會再講真相的句子，多家都用，讀起來自然。
- 缺點：Funliday、兔兔安的同一件事分散在兩三節（企鵝散步、冬季時間），台灣讀者常在留言問；我們按分工規則一件事寫一處，正好避開。

## 給作者的順序建議

**H1 旭山動物園門票、交通與開放時間，企鵝散步什麼時候有**
- 開頭段落先直接回答讀者最想知道的兩三件事（現在開不開、企鵝散步在哪幾個月），再用一句話交代它為什麼有名（行動展示），不要先講歷史。
- 段尾一句帶出全文順序（時間 → 企鵝 → 門票 → 交通 → 園內），讓讀者知道往下找什麼。

**H2 旭川旭山動物園開放時間與休園日**
- 先給一張依日曆順序排的期間表（期間｜開園｜最後入園｜閉園），休園期直接放進表裡同一張。
- 表格前只用一句話說「依季節分幾段、冬天比較短」；表格後一句講最常見的例外。
- **H3 冬季開園的時間**：先講冬期從哪天到哪天、幾點到幾點，再講冬天與夏天最大的差別（關得早、最後入園），最後講對行程的影響（下午到就很趕）。
- **H3 夜間開園**：照「哪幾天 → 開到幾點 → 晚上能看什麼」排，兩種夜間開園各一小段，先冬（雪光）後夏或依日曆順序，二選一後全文一致。

**H2 旭川旭山動物園企鵝散步時間**
- 先回答「哪幾個月有、每天幾場、幾點」，接一句「這是讓企鵝運動、不是表演」。
- 再講什麼情況會取消或改時間、去哪裡看當天公告。
- 最後才是觀看實務（提早到、站哪裡、閃光燈等規矩，每條先講原因）。

**H2 旭川旭山動物園門票怎麼買**
- 先成人票價與免費對象（一句或小表），再講其他票種，最後講在哪裡買、能不能刷卡。
- **H3 款待券**：先講誰能買（住旭川的條件），再講能省什麼，最後講去哪裡拿。
- **H3 2027 年 4 月起的新票價**：先講哪天起、新舊各多少，再一句講「在那之前去照舊價」。

**H2 旭川旭山動物園怎麼去**
- 先一句話列出幾種去法並推薦多數人用哪一種，再進各 H3。
- **H3 公車班次與車資**：照「旭川站哪個乘車處 → 幾號線 → 車程 → 車資 → 怎麼付 → 回程末班」排；路線差別多就用小表。
- **H3 冬季的公車**：先講冬天跟平常哪裡不同（班次或末班），再講錯過末班怎麼辦。
- **H3 78 號**：先講在機場哪裡搭、車程與車資，再講班次少要怎麼配合航班；一段就好。
- **H3 從札幌當天來回**：先說可不可行，再依觀光巴士、自駕各講一兩句「適合誰」，最後才是時間。
- **H3 計程車**：先講從哪裡搭、大約多久，再講什麼時候值得搭（錯過公車、多人分攤）。

**H2 到了旭川旭山動物園，園內怎麼逛**
- **H3 逛多久？**：第一句給時數範圍，接著講什麼會讓時間變長（企鵝散步、餵食時間），最後講從哪個門進比較省力。
- **H3 旭山公園**：先講從動物園怎麼走過去、要多久，再講什麼季節值得去，最後一句接回回程公車。

## 他們有、我們可能缺的

- 從東門進、一路走下坡比較省力（三篇都寫）
- 入口的手寫看板或每天早上公告的餵食與活動時刻表
- 園內各館的介紹與看點（北極熊、海豹圓柱水槽、企鵝水中隧道）
- 夏天去還是冬天去的比較
- 禽流感等原因讓企鵝散步延後或暫停的前例
- 寄物櫃、嬰兒車與輪椅出借、園內接駁
- 園內餐飲與飛鳥搶食提醒、紀念品、企鵝郵筒
- 中文導覽手冊與園區地圖取得方式
- 從新千歲機場出發的完整路線
- 回程公車排隊的情況
- 周邊順遊（旭川拉麵村、美瑛、富良野）與住宿
