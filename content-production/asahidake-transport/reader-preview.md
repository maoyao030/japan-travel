# 旭岳交通，旭川到旭岳的出湯號、機場出發與冬天自駕

旭岳纜車站在旭川機場開車大約60分鐘的山裡，如果不開車的話，旭岳交通就只有一條路線巴士，就是旭川電氣軌道（旭川電気軌道）的66號出湯號（いで湯號）。巴士從旭川站發車，經過旭川機場跟東川開到旭岳纜車站前，一天只有4個來回。旭川站到旭岳要1小時48分鐘，大人單程2,300日圓。回程末班車16:55從旭岳開出，錯過了很難臨時找到車下山。

開車從JR旭川站大約1小時10分鐘。往旭岳溫泉的北海道道1160號冬天不在封路名單上，不過每年10月中旬到4月上旬可能下雪結冰，所以需要換冬季輪胎。

## 旭川到旭岳的出湯號

出湯號在旭川站前巴士總站Bus Touch（バスタッチ）的9號乘車處上車。往富良野的車也停在同一個乘車處，往旭岳的是66號。如果還要從札幌或新千歲機場先到旭川的話，可以看另外整理的旭川交通，裡面有到旭川站的各種走法，Bus Touch在哪裡跟9號乘車處怎麼找也寫在那一頁。

一天4個來回，2025年10月1日起一年四季都用同一張時刻表。

旭川站到旭岳去程1小時48分鐘，回程1小時38分鐘。想在山上玩一整天的話，就搭7:15或9:15從旭川站出發的車。14:15那班到旭岳已經16:03，纜車11月15日以前16:00收班，11月16日到12月10日停駛，12月11日起營業到15:40，所以這班車只適合當晚住旭岳溫泉的行程。如果還沒決定旭岳要當天來回還是住一晚，可以先看旭岳一日遊或住一晚。

東川道草館（ひがしかわ道草館）在路線中段，去程跟回程都會停。想在道草館中途下車逛逛東川的話，東川町那一頁有整理鎮上可以去哪些地方。

### 從旭川機場直接搭出湯號

從機場出發不用先進旭川市區，發車時間是8:00、10:00、13:00、15:00。到旭岳大約1小時3分鐘，大人車資1,650日圓，比從旭川站上車便宜650日圓。

走出航廈的出入口4，左手邊就是公車站，往東川跟旭岳的車停在2號乘車處，1號乘車處是往旭川站的車。售票機在一樓國內線入境大廳的出入口3附近，出航廈前就能把票買好。

出湯號照時刻表開，不等班機。如果飛機晚到錯過10:00那班的話，下一班就要等到13:00了。

### 出湯號的車票與IC卡

旭川站到旭岳單程2,300日圓，來回沒有折扣，要買2張單程票，合計4,600日圓。12月1日起旭川電氣軌道調整車資，不過旭岳線這幾段的車資不變。

Suica、Kitaca這類全國交通IC卡不能用，能刷的只有旭川電氣軌道的Asaca跟道北巴士的DoCARD兩種。如果手上只有其他IC卡的話，就付現金，或是在上車前用售票機買票。

無現金售票機收信用卡跟QR支付，可以買「旭岳線」車票，一次買好幾個人的份也行，畫面有日、英、中、韓文。旭川站那一台放在旭川電氣軌道的服務處綜合案內所，就在站前鶴羽大樓1樓，5:45到22:00都能用。旭川機場的入境大廳也有一台，機場營業時間內都能買。去程跟回程兩張票在旭川站或機場一次買齊的話，回程就不必擔心現金不夠了，因為旭岳周邊沒有銀行、郵局跟ATM，最近的ATM開車要30到40分鐘。

付現金就從中門上車、抽一張整理券，下車時把整理券跟車資一起投進車上的投幣箱（運賃箱）。先買好票也一樣拿整理券，下車時連同車票投進去就好。車上只能換千圓鈔，零錢最好在旭川就備好。

售票機買的票不能直接取消。要退票的話，到買票那台售票機所在的窗口辦，扣100日圓手續費後退現金，旭川站的窗口只開8:00到18:30。

### 帶行李箱搭出湯號

大件行李放車底的行李艙，原則上每人1件，體積0.25立方公尺、長2公尺、重30公斤以內。空間有限，帶第二件可能會被拒收，就算行李艙還有位子，如果會影響其他乘客放行李的話也可能不收。

## 從札幌怎麼去旭岳？

從札幌搭大眾運輸的話，要先到旭川再轉出湯號。札幌往旭川的特急一天大約24班，最快1小時25分鐘，普通車指定席5,440日圓。札幌6:29發的第一班特急7:56到旭川，剛好接得上9:15的出湯號。

高速巴士高速旭川號（高速あさひかわ号）單程2,500日圓，比特急便宜，不過比較慢，車程4月到11月約2小時5分鐘，12月到3月約2小時25分鐘。開車從JR札幌站到旭岳大約3小時。

## 住旭岳溫泉，出湯號在哪站下車？

住K's House北海道，在「旭岳溫泉入口」下車就好。住La Vista大雪山（ラビスタ大雪山），在「旭岳露營場」下車。如果還在挑旅館的話，可以看旭岳溫泉住宿那頁，每一家離哪一站近、有沒有接送都整理在裡面。

出湯號在旭岳溫泉一帶停4站，依序是旭岳溫泉入口（旭岳温泉入口）、旭岳露營場（旭岳キャンプ場）、Hotel Bear Monte前（ホテルベアモンテ前），最後是纜車站前的終點「旭岳」。下表以旭川站7:15發、旭岳9:55發的兩班為例。

| 站名 | 7:15旭川站發的車 | 9:55旭岳發的車 |
|---|---|---|
| 旭岳溫泉入口 | 8:49 | 9:57 |
| 旭岳露營場 | 8:50 | 9:56 |
| Hotel Bear Monte前 | 8:54 | 9:55 |
| 旭岳 | 9:03 | 9:55 |

坐到旭岳溫泉入口的車資跟坐到終點一樣，旭川站上車2,300日圓、機場上車1,650日圓。

## 開車去旭岳，停車場與冬天路況

往旭岳溫泉走北海道道1160號旭岳溫泉線。旭川機場開過去約60分鐘，JR旭川站約1小時10分鐘，旭川北IC約1小時20分鐘。美瑛過來約40分鐘、白金溫泉約1小時10分鐘，東川市區到旭岳遊客中心約40分鐘。從層雲峽溫泉開車約2小時30分鐘，想把兩個地方排在一起的話，旭岳跟層雲峽的比較頁有寫怎麼安排。導航可以輸入纜車的電話0166-68-9111設定目的地。

夏天到紅葉季，旭岳附近的道路跟停車場容易擁擠，遊客中心也呼籲盡量搭公共交通。紅葉旺季的週末跟假日，纜車停車場常常會停滿，入口常排起車隊。纜車停車場有150個小客車車位，6月到10月每天500日圓，11月到5月免費。車可以連續停好幾天，不過除了每天的停車費，還要另外加收費用。要注意纜車收班後停車場出入口就會關閉，車子開不出來，也不能睡在車上。

遊客中心停車場有91個車位，7月1日到9月30日收500日圓，大型車不能停，也不能在車上過夜。冬天遊客中心前的公共停車場會關閉，所以冬天自駕就停纜車停車場。

La Vista大雪山提醒自駕旅客，每年10月中旬到4月上旬要裝冬季輪胎或帶雪鏈。1160號不在道路管理者旭川建設管理部的冬季封路名單上。東川觀光協會也說，冬天這條路的除雪做得很好，只要天氣不是很差，開到旭岳溫泉沒有問題。不過天氣不好的日子，出發前記得查一下北海道的道路資訊再決定。

往旭岳的路上有幾段收不到手機訊號，出發前最好先下載離線地圖。2026年9月到10月，遊客中心的紀錄裡有好幾次是開車時從車上看到棕熊，髮夾彎附近也有。

## 搭出湯號當天來回旭岳的時間安排

如果不開車當天來回的話，能在山上待多久就由巴士決定了。最早的一班9:03到旭岳，最晚的回程是16:55。

| 時間 | 地點 |
|---|---|
| 7:15 | 旭川站發車 |
| 8:00 | 旭川機場 |
| 9:03 | 抵達旭岳，在纜車站前下車 |
| 16:55 | 旭岳發末班車 |
| 17:50 | 旭川機場 |
| 18:33 | 抵達旭川站 |

上山的纜車跟著季節換時間，排行程前記得對一下接下來的營業日。11月15日以前是9:00到16:00，上行末班15:40，9:03下車時纜車已經開門了，不過下山的末班卻比末班巴士16:55早。11月16日到12月10日纜車停駛，這段期間搭出湯號上山也搭不到纜車。12月11日起是9:00到15:40，一樣比末班巴士早收。官網月曆目前只排到12月，之後的月份出發前看纜車官網的營業月曆就好。

夏天纜車開得早、收得晚，2026年7月到9月平日多半6:30、週末跟連假多半6:00開始，下山末班都是17:30，比末班巴士晚，所以回程只要看巴士時間就好。10月1日到20日是8:00到17:00，也比末班巴士晚。

纜車的發車時間跟班距可能臨時微調，纜車官網也提醒要接出湯號的旅客抓好時間。排行程時把14:55那班當回程的話，錯過了還有16:55，比一開始就排末班車多一層保險。想對照其他月份的纜車營業時間跟搭乘方式，可以看旭岳纜車與姿見池。

## 從旭岳回旭川的末班車

旭岳開出的末班出湯號是16:55，17:50到旭川機場、18:33到旭川站。如果要搭當天的飛機離開的話，得配合17:50到機場的這班車，或是搭更早的車。

真的錯過了，旭岳溫泉沒有計程車招呼站跟租車公司，計程車要向最近的計程車公司預約才行。不會講日文的時候，可以到遊客中心或纜車站請工作人員協助叫車，住在旭岳溫泉就請旅館櫃台幫忙。不過遊客中心只開到17:00。從旭岳溫泉搭計程車到JR旭川站大約1小時。另一個做法是在旭岳溫泉住一晚，隔天搭9:55的頭班車回旭川。
