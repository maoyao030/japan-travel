# 旭岳交通競品閱讀筆記（2026-11-01）

用途：給重寫的作者看「台灣讀者常讀的文章怎麼排資訊」。只記順序與寫法，不記事實。這幾篇的時刻、車資、班數互相矛盾而且多半過期（有寫一天 3 班的、有寫 1,430 日圓的、有寫 1,800 日圓的、有把機場發車寫成 7:55 的），一律不當事實來源；正文只用 `reference-review.md`。

搜尋方式：WebSearch（美國端，排名只是大概），查「旭岳交通」「旭川到旭岳」「旭岳溫泉交通」與幾個組合詞（巴士、自駕、一日遊）。台灣讀者的專門「旭岳交通」文章很少，前面多半是官方觀光網站（北海道官方旅遊網、環境省國立公園、東川町）與景點總覽文，交通只是其中一節。好運日本行只有店家目錄頁、MATCHA 沒找到旭岳交通文，沒收。LIVE JAPAN 的交通頁回 503，沒讀。

## 2. 各篇的順序

**UpToGo**
1. 前言：旭岳是北海道最高峰、愛努語意思、四季景色，再說「看起來遠其實不難」，預告會講巴士、自駕、纜車。
2. 巴士：先一句「不開車就搭這個，終點就是纜車站」→ 上車地點與路線（起點、經由、終點條列）→ 時刻與車程（先說一天幾班、提醒看回程末班，再給車程、再給時刻表）→ 回程末班與錯過要搭計程車 → 票價與買票（先價錢，再上車抽整理券投現金，再售票機）。
3. 自駕：路線與車程 → 導航設定（Mapcode、電話）→ 停車（費用、紅葉季客滿）→ 雪季提醒（沒雪地經驗就改搭巴士）。
4. 其他：札幌出發觀光巴士、包車計程車（車資、優點）。
5. 抵達後轉纜車（區間、班距、票價、停駛期）。
6. FAQ：IC 卡、暈車、要不要登山裝備、一天停留多久。
7. 總結：再推一次巴士，自駕或包車當備案。

**WAmazing**
1. 開頭一句：最近的車站是旭川站、開車多久。
2. 巴士：哪條線、幾號乘車處、終點下車、一天幾班、車程、車資，全擠在一段；接著一句機場出發的車程與車資。
3. 自駕或計程車：先停車場（收費月份、金額、其他季節免費）→ 計程車（距離、時間、車資）→ 山上沒有計程車招呼站要先叫車 → 註記某旅館有住客接駁。
4. 札幌出發的夏季觀光巴士（含什麼、價錢、去哪報名）。

**凱子凱**
1. 交通：旭岳離旭川站、美瑛各多遠 → 位置在旭川與富良野中間但要彎進山 → 建議自駕順排美瑛富良野 → 巴士一天只有來回各 4 班、務必先看時刻表 → 舉回程幾班的時間 → 下車點就在纜車站前。
2. 纜車站資訊（票價、到姿見站幾分鐘、末班下行）。

**雪嶼**：纜車 → 步道 → 四季 → 溫泉 → 交通（巴士一句、自駕一句）→ 附近景點。

## 3. 開頭怎麼寫

- UpToGo 和 WAmazing 都先講旭岳是什麼（最高峰、高山花田、紅葉最早），再一句把話轉到「怎麼去」。UpToGo 特別先替讀者說出顧慮（看起來很偏遠），再說其實不難。
- 凱子凱先用距離定位（離旭川站、美瑛各幾分鐘），讓讀者知道它在地圖上哪裡，再講班次少的風險。
- 沒有一篇在開頭就把班次、末班、車資一次講完；我們現在的開頭比競品更直接，這點可以保留，但可以學凱子凱用一句距離讓讀者先有地圖感。

## 4. 關鍵問題怎麼回答

| mustAnswer | 競品的資訊順序 | 表格 |
|---|---|---|
| 旭川站、機場到旭岳怎麼搭、時刻、多久、多少錢 | 一致是：「不開車就搭這班、終點在纜車站前」→ 哪裡上車 → 一天幾班 → 車程 → 時刻 → 車資。班數都在時刻表之前先講，讓讀者先知道「很少」。機場出發多半只是巴士段落裡的一句（車程、車資），不單獨成節 | UpToGo 用「地點×班次」表，只列旭川站、機場、旭岳三列 |
| 車票怎麼買、能用什麼卡、行李 | 先價錢，再上車流程（整理券、現金），最後才講售票機。IC 卡只有 UpToGo 放在 FAQ，而且答得含糊。行李沒有一篇寫 | 無 |
| 開車、停車場、冬天輪胎 | 路線與車程 → 導航 → 停車場收費月份與金額 → 旺季客滿 → 冬天路況（最後講、偏勸退） | 無 |
| 住宿在哪一站下車 | 沒有一篇寫；WAmazing 只有某旅館接駁一句 | 無 |
| 當天來回怎麼排、回程末班 | 末班都放在巴士時刻後面一兩句，口氣是警告（錯過很麻煩、計程車很貴）；沒有一篇把纜車時間和巴士對起來 | 無 |
| 從札幌出發 | WAmazing、UpToGo 寫的是札幌出發的夏季觀光巴士，不是先到旭川再轉車；搭火車到旭川的寫法多半只在別的頁 | 無 |

## 5. 段落與句子的習慣

- 句子短，一句講一件事；常用條列（起點／經由／終點，或費用／旺季注意）把規格拆開，段落很少超過三句。
- 稱呼讀者用「您」（UpToGo、凱子凱）或不稱呼；凱子凱會用「搭乘巴士的朋友」。我們用「你」或不稱呼即可。
- 轉場靠小標或一句條件句：「對於非自駕的旅客來說」「如果您選擇租車自駕」「若您帶著長輩、小孩」。用讀者的狀況開段，再給做法。
- 數字放在句子後半或條列冒號後面，先講事，再講數字。警告句放在段落最後（末班、雪地、客滿）。
- 結尾都會回到「最推薦哪個方式」做收，我們不寫總結，但可以在開頭就把選擇講清楚。

## 6. 給作者的順序建議

標題照現在的 `draft-tagged.md`，只調每一節裡的順序。

- **開頭（H1 下）**：先一句定位（旭岳在旭川東邊山裡、不開車就靠一條巴士），再講一天 4 班與末班，最後一句帶自駕。讀者第一個要知道的是「有沒有車、多不多」。
- **旭川到旭岳的Ideyu號**：1. 在哪上車（Bus Touch 9 號、66 號）2. 一天 4 班、全年同一張表 3. 時刻表 4. 車程與該搭哪班。把「還沒決定當天來回或住一晚」的連結句放在這節結尾或時刻表之後也可以，但句子一字不改。
- **從旭川機場直接搭Ideyu號**：1. 不用進市區、發車時間 2. 車程與車資 3. 走出航廈怎麼找乘車處、售票機在哪 4. 不等班機（警告放最後）。Funliday 的機場巴士小節也是路線→時間票價→時刻→購票與乘車處。
- **Ideyu號的車票與 IC 卡**：競品都是先價錢、再上車流程、最後售票機。建議：1. 車資（含來回沒有折扣）2. 能不能刷卡（Suica 不能用，這是讀者最常問的）3. 售票機在哪、幾點能用 4. 上車整理券流程與零錢、ATM 5. 退票（讀者最少用到，放最後或考慮刪）。
- **帶行李箱搭Ideyu號**：規定一句、可能被拒收一句，維持短段。
- **從札幌去旭岳**：1. 結論：先到旭川再轉 Ideyu號 2. 特急（班數、最快時間、能接上的第一班）3. 高速巴士（便宜、較慢）4. 開車 3 小時。
- **旭岳溫泉交通，Ideyu號在溫泉區的下車站**：先講「住哪家在哪站下」（讀者是帶著旅館名來找的），再給 4 站順序與時刻表，車資一句收尾。
- **開車去旭岳，停車場與冬天路況**：競品順序是路線車程→導航→停車→冬天。建議：1. 走哪條路、各地出發多久 2. 導航可以輸入什麼（F183，可選）3. 停車場（纜車停車場、遊客中心停車場、冬天停哪）4. 冬天輪胎與封路 5. 訊號與棕熊。旺季擁擠可以放在停車場開頭。
- **搭Ideyu號當天來回旭岳的時間安排**：1. 能待多久由巴士決定（最早到、最晚走）2. 時間軸表 3. 纜車和末班巴士的關係，先講接下來的時段（11/15 前、運休、12/11 起），夏季放後面 4. 回程抓 14:55、16:55 當備案。
- **從旭岳回旭川的末班車**：1. 末班時間與到機場、旭川站的時間 2. 當天飛機要搭哪班 3. 錯過了怎麼辦（叫車、住一晚）。

## 7. 他們有、我們缺的

只列出來，不寫進文章；回官方查的結果見 `reference-review.md`「重寫前讀競品補研究」。

- 導航設定（Mapcode、纜車電話）：電話補到 F183，Mapcode 沒有官方來源。
- 札幌出發的夏季定期觀光巴士：中央巴士現在查不到這個行程，不寫。
- 計程車車資：只有過期的東川町頁有數字，不寫。
- 某旅館的住客接駁：歸住宿頁。
- 山路彎道與暈車、要不要登山裝備、在山上停留多久：沒有官方資料或歸纜車與健行頁。
