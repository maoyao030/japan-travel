# 旭岳交通，旭川到旭岳的Ideyu號、機場出發與冬天自駕

旭岳交通靠的是旭川電氣軌道（旭川電気軌道）的66號路線巴士Ideyu號（いで湯號），不然就是自己開車[F177]。每天從旭川站發車，經旭川機場、東川町開到旭岳纜車站前[F23, F177, F29]。一天只有4個來回，旭川站到旭岳要1小時48分鐘，大人單程2,300日圓[F24, F27, F30]。回程末班車16:55從旭岳開出，錯過了很難臨時找到車下山[F26, F13]。

開車也到得了，從旭川機場約60分鐘、JR旭川站約1小時10分鐘[F38]。往旭岳溫泉的北海道道1160號冬天不在封路名單上，但每年10月中旬到4月上旬可能下雪結冰，需要換冬季輪胎[F168, F45]。

## 旭川到旭岳的Ideyu號

還沒決定旭岳要當天來回還是住一晚，可以先看旭岳一日遊或住一晚。

Ideyu號在旭川站前巴士總站Bus Touch（バスタッチ）的9號乘車處上車[F176]。往富良野的車也停同一個乘車處，往旭岳的是66號[F177]。札幌、新千歲機場怎麼到旭川，見旭川交通。站前Bus Touch在哪裡、9號乘車處怎麼找，也寫在那一頁[F176]。

旭川站到旭岳去程1小時48分鐘，回程1小時38分鐘[F27]。想在山上玩一整天，就搭7:15或9:15從旭川站出發的車[F25]。14:15那班到旭岳已經16:03，10月21日起纜車下山的末班是16:00，12月11日起更早，都在這之前就收班了，比較適合當晚住旭岳溫泉的行程[F25, F179]。

東川町的東川道草館（ひがしかわ道草館）在路線中段，去程、回程都會停[F28]。在道草館中途下車逛東川，見東川町。

### 從旭川機場直接搭Ideyu號

從機場出發不用先進旭川市區[F23]。發車時間是8:00、10:00、13:00、15:00，到旭岳約1小時3分鐘[F25, F27]。大人車資1,650日圓，比從旭川站上車便宜650日圓[F30]。

走出航廈的出入口4，左手邊就是公車站，往東川、旭岳的車停2號乘車處，1號乘車處是往旭川站的車[F174]。售票機在一樓國內線入境大廳的出入口3附近，出航廈前就可以把票買好[F174]。

Ideyu號照時刻表開，不等班機[F33]。飛機晚到錯過10:00那班，下一班就要等到13:00[F25]。

### Ideyu號的車票與 IC 卡

Suica、Kitaca這類全國交通IC卡不能用[F163]。Ideyu號能刷的只有旭川電氣軌道的Asaca與道北巴士的DoCARD兩種[F32, F163]。手上只有其他IC卡，就付現金，或在上車前用售票機買票[F164, F165]。

無現金售票機收信用卡與QR支付，可以買「旭岳線」車票，一次買好幾個人的份也行[F164]。畫面有日、英、中、韓文[F164]。旭川站那一台放在旭川電氣軌道的服務處綜合案內所，就在站前Tsuruha大樓1樓[F164]。售票機5:45到22:00都能用，服務處的窗口只開8:00到18:30[F164, F178]。旭川機場的入境大廳也有一台，機場營業時間內都能買[F164]。

來回沒有折扣，要買2張單程票，旭川站到旭岳來回是4,600日圓[F31, F30]。12月1日起的車資調整，旭岳線這幾段的車資不變[F166]。售票機買的票不能直接取消[F164]。要退票，到買票那台售票機所在的窗口辦，扣100日圓手續費後退現金，旭川站的窗口開到18:30[F164, F178]。

付現金就從中門上車、抽一張整理券，下車時把整理券和車資一起投進車上的投幣箱（運賃箱）[F165]。先買好票也一樣拿整理券，下車時連同車票投進去[F165]。車上只能換千圓鈔，零錢最好在旭川備好[F165]。旭岳周邊沒有銀行、郵局與ATM，最近的ATM開車要30到40分鐘[F9]。去程、回程兩張票在旭川站或機場一次買齊，回程就不必擔心現金不夠[F31, F164, F9]。

### 帶行李箱搭Ideyu號

大件行李放車底的行李艙，原則上每人1件，體積0.25立方公尺、長2公尺、重30公斤以內[F34]。空間有限，帶第二件可能被拒收[F34]。就算行李艙還有位子，會影響其他乘客放行李時，也可能不收[F34]。

## 從札幌去旭岳

從札幌搭大眾運輸，要先到旭川再轉Ideyu號。札幌往旭川的特急一天約24班[F172]。特急最快1小時25分鐘，普通車指定席5,440日圓[F170, F171]。札幌6:29發的第一班特急7:56到旭川，接得上9:15的Ideyu號[F181, F25]。高速巴士高速旭川號（高速あさひかわ号）單程2,500日圓，車資比特急便宜，車程4月到11月約2小時5分鐘，12月到3月約2小時25分鐘[F173, F180]。

開車從JR札幌站到旭岳約3小時[F38]。

## 旭岳溫泉交通，Ideyu號在溫泉區的下車站

Ideyu號在旭岳溫泉一帶停4站[F29]。依序是旭岳溫泉入口（旭岳温泉入口）、旭岳露營場（旭岳キャンプ場）、Hotel Bear Monte前（ホテルベアモンテ前），最後是纜車站前的終點「旭岳」[F29]。各站時間以旭川站7:15發、旭岳9:55發的兩班為例[F29]。

|---|---|---|
| 旭岳溫泉入口 | 8:49 [F29] | 9:57 [F29] |
| 旭岳露營場 | 8:50 [F29] | 9:56 [F29] |

住K's House北海道，在「旭岳溫泉入口」下車[F136]。住La Vista大雪山（ラビスタ大雪山），在「旭岳露營場」下車[F169]。坐到旭岳溫泉入口的車資和坐到終點一樣，旭川站上車2,300日圓、機場上車1,650日圓[F167]。各旅館的位置與接送，見旭岳溫泉住宿。

## 開車去旭岳，停車場與冬天路況

往旭岳溫泉走北海道道1160號旭岳溫泉線[F46]。旭川機場開過去約60分鐘，JR旭川站約1小時10分鐘，旭川北IC約1小時20分鐘[F38]。美瑛過來約40分鐘、白金溫泉約1小時10分鐘，東川町市區到旭岳遊客中心約40分鐘[F38, F39]。從層雲峽溫泉開車約2小時30分鐘，兩地怎麼排在一起，寫在旭岳與層雲峽的比較頁[F38]。

夏天到紅葉季，旭岳附近的道路與停車場容易擁擠，遊客中心也呼籲盡量搭公共交通[F40]。紅葉旺季的週末與假日，纜車停車場會停滿，入口常排起車隊[F42]。纜車停車場有150個小客車車位，6月到10月每天500日圓，11月到5月免費[F41]。車可以連續停好幾天，除了每天的停車費，還要另外加收費用[F41]。不過纜車收班後，停車場出入口就會關閉，車子開不出來，也不能睡在車上[F42]。

遊客中心停車場有91個車位，7月1日到9月30日收500日圓，大型車不能停，也不能在車上過夜[F20]。遊客中心前的公共停車場冬季關閉，冬天自駕就停纜車停車場[F43, F41]。

La Vista大雪山提醒自駕旅客，每年10月中旬到4月上旬要裝冬季輪胎或帶雪鏈[F45]。1160號不在道路管理者旭川建設管理部的冬季封路名單上[F168]。東川町觀光協會也說，冬天這條路的除雪做得很好，只要天氣不是很差，開到旭岳溫泉沒有問題[F44]。天氣不好的日子，出發前查一下北海道的道路資訊再決定[F44]。

往旭岳的路上有幾段收不到手機訊號，出發前最好下載離線地圖[F12]。2026年9月到10月，遊客中心的紀錄裡有好幾次是開車時從車上看到棕熊，髮夾彎附近也有[F46]。

## 搭Ideyu號當天來回旭岳的時間安排

不開車當天來回，能在山上待多久由巴士決定。最早的一班9:03到旭岳，最晚的回程是16:55[F25, F26]。

| 時間 | 地點 |
|---|---|
| 7:15 [F25] | 旭川站發車 |
| 8:00 [F25] | 旭川機場 |
| 9:03 [F25] | 抵達旭岳，在纜車站前下車 |
| 16:55 [F26] | 旭岳發末班車 |
| 17:50 [F26] | 旭川機場 |
| 18:33 [F26] | 抵達旭川站 |

2026年7月到9月，纜車平日多半6:30、週末與連假多半6:00開始，下山末班都是17:30[F179]。纜車比末班巴士晚收，回程只要看巴士時間[F179, F26]。10月1日到20日是8:00到17:00，也比末班巴士晚[F179]。10月21日起改成9:00到16:00，11月16日到12月10日停駛[F179]。12月11日起是9:00到15:40，9:03下車時纜車已經開門，下山的末班纜車卻比末班巴士16:55早[F179, F25, F26]。官網月曆目前只排到12月，其他月份出發前看纜車官網的營業月曆[F179]。

纜車的發車時間與班距可能臨時微調，纜車官網也提醒要接Ideyu號的旅客抓好時間[F37]。排行程時把14:55那班當回程，錯過了還有16:55，比一開始就排末班車多一層保險[F26]。纜車各季的營業時間，見旭岳纜車與姿見池。

## 從旭岳回旭川的末班車

旭岳開出的末班Ideyu號是16:55，17:50到旭川機場、18:33到旭川站[F26]。要搭當天的飛機離開，得配合17:50到機場的這班車，或搭更早的車[F33, F26]。

回程排14:55那班、16:55留作備案，比較不會走到錯過末班車這一步[F26]。真的錯過了，旭岳溫泉沒有計程車招呼站與租車公司，計程車要向最近的計程車公司預約[F13]。不會講日文，建議到遊客中心或纜車站請工作人員協助叫車，住在旭岳溫泉就請旅館櫃台幫忙，遊客中心開到17:00[F13, F182]。從旭岳溫泉搭計程車到JR旭川站約1小時[F169]。另一個做法是在旭岳溫泉住一晚，隔天搭9:55的頭班車回旭川[F26]。
