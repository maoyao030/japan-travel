## 各篇的順序

**1. GLTJP**
- 旭川在哪、有什麼魅力（自然＋城市，動物園，美食）→ 適合的季節 → 各季穿著 → 怎麼去、市內交通（巴士為主）。
- 19 個景點：動物園打頭，接著上野農場、就實之丘、科學館、嵐山、北彩都、博物館、男山、神居古潭……沒有照地理或交通分組，比較像人氣排序。
- 每個景點：一句定位（「位於…的…」「…的景觀勝地」）→ 一兩句看點 → 圖說式的一句總結。不放時間與門票，連到自己的資訊頁。
- 景點之後另開美食、購物（平和通、車站、情報中心、道之驛、高砂酒造放在購物）、住宿。

**2. Funliday**
- 沒有前言段落，直接第一個景點。
- 順序：旭川神社 → 上川神社頓宮（常磐公園內）→ 常磐圓環（日劇拍攝地）→ 機場公園 → 嵐山展望台 → 博物館 → 男山酒造資料館 → 拉麵村 → 上野農場 → 動物園。
- 每段：名稱與「為什麼值得去」（歷史、傳說、拍攝地）→ 看點描述 → 地址、開放時間、官網。最大的動物園反而放最後。

**3. 小兔小安**
- 前言（旭川在哪、有名的是什麼、夏天配富良野）→ 從札幌怎麼去（特急、高速巴士）→ 兩條一日遊路線（站名條列）→ 景點逐一開箱 → FAQ（要不要開車）。
- FAQ 的答法：直接說「開車比較方便」，再補一句不開車的替代。

**4. FUN! JAPAN（冬天）**
- 動物園冬季（一句）→ 其他雪上活動帶過 → 冬祭：先講規模（北海道第二大、最大雪雕），再兩個會場各在哪、看什麼，最後日期與交通 → 冬季天氣與穿著。

**5. UpToGo（冬天）**
- 前言：旭川是什麼城市、冬天為什麼值得去，列出後面會講的類別。
- 景點：動物園企鵝散步 → 旭岳纜車與鑽石塵 → 雪地騎馬 → 酒藏（兩家並列，一家一小段）→ 滑雪場兩座 → 冬祭與夜間點燈 → 美食 → 氣候穿搭 → 住宿 → FAQ。
- 冬天的排法是「最有名的冬季畫面先講，再到體驗，最後才是滑雪與祭典」。

## 開頭怎麼寫

- GLTJP、小兔、UpToGo：先一句定位旭川（北海道正中央、第二大城），再一句點出動物園，接著說「不只動物園」或列出後面會講的類別。
- Funliday：沒有開頭，直接進第一個景點。
- 共通點：開頭都先承認動物園最有名，再往外帶。本站現在的開頭也是這個順序（先說不只動物園，再講車站一出去就到的地方），可以保留；差別是本站接著直接分「走路到／搭車到／要開車」，競品沒有這種分法，這是本站的長處，開頭的第二段應該照這個分法預告。

## 關鍵問題怎麼回答

- **①旭川站走路就到的景點**：競品沒有一篇用「走路就到」分組。GLTJP 只在北彩都寫「與車站直通」、在道之驛寫走路約 15 分鐘，情報中心與平和通被放進購物。讀者要的順序：先說車站本身與緊鄰的（情報中心、北彩都），再往北（平和通→常磐公園），再往南（博物館），每處一句「走幾分鐘」。本站的表格（景點／怎麼走）正好補這個空白。
- **②動物園以外值得去的景點**：競品的答法是一長串清單，每處一兩句「為什麼有名」。最常出現的是嵐山展望台、博物館、男山酒造、上野農場、就實之丘、神居古潭、北邦野草園、三浦綾子紀念文學館、設計中心。每處都是「它是什麼→看點」，交通和時間放最後或不寫。
- **③冬天在旭川能玩什麼**：兩篇冬天文章都以冬祭（2 月）為核心，再加動物園企鵝散步、雪地騎馬、滑雪場、鑽石塵。順序是「一年一次的大活動或招牌畫面 → 能參加的體驗 → 滑雪」。本頁目前冬天 H2 先講鑽石塵，完全沒提冬祭。
- **④不開車怎麼去、哪些要開車**：競品幾乎不回答。小兔的 FAQ 只說開車比較方便；Funliday 在上野農場順手寫了 JR 與巴士。讀者在意，但競品沒有好答案——本站的「搭車去／要開車」分 H2 是差異化的地方，每節第一句就該說交通方式。
- **⑤下雨天或帶小孩去哪**：競品沒有專門的段落；科學館（GLTJP 寫「大人小朋友都能一起同樂」）、博物館、動物園被零散標成親子景點。UpToGo 提到男山的一升瓶溜滑梯當成小孩能玩的地方。讀者要的順序：最適合的一處先講（科學館），講為什麼適合（室內、有天象儀、小孩免費），再列其他可以待的室內點。

## 段落與句子的習慣

- 每個景點段落第一句都是「它是什麼」：位置或身分（日本第一、北海道最古老、日劇拍攝地），第二句才是看點。很少從交通起頭。
- 稱呼讀者用「大家」「你」，Funliday 會用「推薦大家」「如果想…非常推薦」；GLTJP 偏書面、不太對讀者說話。
- 轉場靠景點編號或 H2 切開，段與段之間幾乎沒有連接句。
- 數字（海拔、面積、年份）放在第一或第二句當「為什麼有名」的證據；時間、門票、地址放段尾的資訊欄。
- 句子中等長度，一句一個點，形容詞多（「絕美」「必看」）。本站不學形容詞，學「定位句在前、資訊欄在後」。
- 冬天文章習慣在最後放穿著與天氣，本站分工歸 `asahikawa-weather`，一句帶過即可。

## 給作者的順序建議

標題照現在的 `draft-tagged.md` 不改，只排每節裡的順序。

- **開頭兩段**：第一段先承認動物園、立刻帶到「車站一出去就到」；第二段照本頁三種走法（走路／公車／開車）各舉一兩處，再一句冬天。冬天那句可以加冬祭（F246、F247），因為競品冬天都先講它。
- **H2 旭川景點推薦，從車站走路就到的地方**：①一句說景點分在車站南北兩邊 ②表格（景點／怎麼走） ③表格後一兩句補「哪兩處可以一起排」 ④動物園與自由行的連結句放最後。
  - **H3 旭川觀光物產情報中心**：先說它在哪、能做什麼（寄行李最實用），再講租借與體驗活動中心。F235 現在可以寫營業時間，放基本資訊欄就好。
  - **H3 旭川北彩都花園與忠別川**：先「走出車站就到、是什麼樣的花園」，再得獎（定位證據），再冬天變雪上活動區，最後花園中心設施與時間。
  - **H3 平和通買物公園、常磐公園與旭橋**：照走路的動線：平和通（日本第一條常設徒步區）→ 走到底的常磐公園與美術館（含怎麼去）→ 旭橋。冬祭的兩個會場就在平和通與旭橋河畔，可在這節或冬天 H2 一句帶到，不要兩邊都寫。
- **H2 從旭川市區搭車去的景點**：第一句說這節的景點都能搭公車、公車從哪裡發（1條8丁目／Bus Touch），再一句旭川八景當定位；站牌細節濃縮，詳細的交給旭川交通的連結句。
  - 每個 H3 照競品的「它是什麼 → 看點 → 怎麼去 → 開放期間與門票」：嵐山先講展望台看得到什麼，再講公車只到野草園入口；見本林先講《冰點》，再講文學館；愛努與開拓的館先一句總覽有幾間、各看什麼，再逐館；酒藏先講兩家差在哪（試飲 vs 預約參觀工廠），再分別講；設計中心先講旭川是家具產地，再講展場。
- **H2 旭川郊外要開車去的景點**：第一句直接說這幾處要開車、為什麼（公車沒到或班次很少）。上野農場的 69 號公車是例外，放在該 H3 裡講，並標明是 2026 年的季節時刻、2027 年要等官方公布。
- **H2 旭川景點冬天，雪上活動與鑽石塵**：建議順序改成 ①冬天最大的活動冬祭（2 月上旬，2027 年 2/6～2/11，會場在旭橋河畔、常磐公園與平和通，主雪像規模）一兩句 ②鑽石塵與連到旭川天氣 ③車站周邊就能玩的雪（北彩都、情報中心租借）④各 H3（溜冰場、滑雪場、騎馬）。冬祭沒有自己的 H3，放 H2 開頭段落就好。
  - **H3 旭川市內的滑雪場**：先一句兩座各適合誰（整天 vs 晚上幾小時），再分場講雪道→營業→票價→租借，最後公車與「末班趕不趕得上」。現在已經是這個順序，保留。
  - **H3 騎馬走雪地**：先講「冬天也能騎、沒騎過也行」，再價格由短到長，再預約方式，最後交通。預約方式目前放在價格前面，建議往後挪。
- **H2 旭川下雨天與帶小孩去的室內景點**：最適合的一處先講（科學館），理由在同一句（室內、天象儀、國中生以下免費），再交通，再其他可以待的室內點（博物館、設計中心、北鎮）。
