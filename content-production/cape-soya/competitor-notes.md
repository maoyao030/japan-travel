## 3. 開頭怎麼寫

- A：先把「最北端」講精確（可到達的最北端），再帶到行程規劃。
- B：先給精確地理事實，第三句就丟出「只有一條巴士、班次少」的限制。
- C：第一人稱情境，本頁不學。
- D、E：先講位置，再一句講為什麼值得去。
- 共通點：開頭兩三句內都講「北海道或日本可到達的最北端」，攻略型（A、B）緊接著講交通限制。本站現行開頭（最北端→碑→看得到庫頁島→32 公里、巴士一天 4 個來回→丘陵與白色道路的季節）已經符合，順序可以保留。

## 4. 關鍵問題怎麼回答

**mustAnswer 1：值不值得去、停留多久**
- B 最直接：先給只看碑的時間，再給加上其他設施的時間，最後一句「搭巴士就看回程班次」。A 把「玩幾天」放在介紹節，FAQ 再答一次。
- 讀者期待的順序：岬角本身要多久 → 加上丘陵要多久 → 不開車時其實由巴士決定 → 再列排法。本站現行稿先講「值得」再講手冊時間，接著三種排法表，順序符合；表格比競品清楚，保留。
- 競品沒有人列「去程回程配對」的表，這是本站獨有的資料，放前面。

**mustAnswer 2：白色道路與宗谷丘陵的季節限制**
- B 放在「什麼時候去」：先講封閉 → 何時重開 → 今年最後的時機。D 把封閉期放基本資訊欄。A 先描述景觀，再講注意事項、開放季節，最後怎麼去。
- 讀者先想知道「現在去走不走得到」，再看景色與怎麼走。本站 H2「宗谷岬旁的宗谷丘陵與白色道路」第一句就給開放期，符合 B 的順序，保留。

**mustAnswer 3：冬天能不能去**
- B：回程車 → 強風停駛 → 道路封閉 → 元旦。A：直接建議第一次來不要冬天去，理由是風雪與停駛。
- 共通是先給「能去，但…」，再列哪些不能。本站冬天一節第一句就答能去，再講封閉、店家、雪路，符合。

**表格**：競品幾乎不用表格（D 用基本資訊欄）。本站的排法表與基本資訊欄保留。

## 5. 段落與句子的習慣

- 句長：A、B 中等偏長，常加「依現場公告為準」之類的免責語；D 中短句，用「不妨」「推薦」收尾；E 有「喔」「唷」。本站照 writing-guide，不學免責語與語助詞。
- 稱呼讀者：A 用「你」「旅客」；B 多用「……的話」；C 用「朋友」；D 用「各位」。本站維持從讀者處境起頭，不直接稱呼。
- 數字位置：B 把停留分鐘數放在句首；A 數字放句中。本站的停留時間與末班 15:20 可以放在段落第一、二句。
- 景點介紹：D、E 每個景點先講「這是拍照點／為什麼有名」，再講歷史。本站碑與銅像那節目前先講造型、再講年份，順序接近，但可以先一句說它就是大家來合照的那座碑。

## 6. 給作者的順序建議

標題照現在的 `draft-tagged.md`，不改。

- **宗谷岬值得去嗎？北海道最北端要待多久？**：值不值得（一句）→ 岬角約 30 分、加丘陵再 1 小時 → 不開車時由巴士決定 → 三種排法表 → 各排法適合誰（只看岬角、加丘陵、開車）→ 冬天只能前兩種 → 連到稚內的句子。現行順序大致符合；「岬角風大帶外套」可以挪到排法表之後或冬天一節，不要卡在停留時間與巴士表之間。
- **宗谷岬冬天能去嗎？**：能去、巴士照開 → 哪些封閉（白色道路、丘陵步道、公園高台車道，用重查後的 F21 寫冬季封閉日）→ 店家冬天的時間 → 雪路與停駛 → 怎麼問。
- **宗谷岬的元旦日出活動**：日出時間與活動內容 → 一般巴士趕不上 → 接駁巴士 → 冷、沒吃的。現行順序符合。
- **宗谷岬的交通與吃飯**：巴士（路線、車程、車資、付款）→ 開車（改成約 40 分鐘，F54 更正）→ 夏季 Active Bus → 連到交通頁 → 吃飯。
- **宗谷岬一帶的景點**：兩區分布 → 手冊停留時間 → 停車與巴士站基本資訊。各 H3 先一句說讀者在這裡會做什麼（合照、避風、拿證明書），再講來歷。
- **日本最北端之地碑與間宮林藏立像**：這就是合照的那座碑 → 造型意義 → 年份 → 銅像 → 出港地。
- **宗谷岬流冰館與最北端證明書**：讀者最常問「證明書在哪拿」（B 的 FAQ、A 的票券節），兩種證明書的差別可以提前到這一節第一段後段。
- **Base-Soya**：開放期間 → 能做什麼（租車、證明書）→ 費用與手續。
- **宗谷岬旁的宗谷丘陵與白色道路**：開放期 → 各 H3。白色道路一節：開放期間 → 從哪一頭進（導航會排反）→ 路上的請求 → 沒車怎麼去。
- **宗谷丘陵的風車拆除與交通管制**：管制期已過（F42），照「臨時維修不寫」只留風車停止運轉、拆除中的事實與對景色的影響，管制句由作者決定刪或縮。
