- 「利尻島天氣」在中文搜尋排前面的，多半是日文天氣預報站（海天氣、外天氣、tenki 類的 10 天／90 天預報）與 YAMAP 登山紀錄，不是給台灣讀者的文章。
- 繁中文章都是「利尻島全攻略」型，天氣只占一小段或一則 FAQ。沒有一篇給各月氣溫表或穿著建議。
- 所以本頁的機會是：各月數字＋穿法＋冬季怎麼排，這三樣競品都沒有。順序參考的是「攻略文怎麼安排季節段落」與「FAQ 裡讀者怎麼問」。

## 各篇的順序

1. 方格子：開頭作者對島的感情 → 依旅客目的（海膽、登山、祭典）說適合誰 → **最佳季節**（夏季旺季、冬季店家與班次少）→ 交通 → 夏季活動依月份 → 景點 → 美食 → 住宿 → 結語。
2. Funliday 景點 10 選：地理位置與夏季活動導言 → 目錄 → 怎麼去 → 景點 1～10 → FAQ（季節題在這：旺季、平季、冬季可能停航與店家關閉）→ 站內推廣。
3. Funliday 渡輪：渡輪票價座位（季節只一句「春末到初秋、6～9 月最舒適」）→ 禮文島交通與景點 → 利尻島交通與景點（景點資訊欄寫開放月份）。
4. jeepe：位置與象徵山峰 → 亮點條列 → 景點 → 交通 → 總結 → FAQ（山上天氣多變、帶雨具、秋天不穩）→ 日語短句。
5. JNTO：比喻開場 → 活動 → 交通 → 利尻山 → 四季景色 → 單車 → 禮文 → **氣候資訊**（最佳季節 → 旺季 → 冬季季風期風大寒冷）→ 建議天數。

## 開頭怎麼寫

- 攻略型都先講「島在哪、為什麼有名（利尻山、海膽）」，天氣不在開頭。
- 沒有一篇在開頭就給數字。本頁開頭直接給「夏涼冬長＋年平均＋最熱月」的數字，是跟競品不同的地方，保留。
- JNTO 的氣候段是「先說最佳月份 → 再說旺季要早訂 → 最後說冬季的壞消息」，壞消息直接寫，不用形容詞軟化。

## 關鍵問題怎麼回答

### mustAnswer 1：各月氣溫

- 競品都沒有月別表。最接近的是 Funliday FAQ 把一年切成三段（旺季、平季、冬季），以「幾月到幾月＋一句理由」回答。
- JNTO 只給一個冬季平均數字，沒有穿著。
- 讀者實際在問的是「幾月去、要穿什麼」，不是單純的數字。可見的順序是：**先說哪幾個月最舒服 → 再說各段要注意什麼 → 數字當佐證**。

### mustAnswer 2：11 月停航多

- 競品都只用一句帶過：「冬季班次少」「可能停航」「店家關很多」。沒有人說要怎麼排行程。
- 出現的順序都是：**先說會停 → 再說連帶的影響（店家、住宿、班次）→ 最後叫讀者看官方公告**。
- 沒有一篇給「離島後空一天」這類可以照做的建議，這是本頁該放前面的東西。

## 段落與句子的習慣

- 部落客（方格子、Funliday）句子短、口語，常用「你」「大家」，多驚嘆號，數字放括號或條列。本站不學口語語助詞。
- JNTO 句子中等長度（約 20～40 字），一段先一句重點再補細節，數字直接寫在句子裡。這個節奏接近本站導覽編輯口吻，可參考。
- 季節資訊大多是「月份範圍＋一句理由」的寫法，例如先寫月份再寫為什麼；很少先寫理由再寫月份。
- 景點開放季節都放在每個景點的資訊欄裡，不在正文講。本頁的姬沼、白色戀人之丘照現在用條列帶過即可。

## 給作者的順序建議

標題照現在的 `draft-tagged.md`，只排每一節裡的順序。

- **H1 底下開頭**：
  1. 先一句回答「利尻島天氣怎麼樣」：夏涼冬長＋數字。
  2. 接著講對行程最大的影響（11 月起停航多），讓查「天氣」的人馬上知道冬天要小心。
  3. 平年值是什麼、去哪看實際預報放第二段（查詢「利尻島天氣」的人有一部分其實要預報，所以預報頁的做法要留在開頭附近）。
- **利尻島各月氣溫與穿著**：
  1. 先一兩句說穿法的總原則（夏天一件薄外套、冬天整套防寒），再放表格。讀者先要結論，表格是查用的。
  2. 雨量一句接在表格前或後皆可，但不要搶在穿法前面。
- **春季（3–5 月）**：先說「3、4 月還是冬天的穿法」，再給數字，最後才講彼岸風暴與殘雪。順序是「要穿什麼 → 為什麼 → 這季的特別現象」。
- **夏季（6–8 月）**：先講「不熱」這個結論，再分 6 月與 7、8 月的穿法，雨具最後。F220（8 月中旬過後轉涼）可接在 8 月那句後面，提醒 8 月下旬早晚多帶一件；不用也可以。
- **秋季（9–11 月）**：照月份走，9 月一句、10 月換外套、11 月氣溫掉最快。11 月可以先說「這個月要換整套冬裝」，再給數字。
- **冬季（12–2 月）**：先給「白天也在零下」的結論，再講路面與鞋子、風與外套。現在的順序已經是這樣。
- **利尻島的風與山頂氣溫**：先講對一般旅客有用的（機場一帶風大、擋風外套），登山的放後面。現在的順序可以保留。
- **利尻島 11 月以後的渡輪停航**：競品都是「會停 → 影響 → 看公告」；本頁照「怎麼排（空一天）→ 為什麼 → 備案（飛機）→ 住宿 → 巴士與景點 → 改票連到渡輪頁」，先給能照做的事。現在的順序已經符合，保留。

## 他們有、我們缺的

- **幾月去最好**：每篇都有一句「6～9 月最推薦」。本頁不負責選月份（分工上歸主頁 `rishiri-island`），開頭已有連到主頁的句子即可，不加新段落。

- **冬季平均零下七度**（JNTO）：沒寫觀測站，與沓形平年值不同，不採用。

- **山上天氣多變、帶雨具與防水鞋**（jeepe FAQ）：本頁已有 F65、F66 與 8 月雨具，夠用。
