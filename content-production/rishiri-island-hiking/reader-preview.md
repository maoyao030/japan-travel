# 利尻山登山，兩條路線、時間與攜帶式廁所

利尻山是利尻島上標高1,721公尺的獨立峰，別名「利尻富士」，在日本百名山裡是從北邊數來的第一座。目前能登上山頂的只有鴛泊路線，另一條沓形路線的9合目以上已經封閉。鴛泊路線上山6小時、下山4小時，加上山頂休息1小時，天氣好也是11小時的行程，整天都在山上。

山上沒有一般的廁所，島上請大家上山一定自備攜帶式廁所，利尻富士町也規定一定要交登山計畫書。這兩樣在島上的住宿都能拿到，抵達後再準備也來得及。還沒決定要不要排利尻島，可以先看利尻島值得去嗎。

## 利尻島的利尻山登山路線與所需時間

| 路線 | 登山口 | 標高差 | 上山、下山 | 目前狀況 |
|---|---|---|---|---|
| 鴛泊路線 | 北麓野營場 | 1,490公尺 | 6小時、4小時 | 主要路線，2025年夏季10,375人走這條 |
| 沓形路線 | 5合目見返台 | 1,280公尺 | 6小時、4小時 | 2026年6月公告9合目以上封閉 |

### 利尻富士的高度與登山人數

從鴛泊路線的登山口到1,721公尺的山頂，標高差有1,490公尺。2025年夏季（6月1日到10月31日）共有10,625人登上利尻山，幾乎都走鴛泊路線，沓形路線只有250人。環境省認為，6月下旬步道崩塌、9合目以上封閉，是沓形人數變少的原因之一。登山客集中在同一條路上，旺季步道會擠。

### 鴛泊路線

鴛泊路線的起點是北麓野營場，離鴛泊市區約5公里，下山後丟攜帶式廁所的回收箱與洗鞋處也都在這裡。

| 區間 | 參考時間 |
|---|---|
| 北麓野營場到5合目 | 約1小時20分 |
| 5合目到6合目 | 約35分 |
| 6合目到7合目 | 約35分 |
| 7合目到8合目長官山 | 約1小時5分 |
| 長官山到避難小屋 | 約10分 |
| 避難小屋到9合目 | 約35分 |
| 9合目到山頂 | 約1小時10分 |

各段加起來約5小時30分，是不含休息的純走路時間。官方抓的上山時間則是6小時，多出的半小時是在8合目長官山休息。出發後不久，在3合目附近會經過名列日本名水百選的甘露泉水。

最後一段最吃力。9合目到山頂約1小時10分，路面差、坡又陡，旺季人又多，是官方特別點名的路段。9合目往上、和沓形路線會合前的崩塌地，有幾處步道被侵蝕得很窄。遇到對面有人來就互相讓一下，不要硬擠，風大的時候更要小心。

| 項目 | 內容 |
|---|---|
| 日文名 | 利尻北麓野営場 |
| 位置 | 鴛泊市區約5公里 |
| 設施 | 攜帶式廁所回收箱、洗鞋處 |
| 營業期間 | 5月15日～10月15日 |
| 住宿 | 小屋一棟一晚6,000日圓，帳篷區大人每人600日圓 |

### 沓形路線

沓形路線從5合目的見返台出發，標高差1,280公尺。官方把它列為進階路線，適合有經驗的登山者，所需時間與鴛泊路線一樣。通往見返台園地的道路5月中旬到10月中旬可以通行，冬天因積雪封閉。官方請大家等7月以後雪融了再走這條路線。岩場一帶腳下不穩，用來上山會比下山安心。

### 沓形路線的封閉狀況

沓形路線9合目以上的步道目前禁止通行，利尻富士町等單位2026年6月發的注意傳單已經公告。兩條路線過了9合目才會合，所以現在從沓形上山到不了山頂。沓形上山、鴛泊下山的走法同樣排不成。有沒有重新開放，出發前到利尻富士町的登山情報頁確認。

### 利尻山一天來回要多久？

鴛泊路線當天來回，連山頂休息總共11小時，這還是天氣好的情況。官方提醒清晨出發、日落前下山。照11小時算，早上6點從北麓野營場出發，回到登山口已經是下午5點左右。

就算山腳下熱到流汗，山頂附近也可能不到10°C，背包裡最好放一件保暖衣物。6合目以上已經出了森林線，如果在6合目就風大到連雨衣都穿不上，就是該折返的時候。

不想在山上待一整天的話，可以改爬ポン山（Pon山），一樣從北麓野營場出發，來回2到3小時，路上也會經過甘露泉水。

## 利尻島登山的攜帶式廁所與登山計畫書

### 領取與提交登山計畫書

登山計畫書的表格在駐在所與島上的住宿都有，入住時順便拿一張，前一晚填好最省事。填好交給最近的警察署或當地駐在所，也可以用北海道警察網站的線上表單提交。線上表單只在平日早上8:45與下午5點左右開信，週六、週日與假日送出的，要等下一個平日才會處理。週末上山的話，交到駐在所比較確實，交到哪裡最方便，入住時可以問住宿櫃檯。看不懂日文表格，北海道警察網站也有英文版的登山計畫書可以下載。

利尻富士町公所的登山情報頁有日文、英文、韓文、繁體中文、簡體中文五種語言的注意傳單。出發前可以下載繁中版看一遍。

### 攜帶式廁所的購買與使用

攜帶式廁所一套450日圓，島上的住宿、商店、便利商店、町公所、觀光案內所都有賣。北麓野營場等3處露營場也買得到。

山上只有6處給攜帶式廁所用的隔間，裡面不放衛生紙，自己帶一包上去。

| 路線 | 隔間位置 |
|---|---|
| 鴛泊路線 | 6.5合目、避難小屋、9合目 |
| 沓形路線 | 避難小屋、8.5合目 |
| 姬沼到ポン山的步道 | 中途一處 |

用過的攜帶式廁所帶下山，丟進登山口的回收箱。鴛泊路線的回收箱在北麓野營場前，沓形路線的在5合目。

### 登山杖規定與避難小屋

用登山杖，杖尖要套上橡膠頭，減少對步道的破壞。兩條路線上的避難小屋都沒有管理員，也沒有水與一般廁所，喝的水從山下帶足。如廁只能用攜帶式廁所的隔間。小屋只給緊急時躲避用，官方說得很清楚，不要打算在避難小屋過夜。

## 利尻島登山季節與住宿接送

### 利尻山的登山季節

5月的利尻山麓還留著殘雪，見返台園地一帶甚至能玩雪。沓形路線官方請大家7月以後再走，10月上旬又到了山頂看得到初冠雪、也就是第一次積雪的時期。想避開殘雪與初雪，挑7月到9月上中旬最穩，早的年份9月就可能初冠雪。

7月上旬到中旬，9合目附近的碎石地會開出利尻雛罌粟，是日本唯一野生的罌粟屬雛罌粟。花期正好碰上旺季，9合目以上那幾處窄路更容易塞住。

下大雨時，平常乾涸的溪溝會漲水，人過不去，町公所可能看天氣發通知，請大家暫停上山。出發前一晚可以問住宿當天能不能上山。夏天也可能碰上步道整修。2026年7月15日到20日，環境省用直升機運材料整修鴛泊路線，直升機接近時會請登山者暫時停步，這次作業已經結束。出發前可以看利尻富士町登山情報頁的最新公告。

### 住宿的登山口接送

路線巴士不開到登山口，最近只到「溫泉」這個巴士站。好在島上幾乎所有住宿都會接送到登山口，有些還能準備飯糰便當當早餐，配合清晨出發。不過接送不跨區，住鴛泊的不送沓形登山口，住沓形的也不送鴛泊登山口。沓形路線封閉的這段期間，住沓形又想爬鴛泊路線，ホテル利尻可以接送到鴛泊路線。這間早上出發的時間是固定的，下山後來接只限登山當天也住在這裡的人。登山當天就退房的話，下山後就沒有車來接。

有沒有接送、能不能準備早餐便當、下山後要不要來接又怎麼約時間，訂房時一起問清楚比較保險。從鴛泊渡輪站走到北麓野營場約60分鐘。沒車怎麼到登山口，見利尻島交通。

### 救援聯絡與登山嚮導

在山上遇難要求救，第一時間打110。受傷等需要救援時，也可以聯絡當地駐在所0163-82-2110或利尻富士町公所0163-82-1111。島上有幾家登山嚮導業者，部分能用英語帶隊，英語帶隊需事先聯絡。
