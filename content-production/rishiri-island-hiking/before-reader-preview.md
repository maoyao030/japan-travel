# 利尻山登山，兩條路線、時間與攜帶式廁所

利尻山是利尻島上標高1,721公尺的獨立峰，別名「利尻富士」，在日本百名山裡排在第一座。想爬利尻山，目前能登頂的只有鴛泊路線，另一條沓形路線在9合目以上封閉。鴛泊路線上山6小時、下山4小時，加上山頂休息1小時，天氣好也要11小時，等於整整一天都在山上。

山上沒有一般的廁所，入山時自備攜帶式廁所是島上推動的規矩，登山計畫書也一定要交。這兩樣在島上的住宿都拿得到，抵達後再準備也來得及。還沒決定要不要排利尻島，可以先看利尻島值得去嗎。

## 利尻島的利尻山登山路線與所需時間

| 路線 | 登山口 | 標高差 | 上山、下山 | 目前狀況 |
|---|---|---|---|---|
| 鴛泊路線 | 北麓野營場 | 1,490公尺 | 6小時、4小時 | 主要路線，2025年夏季10,375人走這條 |
| 沓形路線 | 5合目見返台 | 1,280公尺 | 6小時、4小時 | 2026年6月公告9合目以上封閉 |

### 利尻富士的高度與登山人數

利尻富士標高1,721公尺，光是鴛泊路線從登山口到山頂，標高差就有1,490公尺。2025年夏季的6月1日到10月31日，共有10,625人登上利尻山，其中10,375人走鴛泊路線，走沓形路線的只有250人。沓形這麼少，是因為6月下旬步道崩塌後封閉。

### 鴛泊路線

鴛泊路線從北麓野營場出發，這裡離鴛泊市區約5公里，下山後丟攜帶式廁所的回收箱和洗鞋處都設在這裡。利尻富士町把路線分成幾段，各段的參考時間如下。

| 區間 | 參考時間 |
|---|---|
| 北麓野營場到5合目 | 約1小時20分 |
| 5合目到6合目 | 約35分 |
| 6合目到7合目 | 約35分 |
| 7合目到8合目長官山 | 約1小時5分 |
| 長官山到避難小屋 | 約10分 |
| 避難小屋到9合目 | 約35分 |
| 9合目到山頂 | 約1小時10分 |

各段加起來約5小時30分，這是沒算休息的走路時間，官方估的上山時間是6小時。剛出發不久，3合目附近會經過日本名水百選的甘露泉水。

最吃力的是最後一段。9合目到山頂要走1小時10分左右，旺季登山客多，這一段路面差、坡又陡，官方特別提醒大家留意。9合目上方、和沓形路線會合之前，步道被侵蝕得很窄，遇到對向的人不要硬擠，互相讓路，颳強風時更是如此。

| 項目 | 內容 |
|---|---|
| 日文名 | 利尻北麓野営場 |
| 位置 | 鴛泊市區約5公里 |
| 設施 | 攜帶式廁所回收箱、洗鞋處 |
| 營業期間 | 5月15日～10月15日 |
| 住宿 | 小屋一棟一晚6,000日圓，帳篷區大人每人600日圓 |

### 沓形路線

沓形路線從5合目的見返台出發，標高差1,280公尺，上山6小時、下山4小時，含山頂休息共11小時，官方把它歸為上級者路線。見返台園地標高約500公尺，通往這裡的道路5月中旬到10月中旬可以通行，冬天因積雪封閉。這條路線官方請大家等7月以後雪融了再走，岩場腳下不穩，比較適合用來上山。

### 沓形路線的封閉狀況

2026年6月利尻富士町等單位發的注意傳單寫明，沓形路線9合目以上的步道目前禁止通行。山頂在9合目之上，兩條路線又是在9合目上方才會合，所以現在走沓形路線上不了山頂，也排不了沓形上山、鴛泊下山的走法。是否重新開放，出發前到利尻富士町的登山情報頁確認。

### 利尻山一天來回要多久？

走鴛泊路線一天來回，天氣好也要11小時，上山6小時、下山4小時，再加山頂休息1小時。官方提醒清晨出發、日落前下山。照11小時算，早上6點從北麓野營場出發，回到登山口已經是下午5點左右。

山麓熱到流汗的日子，山頂附近也可能不到10°C，保暖衣物記得帶上山。6合目以上就出了森林線，在6合目風大到連雨衣都穿不上，就是該折返的時候。

沒打算花一整天，同樣從北麓野營場出發的ポン山，往返2到3小時，沿途也會經過甘露泉水。

## 利尻島登山的攜帶式廁所與登山計畫書

### 登山計畫書怎麼交

利尻富士町要求登山者一定要交登山計畫書，表格放在駐在所和島上的住宿。填好交給最近的警察署或當地駐在所，也可以在網路上提交。住宿就拿得到表格，入住時順便要一張，前一晚填好最省事。

利尻富士町公所的登山情報頁有日文、英文、韓文、繁體中文、簡體中文五種語言的注意傳單，出發前可以下載繁中版看一遍。

### 攜帶式廁所的購買與使用

利尻島推動入山必帶攜帶式廁所。一套450日圓，島上的住宿、商店、便利商店、町公所、觀光案內所都有賣，北麓野營場等3處露營場也買得到。

山上沒有一般的廁所，只有6處攜帶式廁所專用的隔間，裡面不放衛生紙，衛生紙自己準備。

| 路線 | 隔間位置 |
|---|---|
| 鴛泊路線 | 6.5合目、避難小屋、9合目 |
| 沓形路線 | 避難小屋、8.5合目 |
| 姬沼到ポン山的步道 | 中途一處 |

用過的攜帶式廁所帶下山，丟進登山口的回收箱。鴛泊路線的回收箱在北麓野營場前，沓形路線的在5合目。

### 登山杖規定與避難小屋

使用登山杖時，杖尖要套上橡膠頭，減少步道被刨壞。兩條路線上的避難小屋都沒有管理員，也沒有水和廁所，飲水從山下帶足。小屋只限緊急時使用，官方明講不要把住避難小屋排進登山計畫。

## 利尻島登山季節與住宿接送

### 利尻山的登山季節

5月的利尻山麓還留著殘雪，見返台園地一帶甚至能玩雪。沓形路線官方請大家7月以後雪融了再走，10月上旬又是山頂初冠雪的時期，想避開殘雪和初雪，7月到9月最穩。2025年的登山人數，就是用6月1日到10月31日這段夏季統計。

7月上旬到中旬，9合目附近的碎石地會開出利尻雛罌粟，這是日本唯一野生的罌粟屬雛罌粟。花期剛好落在旺季，步道上人也多，9合目以上的窄路更容易塞住。

大雨會讓山上的枯溪漲水，人過不去，町公所可能依天氣發布請登山者暫停入山的通知。夏天也可能遇上步道整修，2026年7月15日到20日鴛泊路線整修時用直升機運料，作業期間登山者可能被請求暫時停步。

### 住宿的登山口接送

沒有巴士開到登山口，路線巴士最近只到溫泉站。島上幾乎所有住宿都會接送到登山口，有些還能準備飯糰便當當早餐，配合清晨出發。接送不跨區，住鴛泊的不送沓形登山口，住沓形的也不送鴛泊登山口。沓形路線封閉期間，住在沓形又想爬鴛泊路線，可以選能接送到鴛泊路線的ホテル利尻。

訂房時一併問清楚有沒有接送和早餐便當。從鴛泊渡輪站走到北麓野營場約60分鐘。沒車怎麼到登山口，見利尻島交通。

### 救援聯絡與登山嚮導

在山上需要救援，聯絡當地駐在所0163-82-2110，或利尻富士町公所0163-82-1111。島上有幾家登山嚮導業者，部分可以用英語帶隊，需事先聯絡。
