# 層雲峽天氣與楓葉，各月氣溫、積雪與紅葉季

層雲峽是大雪山腳下的峽谷溫泉街，標高在600公尺以上。層雲峽天氣一年四季落差很大。以附近的上川觀測點為準，最冷的1月平均氣溫是零下8.4度，最熱的8月白天最高也只有24.7度。秋天的紅葉由山上往下走，黑岳山頂與赤岳銀泉台9月中旬最漂亮，溫泉街一帶要等到10月上旬到中旬。

文中各月的氣溫、雨量與積雪都是氣象廳1991年到2020年的平年值，也就是往年的平均，不是預報。層雲峽自己的觀測點只量降水與積雪，氣溫得看標高324公尺的上川市街。溫泉街比上川觀測點高出不少，照上川的數字準備衣服，再多帶一層比較穩。還沒決定要不要排層雲峽，可以先看層雲峽值得去嗎。

## 層雲峽氣溫，各月平均與雨量

上川一年的平均氣溫是5.4度，12月到3月每個月的平均都在零下。夏天也不熱，7、8月白天最高約24.5度，早晚降到14度左右，一年平均不到3天會到30度以上。雨集中在7月到10月，層雲峽觀測點這四個月每月都超過150毫米，8月的192.6毫米最多。除了7月兩地差不多，其他月份峽谷裡的降水都比上川多，整年多了約330毫米。

表中的氣溫與上川降水是上川觀測點的數字，層雲峽降水則來自標高540公尺的層雲峽觀測點，都是1991年到2020年的平年值。

7、8月白天穿短袖就夠，早晚偏涼，包包裡再放一件長袖外套。這兩個月也是一年雨最多的時候，雨具別忘了帶。6月更涼，早上平均只有9.4度，初夏出門一樣要帶外套。

9月的早晚降到9度左右，10月平均日最低只剩2.2度，一個月裡平均有8.9天早上低於0度。到溫泉街看紅葉，外套要擋得住早晚的低溫。上黑岳或銀泉台看紅葉，背包裡放一件刷毛衣或羽絨衣，再加一件防風外套。2026年9月上旬，遊客中心就說稜線的風已經像晚秋，早上接近0度。

往年到了10月下旬，溫泉街就會有幾天路面積雪。2025年10月30日早上，層雲峽最低零下2度，路面積了雪又結冰，連走人行道都容易滑倒。從這時起就換上冬天的裝備，保暖衣物與防滑的鞋都要有，開車一定要換冬季輪胎。紅葉期的車輛管制與冬天開車的路況，見層雲峽交通。

## 層雲峽冬天的積雪與寒冷

峽谷裡10月就開始下雪，到隔年4月積雪還有將近1公尺。最冷的1、2月，上川早上平均零下13.8度，白天最高也只有零下3到4度。1月平均有27.9天整天都在0度以下。上川市街的風倒是不大，平均風速一年都在每秒1.7到2.6公尺。

| 月份 | 上川最深積雪 | 層雲峽最深積雪 | 層雲峽降雪合計 |
|---|---|---|---|
| 10月 | 2cm | 6cm | 10cm |
| 11月 | 27cm | 41cm | 133cm |
| 12月 | 62cm | 84cm | 202cm |
| 1月 | 80cm | 102cm | 163cm |
| 2月 | 89cm | 121cm | 150cm |
| 3月 | 86cm | 126cm | 160cm |
| 4月 | 47cm | 94cm | 80cm |

積雪在3月最深，層雲峽觀測點平年是126公分，比上川的86公分深約40公分。到了5月，峽谷裡還有9公分的積雪。12月、1月很少出太陽，上川12月整個月的日照只有40.4小時，是一年最少的月份，1月也只有61.7小時。

12月到2月出門，衣服要能應付零下10度以下的冷，保暖外套、帽子、手套都帶齊。積雪會一直留到4月，這段時間的鞋子挑防水又防滑的，遊客中心也提醒，路面結冰時連走人行道都要小心滑倒。

1月下旬開始的冰瀑祭，見層雲峽冰瀑祭。2027年從1月23日辦到3月7日，正好碰上最冷、雪最深的幾個月。

## 層雲峽楓葉什麼時候去？

層雲峽的紅葉從山頂一路往峽谷下走，想上山賞楓就排9月中旬，想在溫泉街散步賞楓就排10月上旬到中旬。黑岳和赤岳銀泉台都被稱為日本最早的紅葉，纜車公司說黑岳山頂附近大約9月上旬開始變色，觀光協會則說銀泉台9月中旬就到高峰。這時溫泉街的樹多半還是綠的，以2024年為例，紅葉谷入口一帶到9月30日前後才轉紅。黑岳山頂、銀泉台和溫泉街最漂亮的時候，相差三週到一個多月。9月下旬到10月初出發時山頂已經過了，搭黑岳纜車還看得到山腰的紅葉。2024年9月26日六到七合目正盛，10月3日纜車沿途也正漂亮。2025年10月1日，紅葉則下到標高800到900公尺一帶。

| 時期 | 地點 | 往年狀況 |
|---|---|---|
| 9月上旬 | 黑岳山頂附近 | 開始變色 |
| 9月中旬 | 赤岳銀泉台、黑岳山頂以上 | 進入最佳觀賞期，接近高峰 |
| 9月下旬 | 黑岳六到七合目 | 2024年9月26日最佳觀賞期 |
| 10月上旬到中旬 | 溫泉街、紅葉谷、銀河・流星瀑布 | 2024年10月初、2025年10月中旬最佳觀賞期 |
| 10月下旬 | 溫泉街 | 落葉，路面開始積雪 |
| 1月下旬到3月上旬 | 溫泉街 | 冰瀑祭，2027年是1月23日到3月7日 |

搭纜車上黑岳看最早的紅葉，見層雲峽纜車與黑岳登山。姿見一帶的紅葉，見旭岳纜車與姿見の池。

### 黑岳、銀泉台與溫泉街的紅葉順序

2024年的紅葉比2025年早一些。9月26日黑岳六到七合目紅葉正盛，八合目以上的葉子已經落了。那年9月21日到23日的秋分連假過後，平日的纜車停車場仍天天客滿。溫泉街在10月1日接近最佳觀賞期，銀河・流星瀑布（銀河・流星の滝）一帶的紅葉已經正好看。10月3日搭黑岳纜車往上，沿途的紅葉也正漂亮。

2025年，黑岳9月6日紅黃明顯變多，但還有很多綠葉，到9月13日山頂以上已經接近最美的時候。銀泉台一帶是標高1,500到1,600公尺的赤岳第一花園，9月12日也到了正好看的時候。10月1日紅葉下到標高800到900公尺一帶。半個月後的10月16日，溫泉街滿是紅葉，19日還很漂亮，26日葉子已經枯落。

2026年遊客中心說葉子變色比往年早，溫泉街10月上旬就到高峰，一直撐到10月10日到12日的體育節三連休。2024、2025兩年溫泉街紅葉最盛的時候也落在10月上旬到中旬，排行程抓這段就好。到了10月下旬就是尾聲了。從溫泉街走紅葉谷步道，單程約30分鐘到紅葉の滝，步道開放到11月上旬。

山上的紅葉季有時會碰上第一場雪。2024年黑岳在9月20日夜裡就下了初雪，遊客中心因此提醒賞紅葉要帶防寒裝備。

### 紅葉期的車輛管制

赤岳銀泉台與高原溫泉在紅葉期有車輛管制。2026年道道銀泉台線是9月12日到9月23日，町道高原溫泉線是9月19日到9月30日。這段期間不管搭上川町的預約制接駁巴士還是自己開車上山，都要事前預約，前一天15:00截止。預約方式、接駁巴士班次與費用，整理在層雲峽交通。

銀泉台只開放到10月上旬，2024年道道銀泉台線10月3日就封路過冬。要看銀泉台的紅葉，排9月中旬最穩。

## 出發前查層雲峽當天的天氣

平年值只能拿來排月份，出發前幾天就改看當地的即時資訊。層雲峽遊客中心（層雲峡ビジターセンター）的官網首頁是最方便的入口。氣象廳週間預報、日本氣象協會的大雪山風資訊、火山資訊、林道管制與北海道開發局的道路資訊，都從這裡連得過去。遊客中心的「山だより」寫的是紅葉、初雪與路面的近況，像2026年10月22日那篇就寫到溫泉街已經積雪。

上黑岳之前，打開黑岳纜車的官網首頁看一下，運行狀況、山麓天氣與停車場空位每天更新，還能看黑岳的即時影像。10月起山上已經是冬天。2026年10月2日旭岳初冠雪，到了10月5日黑岳、赤岳標高1,500公尺一帶已經積了5公分的雪。到了10月25日，五合目以上全是雪，纜車公司提醒，夏季的登山裝備已經不能上山。

開車出發前查一下開發局的「北海道地區道路情報」。冬天山路因大雪封路後，要等天氣轉好、檢查過才重新開放。
