# 稚內天氣，各月氣溫、降雪與穿著

稚內天氣的輪廓是夏天短而涼、冬天長而多雪，一年的平均氣溫只有7.0℃。最暖的8月平均19.5℃，12月到隔年3月每個月的平均都在0℃以下。雪從11月下到4月，一整季的降雪量平均477公分，風則是一年到頭都大。

還沒決定要不要排稚內，可以先看稚內值得去嗎。

## 北海道稚內天氣與各月稚內氣溫

下表是氣象廳1991年到2020年的平年值，也就是30年的平均，不是預報。

| 月份 | 平均氣溫 |
|---|---|
| 1月 | −4.3℃ |
| 2月 | −4.3℃ |
| 3月 | −0.6℃ |
| 4月 | 4.5℃ |
| 5月 | 9.1℃ |
| 6月 | 13.0℃ |
| 7月 | 17.2℃ |
| 8月 | 19.5℃ |
| 9月 | 17.2℃ |
| 10月 | 11.3℃ |
| 11月 | 3.8℃ |
| 12月 | −2.1℃ |

稚內一天裡的溫差不大，1月白天最高平均零下2.4℃、早晚最低平均零下6.4℃，只差4度左右。2月的早晚更冷，最低平均零下6.7℃。夏天最暖的8月，白天最高平均22.3℃，早晚也還有17.2℃。

春天回暖得慢，4月的白天最高平均只有7.4℃，秋天的10月還有14.1℃。同樣是平均17.2℃的7月和9月，白天最高也一樣是20.1℃，9月可以當成夏天的尾巴來排。

### 稚內各月降水與降雪

稚內的雪季從11月到隔年4月，各月的降雪量平年值如下。

| 月份 | 降雪量 |
|---|---|
| 11月 | 41公分 |
| 12月 | 122公分 |
| 1月 | 129公分 |
| 2月 | 105公分 |
| 3月 | 68公分 |
| 4月 | 9公分 |

12月和1月下得最多，這兩個月幾乎天天下雪，平均下雪的天數12月是28.5天、1月是30.4天。積雪最深的時候在2月，平均64公分。整年算起來約有148天會下雪。

雨下得最多的是秋天，9月136.7毫米、10月129.7毫米，11月也有121.4毫米。相對的，4月只有50.3毫米。9月到11月造訪，建議帶一件防水外套或折疊傘，因為這三個月是一年裡降水最多的時候。

### 稚內和札幌的氣溫比較

從札幌北上，夏天的差距比冬天大。8月的平均氣溫稚內19.5℃、札幌22.3℃，稚內低了將近3度。1月則是稚內零下4.3℃、札幌零下3.2℃，只差1.1度。兩地差最多的其實是風，全年平均風速稚內每秒4.6公尺，札幌是3.6公尺。

### 稚內的日照與霧

冬天的白天又短又暗，12月一整個月的日照只有28.4小時，1月也只有40.6小時。日照最多的是5月，有181.6小時，想在晴天看海、看遠方的島，5月的機會最多。6月和7月是濕度高、容易起霧的季節，7月平均相對濕度87%，這兩個月每月約有3天起霧。

## 稚內一年到頭的強風

稚內的風全年平均每秒4.6公尺，11月到1月最強，平均每秒5.0公尺，冬天多吹西風。最弱的7月也還有每秒3.9公尺，夏天多半吹南南西風。

以一天裡最大風速達到每秒10公尺來算，這樣的日子一年平均88.9天。11月、12月和1月每個月都將近10天，7月和8月約3天。稚內觀光協會的說法是一年約有130天颳強風。海邊、岬角這類空曠的地方，11月到1月風最大，排在這段期間的行程要把風算進穿著裡。

## 稚內冬天要穿什麼

稚內的冬天要穿得能防寒又能防風，外層選擋得住風、不怕雪的外套，帽子、手套和圍巾都帶上。12月到2月，每個月有16到24天白天最高氣溫不到0℃，整天都在冰點以下，這樣的真冬日一年平均約73天。這段時間也是風最強的時候，平均每秒5.0公尺，每個月將近10天最大風速達到每秒10公尺以上。

12月和1月幾乎天天下雪，2月平均積雪64公分，冬天的路面還可能結冰，鞋子選防水、鞋底防滑的款式。

3月和11月的平均氣溫也只有零下0.6℃和3.8℃。3月還有68公分、11月有41公分的降雪，這兩個月一樣帶冬季外套。4月平均4.5℃，雪只剩9公分左右，可以換成稍薄的保暖外套。

### 稚內冬天的風雪與交通

風雪也會打亂移動的計畫。稚內機場的機場巴士配合班機行駛，班機取消時巴士也停駛，班機延誤時會等飛機抵達才開。往返札幌的高速巴士わっかない號，夜班在2026年12月1日到2027年3月19日停駛，白天的班次照常。渡輪遇到颱風或低氣壓帶來的大浪與強風可能停航，天氣急變時也可能臨時停開。停航後怎麼改票，整理在稚內到利尻島、禮文島渡輪。

冬天要搭飛機或渡輪離開的那天，建議不要把下一段行程接得太緊，因為班機或船一停，機場巴士也跟著停。JR稚內站附近就有旅館，THE STAY WAKKANAI走路約1分鐘，天北の湯 Dormy Inn稚內約3分鐘。走不了時可以就近多住一晚，其他選擇整理在稚內住宿。

## 稚內看得到流冰嗎？

在稚內看到流冰的機會不高。稚內地方氣象台的平年值裡，流冰初日是2月19日，但1991年到2020年的30年裡只有15年觀測到流冰。就算流冰到了，有流冰的期間平年也只有14天，而且幾乎不會靠岸。

想親眼看看流冰，宗谷岬的流冰館是比較穩的選擇。展示室全年保持在零下10度以下，放著冬天運進來的真正流冰，免費參觀。開館時間4月到11月是8:00到18:00，12月到3月縮短成9:00到16:00，冬天不定休。

### 稚內近年的流冰紀錄

近五年裡，有觀測到流冰的只有2023年和2025年。

| 年份 | 流冰初日 |
|---|---|
| 2025年 | 2月23日 |
| 2024年 | 沒有流冰 |
| 2023年 | 2月22日 |
| 2022年 | 沒有流冰 |
| 2021年 | 沒有流冰 |

有流冰的年份，停留的時間也可能很短，2018年只有2天，2020年是5天。稚內地方氣象台的流冰觀測從1946年做到2025年，這份紀錄就停在2025年。

## 稚內夏天也要帶外套嗎？

要帶。稚內的夏天少有熱天，白天最高氣溫達到25℃的日子一年平均只有8.1天，大多在8月，30℃以上的日子是0天。6月早晚的最低氣溫平均10.4℃，7月是14.9℃，就連最暖的8月，白天最高平均也只有22.3℃。

7月的平均風速也還有每秒3.9公尺，6月和7月的濕度在85%以上，還會起霧，建議帶一件能擋風、不怕濕氣的薄外套。

## 宗谷岬的天氣和稚內一樣嗎？

本頁的氣溫是稚內觀測站的平年值，排宗谷岬的行程時可以拿來當基準，但岬角的風要另外算進去。站在宗谷岬的尖端會被強風吹著，稚內觀光協會也提醒，宗谷岬是風非常強的地方，要做好防寒和防風。

冬天更明顯。跨年夜到元旦清晨，宗谷岬的氣溫會降到零下10度左右，比稚內1月平均最低的零下6.4℃還低。從市區開車前往，夏天約40分鐘，冬天的雪路要1小時左右。冬天的路面可能結冰，也可能遇到暴風雪和視線不良。前往宗谷岬的路線巴士遇到惡劣天氣也可能停駛。

天氣晴朗、空氣清澈的日子，從岬上可以望見40多公里外的庫頁島。宗谷岬冬天能不能去，見宗谷岬值得去嗎。
