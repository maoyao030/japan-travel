# 稚內天氣，各月氣溫、降雪與穿著

說到稚內天氣，夏天短而涼，冬天長又多雪，一年的平均氣溫只有7.0℃。最暖的8月平均19.5℃，12月到隔年3月每個月的平均都在0℃以下。雪從11月一路下到4月，一整季的降雪量平均477公分，風則是一年到頭都大。

冬天的穿著以防寒加防風為主，流冰則是30年裡只有一半的年份看得到。還沒決定要不要排稚內，可以先看稚內值得去嗎。

| 4月 | 4.5℃ | 7.4℃ | 1.8℃ |

稚內一天裡的溫差不大，最冷的1月白天和早晚只差4度左右，最暖的8月也只差5度左右。全年最冷的是2月的早晚，最低平均零下6.7℃。

春天回暖得慢，4月白天最高平均才7.4℃，秋天則涼得慢，10月白天還有14.1℃。7月和9月的平均氣溫都是17.2℃，白天最高也同樣是20.1℃，9月可以當成夏天的尾巴來排。

### 稚內各月降水與降雪

稚內從11月一路下雪到隔年4月，各月的降雪量同樣是平年值。

| 月份 | 降雪量 |
|---|---|
| 11月 | 41公分 |
| 12月 | 122公分 |
| 1月 | 129公分 |
| 2月 | 105公分 |
| 3月 | 68公分 |
| 4月 | 9公分 |

下得最多的是12月和1月，平均下雪的天數12月28.5天、1月30.4天，等於幾乎天天下雪。積雪最深的時候在2月，平均64公分。整年算起來，約有148天會下雪。

雨最多的是秋天，9月136.7毫米、10月129.7毫米，11月也有121.4毫米。春天的4月是50.3毫米。9月到11月去的話，行李裡放一件防水外套或折疊傘比較安心。

### 稚內和札幌的氣溫比較

從札幌北上，夏天兩地的落差比冬天大。8月平均氣溫稚內19.5℃、札幌22.3℃，稚內低了將近3度。1月是稚內零下4.3℃、札幌零下3.2℃，只差1.1度。兩地更明顯的差別在風，全年平均風速稚內每秒4.6公尺，札幌是3.6公尺。

### 稚內的日照與霧

冬天的白天又短又暗，12月一整個月的日照28.4小時，1月40.6小時。日照時數最多的是5月，有181.6小時。晴天的機會要看日照率達到40%以上的日子，9月平均17.1天最多，其次是4月16.1天、10月15.0天，5月是14.9天。想在晴天看海、看遠方的島，9月的機會最多。

6、7月是一年裡最潮濕的時候，平均相對濕度6月85%、7月87%。這兩個月也是最常起霧的季節，不過一個月也只有3到4天。

## 稚內一年到頭的強風

稚內全年的平均風速是每秒4.6公尺，11月到1月最強，平均每秒5.0公尺，冬天多吹西風。風最弱的7月也還有每秒3.9公尺，夏天多半吹南南西風。

以氣象廳的日最大風速每秒10公尺以上來算，這樣的日子一年平均有88.9天。11月、12月和1月每個月都將近10天，7月和8月約3天。稚內觀光協會的說法則是一年約有130天颳強風，兩種數字的算法不同。11月到1月去海邊、岬角這類空曠的地方，正好碰上一年裡風最大的時候，外套挑防風的款式。

風大的影響不只在冬天，渡輪遇到颱風或低氣壓帶來的大浪與強風都可能停開，天氣突然變壞時也會臨時停航。停航後怎麼改票，整理在稚內到利尻島、禮文島渡輪。

## 稚內冬天要穿什麼？

稚內的冬天，衣服除了保暖還要能防風。外層穿擋得住風、不怕雪的外套，帽子、手套、圍巾都帶齊。12月到2月每個月有16到24天白天最高氣溫不到0℃，一整天都在冰點以下，這樣的日子一年平均約73天。12月和1月也正是一年裡風最強的時候。

冬天的路面還可能結冰，鞋子挑防水、鞋底防滑的款式。

3月和11月平均氣溫是零下0.6℃與3.8℃，也各有68公分、41公分的降雪，冬季外套照樣要帶。4月平均4.5℃，雪只剩9公分左右，可以換成稍薄的保暖外套。

### 稚內冬天的風雪與交通

稚內機場的機場巴士配合班機發車，班機取消就停駛，延誤時會等飛機到了再開。往返札幌的高速巴士稚內號（わっかない号），2026年12月1日到2027年3月19日夜班停駛，白天的班次照常。冬天的渡輪同樣可能因大浪與強風停航。

冬天從稚內搭飛機或渡輪離開，接著要轉回台灣的航班時，建議中間多留一天，因為班機一取消，機場巴士也跟著停駛，渡輪也可能因天氣停航。JR稚內站附近就有旅館，THE STAY WAKKANAI走路約1分鐘，天北之湯Dormy Inn稚內（天北の湯 ドーミーイン稚内）約3分鐘。走不了的話可以就近多住一晚，其他選擇整理在稚內住宿。

## 稚內看得到流冰嗎？

在稚內看到流冰的機會不高。依稚內地方氣象台1991年到2020年的紀錄，從海岸第一次看到流冰的日子平均是2月19日，但這30年裡只有15年有流冰。流冰期間的平年值是14天，這是從第一次看到算到最後一次看到的天數，不代表這段時間天天看得到。流冰擠滿岸邊、海面看不到水路的情形，30年裡只有2年。

想親眼看看流冰，宗谷岬流冰館（宗谷岬流氷館）是比較穩的選擇。展示室全年保持在零下10度以下，放著冬天運進來的真正流冰，免費參觀。4月到11月開8:00到18:00，12月到3月縮短成9:00到16:00，冬天不定期休館。冬天出發前，可以到JR稚內站旁KITAcolor（キタカラ）1樓的稚內市觀光案內所確認當天有沒有開。案內所開10:00到18:00，12月31日到1月5日休息。

### 稚內近年的流冰紀錄

近五年裡，有觀測到流冰的是2023年和2025年。

| 年份 | 流冰初日 |
|---|---|
| 2025年 | 2月23日 |
| 2024年 | 沒有流冰 |
| 2023年 | 2月22日 |
| 2022年 | 沒有流冰 |
| 2021年 | 沒有流冰 |

有流冰的年份，停留的時間有時很短，2018年2天，2020年5天。稚內地方氣象台從1946年開始觀測流冰，2025年之後就不再觀測。想知道當年流冰來了沒，可以到稚內市觀光案內所問問。

## 稚內夏天也要帶外套嗎？

要帶。稚內的夏天很少熱，白天最高氣溫達到25℃的日子一年平均只有8.1天，大多集中在8月，30℃以上的日子平年值是0天。6月早晚最低平均10.4℃，7月是14.9℃，就連最暖的8月，白天最高平均也才22.3℃。

夏天一樣有風，6、7月又潮濕，帶一件能擋風、不怕濕的薄外套。

## 宗谷岬的天氣和稚內一樣嗎？

氣溫大致可以照稚內來看，但岬角的風非常強，跨年清晨也比稚內1月的平均最低更冷。本頁的氣溫都是稚內觀測站的平年值，排宗谷岬的行程時可以拿來當基準。站在宗谷岬尖端會被強風吹著，稚內觀光協會也提醒要穿得夠暖、夠擋風。

跨年夜到元旦清晨，宗谷岬的氣溫會降到零下10度左右，稚內1月的平均最低是零下6.4℃。從市區開車過去夏天約40分鐘，冬天走雪路要1小時左右。路面可能結冰，也可能碰上暴風雪或視線不良。天候太差時，往宗谷岬的路線巴士也可能停駛，班次見宗谷岬交通。

天氣晴朗、空氣清澈的日子，從岬上可以望見40多公里外的庫頁島。宗谷岬冬天能不能去，見宗谷岬值得去嗎。
