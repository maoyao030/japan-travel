# 稚內天氣，各月氣溫、降雪與穿著

稚內的夏天短而涼、冬天長又多雪，而且風一年到頭都大，全年平均氣溫只有7.0℃。12月到隔年3月每個月的平均都在0℃以下，雪從11月一路下到4月，一整季的降雪量平均477公分。

冬天穿的衣服要能保暖、也要能擋風。流冰在稚內30年裡只有一半的年份看得到，所以不太適合當成冬天造訪的唯一理由。如果還沒決定要不要排稚內，稚內值得去嗎那頁整理了主要的看點跟怎麼到。

## 稚內各月氣溫

下表的氣溫是氣象廳的平年值，也就是1991年到2020年這30年的平均，不是天氣預報。

|---|---|---|---|
| 1月 | −4.3℃ | −2.4℃ | −6.4℃ |
| 2月 | −4.3℃ | −2.0℃ | −6.7℃ |
| 3月 | −0.6℃ | 1.6℃ | −3.1℃ |
| 4月 | 4.5℃ | 7.4℃ | 1.8℃ |
| 5月 | 9.1℃ | 12.4℃ | 6.3℃ |
| 6月 | 13.0℃ | 16.1℃ | 10.4℃ |
| 7月 | 17.2℃ | 20.1℃ | 14.9℃ |
| 8月 | 19.5℃ | 22.3℃ | 17.2℃ |
| 9月 | 17.2℃ | 20.1℃ | 14.4℃ |
| 10月 | 11.3℃ | 14.1℃ | 8.4℃ |
| 11月 | 3.8℃ | 6.3℃ | 1.3℃ |
| 12月 | −2.1℃ | 0.0℃ | −4.2℃ |

一年裡最冷的是2月的早晚，平均最低零下6.7℃。不過稚內一天之中的溫差不大，1月白天跟早晚只差4度左右，8月也只差5度左右，所以白天出門穿多少，晚上大致也照著穿就好。

春天回暖得慢，4月白天最高平均才7.4℃，秋天則涼得慢，10月白天還有14.1℃。7月跟9月的平均氣溫同樣是17.2℃，白天最高也都是20.1℃，所以排行程的時候9月可以當成夏天的尾巴。

### 稚內各月降水與降雪

稚內的雪從11月一路下到隔年4月，下表的降雪量同樣是平年值。

| 月份 | 降雪量 |
|---|---|
| 11月 | 41公分 |
| 12月 | 122公分 |
| 1月 | 129公分 |
| 2月 | 105公分 |
| 3月 | 68公分 |
| 4月 | 9公分 |

12月跟1月下得最多，下雪的天數平均12月28.5天、1月30.4天，幾乎天天都在下。積雪最深是在2月，平均64公分，整年算起來大約有148天會下雪。

雨則集中在秋天，9月136.7毫米、10月129.7毫米，11月也有121.4毫米，4月只有50.3毫米。9月到11月去的話，行李裡記得放一件防水外套或折疊傘會比較安心。

### 稚內跟札幌的氣溫比較

從札幌北上，夏天的溫差比冬天明顯，不過兩地真正拉開的其實是風。8月平均氣溫稚內19.5℃、札幌22.3℃，稚內低了將近3度，1月則是稚內零下4.3℃、札幌零下3.2℃，只差1.1度。全年平均風速稚內每秒4.6公尺，比札幌的3.6公尺強上一截，所以體感上會覺得差更多。

### 稚內的日照與霧

想碰上晴天看海、看遠方的島，9月的機會最多。日照率達到40%以上的日子，9月平均17.1天，其次是4月16.1天、10月15.0天、5月14.9天。日照時數最長的是5月，一個月181.6小時。冬天的白天又短又暗，12月一整個月只有28.4小時的日照，1月也只有40.6小時。

6、7月最潮濕，平均相對濕度6月85%、7月87%，也是最常起霧的季節，不過一個月只有3到4天，不至於整趟都碰不到好天氣。

## 稚內一年到頭都在吹的強風

稚內的風在11月到1月最強，平均風速每秒5.0公尺，冬天多吹西風。風最弱的7月也還有每秒3.9公尺，夏天多半吹南南西風，全年平均是每秒4.6公尺。

日最大風速達到每秒10公尺以上的日子，一年平均有88.9天，11月、12月跟1月每個月都將近10天，7月跟8月大約3天。稚內觀光協會則說一年大約有130天颳強風，跟氣象廳的數字是不同的算法。冬天去海邊、岬角這類空曠的地方，正好碰上一年裡風最大的時候，記得外套要挑防風的款式。

風大也會影響離島的船，遇到颱風或低氣壓帶來的大浪跟強風，渡輪可能停開，天氣突然變壞時也會臨時停航。如果搭渡輪碰上停航，稚內到利尻島、禮文島渡輪那頁有整理改票的做法跟要注意的事。

## 稚內冬天要穿什麼？

稚內的冬天，衣服要同時擋得住冷跟風。12月到2月每個月有16到24天，白天最高氣溫都不到0℃，而且整天在冰點以下的日子一年大約73天，12月跟1月又正好是風最強的時候。

外層穿擋風、不怕雪的外套，帽子、手套、圍巾都帶齊。冬天的路面可能結冰，鞋子要挑防水、鞋底防滑的款式。

3月跟11月平均氣溫是零下0.6℃跟3.8℃，降雪也各有68公分、41公分，所以冬季外套照樣要帶。到了4月，平均4.5℃，雪只剩9公分左右，就可以換成稍薄的保暖外套了。

### 稚內冬天的風雪與交通

冬天從稚內搭飛機或渡輪離開，如果接著要轉回台灣的航班的話，記得中間多留一天比較保險。稚內機場的機場巴士配合班機發車，班機取消就停駛，延誤時會等飛機到了才開。渡輪也可能因為大浪跟強風停航。往返札幌的高速巴士稚內號（わっかない号）冬天停駛夜班，這一季是2026年12月1日到2027年3月19日，不過白天的班次照常。

走不了的時候，可以在JR稚內站附近多住一晚，THE STAY WAKKANAI離車站走路大約1分鐘，天北之湯Dormy Inn稚內（天北の湯 ドーミーイン稚内）大約3分鐘。如果想找站前以外的旅館，稚內住宿那頁有更多選擇。

## 稚內看得到流冰嗎？

在稚內看到流冰的機會不高。1991年到2020年這30年，從海岸第一次看到流冰的日子平均是2月19日，不過只有15年看得到。流冰期間的平年值是14天，這是從第一次看到算到最後一次看到的天數，不代表這段時間天天都在。流冰擠滿岸邊、海面看不到水路的情形，30年裡只有2年。同在北海道的網走，流冰初日平年是1月22日，比稚內早將近一個月，平年2月4日就會擠滿岸邊。

如果冬天在稚內想看看真正的流冰，宗谷岬流冰館（宗谷岬流氷館）比較穩。展示室全年保持在零下10度以下，放著冬天運進來的流冰，免費參觀。4月到11月開8:00到18:00，12月到3月縮短成9:00到16:00，不過冬天不定期休館，出發前可以到JR稚內站旁KITAcolor（キタカラ）1樓的稚內市觀光案內所確認當天有沒有開，案內所開10:00到18:00，12月31日到1月5日休息。

### 稚內近年的流冰紀錄

近五年裡，有流冰的只有2023年跟2025年。

| 年份 | 流冰初日 |
|---|---|
| 2025年 | 2月23日 |
| 2024年 | 沒有流冰 |
| 2023年 | 2月22日 |
| 2022年 | 沒有流冰 |
| 2021年 | 沒有流冰 |

有流冰的年份，停留的時間也可能很短，2018年只有2天，2020年5天。稚內地方氣象台從1946年開始觀測流冰，2025年之後就不再觀測了，如果想知道當年流冰來了沒，可以到稚內市觀光案內所問。

## 稚內夏天也要帶外套嗎？

要帶。稚內的夏天很少熱，白天最高氣溫到25℃的日子一年平均只有8.1天，大多在8月，30℃以上的日子平年值是0天。最暖的8月白天最高平均也才22.3℃，而且6月早晚最低平均10.4℃，7月是14.9℃，入夜後還是會涼。

夏天一樣有風，6、7月又潮濕，帶一件能擋風、不怕濕的薄外套就夠用了。

## 宗谷岬的天氣和稚內一樣嗎？

宗谷岬的氣溫大致可以照稚內來看，本頁的數字都是稚內觀測站的平年值，排宗谷岬的行程時可以拿來當基準。不過岬角的風非常強，站在尖端會被強風吹著，稚內觀光協會也提醒要做好防寒跟防風。

跨年夜到元旦清晨，宗谷岬會降到零下10度左右，比稚內1月的平均最低零下6.4℃還冷。從市區開車過去夏天大約40分鐘，冬天走雪路要1小時左右，路面可能結冰，也可能碰上暴風雪或視線不良，要特別注意行車安全。天候太差時，往宗谷岬的路線巴士也可能停駛，想知道巴士一天幾班、幾點回程，宗谷岬交通那頁有完整的時刻表。

天氣晴朗、空氣清澈的日子，從岬上可以望見40多公里外的庫頁島。如果冬天也想把宗谷岬排進行程，宗谷岬值得去嗎那頁寫了冬天前往的條件跟岬上的看點。
