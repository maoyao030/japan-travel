# 稚內天氣，各月氣溫、降雪與穿著

稚內天氣是夏天短而涼、冬天長又多雪，風一年到頭都大，全年平均氣溫只有7.0℃[F1, F10]。12月到隔年3月，每個月的平均都在0℃以下[F1]。雪主要下在11月到4月，一整季的降雪量平均477公分[F5]。

冬天的衣服要能保暖也要能擋風[F13, F10]。流冰則是30年裡只有一半的年份看得到，不適合當成冬天造訪的唯一理由[F17]。還沒決定要不要排稚內，可以先看稚內值得去嗎。

一年裡最冷的是2月的早晚，平均最低零下6.7℃[F32]。稚內一天之中的溫差不大，1月白天和早晚只差4度左右，8月也只差5度左右[F31, F32]。白天出門穿多少，晚上大致也照著穿[F31, F32]。

春天回暖得慢，4月白天最高平均才7.4℃[F31]。秋天倒是涼得慢，10月白天還有14.1℃[F31]。7月和9月的平均氣溫同樣是17.2℃，白天最高也都是20.1℃，排行程時可以把9月當成夏天的尾巴[F1, F31]。

### 稚內各月降水與降雪

稚內的雪主要下在11月到隔年4月，下表的降雪量同樣是平年值[F5]。

| 月份 | 降雪量 |
|---|---|
| 11月 | 41公分 [F5] |
| 12月 | 122公分 [F5] |
| 1月 | 129公分 [F5] |
| 2月 | 105公分 [F5] |
| 3月 | 68公分 [F5] |
| 4月 | 9公分 [F5] |

12月和1月下得最多，下雪的天數平均12月28.5天、1月30.4天，幾乎天天都在下[F5, F6]。積雪最深是在2月，平均64公分[F5]。整年算起來，約有148天會下雪[F6]。10月平均也有3.8天下雪，降雪量只有1公分左右，10月下旬造訪要有碰上初雪的準備[F36]。

降水則集中在秋天，9月136.7毫米、10月129.7毫米，11月也有121.4毫米，其中11月已經有一部分是雪[F4, F5]。相比之下，4月只有50.3毫米[F4]。9月到11月造訪，行李裡放一件防水外套比較安心，9、10月再加一把折疊傘[F4, F5]。

### 稚內和札幌的氣溫比較

從札幌北上，兩地的氣溫夏天差得比冬天多，真正拉開距離的是風[F7]。8月平均氣溫稚內19.5℃、札幌22.3℃，稚內低了將近3度[F7]。1月則是稚內零下4.3℃、札幌零下3.2℃，只差1.1度[F7]。全年平均風速稚內每秒4.6公尺，比札幌的3.6公尺強上一截[F7]。

### 稚內的日照與霧

想碰上晴天看海、看遠方的島，9月的機會最多[F33]。一天有四成以上時間照得到太陽的日子，9月平均17.1天，其次是4月16.1天、10月15.0天、5月14.9天[F33]。日照時數最長的則是5月，一個月181.6小時[F8]。冬天的白天又短又暗，12月一整個月只有28.4小時的日照，1月也只有40.6小時[F8]。

6、7月最潮濕，平均相對濕度6月85%、7月87%[F9]。這兩個月也最常起霧，不過一個月只有3到4天[F9]。

## 稚內一年到頭的強風

稚內的風在11月到1月最強，平均風速每秒5.0公尺[F10]。風最弱的7月也還有每秒3.9公尺[F10]。

一天裡最大風速達到每秒10公尺以上的日子，一年平均有88.9天[F11]。11月、12月和1月每個月都將近10天，7月和8月則約3天[F11]。冬天正是一年裡風最大的時候，去海邊、岬角這類空曠的地方，外套要挑防風的款式[F10, F11]。

風大也會影響往離島的船[F16]。遇到颱風或低氣壓帶來的大浪與強風，渡輪可能停開，天氣突然變壞時也會臨時停航[F16]。搭渡輪碰上停航，改票的做法在稚內到利尻島、禮文島渡輪有整理[F16]。

## 稚內冬天要穿什麼？

稚內的冬天，衣服要同時擋得住冷和風。12月到2月，每個月有16到24天白天最高氣溫都不到0℃，像這樣整天在冰點以下的日子一年約73天[F13]。12月和1月又正好是風最強的時候[F10, F11]。

外層穿擋風、不怕雪的外套，帽子、手套、圍巾都帶齊[F13, F10, F6]。冬天的路面可能結冰，鞋子挑防水、鞋底防滑的款式[F6, F5, F24]。

3月和11月的平均氣溫是零下0.6℃與3.8℃，降雪也各有68公分、41公分[F1, F5]。這兩個月冬季外套照樣要帶[F1, F5]。到了4月，平均4.5℃，雪只剩9公分左右，可以換成稍薄的保暖外套[F1, F5]。

### 稚內冬天的風雪與交通

冬天離開稚內那天，不論搭飛機、JR還是巴士，以及從利尻島、禮文島搭渡輪回稚內那天，和回台灣的航班之間都建議多留一天[F14, F16]。稚內機場的機場巴士配合班機發車，班機取消就停駛，延誤時會等飛機到了才開[F14]。渡輪也可能因大浪與強風停航[F16]。往返札幌的高速巴士稚內號（わっかない号），2026年12月1日到2027年3月19日這個冬天停駛夜班，白天的班次照常[F15]。

走不了的時候，可以在JR稚內站附近多住一晚[F29, F30]。THE STAY WAKKANAI離車站走路約1分鐘，天北之湯多美迎稚內（天北の湯 ドーミーイン稚内）約3分鐘[F29, F30]。站前以外的旅館，可以從稚內住宿挑。

## 稚內看得到流冰嗎？

在稚內看到流冰的機會不高。1991年到2020年這30年，從海岸第一次看到流冰的日子平均是2月19日，但只有15年看得到[F17]。流冰期間的平年值是14天，這是從第一次看到算到最後一次看到的天數，不代表這段時間天天都在[F18]。流冰擠滿岸邊、海面看不到水路的情形，30年裡只有2年[F18]。同在北海道的網走，流冰初日平年是1月22日，比稚內早將近一個月，平年2月4日就會擠滿岸邊[F35, F17]。一定要看海上的流冰，排網走比較有把握[F35, F17]。

想在稚內近距離看到真正的流冰，可以去宗谷岬流冰館（宗谷岬流氷館）。展示室全年保持在零下10度以下，放著冬天運進來的流冰，參觀免費[F26, F27]。4月到11月開8:00到18:00，12月到3月縮短成9:00到16:00[F27]。冬天不定期休館，出發前可以到JR稚內站旁KITAcolor（キタカラ）1樓的稚內市觀光案內所確認當天有沒有開[F27, F34]。案內所開10:00到18:00，12月31日到1月5日休息[F34]。

### 稚內近年的流冰紀錄

近五年裡，有流冰的只有2023年和2025年[F17]。

| 年份 | 流冰初日 |
|---|---|
| 2025年 | 2月23日 [F17] |
| 2024年 | 沒有流冰 [F17] |
| 2023年 | 2月22日 [F17] |
| 2022年 | 沒有流冰 [F17] |
| 2021年 | 沒有流冰 [F17] |

有流冰的年份，停留的時間也可能很短，2018年只有2天，2020年5天[F18]。稚內地方氣象台從1946年開始觀測流冰，2025年之後就不再觀測[F19]。碰上有流冰的年份，今年流冰來了沒、現在哪裡看得到，可以到稚內市觀光案內所問[F34]。

## 稚內夏天也要帶外套嗎？

要帶。稚內的夏天很少熱，白天最高氣溫到25℃的日子一年平均只有8.1天，大多在8月[F20]。30℃以上的日子，平年值是0天[F20]。最暖的8月，白天最高平均也才22.3℃[F2]。早晚最低平均6月10.4℃，7月是14.9℃[F3]。

夏天一樣有風，6、7月又潮濕，帶一件能擋風、不怕濕的薄外套就夠用[F10, F9]。

## 宗谷岬的天氣和稚內一樣嗎？

宗谷岬的氣溫大致可以拿本頁稚內觀測站的平年值當基準[F1]。不同的是岬角的風非常強，站在尖端會被強風吹著[F21, F22]。稚內觀光協會也提醒要做好防寒和防風[F22]。

跨年夜到元旦清晨，宗谷岬會降到零下10度左右，比稚內1月的平均最低零下6.4℃還冷[F23, F3]。從市區開車過去，夏天約40分鐘，冬天走雪路要1小時左右[F24]。路面可能結冰，也可能碰上暴風雪或視線不良[F24]。天候太差時，往宗谷岬的路線巴士也可能停駛[F25]。巴士一天幾班、幾點回程，宗谷岬交通附了時刻表[F25]。

天氣晴朗、空氣清澈的日子，從岬上可以望見40多公里外的庫頁島[F28]。如果冬天也想把宗谷岬排進行程，可以看宗谷岬值得去嗎，那頁寫了冬天前往的條件和岬上的看點[F24, F25]。
