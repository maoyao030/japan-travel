# 稚內天氣 資訊順序筆記（重寫，2026-11-02）

照 `competitor-notes.md` 第 6 節的建議排每一節，標題照網站版本一字不改。事實只用 `reference-review.md`（含 F35）。

| 節 | 用的順序 | 照筆記哪一點 |
|---|---|---|
| 開頭 | 一年的樣子（夏涼冬長、風大、年均 7.0℃）→ 冬天多冷多雪 → 穿著重點與流冰不穩 → 連回主頁 | 第 3、6 節：先一句一年的樣子，再直接回答讀者最想知道的三件事，數字留給表 |
| 北海道稚內天氣與各月稚內氣溫 | 平年值不是預報 → 表 → 最冷的 2 月早晚 → 溫差小、早晚照白天穿 → 春天回暖慢、9 月像夏天尾巴 | 第 4、6 節：讀者先看一年的樣子再看表，表後只挑排行程用得到的點 |
| 稚內各月降水與降雪 | 雪下多久 → 表 → 12、1 月最多、天天下 → 最深積雪與全年雪日 → 秋天雨多、帶雨具 | 第 6 節建議順序 |
| 稚內和札幌的氣溫比較 | 結論（夏天差得多、冬天差不多、真正差在風）→ 8 月、1 月數字 → 風速 | 第 6 節：先給結論再給數字 |
| 稚內的日照與霧 | 晴天機會哪個月多（改到最前）→ 5 月日照最長 → 冬天白天短 → 6、7 月潮濕起霧 | 第 6 節：先講讀者在意的晴天機會 |
| 稚內一年到頭的強風 | 什麼時候最強 → 最弱月與全年 → 強風天數與觀光協會說法 → 去海邊岬角的建議 → 渡輪停航一句帶過 | 第 6 節；第 5 節 D 把「出狀況」接在後面 |
| 稚內冬天要穿什麼？ | 為什麼（冰點以下天數、風）→ 外套 → 帽子手套圍巾 → 鞋 → 3、11、4 月過渡期 | 第 4 節 B、C 共通的「原因→外套→配件→鞋」，鞋放最後；第 6 節過渡期放最後 |
| 稚內冬天的風雪與交通 | 建議（接回台灣的航班前多留一天）→ 原因（機場巴士、渡輪、夜班巴士）→ 備案住站前 | 第 6 節；第 3 節 D 條件放前面 |
| 稚內看得到流冰嗎？ | 機率（30 年一半）→ 流冰期間的意思 → 接岸 2 年 → 網走比較（F35）→ 流冰館 → 開館時間 → 案內所 | 第 4 節 D 先講機率再講替代；第 6 節建議加網走比較 |
| 稚內近年的流冰紀錄 | 一句結論 → 表 → 停留很短的年份（只寫到 2020 年）→ 觀測已停、去哪裡問 | 第 6 節建議順序 |
| 稚內夏天也要帶外套嗎？ | 第一句回答「要」→ 25℃ 以上天數 → 最暖月最高與早晚最低 → 穿什麼 | 第 6 節 |
| 宗谷岬的天氣和稚內一樣嗎？ | 結論（氣溫照稚內、風更強）→ 跨年更冷 → 冬天路況與巴士停駛 → 晴天看得到庫頁島 → 連到宗谷岬主頁 | 第 6 節 |
