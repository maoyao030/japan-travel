## 2. 各篇的順序

- **A 好運日本行**：開頭一段總說會介紹哪些料理 → H2「第一次到旭川必吃清單」用氣候帶出飲食特色 → H2 拉麵（先一段講旭川拉麵為什麼浮一層豬油、雙湯頭、中細捲麵，再逐店）→ 各店 H3：創業年與湯頭 → 口味形容 → 店家資訊塊（地址、時間、休日、交通分鐘數）→ 拉麵村放在拉麵的最後一個 H3 → 壽司 → 燒肉、成吉思汗、鹽荷爾蒙 → 新子燒（先講料理由來，再兩家店）→ 地圖。
- **B WAmazing**：開頭講旭川位置與幾樣招牌料理 → 每家店一個 H2，店內順序是歷史或特色 → 招牌菜 → 氣氛 → 資訊塊 → 最後兩節加碼伴手禮與購物。沒有拉麵村、沒有訂位說明。
- **C 喵爸喵媽**：先說三家各有支持者 → 每家：背景 → 營業時間 → 地圖 → 照片 → 個人感想 → 另一節寫排隊多久、店內、點了什麼。
- **D 大黑屋兩篇**：Mimi韓是資訊塊放最前面，再走路分鐘數 → 時間依季節要看官網 → 到店抽號碼等候 → 菜單 → 煙很大 → 每人花費；娜塔蝦是交通 → 沒訂位怎麼等 → 「免排隊」一節專講訂位與提早到 → 座位型態 → 菜單 → 必點。
- **E 拉麵村兩篇**：小兔是交通（電車先、開車後）→ 園區地圖 → 環境與拍照點 → 吃了哪家 → 地址時間；威廉是開頭速查（時間、交通、停車）→ 拉麵村簡介與付款 → 神社 → 期間限定店 → 各店（歷史與口味 → 必點 → 交通）→ 交通比較表（自駕、電車、巴士）→ 幾點去人少 → 周邊 → FAQ。

## 3. 開頭怎麼寫

- A、B 都是「先點名幾樣招牌料理，再承諾整理好名店」，A 多一句用冬天冷與溫差解釋口味重。
- 部落客多從自己的期待或朋友推薦切入，再補評分或名氣。
- 共通點：開頭三兩句就把「拉麵、成吉思汗、新子燒、鹽荷爾蒙」並列點名，讀者一進來就知道這頁涵蓋哪些料理。本站開頭已經這樣做，順序對。

## 4. 關鍵問題怎麼回答

1. **旭川拉麵是什麼、拉麵村怎麼去**：A 先用一兩句定義（醬油、雙湯頭、豬油、中細捲麵），再逐店；拉麵村放在拉麵一節的最後。拉麵村專文都是「交通先講」，其中一篇電車先、一篇開車先；威廉用一張交通表比三種方式。各店介紹都是「創業年或湯頭 → 口味 → 資訊」。有兩篇提到人多的時段與吃半碗多吃幾家的作法。
2. **大黑屋在哪、要不要預約**：部落客的順序是「走路幾分鐘 → 沒訂位怎麼辦（現場抽號碼等）→ 訂位方法 → 菜單與點法」。讀者最在意的是「不訂會等多久」，訂位規則反而講得零散。沒有一篇講清楚「只能訂開店那一場」「每月下旬開放下月」，這是本站的強項，可以放在這節前段。
3. **新子燒、鹽荷爾蒙等在地料理**：A、B 都先講料理由來（戰後、仔雞半隻），再接店家；店家段落先招牌菜，再講要等多久（新子燒要烤約 30 分鐘是各篇都會提的提醒），最後氣氛。鹽荷爾蒙各篇點的店不同，但順序一樣：先說旭川是發源地，再講店。
4. **晚上去哪吃喝**：沒有競品專門寫一節，夜晚的資訊散在各店（居酒屋、燒鳥配酒）。本站把 Sanroku 街、屋台村、角打集中成一節是差異點。
5. **伴手禮去哪買**：只有 B 寫，而且是導購自家購物網站；A 沒寫。本站的直賣店與休息站是競品沒有的。

表格：幾乎不用。只有威廉的交通比較表。店家資訊一律用條列資訊塊（地址、時間、休日、交通）放在介紹段落後面。

## 5. 段落與句子的習慣

- 好運日本行：每家店一段 3～5 句，先定位（老店、元祖、名店）再寫口味，形容詞多但句子不長；資訊塊用條列，數字集中在資訊塊，正文少數字。稱讀者用「你」或省略主詞，會用「記得…」「如果時間有限…就來…」這類條件句開頭帶建議。
- 部落客：短句、口語，常用「建議」「記得」，數字多是等了幾分鐘、幾組人、每人花多少。
- 轉場：A 的 H2 開頭會先用一句把料理放回旭川的脈絡（冷、內陸），再進店家；拉麵村用「時間有限、想一次吃好幾家」這種情境句帶出。
- 數字位置：營業時間與走路分鐘數放在店家介紹的最後，不放開頭第一句。

## 6. 給作者的順序建議（標題照現在的版本，不改）

- **H2 旭川美食推薦，旭川拉麵與百名店**：① 一兩句講旭川拉麵是什麼（醬油、雙湯頭、捲麵）；② 讀者接著想知道「去哪吃」，先給市中心走得到的選擇（Furarito 的蜂屋、休息站的梅光軒），再接百名店榜單當挑店參考；③ 榜單 8 家的列表放後面，拉麵村的分店說明緊接列表。
- **H3 旭川拉麵村怎麼去、有哪幾家**：① 一句話定位（郊外、8 家集中、免費入場，適合想一次比較的人）；② 交通：開車先講（停車免費；競品多半也先講開車，但不要寫成「多數人開車」），再電車與回程空檔，時刻表接在電車段落；③ 營業與縮短營業、幾點去最穩；④ 各店差在哪（表格）；⑤ 神社與拍照點放最後；⑥ 基本資訊欄收尾。
- **H2 旭川成吉思汗大黑屋怎麼訂位**：① 一兩句招牌與「旭川只有一家、別訂到台灣或札幌分店」（搜尋結果多是台北分店，這句提早）；② 訂位規則：每月下旬開放下月、只訂開店那一場、這個月幾點；③ 沒訂到怎麼辦（現場等候、超時取消改帶等候客人、全員到齊才帶位、當天不能改人數）；④ 營業到幾點、休日；⑤ 替代：大雪地啤酒館。開店時間表格 10 月那列已過，只留 11 月。
- **H2 旭川的在地料理，新子燒、鹽荷爾蒙與炸花枝腳丼**：每樣料理都照「是什麼、怎麼來的 → 去哪家吃 → 招牌與價格 → 時間與限制（站著吃、不能刷卡、17:00 才開）」；三樣都在 Furarito，可以先一句帶出 Furarito 位置再分講。Okada 紅雪庭放最後。
- **H3 5・7小路Furarito的新子燒**：① 新子燒是什麼（戰後、仔雞半隻）；② Ginneko：要烤 30 分鐘、不能訂位，這兩點是讀者最需要的，放在價格前面；③ 價格、調味、營業與最晚點餐；④ 其他店家名單放最後。
- **H3 旭川醬油炒麵**：① 是什麼（規定）；② 去哪吃（大雪地啤酒館最好找）；③ 推廣會的店家數與活動限定。
- **H2 旭川晚上去哪吃，Sanroku街與屋台村**：① 先說距離關係（都在車站走路 15 分鐘內）；② 依讀者類型分：想熱鬧找 Sanroku 街與巴黎街，一個人或不想挑店去屋台村，想喝地酒去角打；③ 孤獨的美食家放最後當彩蛋。
- **H2 旭川伴手禮，醬油、地酒與休息站**：① 一次買齊去休息站（怎麼去、時間、年末年始休）；② 想帶旭川拉麵的味道回家買醬油；③ 地酒去酒藏；④ 總表收尾。
