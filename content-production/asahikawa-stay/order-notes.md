# 旭川住宿｜重寫的資訊順序（作者，2026-11-01）

照 `competitor-notes.md` 第 6 節。標題照線上稿一字不改。

- **開頭**：兩區 → 各離車站多遠 → 平和通買物公園連起兩區、沿路百貨與餐廳（F423，筆記第 6 節「開頭」）→ 行程怎麼對應 → 住宿稅。
- **H2 旭川住宿選哪一區，車站周邊或市中心**：先站前（多數人的答案，巴士在站前搭）→ 再市中心（機場巴士坐到門口，OMO7 終點、Art 與 Dormy Inn 門口有站，補上原稿沒寫進這節的 Dormy Inn）→ 缺點（走到車站 13 到 15 分）→ 一句誰適合市中心（只從機場進出、不搭火車與站前巴士）。照筆記「站前 → 市中心 → 誰適合哪區」。連結句改寫成完整的一句。
- **H3 住旭川可以用的動物園款待券**：是什麼與條件 → 怎麼用最划算 → 買時要證明 → 在哪買（先住的飯店櫃台，再講名單上沒有的四間）。照筆記「順序可以留」。券價 1,000 日圓照住宿頁不寫價格刪掉；「照2026年5月的販售名單」改成直接寫（writing-guide 第 3 條）。
- **H2 旭川住宿推薦，各飯店的位置**：兩區各幾間、各走幾分 → 照遠近排 → 館名欄的用途 → 查核日期 → 表。
- **H3 旭川站直結的JR Inn旭川**：用讀者需求起頭（搭 JR 進出）→ 直結 → 浴場 → 走法。照筆記「浴場可以往前移到走法之前」。
- **H3 旭川站前的飯店**：照距離 1 分 → 2 分 → 3 分 → 5 分一段走完 → 想泡湯的一句點出有大浴場的四間 → Seicomart 與免費早餐 → 東橫 INN 分清楚與 KOKO 舊名放最後。刪掉 AMANEK「2021年開幕」與 3 樓早餐會場（第 16 條，規格不影響選擇）。
- **H3 市中心的三間**：一句總說（走 13 到 15 分換機場巴士到門口）→ 每間先走到車站幾分、再機場巴士 → Dormy Inn 再接溫泉。
- **H2 旭川住宿的訂房管道**：一句結論（官網、Trip.com、Agoda 都能訂，冬天照常營業併進第一句）→ 官網才有的差別 → OMO7 在 Agoda 要直接搜尋。
- **H2 旭川住宿稅怎麼算？**：維持金額範圍 → 開始日與兩份 → 稅率表 → 試算 → 怎麼付（緊接試算）→ 免稅。
