## 2. 各篇的順序

**A 波比**
1. 開頭：主張「住旭川」→ 理由（交通、車程、房價）→ 預告 7 間
2. 為什麼住旭川：優點（交通樞紐、美瑛富良野中繼、動物園購物）→ 缺點與提醒
3. 快速選擇：5 種需求（車站直通、海鮮早餐、免費溫泉、小資、親子）各對一間
4. 訂房守則（離車站近、提早訂）
5. 逐間：價格 → 訂房連結 → 標籤與停車 → 位置與步行分鐘 → 房間設施（大浴場）→ 早餐 → 總評

**B Mimi韓**
1. 開頭：城市定位與周邊景點 → 冬天很冷，所以住哪裡很重要 → 二選一框架（車站周邊或買物公園一帶）→ 預告 9 間
2. 為什麼住旭川 → 怎麼到旭川（交通表，含機場巴士）
3. 住宿區域怎麼選：兩區各寫優缺點（條列），再接預算
4. 車站 AEON 周邊 6 間 → 買物公園一帶 3 間
5. 逐間：名稱 → 位置與距離、設施、大浴場、早餐寫成一段 → 速查條列（交通、亮點、適合誰、連結）→ 實住心得優缺點
6. 總結

**C 北海道旅遊站**
1. 開頭：用讀者的疑問開場（不知道選哪間）→ 列情境（車站周邊、親子、CP 值）→ 預告
2. 房價趨勢
3. 逐間：三點亮點（地點 → 設施 → 划算）→ 缺點 → 評論一正一負 → 建議 → 訂房按鈕 → 地址電話官網

## 3. 開頭怎麼寫

- 五篇都先講「旭川值得住」（第二大城、往美瑛富良野與動物園的中繼），再預告幾間。沒有一篇第一段就說要住哪一區。
- B 是唯一在開頭就丟出「車站周邊或買物公園一帶」二選一的；A、D 在第二節才講「住車站周邊最方便」。
- 本站開頭已經是「兩區在哪、各離車站多遠、行程怎樣住哪區」，比競品直接，順序不用改。「值得住旭川」不用補，主頁負責（有內連句）。
- 稅的頁面（稅 1）首句就給「每晚多少」，本站開頭最後一句也已經這樣做。

## 4. 關鍵問題怎麼回答

**① 住車站周邊還是市中心**
- 競品幾乎一面倒「住車站周邊」，理由順序固定：交通（JR、巴士）→ 購物與超市（AEON 連通）→ 吃飯方便。
- B 是唯一講另一區的，名字叫「平和通買物公園一帶」，不叫「5 條通到 7 條通」；優缺點條列，車站周邊的缺點寫得很少。
- 讀者熟悉的地標是 AEON 與買物公園。本站有官方事實：JR イン經 AEON 進出（F401）、買物公園從車站往北約 1 公里（F423）。

**② 有哪些飯店、各在哪、離車站多遠、怎麼訂**
- 每間的順序大致是：名稱 → 離車站幾分鐘（B、D 放第一句或第二句）→ 大浴場或溫泉 → 早餐 → 適合誰 → 訂房連結。A 例外，價格放第一行。
- 選店的依據競品幾乎都用「需求」：車站直通、大浴場或溫泉、早餐（海鮮丼）、平價、親子。距離是一定有的，大浴場排第二。
- 比較表：E 有兩張（前面選店表、後面總整理），其他用條列速查。沒有一篇的表有「訂房管道」欄，訂房都只是聯盟連結。
- 同品牌兩間（東橫 INN）沒有一篇提醒分清楚；舊名（Hotel Wing）D 還用舊名當標題。

**③ 住宿稅怎麼算**
- 五篇住宿清單都沒提住宿稅。
- 稅 1 的順序：金額範圍 → 開始日 → 稅率表 → 道稅與市稅的組成 → 免稅 → 試算。稅 2 多寫一點「平台預付通常不含、櫃台另付」（本站 F132：各館不同）。
- 本站現在的順序（金額範圍與級距 → 開始日與兩份 → 稅率表 → 試算 → 怎麼付 → 免稅）和稅 1 幾乎一樣，可以留。

**④ おもてなし券**
- 五篇都沒寫，只有一般的動物園門票連結。是本站獨有的資料，可以放前面。

## 5. 段落與句子的習慣

- 部落客口吻：稱讀者「你」「大家」，自稱名字，感嘆號、表情符號多；本站不學這些。
- 數字放的位置：步行分鐘一定跟在館名或位置後面；價格、評分放速查條列。
- 轉場靠小標和條列，很少用連接詞；B 用「不過」「重點是」轉缺點。
- 每間飯店是「一段介紹＋條列速查」的兩層。本站每間寫一兩句，資訊量接近他們的速查條列，不需要另做條列。

## 6. 給作者的順序建議

標題照現在的 `draft-tagged.md` 不改，只排每一節裡的順序。

- **開頭**：維持「兩區 → 各離車站多遠 → 行程怎麼對應 → 住宿稅」。可以在「另一區」那句把市中心和讀者認得的買物公園綁在一起（F423：從車站往北約 1 公里的步行街），讓讀者知道兩區中間就是這條街。
- **H2 旭川住宿選哪一區，車站周邊或市中心**：
  1. 先寫站前（多數人的答案）：離車站幾分鐘、巴士在站前搭（往動物園、機場、旭岳）。
  2. 再寫市中心：位置用買物公園說明，再接機場巴士直達門口（OMO7 終點站、Art 門口站、ドーミーイン門口）。
  3. 最後一兩句說誰適合哪區（搭火車或早上搭巴士 → 站前；機場直進直出、想住在吃飯的街上 → 市中心）。判斷句要有事實撐，「吃飯的街」用 F423 的「百貨與餐廳」，不要寫成「市中心比較熱鬧」之類沒事實的話。
- **H3 住旭川可以用的動物園款待券**：這是競品沒有的，現在的順序（是什麼 → 條件 → 怎麼用最划算 → 在哪買）可以留；「在哪買」先講「住的飯店櫃台」，再講名單上沒有的四間怎麼辦。
- **H2 旭川住宿推薦，各飯店的位置**：表格前一句先說兩區各幾間、各走幾分，再提訂房網站館名欄的用途。表格照距離排（現在已經是），這點比競品清楚。
- **H3 旭川站直結的JR Inn旭川**：先講直結（出站就到），再講走法（AEON 入口、電梯 5 樓），最後浴場。競品習慣「距離 → 浴場 → 早餐」，浴場可以往前移到走法之前，走法是實用細節放後面也可以，作者自己判斷。
- **H3 旭川站前的飯店**：照距離近到遠走（1 分 → 2 分 → 3 分 → 5 分），每間先距離、再浴場或溫泉。競品用「有沒有大浴場」選飯店，可以把有大浴場的幾間（ルートイン兩間、CABIN 溫泉、アマネク）在一句裡點出來，讓想泡湯的讀者一眼看到。東橫 INN 的「分清楚是哪一間」和 KOKO 舊名放最後。
- **H3 市中心的OMO7旭川、Dormy Inn旭川與Art Hotel旭川**：每間先「走到車站幾分」，再「機場巴士怎麼到」，ドーミーイン再接溫泉。
- **H2 旭川住宿的訂房管道**：先一句結論（12 間官網、Trip.com、Agoda 都能訂）→ 官網才有的差別（ルートイン早餐、東橫與ドーミーイン的官網最便宜標示）→ OMO7 在 Agoda 要直接搜尋。冬天照常營業可以留在第一段。
- **H2 旭川住宿稅怎麼算？**：維持現在順序。「事前付款時一起收或櫃台另收」是競品（稅 2）特別提醒的點，讀者在意，可以放在試算後面第一句，不要埋在段落中間。

## 7. 他們有、我們缺的

只列出來，不寫進文章；有官方事實的已標事實編號。

- **早餐當選飯店的理由**（海鮮丼、各館早餐評價）：A、C、E 都當主要賣點。本站事實只有 ルートイン兩間免費早餐（F403、F404）、アマネク 3 樓早餐會場（F406）、KOKO 12 樓早餐（F402）。照 Darren 2026-10-26「含餐只在影響選擇時寫」，維持現狀；早餐內容沒有查。
- **停車場與停車費**（自駕）：E 的標題就是「附設停車場」。本站大綱沒有自駕的題目，沒查，不寫。
- **親子**（家庭房、不佔床兒童）：E、C 有一組。沒查，不寫。
- **AEON 與超市**：競品當車站周邊的主要理由。本站只有 JR イン經 AEON 進出（F401）、ルートインGrand 1 樓有 Seicomart（F403）。
- **買物公園當市中心的名字**：已補 F423。
- **房價、評分、評論**：不寫（住宿頁不寫價格；評論要兩個平台三則以上才統整，本頁沒有人氣段落）。
- **「平台預付不含住宿稅」**：稅 2 的說法；官方只寫「各館不同」（F132），照官方寫。
