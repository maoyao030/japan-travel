# furano-transport 同搜尋意圖的繁中頁

查詢日期：2026-11-09
搜尋詞：「札幌到富良野交通」「札幌到富良野 JR 巴士 攻略」

## 1. JR北海道官方繁中頁

- **URL**：https://www.jrhokkaido.co.jp/global/chinese/travel/furanobiei/course/2a.html
- **性質**：官方範例行程（2026年7月1日～8月11日限定）
- **涵蓋**：札幌→旭川（特急Lilac）→富良野（Norokko號或普通車）→觀光周遊巴士→薰衣草特急回札幌
- **票價**：完全沒列
- **時刻**：只列範例行程的單一班次
- **特色**：確認全車指定席（Lilac、Norokko、薰衣草特急都標示），無座席未指定券說明
- **弱點**：夏季限定、沒有票價、沒有冬季或全年的走法、Norokko號已永久結束但頁面還在
- **我們的機會**：全年通用的交通指南、包含巴士選項、冬季走法、票價比較

## 2. todolist-japan.com（新千歲到富良野）

- **URL**：https://todolist-japan.com/zh/new-chitose-airport-to-furano/
- **性質**：聯盟行銷攻略文（Klook/Trip.com 連結）
- **發布**：2026年10月9日
- **涵蓋**：Bus Gorilla Liner、JR全年路線、薰衣草特急（已結束）、Resort Liner冬季巴士、高速富良野號（經札幌轉）、自駕、包車、周遊券比較
- **票價**：Bus Gorilla 5,000圓、Resort Liner 6,000圓、高速富良野號約2,700圓有寫；JR只寫「6,000多至7,000多」很模糊
- **時刻**：只有Bus Gorilla列出4班具體時刻，其他全是概略
- **特色**：提到Bus Gorilla車上沒廁所、不配合航班、冬季載客上限約30人；周遊券限非日本護照；瀧川以南不能用IC卡
- **弱點**：JR票價和時間都很模糊、沒有富良野市內交通、沒有旭川到富良野的走法、聯盟連結多
- **我們的機會**：完整JR時刻與確切票價、瀧川轉車的具體班次、旭川方向的薰衣草號、市內交通

## 3. funliday.com（旭川機場交通）

- **URL**：https://www.funliday.com/posts/asahikawa-airport-transportation-bus/
- **性質**：旭川機場巴士攻略（不是札幌到富良野）
- **發布**：2022年，最後更新2025/02/08
- **涵蓋**：旭川機場→旭川市區巴士、旭川機場→富良野巴士（ふらのバス）
- **票價**：旭川機場→富良野 790圓（與F6一致，但2025年資料）
- **弱點**：不是我們的直接競品（搜尋意圖不同）、資料可能過時（尤其12/1改價後）
- **我們的機會**：最新票價、薰衣草號完整時刻表（他們沒列）

## 4. WebSearch 綜合觀察

除了上述三篇，搜尋結果中還有：
- **veltra.com**：一日遊行程販售頁，不是攻略
- **furanotourism.com PDF**：2016-2017年的舊版交通PDF，嚴重過時
- **ekitan.com**：日文轉乘查詢結果

### 繁中市場的缺口

1. **沒有一篇完整列出全年各路線時刻表與確切票價**：JR官方不列價格，todolist只有Bus Gorilla有時刻，funliday只寫旭川機場出發
2. **沒有人寫全車指定席對票價的影響**：JR官方頁提到但沒解釋；todolist完全沒提
3. **沒有人寫富良野市內交通**：麓郷線、麻町線、計程車情報都沒有
4. **沒有人提到12/1薰衣草號改價**：我們是第一個注意到的
5. **冬季交通的具體資訊不足**：只有todolist提到Resort Liner，但沒有冬季高速ふらの号或冬季Bus Gorilla時刻
6. **旭川到富良野的走法被忽略**：台灣旅客也可能從旭川方向進入

### 我們的差異化

- 經營者官方的確切時刻表與票價（不是概略數字）
- 全車指定席的說明（座席未指定券同價、不會比較便宜）
- 富良野市內移動（麓郷線4班、麻町線3班，直接列時刻）
- 12/1 票價改定的提醒
- 冬季走法（Bus Gorilla冬季時刻、Resort Liner、上季冬季特便）
- 旭川到富良野（薰衣草號7班 + JR富良野線12班）
