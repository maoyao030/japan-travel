# 段落順序說明

大綱標記 `headingOrder: traveler-journey`，照旅客動線排。

1. **開頭**：身分（北海道薰衣草最集中的地方）→ 最重要的答案（最盛期7月上旬到中旬）→ 最重要的變化（慢車號停駛、花田站走法沒了）。
2. **薰衣草季節**：讀者第一件事是決定什麼時候去，給花期跟品種的時間差。
3. **看薰衣草的地方**：決定了月份就挑地方。按知名度排：富田農場 → 北星山 → 日之出公園 → 市內晚開。每處帶基本資訊欄，細節連到各地點頁。
4. **薰衣草特急**：挑好地方就安排怎麼從札幌過去。薰衣草特急是讀者最關心的直達車，2027年待公布改寫成「看JR公告」。
5. **慢車號已停駛**：接在特急下面，因為讀者搜「薰衣草特急」常一起問慢車號。這是競品還沒更新的資訊，放在顯眼的位置。
6. **不開車一天看兩三處**：排好交通工具，給不開車的人一個概略排法，細節連到各交通頁。
7. **薰衣草祭與花火**：額外行程，照日期排三個祭典。
8. **塞車與住宿**：最後提醒擠的時段跟宿泊稅，連到住宿頁。
