## 3. 開頭怎麼寫

- A：第一句就說最適合的方式是什麼，接著兩三個關鍵條件（直達、一天幾班），再提醒要劃位，最後帶票價與省錢方式。沒有故事。
- B：一句點主題與有哪些選項，再說作者選了哪個，接著預告體驗感受，語氣輕快。
- C：從地理位置與「最北」切入，反駁一個常見印象，再說適合誰，最後預告交通其實方便。
- E：先講車站的身分（最北端車站），再用到各地的車程把讀者定位。
- 共同點：交通類文章第一段就給「哪個方式、多久」，不先鋪陳。本站現在的開頭也是先給三種方式的時間，方向一致；競品比較常在開頭直接說「推薦哪一種、給誰」。

## 4. 關鍵問題怎麼回答

**mustAnswer 1：札幌到稚內 JR 與巴士要多久、要不要訂位**
- A：先說直達只有一班 → 車程 → 全車指定席要劃位 → 價格 → 周遊券怎麼劃位。用表格放價格。
- B：先列選項（JR、巴士、租車）→ 作者選 JR 的理由 → 班次條列 → 建議先劃位。
- C：表格一次列飛機、JR、巴士、自駕的時間，沒寫訂位。
- 高速巴士在中文競品裡只當選項一句帶過，沒人寫要預約、上車地點在大通、網路怎麼訂。順序上讀者習慣「先比時間與價格 → 再說各自要不要先訂」。

**mustAnswer 2：機場巴士只收現金或 PayPay、班機取消時停駛**
- 機場官網中文頁與搜尋摘要：先講時間（到車站約 30 分）→ 車資 → 付款限制 → 配合班機、不接渡輪。
- 付款限制都放在車資後面、一句話；班機取消停駛放最後當注意事項。
- 沒有競品列出巴士配合哪些班機的表。

**mustAnswer 3：JR 稚內站、巴士總站、渡輪站的位置關係**
- D：先講出站往哪走、走幾分 → 渡輪站在哪 → 怎麼買船票。
- E：先講車站本身 → 到渡輪站多久 → 站前巴士總站的功能 → FAQ 才講置物櫃。
- 讀者熟悉的順序是「出站 → 往哪走 → 多久 → 到了做什麼（買票、寄行李）」。

## 5. 段落與句子的習慣

- 句子中等偏長，常用逗號串好幾個資訊；本站要照自己的規則寫出句子之間的關係，不學這個。
- 部落客多用「我們」講經驗，對讀者用「建議」「如果…也可以…」「記得要…」；Funliday 用「你」「大家」，常見祈使句。本站不假裝去過，只學「如果…就…」這種條件句的給建議方式。
- 數字直接放在句子中間，帶單位；比較性資訊（時間、價格）多半進表格。
- 轉場詞常見「不過」「另外」「其中要注意的是」「至於」「最後」。
- 專有名詞附日文原名，重要數字粗體（本站不用粗體強調數字）。
- 結構上常用問答式小標收尾（FAQ）；本站不設 FAQ。

## 6. 給作者的順序建議

標題照現在的 `draft-tagged.md`，只排每節裡的順序。

- **開頭兩段**：先給三種方式各要多久，接著馬上講「要先訂位」這件事（JR 全車指定席、巴士只收預約），再講下車後容易卡的事。現在的順序已大致如此，可以把「推薦給誰」說得更直接（趕時間選 JR、省錢選巴士），但要有事實撐。
- **札幌到稚內，JR 特急與高速巴士**：1. 時間與價格的比較（表）；2. 各自適合怎樣的行程；3. 班次少要先排時間。表格放在比較句後面。
- **札幌到稚內的特急宗谷號**：1. 一天幾班、幾點開到；2. 要劃位與座席未指定券的差別；3. 從台灣怎麼劃位、怎麼領票。可以在這節或旭川那節加一句車上沒有販售，要先買好吃的（F201）。
- **旭川到稚內的特急Sarobetsu號**：1. 每天開的那班幾點到；2. 從札幌轉乘同價的條件；3. 只在指定日開的班次與觀光列車。
- **札幌到稚內的高速巴士稚內號**：1. 在大通上車、不在札幌車站（讀者最容易搞錯，放最前）；2. 全車預約、怎麼訂（網路先、電話後）；3. 票價與折扣票限制；4. 夜班停駛。競品沒寫這節，順序照讀者動作：在哪上車 → 怎麼訂 → 多少錢 → 什麼時候沒車。可補札幌發各班在稚內的下車地點（F202）。
- **搭飛機到稚內機場，怎麼進市區**：1. 從哪裡飛來、多久；2. 下機搭巴士多久到車站、渡輪站；3. 巴士配合班機的表。表要換成現在的冬季表（F198），夏季表當作明年參考或拿掉，交給作者判斷。
- **稚內機場巴士的車資與付款**：1. 多少錢、不用預約；2. 能用什麼付、不能用什麼；3. 沒零錢怎麼辦；4. 回程在哪買票。和競品順序一致。
- **班機取消或延誤時的機場巴士**：1. 取消停駛、延誤會等；2. 不等渡輪，趕船的備案；3. 中途上下車限制。可加巴士會等領完行李才開（F200）。
- **從稚內機場直接去宗谷岬與野寒布岬**：時間 → 期間限定 → 連到宗谷岬交通。
- **到了稚內車站，車站、巴士總站與渡輪站怎麼走**：照競品 D、E 的動線：出站就在 KITAcolor → 巴士總站與觀光案內所在同一樓 → 營業時間。
- **從稚內車站走到渡輪站**：走路幾分 → 計程車 → 機場巴士從車站搭不上。
- **在稚內車站寄行李**：先直接回答「沒有」→ 去哪寄 → 那裡還有什麼。
- **稚內租車與市內移動**：讀者動線是「機場取車 → 停車 → 不開車怎麼移動（市內線、觀光巴士、計程車）」，現在的順序已經是這樣。觀光巴士 2026 年度已結束，寫法要讓讀者知道是夏季才有。
- **稚內的路線巴士怎麼付錢**：能用什麼付 → 上車拿整理券 → 下車怎麼付 → 不找零、兌幣。
- **從稚內搭渡輪去利尻島、禮文島**：航程 → 報到時間 → 連到渡輪頁。
- **從稚內回札幌、旭川**：先 JR（班次少、直達只有一班）→ 綠色窗口與 IC 卡 → 巴士兩個發車地點（表）→ 從島上回來怎麼接。和開頭的順序對稱。
