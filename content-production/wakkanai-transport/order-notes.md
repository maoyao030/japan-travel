# 稚內交通 重寫的順序筆記（2026-11-01）

標題照線上版一字不改，只排每節裡的順序。依據是 `competitor-notes.md` 第6節。

- **開頭兩段**：三種方式各要多久 → 兩種陸路都要先訂位（JR全車指定席、巴士只收預約）→ 趕時間選JR、省錢選巴士（用F55、F56、F65、F66的差距撐）→ 下車後容易卡的事。照筆記「開頭兩段」把推薦給誰說得更直接。
- **札幌到稚內，JR 特急與高速巴士**：比較句 → 表 → JR直達只有一班、錯過還有旭川轉車。照筆記「時間與價格的比較 → 各自適合怎樣的行程 → 班次少要先排時間」。
- **札幌到稚內的特急宗谷號**：班次與時刻 → 要劃位與座席未指定券 → 車上沒有販售（新增F201）→ 從台灣怎麼劃位、領票。照筆記建議的位置加F201。
- **旭川到稚內的特急Sarobetsu號**：每天的班次 → 從札幌轉乘同價的條件 → 指定日班次與觀光列車。順序原本就和筆記一致。
- **札幌到稚內的高速巴士稚內號**：在大通上車、不在札幌車站 → 網路訂（日本巴士e路通、電子車票）→ 電話訂與窗口 → 票價與折扣票限制 → 在稚內的下車地點（新增F202）→ 夜班停駛。照筆記「在哪上車 → 怎麼訂 → 多少錢 → 什麼時候沒車」，票價從夜班之後移到訂位之後。
- **搭飛機到稚內機場，怎麼進市區**：從哪裡飛來 → 下機搭巴士多久 → 冬季巴士配合班機的表（夏季表F74、F194撤下，換成F198）→ 從羽田來的走法 → 2月以後去官網確認 → 機場服務台。照筆記第6節，夏季表拿掉，只留「夏天羽田多一班」一句。
- **稚內機場巴士的車資與付款**：車資、不用預約 → 能用與不能用（F70加感應支付）→ 沒零錢 → 回程在哪買票 → 冬季往機場的時刻（新增F199）。照筆記「多少錢 → 怎麼付 → 沒零錢 → 回程」。
- **班機取消或延誤時的機場巴士**：取消停駛、延誤會等 → 等領完行李才開（新增F200）→ 不等渡輪、計程車備案 → 中途上下車限制。照筆記。
- **從稚內機場直接去宗谷岬與野寒布岬**：時間 → 期間限定 → 連結句改寫。順序不變。
- **到了稚內車站，車站、巴士總站與渡輪站怎麼走**：出站就是KITAcolor → 巴士總站與觀光案內所 → 營業時間。照筆記競品D、E的動線。
- **從稚內車站走到渡輪站**：走路 → 帶行李搭計程車 → 機場巴士搭不上。照筆記。
- **在稚內車站寄行李**：先回答沒有 → 去哪寄 → 渡輪站還有什麼。照筆記。
- **稚內租車與市內移動**：機場取車 → 停車 → 不開車的市內線 → 定期觀光巴士（寫明2026年的期間、今年已結束）→ 計程車。照筆記「機場取車 → 停車 → 不開車怎麼移動」，觀光巴士改成季節資訊。
- **稚內的路線巴士怎麼付錢？**：能用什麼付 → 整理券 → 不找零與兌幣。照筆記。
- **從稚內搭渡輪去利尻島、禮文島**：航程 → 報到時間 → 連結句改寫。照筆記。
- **從稚內回札幌、旭川，JR 特急與高速巴士**：JR班次少 → IC卡與窗口 → 巴士兩個發車地點（表）→ 從島上回來怎麼接。順序原本就和筆記一致、和開頭對稱。
