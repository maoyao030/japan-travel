# 禮文島旅遊攻略，敦盛草、澄海岬、海膽與一日來回排法

禮文島北邊的澄海岬，從高台望下去，海灣彎成弧形，四周圍著斷崖，夏天的海水會隨著光線，變成藍綠色或翡翠色[F563][F427]。

禮文島在稚內西方大約60公里的日本海上，春天開水芭蕉，接著換禮文敦盛草（レブンアツモリソウ）、禮文金梅草、禮文薄雪草輪流登場，夏天去最好[F401][F445][F446][F443]。夏天只看精華的話，當天來回排得進去，要走8小時步道（8時間コース）、看清晨的雲海或慢慢賞花，就住一晚[F405][F38][F442][F32]。

## 北海道禮文島是什麼樣的地方？

禮文島南北長29公里，東西寬只有8公里，東西兩側的海岸長得很不一樣，東海岸是平緩的丘陵，西海岸冬天迎著強勁的西風，斷崖一路連綿[F401][F402]。夏天在島上走路是涼的，最熱的8月平均氣溫也只有19.7℃，風不小，又常起霧[F59][F489][F442]。

白天沿著步道走，5月下旬到6月中旬是禮文敦盛草的花期，6月下旬到8月換成沿著禮文林道成片開花的禮文薄雪草[F443][F471]。傍晚到元地海岸的地藏岩，夕陽沉進西邊的海面，這一帶就是以夕陽出名的[F74]。香深港旁的薄雪之湯（うすゆきの湯），泡在露天浴池裡就望得到利尻山[F435]。

## 禮文島有什麼好玩、好吃的？

### 禮文敦盛草｜只長在這座島上的花

禮文敦盛草的花是奶油色的，只長在禮文島[F309]。因為盜挖的威脅，成片生長的地方劃成保護區由環境省管理，只在花季開放，日期每年跟著開花狀況前後調整[F309][F441]。錯過保護區的花期也不用放棄，船泊的高山植物園有控溫，禮文敦盛草到8月初左右都看得到[F438]。

### 澄海岬｜夏天海水變成藍綠與翡翠色的禮文藍

澄海岬的海色有個名字，叫禮文藍（レブンブルー），夏天隨光線變成藍綠色或翡翠色[F73][F427]。位置在島的北部，路線巴士沒有停這裡，不開車的話，夏天搭觀光巴士最省事[F73][F313][F26]。

### 須古頓岬｜禮文島的最北端，晴天望得到庫頁島

須古頓岬（スコトン岬）是禮文島的最北端，天氣晴朗的時候，站在岬上還能遠望海對面的庫頁島（サハリン）[F39]。正前方大約1公里的海上是無人島海馬島（トド島），島上立著海馬島燈塔[F308][F428]。

### 桃岩展望台｜起霧的清晨，有機會看到腳下的雲海

桃岩展望台標高225公尺，起霧又微風的清晨，冷霧壓在200公尺以下的時候，從這裡有機會看到雲海[F442]。標高雖然不到300公尺，強風跟濃霧並不少見，記得帶件防風外套[F442][F36]。

### 久種湖｜日本最北的湖，天氣好的日子湖面倒映禮文岳

久種湖是日本最北的湖，春秋有候鳥飛來，天氣好的日子湖面會倒映禮文島最高點的禮文岳[F466][F459]。

### 北方金絲雀公園｜吉永小百合主演電影的外景校舍，裡面重現了電影的教室

北方金絲雀公園（北のカナリアパーク）裡的木造校舍，是吉永小百合主演的電影（北のカナリアたち）的外景地，校舍裡重現了電影中的教室，也展示劇照跟演員穿過的戲服[F310][F432][F431]。公園11月到隔年4月左右休館[F431]。

### 海膽｜夏天有海膽丼，還有放了海膽的拉麵

夏天的禮文島是吃海膽的季節，香深的老店爐端燒千鳥（炉ばた ちどり）在6月到8月有海膽丼，還有一碗放了海膽跟牡丹蝦的磯拉麵[F42][F450]。島上的海膽有北紫海膽跟蝦夷馬糞海膽兩種，北紫海膽的肉是淡黃色、味道清淡，蝦夷馬糞海膽是濃濃的橘色、偏甜，剝開後一眼就分得出來[F456]。

### 花魚鏘鏘燒｜香深老店的「元祖」，40年以上的招牌

香深的爐端燒千鳥把花魚鏘鏘燒當招牌，叫它元祖花魚鏘鏘燒（元祖ほっけのちゃんちゃん焼き），說已經有40年以上的歷史[F450]。鏘鏘燒是禮文島花魚最有名的吃法，有的抹味噌烤，有的在厚厚一片新鮮花魚上鋪蔥、淋醬汁再烤，島上的花魚油脂豐厚，直接烤就很好吃[F447][F75]。花魚最肥的季節是6月到8月，跟海膽正好是同一段時間，兩樣想一起吃就挑夏天去[F447][F450]。

## 禮文島幾月去最好？

6月中旬到8月初花的種類最多，這段時間去最好[F443]。想看禮文敦盛草的話要早一點，花期在5月下旬到6月中旬，6月下旬接著輪到禮文薄雪草[F443]。夏天也是吃海膽的季節，花魚在6月到8月最肥[F42][F447]。

| 月份 | 島上的狀況 |
|---|---|
| 4月到5月上旬 | 觀光案內所4月中旬重新開門，觀光巴士要到5月才開始跑[F115][F26] |
| 5月中旬 | 禮文敦盛草保護區開放，日期每年跟著開花狀況前後調整[F31][F441] |
| 5月下旬到6月中旬 | 禮文敦盛草的花期，5月的風是一年裡最強的[F443][F489] |
| 6月中旬到8月初 | 禮文薄雪草從6月下旬開花，6、7月是夏天最陰的兩個月[F443][F490] |
| 8月 | 一年裡最暖的月份，雨量也是全年最多的月份之一[F59][F488] |
| 9月 | 花少了，日照多，在意晴天的話好排，觀光巴士大約開到月底[F490][F26] |
| 10月 | 多數步道陸續冬季封閉，出發前先看[禮文島健行](/places/rebun-island/hiking/)的公告，觀光巴士停駛[F496][F26] |
| 11月到4月上旬 | 島上能做的事少很多[F496][F431] |

9月花少了，不過比起花更在意晴天的話，9月反而好排，因為日照多[F490]。島上的活動集中在5月底到8月，5月底到6月初有敦盛草感謝祭，7月是祭典月，8月有花火大會跟海峽祭[F41][F474][F497]。

11月到隔年4月前往不太適合，觀光案內所10月中旬就關了，往北端的巴士也很少[F115][F500]。

## 禮文島旅遊要排幾天，怎麼排？

從稚內搭渡輪直航香深港大約1小時55分，島上不開車的話靠宗谷巴士（宗谷バス）的3條路線巴士，5月到9月另有定期觀光巴士（定期観光バス），也有租車跟出租自行車的店[F5][F21][F26][F501]。日文不好也不用擔心，禮文島觀光協會有台灣籍工作人員寫的中文專頁，還經營中文臉書「禮文島觀光中文」[F494]。

### 禮文島一日來回可不可行？

可以，6月到9月最好排[F1][F2]。這段時間稚內到香深一天有3個來回，最早一班6:30出發，最晚一班17:10從香深開回稚內，錯過這班當天就回不了稚內[F1][F2]。坐2等艙要在開船前40分鐘辦好乘船手續，所以搭17:10的末班船，16:30前就要回到渡輪站，1等、特別室跟2等指定席是16:50前[F46][F2]。

稚內6:30的船 → 8:25到香深港 → 8:40搭觀光巴士禮文A線繞北端 → 12:30回到渡輪站 → 下午走桃岩展望台，從渡輪站走上去大約1小時 → 17:10的船回稚內[F1][F26][F407][F2]。

不搭觀光巴士、只走南部的話：稚內6:30的船 → 8:25到香深港 → 8:50從渡輪站走路出發 → 9:50到桃岩展望台，周邊散步1小時 → 11:50回到渡輪站 → 14:20或17:10的船回稚內[F405][F407]。

最容易卡住的是巴士。船8:25靠岸，巴士8:40就開，只隔15分鐘，宗谷巴士說有15分鐘以上就來得及，不過船上人多的話，最好早點下船[F1][F26][F306]。下午14:15才發車的禮文B線，16:40才回到渡輪站，已經超過2等艙的16:30，所以一日來回要選上午的A線[F27][F46][F81]。

### 看禮文敦盛草，當天來回或住一晚都排得出來

禮文敦盛草的保護區有兩處，一處在船泊一帶，一處在濱中往南的鐵府，從香深港開車大約30分鐘[F309][F209][F32]。當天來回也看得到，搭路線巴士到濱中，往南走大約20分鐘就到鐵府的保護區，看完再折返，記得先對好回程巴士跟末班船[F120][F209][F210][F4]。

稚內6:30的船 → 8:25到香深港 → 搭路線巴士到濱中 → 往南走約20分鐘到鐵府的保護區 → 折返回香深港[F1][F120][F210]。

觀光巴士禮文A線經過澄海岬跟須古頓岬，卻不經過保護區，搭A線看不到敦盛草[F26][F443]。兩處都想看又不想趕時間的話，5月下旬到6月中旬住一晚比較好排，住北邊的船泊離北部比較近[F443][F49]。

### 為了清晨的雲海或8小時步道，住一晚

要看雲海的桃岩展望台在南邊，從香深的渡輪站走上去大約1小時，住香深最近，而且渡輪最早8:25才到港，要看清晨的雲海就得前一晚住在島上[F113][F407][F49][F1][F442]。

8小時步道是禮文島最難的一條，要有跟登利尻山一樣的體力跟裝備，參考步行時間6小時50分，起點濱中在北部，要一路往南走，大半段收不到手機訊號，官方也提醒不要一個人走，所以最好前一晚就住在島上，住北邊的船泊離起點比較近[F102][F113][F38][F49]。清晨去起點的路線巴士班次，還有旅館有沒有接送，訂房時先問清楚。

雲海：住香深 → 清晨從渡輪站走約1小時到桃岩展望台[F113][F407]。8小時步道：住北邊的船泊 → 清晨到濱中 → 由北往南走到香深井[F38][F49]。

## 禮文島住哪一區？

第一次去、沒有租車的話，住南邊的香深最省事，渡輪站在這裡，旅館也比較多，隔天一早要搭船也方便[F49]。行程以北邊的岬角、步道跟賞花為主，傍晚還想看須古頓岬的夕陽，住北邊的船泊比較順[F49][F604]。

花季的房間要比船票先訂，房間很早就開賣，渡輪卻要到乘船日2個月前的同一天才開放預約[F602][F11]。島上有民宿說，每年最早滿的是禮文敦盛草開花的5月下旬到6月中旬、花的種類最多的6月到7月，還有日本的盂蘭盆節，9月就比較好訂[F603]。冬天有些旅館休館[F602]。

## 禮文島和利尻島怎麼一起排？

只能去一個島的話，想登利尻山就選利尻島，想看花、走海岸步道就選禮文島[F608][F403]。兩座島夏天都能從稚內當天來回，不過禮文島要走8小時步道、利尻島要登山，就都得住一晚[F405][F38][F608]。

兩座島都去的話，兩島之間有船，船程大約40到45分鐘，夏天一天3個來回，其中1個走利尻島西邊的沓形港[F605][F606][F607][F66]。住在利尻島的話，夏天早上從鴛泊搭9:30的船過來，10:15就到香深，傍晚再搭17:10從香深直接回稚內，觀光協會的一日遊行程也是這樣排的[F406][F2]。
