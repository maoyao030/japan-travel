## 各篇的順序

1. **Funliday 十大景點**
   - 開頭：島的位置與稱號 → 季節景色 → 吃什麼 → 預告文章內容。
   - 怎麼去（從稚內站走到渡輪站 → 買票 → 季節班次數）→ 十個景點（每個先一段介紹，再條列地址、營業時間）→ FAQ 五題（在哪、怎麼去、是不是最北、看什麼、幾月去）→ 推廣區塊。
   - 住幾晚、一日來回都只在 FAQ 或推廣段一句帶過。
2. **Funliday 交通懶人包**
   - 稚內渡輪站怎麼到 → 訂票與艙等 → 禮文島交通（先講港口與據點在香深，再比較租車、公車一日券、觀光巴士）→ 景點 → 利尻。
   - 一日來回寫成「船班和觀光巴士排好就可以」，沒有列時刻。
3. **nippon.com 專欄**
   - 開頭：最北的島與花之浮島 → 花期 → 海膽 → 邀讀者用走的認識島。
   - 唯一的小標是步道：先說為什麼要走 → 七條步道 → 桃岩路線細寫（花、怎麼去、看得到利尻山）→ 其他路線 → 長路線的距離與體力 → 最後一段住宿與資訊來源。
4. **JNTO 花卉導覽**
   - 先定義島與稱號 → 導覽團路線 → 出發時間與預約 → 交通（一步一步，從東京轉機到渡輪）。
5. **北海道觀光機構三天兩夜**
   - 路線概要 → 夏天氣溫與要帶外套（附穿著指南連結）→ 逐日逐站：交通時間 → 景點標語 → 介紹 → 地址、營業時間 → 小提示。
   - 利尻、禮文各住一晚。

## 開頭怎麼寫

- 五篇都先講「最北」和「花之浮島」這個身分，再講花期或海膽，最後才預告內容或邀讀者出發。沒有一篇在開頭回答「值不值得去、住幾晚」。
- 本站現在的開頭是：位置與大小、花之浮島 → 從稚內當天來回可行 → 一日來回能排什麼、什麼要住一晚。比競品多了「直接回答」，讀者熟悉的身分句也有，順序可以保留；第二段的時刻細節可以再少一點，留到下面的 H3。

## 關鍵問題怎麼回答

- **值不值得去**：競品沒有正面回答，都是用「最北」「花」「海膽」「海景」堆出吸引力。讀者熟悉的順序是「為什麼有名（花、地形）→ 適合什麼人 → 什麼時候不適合」。
- **幾月去**：Funliday 先給答案（夏天最好）、再說哪幾個月人少、最後說冬天別去（停航、封閉）。nippon.com 與 JNTO 只講花期。共同順序：「最佳月份 → 理由（花）→ 淡季的取捨」。都沒有用表格。
- **住幾晚**：Funliday 一句「建議 1～2 晚」，北海道觀光機構直接排一晚；都沒有依旅客類型分。本站的條列（只排一天、賞敦盛草、走長步道、冬天）是競品沒有的，保留。
- **一日來回**：競品只說「可以，船班和巴士要排好」，沒有列時刻、沒講末班船和報到時間。讀者會先想知道「可不可以」，接著「幾點去、幾點回」，最後「島上能看到哪裡」。
- **各月氣溫、夏天要不要外套**：只有北海道觀光機構寫，順序是「夏天平均約幾度 → 早晚涼 → 要帶外套」，先給數字、再給結論、最後給建議。沒有人列 12 個月的表。
- **活動日期**：五篇都沒寫。本站的活動表是獨有資料。

## 段落與句子的習慣

- Funliday 句子長、逗號多，常用「超級」「絕對」「推薦大家」與感嘆號；本站不學。
- nippon.com 與北海道觀光機構是編輯口吻：段落先下一句總結，再補兩三個具體細節；數字直接放句中，時間用「約」。
- 景點介紹的固定順序是「一句特色 → 怎麼去、多久 → 時間或注意事項」，實用資訊放段尾或另列。
- 稱呼讀者多用「你」「您」或不稱呼；轉場用「另外」「如果…」「不過」。條件句常放句首（「如果時間有限…」）。

## 給作者的順序建議

標題照現在的 `draft-tagged.md`，不改。

- **開頭（H1 下）**
  1. 先講島的身分（位置、花之浮島），一兩句就好。
  2. 接著直接回答：當天來回可行，什麼要住一晚。時刻留給下面的 H3。
- **北海道禮文島旅遊值得去嗎？**
  1. 先下結論：適合喜歡花與海岸步道的人。
  2. 再講為什麼（固有種、地形、沒有棕熊和蛇），最北端看庫頁島放在這裡。
  3. 最後講什麼時候不適合（11 月到 4 月），中文資訊管道與基本資訊欄放最後。
- **禮文島幾月去最好？**
  1. 先給最佳月份與理由（花最多）。
  2. 再講想看敦盛草要早一點、夏天的吃（海膽、花魚）。
  3. 最後講 9 月、10 月的取捨（花少、晴天多、步道陸續封閉）。不寫「10月1日」（F33 已更正）。
- **禮文島各月氣溫與降雨**
  1. 先一句最熱的月份也不熱的結論，接著表格。
  2. 平年值是什麼的說明放在表格前一句或後一句，不放第一句。
- **禮文島的霧與雲海**：先說常起霧、哪兩個月最陰，再轉到雲海去哪看、要住一晚。現在的順序可以。
- **禮文島夏天也要帶外套嗎？**
  1. 先答「要」，接一個最有感的數字（8 月日最高）。
  2. 再講風與天氣多變。
  3. 最後依月份給穿法（7、8 月薄外套；5、6 月加中層），熱的時候也有一句。
- **禮文島的祭典與活動日期**：先講活動集中在幾月、表格是哪一年，再放表；住宿連結句放在表後。各 H3 先講日期地點、再講怎麼跟行程配。
- **禮文島住幾晚？**
  1. 先給結論：只看南部加觀光巴士當天就夠，長步道、雲海、敦盛草住一晚。
  2. 再依旅客類型條列。
  3. 冬天的公車表放最後。
- **禮文島一日來回可不可行？**
  1. 先答「可行，6 到 9 月最好排」。
  2. 再給時刻表，最後講末班船、報到時間與 B 線接不上。停航一句帶過連渡輪頁。
- **禮文島一日遊行程範例**：照時間順序條列是讀者熟悉的寫法，保留；觀光巴士替代方案放在條列後。
- **禮文島和利尻島怎麼一起排？**：先講住利尻怎麼過來、怎麼回稚內，再講兩島船程與班次，最後連利尻頁。
- **禮文島的交通、住宿、步道、景點與美食**：每段先一句這件事的結論（島上怎麼移動、住哪一區），再一兩個細節，最後連過去。交通段可以加一句島上有租車、租自行車與計程車（F501），細節連交通頁。

## 他們有、我們缺的

- **租車、租自行車、計程車**：兩篇 Funliday 都把租車放在島上交通的第一個選項。已在觀光協會日歸行程 PDF 查到有租車、租自行車與機車、計程車（F501，存檔），本頁一句帶過即可，細節歸交通頁。
- **公車一日券**：Funliday 交通文有寫。屬交通頁，本頁不寫。
- **海豹（金田之岬）、澄海岬的海水顏色、高山植物園**：Funliday 十大景點都有。屬景點頁；禮文町導覽地圖 11 個景點沒有金田之岬，本頁不補。
- **花卉導覽團**：JNTO 整篇在講。屬健行或景點頁，本頁沒有事實，不寫。
- **競品之間互相矛盾的說法**（不採用，供作者避開）：Funliday 同一篇把最北端分別寫成金田之岬和須古頓岬；Funliday 寫有約 55 分鐘的高速船，Heartland Ferry 稚內～禮文時刻表只有約 1 小時 55 分的直航與經利尻的班次。
