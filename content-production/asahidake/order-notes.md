# 旭岳重寫的資訊順序（2026-11-01）

依 `competitor-notes.md`「給作者的順序建議」排，標題照線上版不改。事實只用 `reference-review.md`。

| 段落 | 用的順序 | 依據筆記的哪一點 |
|---|---|---|
| H1 底下開頭 | 最高峰與標高 → 不爬山搭纜車10分鐘上1,600公尺 → 當天來回、首班到與末班回 → 天人峽要開車放最後 | 開頭：讀者先確認「不登山也能去嗎」；首末班是競品沒有的，保留在第二段 |
| 旭岳是什麼樣的地方 | 姿見池一圈多長多久（含纜車頁連結句）→ 國立公園、活火山背景 → 沒有溫泉街、值得專程的判斷 | 先講讀者會做的事，背景其次，判斷放最後。第一段講到地獄谷白煙，噴氣孔照片接在後面 |
| 旭岳一日遊或住一晚 | 當天來回可以與巴士車程 → 什麼情況住一晚（早班纜車對照首班巴士、登頂）＋住宿連結句 → 開車車程一句＋交通連結句 | 競品都先說「當天來回可以」，開車放巴士後面一句帶過 |
| 幾月去旭岳 | 季節比平地早、散策路開放期 → 月份表（春到冬）→ 花與紅葉（影片接在這段後）→ 紅葉週末擁擠 → 初冠雪結冰與登山季＋登山連結句 | 先一句總結、表格、表後只補讀者會卡的。2026年11/16～12/10纜車停駛是短期資訊，拿掉表格那一列 |
| 旭岳的天氣與氣溫 | 山上比表冷、出門前看纜車官網即時天氣、強風可能停駛（F64）→ 測站說明與平年值表 → 9月早上就冷與穿著建議 | 讀者要的是怎麼穿、去不去，即時天氣放前，平年值放後；競品的「風大會停駛」一句帶過 |
| 冬天的旭岳滑雪、雪鞋與粉雪 | 粉雪 → 滑雪路線、票價、冬季營業 → 不滑雪的人搭纜車看雪與雪鞋路線 → 出租（雪鞋影片接在這段後）→ 離開路線的危險 → 冬季輪胎 | 不滑雪的人能做什麼緊接在滑雪路線之後；危險與輪胎放最後 |
| 到了旭岳溫泉 | 沒有ATM與收訊 → 遊客中心能做什麼、租借、付款 → 吃飯與便利商店 → 廁所 → 基本資訊表 | 沒有ATM放最前，到了才發現就來不及 |
| 旭岳溫泉日歸入浴 | 幾家、都中午以後 → 表格 → 選擇理由（最便宜但有休館期、要露天找K's House、Bear Monte只有露天三溫暖） | 表後只補選擇理由，用讀者需求起頭 |
| 不上山也能走的步道 | 什麼時候會想走（纜車停駛、等車）→ 路線表 → 推薦木道與路況 | 照筆記 |
| 天人峽與羽衣瀑布 | 柱狀節理與北海道落差最大（柱狀節理照片接在這段後）→ 怎麼去（沒公車、開車路線、不開車的辦法）→ 步道開放期、停車、走多久 → 觀瀑台 → 唯一的旅館與日歸 | 先讓讀者知道值不值得繞，旅館放最後；刪掉旅館18間客房的規格 |
| 不開車、從旭川當天來回 | 搭哪班去、哪班回 → 時刻表 → 車資、來回沒折扣要買兩張與售票機（F377）、IC卡、冬天 | 筆記的「誰 → 走哪條 → 要多久」與交通段順序 |
| 只想搭纜車看姿見池 | 搭哪班 → 纜車不用預約、15分鐘一班（F378）→ 走完接哪班回 | 先講搭哪班，再走完接哪班 |
| 要登頂旭岳 | 要一整天、上下山時間 → 入山手續 | 照筆記 |
| 接層雲峽或東川 | 要在旭川轉車 → 一組時刻 → 開車時間 → 跨地點頁連結句；東川經過時間 → 一組例子 → 東川町連結句 | 照筆記 |
