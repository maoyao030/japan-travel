## 各篇的順序

**雪嶼**
1. 開頭：作者自介一句 → 位置、標高、北海道最高峰 → 四季各一句 → 地圖連結
2. 纜車：它是上山的入口 → 幾分鐘、到哪個高度 → 各季看什麼 → 上去能走哪些路 → 最後才是票價
3. 步道：由易到難，每條固定講長度、路面、適合誰、看點；登頂放最後並先講時間與路況
4. 四季：季節當標題、月份放括號，每季一兩句
5. 溫泉：在哪 → 三種泡法情境 → 泉質（沒有日歸時間與價格）
6. 交通：先巴士（標成最推薦）→ 再開車，各附冬季提醒
7. 附近景點：只列名字
8. 結語

## 開頭怎麼寫

- 五篇裡四篇第一個資訊都是「北海道最高峰＋標高」，接著一句四季或纜車，再一句「從旭川出發」。差別在第三句：雪嶼接四季，LINE GO 直接預告交通與車資，部落客接「當天來回可以」。
- 沒有一篇在開頭就給班次時刻；時刻都放在交通段或排法段。
- 本站現在的開頭（最高峰與標高→纜車 10 分鐘不用爬山→當天來回、第一班與末班）跟讀者習慣的順序一致，第二段直接給首末班是競品沒有、但讀者想知道的，可以保留。

## 關鍵問題怎麼回答

1. **旭岳是什麼地方、值得去嗎**：先最高峰、活火山、國立公園，再講不用爬山搭纜車就能上 1,600 公尺，最後講四季各看什麼。「值不值得」都沒有正面判斷，只用「每個季節都值得」這類泛話。
2. **一日遊或住一晚**：部落客與 LINE GO 都是先說「當天來回可以」，再講巴士車程，最後才說「住旭岳溫泉比較從容」；理由大多只寫「從容」，沒有用首班車時間去對照早班纜車。LINE GO 用兩個並排的行程（一日、兩日）回答。
3. **幾月去**：都照季節順序（夏花→秋紅葉→冬雪），月份放在季節名後面的括號；紅葉都強調「日本最早」並給 9 月中下旬。沒人用表格；本站用月份表格是獨有的。
4. **冬天能做什麼**：雪嶼與 LINE GO 只講粉雪、滑雪，沒有雪鞋與租借；冬季交通都附在交通段末尾一句提醒（積雪、班次）。
5. **旭岳溫泉一帶有什麼**：溫泉只講泡湯情境，沒有日歸時間與價格；方格子是唯一提到遊客中心（租裝備）的，放在「下巴士後第一站」。ATM、吃飯沒有人寫。
6. **天人峽與羽衣瀑布**：五篇都沒寫（只有 Trip.com 一日遊商品把兩地排在一起）。
7. **依旅客類型怎麼排**：雪嶼依對象分（家庭走姿見池、登山者攻頂、攝影、滑雪）；LINE GO 依天數分。順序都是「誰 → 走哪條 → 要多久」。
8. **天氣與氣溫**：沒有獨立一節；散在纜車段與建議段，固定講法是「山上變化快 → 會停駛 → 帶保暖衣物」。沒有人給氣溫數字。

## 段落與句子的習慣

- 句子短，常用條列與小標切換，很少用連接詞；一段兩到三句。
- 稱呼讀者用「你」，提醒句用「建議」「記得」；部落客用「我們」講自己經驗（本站不學這點）。
- 數字直接嵌在句子裡（約 10 分鐘、1.7 公里），時間範圍用連字號；票價都附「依季節不同」。
- 轉場靠小標，不靠「接下來」這類句子。
- 交通段固定順序：怎麼去（巴士）→ 多久 → 多少錢 → 怎麼買票 → 下車接什麼。

## 給作者的順序建議

標題照現在的 `draft-tagged.md`，不改；以下只講每節裡先講什麼。

**H1 底下的開頭**
1. 最高峰、標高、搭纜車不用爬山就上 1,600 公尺（讀者第一個想確認的是「我不登山也能去嗎」）。
2. 從旭川當天來回可以 → 首班到、末班回。
3. 天人峽要開車一句可以留在開頭，但放最後。

**旭岳是什麼樣的地方**
1. 大多數人去的是纜車上方的姿見池一帶，一圈多長、多久（先講讀者會做的事）。
2. 再講國立公園、活火山這些背景。
3. 山腳溫泉沒有溫泉街、值不值得專程，放最後當判斷。

**旭岳一日遊或住一晚**
1. 先回答「當天來回可以」與巴士車程（競品都這樣起頭）。
2. 再講什麼情況要住一晚：想趕早班纜車（用首班巴士時間對照）、要登頂。
3. 開車的車程放在巴士後面，一句帶過。

**幾月去旭岳，紅葉、花季與雪季**
1. 先給一句總結：季節比平地早、姿見一帶大半年有雪、散策路開放幾月到幾月。
2. 月份表格（讀者習慣季節順序：春→夏花→秋紅葉→冬雪）。
3. 表格後只補讀者會卡的：紅葉每年前後差很多、紅葉週末擁擠、初冠雪後結冰。

**旭岳的天氣與氣溫**
1. 先講「山上比表上冷」與出門前看哪裡的即時天氣（讀者要的是怎麼穿、要不要去）。
2. 平年值表格放後面，表前一句說是山下測站。
3. 穿著建議跟在冷的事實後面。

**冬天的旭岳滑雪、雪鞋與粉雪**
1. 粉雪有名一句。
2. 不滑雪的人能做什麼（搭纜車看雪、雪鞋、租借）—競品都沒寫，讀者卻常是這種人；可以放在滑雪路線細節前面或緊接其後。
3. 滑雪路線、開放期間、纜車冬季營業日。
4. 離開滑雪路線的危險、開車冬季輪胎放最後。

**到了旭岳溫泉，遊客中心與周邊設施**
1. 先講沒有 ATM、要先帶現金（讀者到了才發現就來不及）。
2. 遊客中心能做什麼（看當天狀況、租用品）。
3. 吃飯與便利商店。
4. 廁所、基本資訊表放最後。

**旭岳溫泉日歸入浴**
1. 先講有幾家、都是中午以後才開。
2. 表格（時間、價格、下車站）。
3. 表後只補選擇的理由（最便宜但有休館期、露天浴池有沒有）。

**不上山也能走的旭岳溫泉步道**
1. 什麼時候會想走（纜車停駛、等回程巴士）。
2. 路線表。
3. 推薦哪條與路況注意。

**旭岳順路去天人峽與羽衣瀑布**
1. 天人峽是什麼、羽衣瀑布多高（競品沒寫，讀者先要知道值不值得繞）。
2. 怎麼去：沒有公車 → 開車路線 → 不開車的辦法。
3. 步道開放期間與停車 → 走多久 → 觀瀑台。
4. 唯一的旅館與日歸放最後。

**旭岳的排法，依旅客類型**（照競品「誰 → 走哪條 → 要多久」）
- 不開車當天來回：先講搭哪班去、搭哪班回 → 時刻表 → 車資與 IC 卡、來回要買兩張（F377）。
- 只看姿見池：先講搭哪班 → 走完接哪班回。
- 登頂：先講要一整天、上下山時間 → 入山手續。
- 接層雲峽或東川：先講要不要轉車 → 舉一組時刻 → 開車時間。

## 他們有、我們缺的

- **巴士來回沒有折扣、車票去哪買**（LINE GO、方格子都寫）：已回旭川電氣軌道官網查到，加為 F377。
- **纜車多久一班**（LINE GO、搜尋摘要都寫）：已回纜車官網查到，加為 F378（夏 15 分、10/21 起 20 分、不用預約）；本頁只摘要，細節歸纜車頁。
- **建議停留多久**（LINE GO 有一欄）：本站已有姿見池一圈 1 小時到 1 小時半與登頂時間，不用另補。
- **風大纜車會停駛**（方格子親身經歷、多篇提醒）：事實表已有 F64（強風、有落雷危險時纜車可能暫停）；本頁天氣一節可一句帶過，細節歸纜車頁。
- **從札幌出發**（LINE GO、Tabirai、各家一日遊商品）：大綱沒有這一項，出入口交通歸 `asahidake-transport`，不補。
