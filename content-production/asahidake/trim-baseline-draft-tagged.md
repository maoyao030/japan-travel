# 旭岳旅遊，一日遊或住一晚、幾月去與順路的天人峽

旭岳是北海道最高峰，標高2,291公尺，也是大雪山的主峰，列在日本百名山之中[F1, F2]。山腳的旭岳溫泉在標高約1,100公尺，搭纜車約10分鐘就上到標高約1,600公尺的姿見站，不必登山也能走進高山的景色[F3, F49]。

旭岳一日遊從旭川出發排得進去，旭川站前的いで湯號一天4個來回，最早9:03到、最晚16:55從旭岳回程[F24, F25, F26]。想搭夏天清晨的首班纜車或登上山頂，就住一晚[F300, F86]。不開車想去天人峽，住天人峽唯一的旅館才有巴士站接送[F142, F317]。

## 旭岳是什麼樣的地方

旭岳一帶屬於大雪山國立公園，面積約23萬公頃，是日本最大的國立公園[F6]。旭岳也是氣象廳列管的活火山[F8]。

多數人造訪的是纜車上方的姿見の池一帶。從姿見站出發的散策路一圈約1.7公里、走約1小時，沿路看得到冒著白煙的地獄谷、舊火口形成的姿見の池與夫婦池[F72, F75]。纜車時間、票價與姿見の池散策路，見旭岳纜車與姿見の池。

山腳的旭岳溫泉沒有溫泉街，旅館有高度限制、彼此隔著距離，散在樹林裡，每間都有溫泉[F5, F313]。想逛老街、吃小吃的旅客會覺得冷清，想看高山花草、紅葉與雪景的話，旭岳值得專程跑一趟[F79, F106, F110]。

## 旭岳一日遊或住一晚

不開車也能當天來回，從旭川站搭いで湯號1小時48分到旭岳，回程1小時38分，中途停旭川機場[F25, F27]。開車的話，旭川機場約60分鐘、JR旭川站約1小時10分[F38]。

住一晚的理由要看想做什麼。2026年7月到9月纜車6:00或6:30就開，但第一班いで湯號9:03才到，想搭早班纜車，前一晚就要住在旭岳溫泉[F300, F25]。登頂來回的路線時間約4小時55分，再加上搭纜車，住一晚、早上出發比較有餘裕[F86, F49]。旭岳溫泉約有9間住宿，天人峽溫泉目前只有1間[F125]。

いで湯號時刻與開車路況，見旭岳交通。旭岳溫泉與天人峽溫泉的旅館，見旭岳溫泉住宿。

## 幾月去旭岳，紅葉、花季與雪季

旭岳的季節比平地早很多，姿見の池一帶從9月下旬到隔年6月，一年有三分之二被雪蓋住[F74]。

| 時期 | 姿見の池與旭岳溫泉 |
|---|---|
| 5月下旬 | 山麓濕地開出水芭蕉，姿見一帶的散策路還在雪中 [F109, F304] |
| 6月上旬～8月中旬 | 高山植物開花，7月最盛 [F79, F309] |
| 6月第3個週六 | 旭岳開山，登山季開始 [F321, F92] |
| 9月中旬～下旬 | 姿見一帶紅葉最好看，之後每天往下移到旭岳溫泉 [F106, F107] |
| 10月初 | 天人峽的柱狀節理與紅葉 [F157] |
| 11月16日～12月10日 | 2026年纜車檢修停駛 [F59] |
| 12月～5月 | 旭岳滑雪路線開放 [F112] |

夏天看花，7月下旬是高山植物的高峰，黃花石楠（キバナシャクナゲ）與チングルマ會成片開[F80, F79]。紅葉的主角是七竈的紅與岳樺的黃，旭岳以日本最早的紅葉聞名，但每年前後差很多[F108, F106, F107]。2026年9月17日紅葉在姿見一帶正好看，到9月30日已經下到山麓[F310]。

紅葉季9月中旬的週末假日，纜車非常擁擠，停車場也會客滿排隊[F66, F42]。紅葉季想避開人潮，排平日最好[F66]。

紅葉季也是天氣轉冷的時候。2026年10月2日旭岳初冠雪，當天姿見站早上-1℃，散策路有的地方結冰[F78]。登山季從6月第3個週末開山到9月下旬初冠雪為止[F92]。登頂的時間與入山規則，見旭岳登山。

### 旭岳的天氣與氣溫

旭岳一帶沒有氣象廳的氣溫觀測點，最近有平年值的是山下東川町的志比内，標高310公尺[F117]。表中是志比内1993年到2020年的平年值，不是預報[F118]。

| 2月 | -7.5℃ [F118] |
| 5月 | 11.0℃ [F120] |
| 6月 | 15.5℃ [F120] |
| 7月 | 19.6℃ [F119] |

旭岳溫泉比志比内高約800公尺，姿見站高約1,300公尺，山上會比表上的數字冷不少[R9]。2026年9月17日的早上，旭岳溫泉只有9℃[F359]。纜車官方建議穿登山鞋或鞋底厚的鞋，帶雨衣或擋得住風雨的長袖外套[F76]。

當天的狀況可以看纜車官網首頁，上面有姿見站的天氣、氣溫、風速與能見度[F69]。東川町網站的旭岳山頂攝影機每小時更新一張照片，出發前看一眼山上有沒有雲[F307]。

## 冬天的旭岳滑雪與粉雪

冬天的旭岳是國內數一數二的豪雪地，雪輕到被稱作「Silky Snow」，纜車官網說是日本最高級的粉雪[F111, F110]。天氣條件對的時候，還看得到鑽石塵與日柱[F110]。

旭岳滑雪路線從纜車姿見站往山麓站滑，有A、B、C、D四條，12月到5月開放，觀光協會說是日本開放期最長的[F361, F112]。這裡被稱為上級者山岳滑雪的聖地，適合有野外滑雪經驗的人[F112]。2025年冬季纜車在12月11日恢復，壓雪路線同一天開放，只開B、C兩條[F305]。2026年的月曆也是12月11日起營業，時間9:00到15:40[F300]。

離開滑雪路線就是野外的雪山。遊客中心的冬季地圖標出往北走會回不來、大広間一帶容易雪崩、從山頂往南下容易迷路，路線外要帶雪崩信標、雪鏟與探測桿[F361]。

不滑雪也有雪地活動。旭岳溫泉有三條越野滑雪與雪鞋路線，分別是7.5公里、2.5公里與3.0公里，11月到5月可以用[F360, F114]。遊客中心在積雪期出租雪鞋，一天含稅1,000日圓，附登山杖，越野滑雪的板、杖、鞋一組也是1,000日圓[F362]。租的時候要出示有照片的證件[F362]。雪橇、雪球夾這類雪地玩具一件500日圓，兩件以上1,000日圓[F362]。

冬天開車上山，觀光協會說道路除雪確實，除非天候惡劣，開到旭岳溫泉沒有問題[F44]。拉比斯塔大雪山提醒每年約10月中旬到4月上旬要裝冬季輪胎或帶雪鏈[F45]。

## 到了旭岳溫泉，遊客中心與周邊設施

旭岳溫泉一帶沒有銀行、郵局與ATM，最近的ATM開車要30到40分鐘，現金在旭川就準備好[F9]。手機在遊客中心與纜車站附近收得到，往旭岳的路上與山區有收不到的地方[F12]。

旭岳遊客中心離纜車山麓站約100公尺，免費入館，館內有天氣、登山道與自然的資訊，也有免費Wi-Fi、休息區與自動販賣機[F17, F16]。進門左手邊的看板公告纜車運行狀況與登山道資訊，上山前值得進去看一下[F18]。館內收信用卡、電子錢包、Suica與Kitaca這類交通IC卡與QR碼支付[F19]。出租雨鞋一雙500日圓，也有給姿見散策用的500日圓登山杖，都是含稅價[F21]。

吃飯的選擇很少。纜車山麓站2樓有「姿見食堂」，1樓有賣店，夏天最受歡迎的是用東川產蔬菜做的咖哩[F10, F355, F70]。上到姿見站，賣的是東川產馬鈴薯與旭川笹豚做的手工可樂餅、用旭岳源水沖的有機咖啡[F70]。拉比斯塔大雪山1樓的「Yショップ」是2025年10月31日開幕的旭岳第一家便利商店，不住宿也能進去買[F319]。Hotel Bear Monte在2026年10月20日公告延長午餐營業，12:00到15:00，14:00最後點餐[F354]。

廁所在遊客中心、纜車山麓站與姿見站，另外旭岳青少年野營場的廁所全年24小時開放[F14]。

## 旭岳順路去天人峽與羽衣の滝

天人峽在大雪山國立公園東南麓、忠別川上游，約3萬年前大噴發留下的柱狀節理是這裡的象徵，岩壁有「淚岩」「七福岩」這類名字[F148]。峽谷深處的羽衣の滝落差270公尺，是北海道落差最大的瀑布，分7段流下[F149]。10月初柱狀節理配上紅葉，是攝影的人最喜歡的時候[F157]。

天人峽沒有公共交通，いで湯號也不開到天人峽，要開車或搭計程車[F142, F316]。從東川往旭岳的道道1160號線過了忠別湖，左轉是旭岳，右轉就是天人峽，之後一條路到底，冬天也有除雪[F159]。

羽衣の滝的遊步道冬季封閉，2026年開放到10月30日，降雪時可能提早關[F151]。天人峽公共停車場目前改修中，要停羽衣の滝側或忠別湖側的替代停車場，這是2026年10月27日查核的狀況[F154]。羽衣の滝側滿了，就停約600公尺前、走路約8分鐘的忠別湖側[F154]。公共停車場走到瀑布約20分鐘，步道有路面不清與泥濘的地方，瀑布前走約2分鐘有廁所[F152]。

想看瀑布全景，可以爬到「滝見台」。登山口在公共停車場對面，看板寫著「軽登山コース」「トムラウシ登山道入口」[F156]。爬過33個急彎的「三十三曲」上到標高850公尺的台地，再走約15分鐘就到，晴天能同時看到瀑布與旭岳[F156]。這條路2026年整修得很好走，但雨後落葉多會滑[F353]。

天人峽溫泉唯一的旅館御宿しきしま莊（御やど しきしま荘）全館18室，走到羽衣の滝15分鐘左右[F139]。日歸入浴12:00到15:00，14:00停止受理，大人1,000日圓[F124]。住宿的話，旅館可以到いで湯號的「旭岳源水公園前」站接送，要事先聯絡[F317]。

## 旭岳的排法，依旅客類型

いで湯號一天只有4個來回，不開車的行程都要配合時刻表排[F24]。

### 不開車、從旭川當天來回

いで湯號由旭川電氣軌道經營，每天行駛，全年用同一份時刻表[F23, F25]。

去程（旭川往旭岳）

| 旭川站發 | 旭川機場發 | 到旭岳 |
|---|---|---|
| 7:15 | 8:00 | 9:03 [F25] |
| 9:15 | 10:00 | 11:03 [F25] |
| 12:15 | 13:00 | 14:03 [F25] |
| 14:15 | 15:00 | 16:03 [F25] |

回程（旭岳往旭川）

| 旭岳發 | 到旭川機場 | 到旭川站 |
|---|---|---|
| 9:55 | 10:50 | 11:33 [F26] |
| 11:55 | 12:50 | 13:33 [F26] |
| 14:55 | 15:50 | 16:33 [F26] |
| 16:55 | 17:50 | 18:33 [F26] |

想在山上待一整天，搭7:15從旭川站出發的車，回程搭14:55，或16:55的末班車[R1]。搭9:15那班去，一樣可以待到末班車[R1]。旭川站到旭岳大人單程2,300日圓[F30]。這條路線只能用Asaca與DoCARD兩種IC卡，Suica、Kitaca不能用[F314]。冬天也排得進當天來回，2026年12月11日起纜車營業到15:40，末班巴士16:55才開[R3]。

### 只想搭纜車看姿見の池

散策路開放的6月到10月中旬，搭9:03到旭岳的車上山最順，纜車單程約10分鐘，散策路一圈1小時到1小時半[F72, F49, F308]。走完下山，可以搭11:55的車回旭川，想多看一會或加泡湯，就搭14:55或16:55的車[R4]。

降雪之後散策路會結冰或被雪蓋住，遊客中心建議只在站前一帶走走[F78]。

### 要登頂旭岳

從姿見站登頂，上山2小時50分、下山2小時5分，在大雪山的路線分級是等級3[F86]。入山前要向北海道警察提交登山計畫書，並在纜車站或登山口填入林屆[F94]。這種行程建議住旭岳溫泉，早上搭第一班纜車出發[F300, F86]。

### 接層雲峽或東川

從旭岳到層雲峽搭巴士，要在旭川站前轉道北巴士，例如旭岳11:55發車，13:33到旭川站，再接14:25的車，16:24到層雲峽[R6]。開車兩地約2小時30分[F38]。接層雲峽或縱走到黑岳，見旭岳與層雲峽怎麼選。

東川町在旭川與旭岳之間，いで湯號經過道之驛「道草館」的時間是8:12、10:12、13:12、15:12[F28]。例如7:15從旭川站上車，8:12在道草館下車，逛完再搭10:12那班，11:03到旭岳[R7]。往旭岳路上順路停的東川，見東川町。
