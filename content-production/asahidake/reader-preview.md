# 旭岳旅遊，一日遊或住一晚、幾月去與順路的天人峽

旭岳標高2,291公尺，是北海道的最高峰，也是大雪山的主峰，列在日本百名山裡面。就算不爬山也上得去，從山腳標高大約1,100公尺的旭岳溫泉搭纜車大約10分鐘，就可以到標高約1,600公尺的姿見站。

從旭川出發的話可以當天來回。旭川站前發車的出湯號（いで湯號）一天有4個來回，最早一班9:03到旭岳，末班16:55從旭岳開回旭川。不過順路的天人峽沒有公車，如果要過去就需要開車或搭計程車。

## 旭岳是什麼樣的地方？

大多數人去的是纜車上方的姿見池（姿見の池）一帶。從姿見站出發的散策路一圈大約1.7公里，走1小時到1小時半左右，沿路會經過冒著白煙的地獄谷與姿見池。如果要排上山的時間、比較季節票價，或是想知道這一圈怎麼走，可以看旭岳纜車與姿見池，那一頁整理了營業時間、班距與散策路的走法。

這一帶屬於大雪山國立公園，面積大約23萬公頃，是日本最大的國立公園。旭岳本身也是活火山，目前由氣象廳在監測。

山腳的旭岳溫泉沒有所謂的溫泉街。旅館為了保護景觀不能蓋高，一間間隔開來散在樹林裡，不過每間都有溫泉。旭岳的看頭主要在山上，就算不爬山也能搭纜車到1,600公尺，夏天看高山植物、秋天看日本最早的紅葉、冬天看雪景。喜歡山景的人蠻值得專程去一趟。

## 旭岳一日遊或住一晚

沒有車也可以當天來回。出湯號從旭川站到旭岳需要1小時48分，回程1小時38分，中途都會停旭川機場。

如果想搭早班纜車或是要登頂的話，就比較值得住一晚。2026年7月到9月纜車最早6:00就開了，不過第一班出湯號卻要9:03才到，所以搭巴士的人只有前一晚住進旭岳溫泉才趕得上。登頂來回的路線時間大約4小時55分，再加上搭纜車的時間，早上從山腳出發會比較有餘裕。纜車山麓站沿著道路大約1公里內有7間住宿。決定要住下之後，可以看旭岳溫泉住宿，那裡比較了旭岳溫泉與天人峽溫泉各家旅館的位置、營業期間與訂房管道。

開車從旭川機場大約60分鐘，從JR旭川站大約1小時10分。如果要從機場直接上山，或是打算自己開車的人，可以讀旭岳交通，裡面有出湯號全部的班次與冬天的路況。

## 幾月去旭岳，紅葉、花季與雪季

旭岳的季節比平地早很多，姿見池一帶一年有三分之二的時間都積著雪。散策路的開放期間是6月到10月中旬，不過開放初期與9月下旬以後路上可能還有雪或結冰。如果遇到降雪，遊客中心會建議只在姿見站前一帶走走就好。

| 時期 | 姿見池與旭岳溫泉 |
|---|---|
| 5月下旬 | 山麓濕地開出水芭蕉，姿見一帶的散策路還在雪中 |
| 6月上旬～8月中旬 | 高山植物開花，7月下旬最盛 |
| 6月第3個週六 | 旭岳開山，登山季開始 |
| 9月中旬～下旬 | 姿見一帶紅葉最好看，之後每天往下移到旭岳溫泉 |
| 10月初 | 天人峽的柱狀節理與紅葉 |
| 12月～5月 | 旭岳滑雪路線開放 |

高山植物在7月下旬最盛，黃花石楠（キバナシャクナゲ）與稚兒車（チングルマ）會成片開出來。旭岳以日本最早的紅葉聞名，紅的是七竈、黃的是岳樺，只是每年時間前後差很多。2026年是9月17日姿見一帶正好看，到9月30日就已經紅到山麓了。

9月中旬紅葉季的週末假日，纜車會非常擁擠，停車場也可能滿到要排隊。如果可以排在平日去是最好的。

2026年10月2日旭岳初冠雪，那天早上姿見站-1℃，散策路有些地方已經結冰了。往年的登山季，從6月第3個週末開山到9月下旬初冠雪前後為止。如果打算在這段期間登上山頂的話，出發前記得讀一下旭岳登山，那裡寫了登頂路線要走多久與入山前的手續。

### 旭岳的天氣與氣溫

旭岳溫泉比下表的志比內高大約800公尺，姿見站高大約1,300公尺，所以山上會比表上的數字冷，冬天更是冷很多。出門前可以看看纜車官網首頁，上面有姿見站當下的天氣、氣溫、風速與能見度，冬天上山前尤其要確認一下。如果遇到強風或有落雷危險，纜車可能會暫停。東川的旭岳山頂攝影機照片每小時更新一次。

## 冬天的旭岳滑雪、雪鞋與粉雪

旭岳的雪量在日本數一數二，雪輕到被叫做「Silky Snow」，這裡的粉雪也被稱為日本最高級的。如果條件對的日子，還有機會看到鑽石塵與日柱。

滑雪路線從纜車姿見站滑到山麓站，共有A、B、C、D四條，12月到5月開放，開放期間據稱是全日本最長的。這裡被稱為給滑雪高手的山岳滑雪聖地。滑雪是搭纜車上姿見站再滑下來，11月1日到5月31日大人單程1,700日圓、來回2,800日圓，都是含稅價。2026年冬季的纜車營業時間是9:00到15:40，從12月11日開始。2025年冬天也是12月11日開始營業，壓雪路線同一天開放，不過只開了B跟C兩條。

不滑雪也能搭纜車上姿見站，晴天從站前一帶看雪景就很值得，大人來回2,800日圓。旭岳溫泉還有7.5公里、2.5公里與3.0公里三條越野滑雪與雪鞋路線，起終點在湯之沼（湯の沼）一帶，11月到5月都可以走。

積雪期遊客中心有出租雪鞋，一天含稅1,000日圓，會附登山杖，越野滑雪的板、杖、鞋一組也是1,000日圓。雪橇、雪球夾這類雪地玩具一件500日圓，兩件以上1,000日圓。租借時要出示有照片的證件。如果是第一次走雪鞋，可以在租借時問遊客中心當天適合走哪條。

離開滑雪路線就是野外的雪山了。遊客中心的冬季地圖標了三個危險處：往北走會回不來、大廣間一帶容易雪崩、從山頂往南下容易迷路。如果要離開滑雪路線，記得帶雪崩信標、雪鏟與探測桿。

冬天的道路除雪做得確實，只要不是碰到惡劣天候，開車到旭岳溫泉是沒有問題的。每年大約10月中旬到4月上旬需要裝冬季輪胎或帶雪鏈。

## 到了旭岳溫泉，遊客中心與周邊設施

旭岳溫泉一帶沒有銀行、郵局跟ATM，最近的ATM開車要30到40分鐘，所以現金最好在旭川就準備好。手機在遊客中心與纜車站附近有訊號，不過往旭岳的路上與山裡有些地方會收不到。

旭岳遊客中心有天氣、登山道與自然的資訊，也有免費Wi-Fi、休息區與自動販賣機。進門左手邊的看板貼著纜車運行狀況與登山道資訊，上山前可以先進去看一眼。雨鞋一雙、姿見散策用的登山杖一支，租金都是含稅500日圓。館內收信用卡、電子錢包、Suica與Kitaca這類交通IC卡跟QR碼支付。

纜車山麓站1樓是商店，2樓是「姿見食堂」，食堂夏天最受歡迎的是用東川產蔬菜做的咖哩。到了姿見站，那邊還有手工可樂餅與有機咖啡。La Vista大雪山（ラビスタ大雪山）1樓有2025年10月31日開幕的便利商店Y Shop（Yショップ），就算沒住宿一樣能進去買。如果搭出湯號要到La Vista，在旭岳露營場（旭岳キャンプ場）站下車就好。Hotel Bear Monte在2026年秋天的午餐時間是12:00到15:00，14:00最後點餐。

廁所在遊客中心、纜車山麓站與姿見站都有，旭岳青少年野營場的廁所則是全年24小時開放的。

## 旭岳順路去天人峽與羽衣瀑布

天人峽在大雪山國立公園東南麓的忠別川上游，招牌是大約3萬年前大噴發留下的柱狀節理。峽谷深處的羽衣瀑布（羽衣の滝）是北海道落差最大的瀑布。

天人峽沒有大眾運輸，出湯號也不到，所以從旭岳過去需要開車或搭計程車。開車沿北海道道1160號線從東川往旭岳方向，過了忠別湖左轉是旭岳、右轉是天人峽，之後一條路到底，冬天也有除雪。天人峽的旅館寫的車程是旭川站大約60分鐘、旭川機場大約40分鐘。如果是搭大眾運輸的人，可以從旭川搭計程車，或是住天人峽的旅館，請旅館到出湯號的「旭岳源水公園前」站接送，不過要事先聯絡才行。

羽衣瀑布的遊步道冬季封閉，2026年的開放期間是6月6日到10月30日，遇到降雪可能提早關。天人峽公共停車場正在整修，2026年10月27日查核時需要停在羽衣瀑布側或忠別湖側的替代停車場。如果羽衣瀑布側停滿了，就要停在大約600公尺外、走路大約8分鐘的忠別湖側。從公共停車場一帶走到瀑布大約20分鐘，停忠別湖側要再多走大約8分鐘。有些路段路徑不明顯、也會泥濘，瀑布前走大約2分鐘有廁所。

如果想看瀑布全景，需要爬上觀瀑台（滝見台），登山口在公共停車場對面，看板寫著「軽登山コース」「トムラウシ登山道入口」。爬過33個急彎的「三十三曲」上到標高850公尺的台地，再走大約15分鐘就到了，晴天的時候能同時看到瀑布與旭岳。這條路2026年整修過，很好走，只是雨後落葉多的時候會比較滑。

如果想住在瀑布旁邊，天人峽溫泉唯一的旅館是御宿敷島莊（御やど しきしま荘），走到羽衣瀑布大約15分鐘左右。不住宿也能泡湯，日歸入浴12:00到15:00，14:00截止，大人1,000日圓。

## 旭岳的排法，依旅客類型

以下四種排法都是從旭川出發，差別在開不開車、想在山上做什麼。

### 不開車、從旭川當天來回

如果想在山上待一整天，搭7:15從旭川站出發的車，回程搭14:55或16:55的末班車。搭9:15那班去，同樣可以待到末班車。出湯號由旭川電氣軌道經營，每天行駛，全年用同一份時刻表。

去程（旭川往旭岳）

| 旭川站發 | 旭川機場發 | 到旭岳 |
|---|---|---|
| 7:15 | 8:00 | 9:03 |
| 9:15 | 10:00 | 11:03 |
| 12:15 | 13:00 | 14:03 |
| 14:15 | 15:00 | 16:03 |

回程（旭岳往旭川）

| 旭岳發 | 到旭川機場 | 到旭川站 |
|---|---|---|
| 9:55 | 10:50 | 11:33 |
| 11:55 | 12:50 | 13:33 |
| 14:55 | 15:50 | 16:33 |
| 16:55 | 17:50 | 18:33 |

旭川站到旭岳大人單程2,300日圓。來回沒有折扣，去回要各買一張單程票，車票可以在旭川電氣軌道總合案內所或旭川機場的售票機預先買好。這條路線的IC卡只能用Asaca與DoCARD，Suica跟Kitaca不能用，所以記得準備現金。冬天一樣能當天來回，2026年12月11日起纜車營業到15:40，末班巴士16:55才開，所以時間上是來得及的。

### 只想搭纜車看姿見池

散策路開放的6月到10月中旬，搭9:03到旭岳的車最順。纜車不用預約，6月1日到10月20日每15分鐘一班。走完一圈下山之後，接11:55的車回旭川就好。如果要多留一會或加個泡湯，回程可以改搭14:55或16:55。

### 要登頂旭岳

從姿見站登頂，上山2小時50分、下山2小時5分，是一整天的登山行程。入山前需要向北海道警察提交登山計畫書，並且在纜車站或登山口的入林屆簿登記入山。

### 接層雲峽或東川

從旭岳搭巴士到層雲峽，需要在旭川站前轉道北巴士。例如搭旭岳11:55的車到旭川站，再接14:25的車，16:24就到層雲峽了。開車的話兩地大約2小時30分。如果還想從旭岳縱走到黑岳、在層雲峽住下，可以看旭岳與層雲峽怎麼選，那裡比較了兩地的看點，也寫了縱走的走法。

東川在旭川與旭岳之間，出湯號經過東川道草館（ひがしかわ道草館）的時間是8:12、10:12、13:12、15:12。例如7:15從旭川站上車，8:12在道草館下車，逛完再搭10:12那班，11:03就到旭岳了。在道草館下車之後如果想多逛一點，可以看東川町那一頁，裡面整理了町裡順路能去的地方。
