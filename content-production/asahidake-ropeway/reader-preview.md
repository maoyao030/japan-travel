# 旭岳纜車與姿見池，營業時間、票價與散策路怎麼走

大雪山旭岳纜車（大雪山旭岳ロープウェイ）從海拔大約1,100公尺的山麓站出發，10分鐘左右就能上到1,600公尺的姿見站。姿見池（姿見の池）散策路從姿見站出發，繞一圈大約1.7公里、走大約1小時，每年6月到10月中旬開放。沿路可以看到冒著白煙的地獄谷，還有舊火口積水形成的姿見池。

旭岳纜車全年都有運行，不過營業時間會跟著季節換，夏天週末清晨6:00就開了，冬天15:40就收。春秋兩季各有一段檢修停駛的期間，2026年秋季是從11月16日停到12月10日。

## 旭岳纜車的營業時間與停駛期

營業時間決定了在山上能待多久，也決定接不接得上回旭川的巴士。2026年7月到12月的營業時間整理如下，時間是從上行首班算到下行末班。

| 期間（2026年） | 營業時間 |
|---|---|
| 7月～9月 | 平日6:30～17:30，週末與連假6:00～17:30 |
| 10月1日～10月20日 | 8:00～17:00 |
| 10月21日～11月15日 | 9:00～16:00 |
| 11月16日～12月10日 | 停駛 |
| 12月11日～12月31日 | 9:00～15:40 |

6月1日到10月20日每15分鐘就有一班，在每小時的00、15、30、45分發車。10月21日到隔年5月31日改成20分鐘一班，在00、20、40分發車。

秋季檢修停駛大約3個多星期，2026年跟前一年都是在12月11日恢復運行，前一年的壓雪滑雪道也在同一天開放。不過就算是平常營業的日子，遇到強風或可能打雷，纜車也會暫停。纜車官網的月曆每天標著A到G其中一個代號，對應當天的營業時間，打叉的就是停駛日。隔年1月以後的月曆要等排程決定才會放上去，所以出發前記得先查一下當天的代號，官方也提醒可能臨時停業。

如果還沒決定旭岳要當天來回還是住一晚的話，可以先看旭岳一日遊或住一晚。

## 旭岳纜車票價與買票

纜車票價分成兩季，6月到10月的比較貴，下表都是含稅價。

|---|---|---|
| 大人來回 | 3,500日圓 | 2,800日圓 |
| 大人單程 | 2,200日圓 | 1,700日圓 |
| 兒童來回 | 1,750日圓 | 1,750日圓 |
| 兒童單程 | 1,100日圓 | 1,100日圓 |

如果只是上姿見站走散策路、再搭回山麓的話，買來回票就好了，6月到10月比兩張單程省900日圓，11月到5月省600日圓。國中生以上買大人票，學齡前的小孩每位大人可以免費帶1位。

纜車不用預約，個人跟團體都是到現場買票上車。售票處可以刷卡，收VISA、Master、JCB、AMEX、Diners、DISCOVER跟JCB PREMO。

### 紅葉季週末的排隊

9月中旬進入紅葉季之後，週末跟假日的纜車會非常擁擠。特別是9月白銀週（シルバーウィーク）連假的後半，車窗外的紅葉正好最美，日本國內外的遊客都很多。2026年紅葉季的週末跟連假是9月12、13日，19日到23日，以及26、27日。

這幾天纜車清晨6:00就開了，比平日的6:30早半小時，想少排一點隊的話建議搭早班上山。自己開車去，停車也要花不少時間。纜車停車場只有150個普通車位，紅葉旺季的週末跟假日很容易停滿，到時候只能在入口等到有車位空出來。

## 旭岳的即時影像與山上天氣

出門前可以先打開纜車官網首頁，「ロープウェイ運行状況」欄寫著當天的運行時間跟狀態。旁邊還列著姿見站當下的天氣、氣溫、風速跟能見度，首頁也直接放了一張姿見站的攝影機畫面。

想多看幾張山上的畫面，可以到東川町網站的旭岳山頂攝影機（旭岳山頂カメラ），鏡頭架在姿見站前。遊客中心首頁標著「ロープウェイ姿見駅前より」的畫面也連到同一個頁面。這裡的畫面是每小時更新一次的照片，不是直播，不過還能往回翻過去7天的照片。要注意連線不穩時照片可能沒更新，畫面上的拍攝時間如果已經是好幾個小時前的話，就不能當成山上現在的樣子了。

山上風一大，纜車就可能會停。像是2026年10月2日下午姿見站風速到了每秒13公尺，站內就已經掛出可能停駛的告示。到了山麓，離山麓站大約100公尺的旭岳遊客中心，進門左手邊的展示板貼著纜車運行狀況跟登山道資訊。遊客中心跟纜車站一帶手機有訊號，不過往山區走就有收不到的地方，所以要查的東西記得在山下先查好。

## 旭岳纜車姿見站的服裝與雨鞋租借

纜車官方建議穿登山鞋或鞋底比較厚的鞋，再帶件雨衣或能擋風雨的長袖外套。姿見站比山麓站高了大約500公尺，這一帶從9月下旬到隔年6月都積著雪，一年有三分之二的時間都是雪地。遊客中心也提醒，只穿運動鞋走散策路的話鞋子會濕，也比較容易出意外。

如果沒帶合適的鞋也不用擔心，上了姿見站可以租雨鞋，一雙500日圓，防滑用的登山杖也是500日圓。山麓旁的遊客中心同樣有出租雨鞋跟姿見散策用的登山杖，一天各500日圓，雨鞋有男女跟兒童的尺寸，不過租借時要出示有照片的身分證件。纜車站有投幣置物櫃，但是沒有更衣室。

10月到11月特別容易有人因為裝備不夠出事，甚至遇上山難。像是2026年10月2日旭岳山頂第一次積雪，那天早上9點姿見站零下1℃、風速每秒9公尺，散策路有些地方結冰了，有些被雪蓋住看不出路在哪裡。遊客中心的建議是，下雪的時候只在姿見站前一帶散步就好，裝備不夠就折返。

## 旭岳姿見池散策路怎麼走？

姿見池散策路一圈大約1.7公里，大約1小時可以走完。路線不只一條，如果時間不多的話，也能挑30分鐘左右的走法。

旭岳遊客中心的散策地圖時間抓得比較寬，一圈寫1小時到1小時30分，各段時間照這份地圖整理如下。

| 區段 | 約幾分鐘 |
|---|---|
| 姿見站到第1展望台 | 5分鐘 |
| 第1展望台到第3展望台 | 10分鐘 |
| 第3展望台到第4展望台 | 10分鐘 |
| 第4展望台到姿見展望台 | 15分鐘 |
| 姿見展望台回姿見站 | 20分鐘 |

沿路會先後經過噴氣孔冒著白煙的地獄谷、舊火口形成的姿見池，還有鏡池跟擂缽池（すり鉢池）合稱的夫婦池和滿月沼（満月沼）。這一帶也有機會看到花栗鼠，以及松雀、紅喉歌鴝這些野鳥。

這一帶在大雪山國立公園的分級裡是最容易的等級1，不過路上有岩石路段跟不少階梯，東側往姿見站那段下坡的階梯特別陡。走累了的話，除了第2展望台之外，其他展望台大多有長椅可以坐。時間不夠的時候，從第2展望台附近走大約10分鐘的中道接回東側的路，就不必繞到姿見池了。

姿見一帶屬於特別保護地區，不能帶植物進來，也不能採集。寵物不能搭纜車，導盲犬跟輔助犬除外。沒有許可的空拍機不能帶上車，纜車公司也請大家別在散策路上飛。往山上走的話，最後一間沖水廁所就在姿見站，開放時間跟纜車營業時間一樣，所以記得出發散策前先在站內上好。

姿見池旁邊就是旭岳的5合目，往山頂的登山道從這裡分出去。池邊的旭岳石室能容納20人，是緊急時才用的避難小屋。如果打算從姿見池旁的岔路一路登上山頂的話，可以看旭岳登山，那一頁整理了從姿見站出發的路線跟入山規則。

| 日文名 | 姿見の池 |
| 開放期間 | 6月～10月中旬 |
| 一圈 | 約1.7公里，1小時～1小時30分 |
| 難度 | 大雪山等級1，最容易 |
| 廁所 | 姿見站，依纜車營業時間開放 |

### 高山植物與紅葉的時期

5月下旬，旭岳山麓的濕地就會開出水芭蕉，春天從這裡開始。不過這時候山上還是雪地，2026年纜車在春季檢修後是5月23日恢復運行的，那天散策路都還埋在雪裡。官方當天的建議是條件好的時候穿租來的雨鞋，走到第1展望台看看就好。

6月上旬到8月中旬換成高山植物登場，黃花石楠跟稚兒車（チングルマ）成片開花。7月下旬是花最多的時候，遊客中心的地圖把7月標成最盛期。愛努語把這一帶叫作Kamuimintara（カムイミンタラ），纜車官網解釋成眾神遊玩的庭園（神々の遊ぶ庭）。

9月中旬到下旬，號稱日本最早的旭岳紅葉會從姿見一帶開始轉紅，再一天天往下移到旭岳溫泉。主角是七竈（ナナカマド）的紅跟岳樺的黃。2026年海拔大約1,600公尺的散策路在9月17日正好最好看，到了9月30日，紅葉已經下到山麓了。遊客中心說最好看的時候通常落在9月中旬到下旬，不過每年前後差很多，9月也可能碰上第一場雪，如果想知道當下紅到哪裡的話，可以問遊客中心的工作人員。

10月中旬散策路關閉之後，旭岳就換成雪景了。這裡的雪輕到被稱為Silky Snow，天氣好的時候能看到鑽石塵、日柱跟霧凇，晴天從姿見站一帶望出去視野非常開闊。積雪期可以到遊客中心租雪鞋，一天1,000日圓，穿著在周邊散步就很不錯了。

## 旭岳纜車站的食堂與賣店

旭岳溫泉一帶能吃東西的地方很少，只有纜車山麓站2樓的食堂、1樓的賣店，以及La Vista大雪山（ラビスタ大雪山）1樓的便利商店Yamazaki Shop這三處。食堂夏天最受歡迎的是用東川產蔬菜煮的咖哩，也有炸豬排拉麵跟燉內臟拉麵。山麓站1樓的賣店賣輕食、點心、飲料跟伴手禮，也有啤酒、點心這類纜車限定的原創商品，飲食區另外還有賣香腸跟冰淇淋。

上到姿見站之後，站內有賣用東川產馬鈴薯跟旭川笹豚做的手工可樂餅，還有用旭岳源水沖的有機咖啡。要注意旭岳一帶沒有銀行、郵局跟ATM，最近的ATM開車要30到40分鐘，所以現金最好在出發前就備好。

## 旭岳纜車的末班與回程巴士銜接

當天營業時間的結束時間，就是最後一班下山纜車的時間。曾經有人錯過這班，結果被報警當成山難處理。在營業時間外要請纜車緊急發車的話，除了車資還要另付一筆運行費用，需要出動雪地車也要另外收費。

上山的末班會比下山的早。2026年10月1日起是散策路開放期的尾聲，下行末班17:00，上行末班16:40，搭這班上去大約16:50到姿見站，只剩10分鐘左右，根本走不了散策路。如果想繞完一圈的話，最好在下行末班前1小時30分以上就到姿見站，因為一圈要走1小時到1小時30分。10月21日起散策路已經關閉了，營業時間改成9:00到16:00，坐15:40的最後一班上山，到站大約15:50，也只夠在站前看一眼。

回旭川的出湯號（いで湯號）全年每天都有行駛，用的是同一份時刻表。從旭岳發車的末班是16:55，18:33到旭川站，前一班是14:55。巴士的終點「旭岳」站就在纜車山麓站的站舍前面，下了纜車不用走遠。

7月到10月20日，纜車營業到17:30或17:00，比16:55的末班巴士還要晚。這段期間下山纜車每15分鐘一班，單程大約10分鐘，要接16:55的巴士的話，最晚搭16:30那班下山，大約16:40回到山麓。16:45那班到山麓大約16:55，跟巴士發車同一時間，太趕了。

10月21日以後纜車16:00收，坐最後一班下山大約16:10回到山麓，接得上16:55的巴士。冬天纜車15:40收，一樣來得及。不過纜車發車時間可能會依狀況微調，所以回程要接巴士、飛機或JR的話，時間最好別抓得太緊。想改搭更早的巴士回旭川，或是要接旭川機場的班機，旭岳交通列了出湯號全部的班次，也寫了開車跟停車的細節。

萬一錯過了16:55的末班巴士，旭岳溫泉沒有計程車招呼站，也沒有租車公司，要搭計程車就得事先向計程車公司預約才行。對回程時間沒有把握，可以改搭14:55那班巴士比較保險，或是乾脆在旭岳溫泉住一晚，從纜車山麓站沿著道道1160號線大約1公里內就有7間住宿設施。決定在山上住一晚的話，旭岳溫泉住宿比較了這一帶旅館的位置、營業期間跟訂房管道。
