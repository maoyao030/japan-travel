# 旭岳纜車與姿見の池，營業時間、票價與散策路怎麼走

大雪山旭岳纜車（大雪山旭岳ロープウェイ）從海拔約1,100公尺的山麓站，上到約1,600公尺的姿見站。單程約10分鐘，一個車廂最多載101人。姿見の池散策路就從姿見站出發，一圈約1.7公里、走約1小時，每年6月到10月中旬開放。沿路看得到冒著白煙的地獄谷，還有舊火口形成的姿見の池。

旭岳纜車全年運行，只是營業時間隨季節變動，夏天週末清晨6:00開，冬天15:40收。春秋兩季各有一段檢修停駛，2026年秋季從11月16日停到12月10日。

## 旭岳纜車的營業時間與停駛期

營業時間會影響在山上能待多久，也會影響接不接得上回旭川的巴士。還沒決定旭岳要當天來回還是住一晚，可以先看旭岳一日遊或住一晚。

纜車官網的月曆上，每天標著A到G其中一個代號，代號對應當天的營業時間，打叉的日子停駛。2026年7月到12月的營業時間如下，時間從上行首班算到下行末班。

| 期間（2026年） | 營業時間 |
|---|---|
| 7月～9月 | 平日6:30～17:30，週末與連假6:00～17:30 |
| 10月1日～10月20日 | 8:00～17:00 |
| 10月21日～11月15日 | 9:00～16:00 |
| 11月16日～12月10日 | 停駛 |
| 12月11日～12月31日 | 9:00～15:40 |

6月1日到10月20日每15分鐘一班，在每小時的00、15、30、45分發車。10月21日到隔年5月31日改成20分鐘一班，00、20、40分發車。

秋季檢修後，2026年與前一年都是12月11日恢復運行，前一年的壓雪滑雪道也在同一天開放。遇到強風或有打雷危險的天氣，平常營業的日子也可能停駛。隔年1月到6月要去，出發前到纜車官網的月曆查當天的代號，官方也提醒可能臨時停業。

## 旭岳纜車票價與買票

纜車票價分成兩季，6月到10月比較貴，下表都是含稅價。

國中生以上買大人票，每位大人可以免費帶1位學齡前的小孩。如果只是上姿見站走散策路、再搭回山麓，買來回票就好。6月到10月比兩張單程省900日圓，11月到5月省600日圓。

搭纜車不用預約，不管個人還是團體，都是到現場買票上車。買票可以刷卡，收VISA、Master、JCB、AMEX、Diners、DISCOVER與JCB PREMO。為了防範山難，纜車可能提早停賣上行單程票，或在接近日落時拒載只買上行單程的人。

### 紅葉季週末的排隊

9月中旬進入紅葉季，週末與假日的纜車非常擁擠。9月シルバーウィーク連假的後半，車窗外的紅葉正好最美，日本國內外的遊客都多。這段時間的週末與連假，纜車清晨6:00就開，比平日的6:30早半小時。2026年是9月12、13日，19日到23日，以及26、27日。想少排一點隊，可以搭早班上山。

自己開車去，停車也會花時間。纜車停車場有150個普通車位，紅葉旺季的週末與假日會停滿，只能在入口等到有車位空出來。

## 出發前看旭岳即時影像與山上天氣

出門前打開纜車官網首頁，「ロープウェイ運行状況」欄寫著當天的運行時間與狀態。旁邊是姿見站當下的天氣、氣溫、風速與能見度。例如2026年10月25日15:00，姿見站陰天、4℃、風速每秒8公尺，能見度還算好。纜車官方也有X、Facebook與Instagram帳號可以追蹤。

想看山上現在的樣子，可以到東川町網站的「旭岳山頂カメラ」，鏡頭架在姿見站前。旭岳遊客中心首頁標著「ロープウェイ姿見駅前より」的畫面也連到這裡，纜車官網首頁則直接放了一張姿見站的攝影機畫面。東川町的山頂カメラ是每小時更新一次的照片，不是直播，也能往回翻過去7天的畫面。連線不穩時照片可能沒更新，如果畫面上的拍攝時間已經是很久以前，就別當成山上現在的狀況。

山上風一大，纜車就可能停。2026年10月2日下午姿見站風速到了每秒13公尺，姿見站已經掛出可能停駛的告示。到了山麓，離山麓站約100公尺的旭岳遊客中心，進門左手邊的展示板貼著纜車運行狀況與登山道資訊。遊客中心與纜車站一帶手機有訊號，往山區走就有收不到的地方，要查的東西在山下查好。

## 旭岳纜車姿見站的服裝與雨鞋租借

姿見站比山麓站高約500公尺，這一帶從9月下旬到隔年6月都積著雪，一年有三分之二的時間是雪地。鞋子照纜車官方的建議，穿登山鞋或鞋底較厚的鞋，再帶件雨衣或能擋風雨的長袖外套。遊客中心提醒，只穿運動鞋走散策路，鞋子會濕，也容易出意外。姿見站可以租雨鞋，一雙500日圓，防滑用的登山杖也是500日圓。

山麓旁的遊客中心也出租雨鞋與姿見散策用的登山杖，一天各500日圓，雨鞋有男女與兒童的尺寸。租借時要出示有照片的身分證件。纜車站有投幣置物櫃，但沒有更衣室。

10月到11月特別容易有人因為裝備不夠出事、遇上山難。2026年10月2日旭岳山頂第一次積雪，那天早上9點姿見站零下1℃、風速每秒9公尺。散策路有些地方結冰，有些被雪蓋住看不出路在哪。遊客中心的建議是，下雪時只在姿見站前一帶散步，裝備不夠就折返。

## 旭岳姿見の池散策路怎麼走？

姿見の池散策路一圈約1.7公里，約1小時走完。旭岳遊客中心的散策地圖抓得寬一點，寫1小時到1小時30分。這一帶在大雪山國立公園的分級裡是最容易的等級1，路線不只一條，30分鐘到1小時的走法都有。各段大約要走多久，照遊客中心地圖整理如下。

| 區段 | 約幾分鐘 |
|---|---|
| 姿見站到第1展望台 | 5分鐘 |
| 第1展望台到第3展望台 | 10分鐘 |
| 第3展望台到第4展望台 | 10分鐘 |
| 第4展望台到姿見展望台 | 15分鐘 |
| 姿見展望台回姿見站 | 20分鐘 |

沿路會經過噴氣孔冒著白煙的地獄谷、舊火口形成的姿見の池，還有鏡池與すり鉢池合稱的夫婦池，以及満月沼。這一帶也有機會看到花栗鼠，以及松雀、紅喉歌鴝這些野鳥。走累了，展望台大多有長椅可以坐，只有第2展望台沒有。時間不夠時，從第2展望台附近走約10分鐘的中道接回東側的路，就不必繞到姿見の池。路上有岩石路段與不少階梯，東側往姿見站那段下坡的階梯特別陡。

姿見の池旁邊是旭岳的5合目，往山頂的登山道從這裡分出去。池邊的旭岳石室能容納20人，是緊急時才用的避難小屋。從姿見站往山頂，見旭岳登山。

姿見一帶屬於特別保護地區，不能帶植物進來，也不能採集。寵物不能搭纜車，導盲犬與輔助犬除外。沒有許可的空拍機不能帶上車，纜車公司也請大家別在散策路上飛。往山上走，最後一間沖水廁所就在姿見站，開放時間跟纜車營業時間一樣，出發散策前在站內上好比較安心。

| 日文名 | 姿見の池 |

### 高山植物與紅葉的時期

5月下旬，旭岳山麓的濕地開出水芭蕉，春天從這裡開始。這時山上還是雪地，2026年纜車在春季檢修後於5月23日恢復運行，那天散策路還埋在雪裡。官方當天的建議是條件好時穿租來的雨鞋，走到第1展望台看看。

6月上旬到8月中旬換高山植物登場，黃花石楠與稚兒車（チングルマ）成片開花。7月下旬是花最多的時候，遊客中心的地圖也把7月標成最盛期。愛奴語把這一帶叫作カムイミンタラ，纜車官網寫成「神々の遊ぶ庭」，也就是眾神遊玩的庭園。

旭岳的紅葉號稱日本最早，9月中旬到下旬從姿見一帶開始轉紅，再一天天往下移到旭岳溫泉。主角是七竈（ナナカマド）的紅與岳樺的黃。2026年海拔約1,600公尺的散策路在9月17日正是最好看的時候，到了9月30日，紅葉已經下到山麓。遊客中心說，最好看的時候通常落在9月中旬到下旬，只是每年前後差很多，9月也可能碰上第一場雪。想知道當下紅到哪裡，可以問遊客中心的工作人員。

散策路到10月中旬就不開放，冬天的旭岳換成雪景。這裡的雪輕到被稱為Silky Snow，天氣好時能看到鑽石塵、日柱與霧凇，晴天從姿見站一帶望出去視野開闊。積雪期到遊客中心租雪鞋，一天1,000日圓，就能穿著在周邊散步。

## 旭岳纜車站的食堂與賣店

旭岳溫泉一帶能吃東西的地方很少，遊客中心列出的只有三處。纜車山麓站2樓有食堂、1樓有賣店，另一處是ラビスタ大雪山1樓的便利商店Yamazaki Shop。食堂夏天最受歡迎的是東川產蔬菜煮的咖哩，也有炸豬排拉麵與燉內臟拉麵。山麓站1樓的賣店賣輕食、點心、飲料與伴手禮。纜車站的賣店還有啤酒、點心這類纜車限定的原創商品，飲食區另外賣香腸與冰淇淋。

上到姿見站，站內賣東川產馬鈴薯與旭川笹豚做的手工可樂餅，還有用旭岳源水沖的有機咖啡。旭岳一帶沒有銀行、郵局與ATM，最近的ATM開車要30到40分鐘，現金最好在出發前備好。

## 旭岳纜車的末班與回程巴士銜接

當天營業時間的結束時間，就是最後一班下山纜車的時間。曾有人錯過這班，被人報警當成山難處理。營業時間外要請纜車緊急發車，除了車資還要另付一筆運行費用，需要出動雪地車也要另外收費。

上山的末班比下山的早。2026年10月1日起是散策路開放期的尾聲，下行末班17:00，上行末班16:40。搭16:40那班上去，約16:50到姿見站，只剩10分鐘左右，走不了散策路。想繞完一圈，最好在下行末班前1小時30分以上就到姿見站，因為一圈要走1小時到1小時30分。

10月21日起已過散策路的開放期，營業時間改成9:00到16:00，上行末班是15:40。這時坐最後一班上山，到站約15:50，只夠在站前看一眼。

回旭川的いで湯號全年每天行駛，用的是同一份時刻表。從旭岳發車的末班是16:55，18:33到旭川站，前一班是14:55。巴士的終點「旭岳」站就在纜車山麓站的站舍前。

7月到10月20日，纜車營業到17:30或17:00，比16:55的末班巴士還晚。這段期間下山纜車每15分鐘一班，在00、15、30、45分發車，單程約10分鐘。要接16:55的巴士，最晚搭16:30那班下山，約16:40回到山麓。16:45那班到山麓約16:55，和巴士發車同一時間，太趕了。

10月21日以後纜車16:00收，坐最後一班下山約16:10回到山麓，接得上16:55的巴士。冬天纜車15:40收，一樣來得及。纜車發車時間可能依狀況微調，回程要接巴士、飛機或JR，時間別抓得太緊。回旭川的いで湯號時刻，見旭岳交通。

萬一錯過16:55的末班巴士，旭岳溫泉沒有計程車招呼站，也沒有租車公司，要搭計程車必須事先向計程車公司預約。回程時間沒把握，可以改搭14:55那班巴士，或乾脆在旭岳溫泉住一晚。從纜車山麓站沿著道道1160號線約1公里內，有7間住宿設施。旭岳溫泉的旅館，見旭岳溫泉住宿。
