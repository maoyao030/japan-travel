# 旭岳纜車與姿見の池，營業時間、票價與散策路怎麼走

大雪山旭岳纜車（大雪山旭岳ロープウェイ）從標高約1,100公尺的山麓站，把人送到約1,600公尺的姿見站。單程約10分鐘，一個車廂最多載101人。姿見の池散策路就從姿見站出發，一圈約1.7公里、走約1小時，每年6月到10月中旬開放。沿路看得到冒著白煙的地獄谷，還有舊火口形成的姿見の池。

旭岳纜車全年運行，營業時間卻跟著季節換，夏天的週末清晨6:00就開，冬天到15:40就收。春秋兩季各有一段檢修停駛，2026年秋季從11月16日停到12月10日。

## 旭岳纜車的營業時間與停駛期

纜車的營業時間決定了在山上能待多久，也決定接不接得上回旭川的巴士。還沒決定旭岳要當天來回還是住一晚，可以先看旭岳一日遊或住一晚。

纜車官網把營業時間分成A到G七種代號，月曆上每天標一個代號，打叉的日子停駛。2026年7月到12月的營業時間整理如下，時間指的是上行首班到下行末班。

| 期間（2026年） | 營業時間 |
|---|---|
| 7月～9月 | 平日6:30～17:30，週末與連假6:00～17:30 |
| 10月1日～10月20日 | 8:00～17:00 |
| 10月21日～11月15日 | 9:00～16:00 |
| 11月16日～12月10日 | 停駛 |
| 12月11日～12月31日 | 9:00～15:40 |

班距分成兩段，6月1日到10月20日每15分鐘一班，在每小時的00、15、30、45分發車。10月21日到隔年5月31日改成每20分鐘一班，00、20、40分發車，實際發車時間偶爾會依狀況微調。

秋季的檢修停駛結束後，2026年是12月11日恢復運行。前一年也是12月11日重新運行，同一天開放壓雪的滑雪路線。遇到強風或有打雷危險的天氣，平常營業的日子也可能暫停。隔年1月到6月的營業時間與春季檢修的日期，出發前到纜車官網的月曆看當天的代號，官方也提醒可能臨時停業。

## 旭岳纜車票價與買票

纜車票價分成兩季，6月到10月比較貴，價格都是含稅。

| 票種（含稅） | 6月1日～10月31日 | 11月1日～5月31日 |
|---|---|---|
| 大人來回 | 3,500日圓 | 2,800日圓 |
| 大人單程 | 2,200日圓 | 1,700日圓 |
| 兒童來回 | 1,750日圓 | 1,750日圓 |
| 兒童單程 | 1,100日圓 | 1,100日圓 |

大人指國中生以上，學齡前的小孩每位大人可以免費帶1人。只到姿見站走散策路再搭回山麓，買來回票比較划算。比起買兩張單程，6月到10月省900日圓，11月到5月省600日圓。

搭纜車不用預約，個人與團體都是到現場買票搭車。買票可以刷卡，VISA、Master、JCB、AMEX、Diners、DISCOVER與JCB PREMO都收。上行的單程票為了防止山難，可能提早停止販售，只搭上行單程的旅客也可能因為接近日落被拒載。

### 紅葉季週末的排隊

9月中旬紅葉季的週末與假日，纜車非常擁擠。9月シルバーウィーク連假的後半，正好是從車窗看紅葉的高峰，國內外的遊客都多。這段時間的週末與連假，纜車清晨6:00就開始運行，比平日的6:30早半小時。2026年清晨6:00開的日子是9月19日到23日與26、27日。想少排一點隊，可以搭早班上山。

開車前往，停車也會花時間。纜車停車場有150個普通車位，紅葉旺季的週末與假日會停滿，只能在入口等到有車位空出來。

## 出發前看旭岳即時影像與山上天氣

纜車官網首頁的「ロープウェイ運行状況」欄，顯示當天的運行時間與狀態。旁邊接著列出姿見站的天候、氣溫、風速與能見度。以2026年10月25日15:00為例，姿見站是陰天、4℃、風速每秒8公尺，能見度稍好。

旭岳的即時影像是東川町網站的「旭岳山頂カメラ」，拍的是姿見站前的景色，纜車官網首頁也有連結。畫面是每小時更新一次的照片，不是連續播放的直播，還可以往回看過去7天的畫面。電話線路不穩時照片可能沒有傳上來，看到的拍攝時間太舊，就別當成山上的現況。

山上的風一強，纜車就可能停。2026年10月2日下午姿見站的風速到了每秒13公尺，站內已經掛出可能停駛的告示。官方另有X、Facebook與Instagram帳號。抵達山麓後，離山麓站約100公尺的旭岳遊客中心，入口左側的看板也公告纜車運行狀況與登山道資訊。遊客中心與纜車站一帶手機有訊號，往山區走就有收不到的地方，要查的資料在山下查好。

## 搭旭岳纜車上姿見站，要穿什麼

姿見站比山麓站高約500公尺，姿見一帶從9月下旬到隔年6月都被雪蓋住，一年有三分之二是雪地。纜車官方建議穿登山鞋或鞋底較厚的鞋，再帶雨衣或能擋風雨的長袖外套。旭岳遊客中心也提醒，穿運動鞋走散策路會弄濕，容易出危險。姿見站可以租雨鞋，一雙500日圓，防滑用的登山杖也是500日圓。

山麓旁的遊客中心也出租雨鞋與姿見散策用的登山杖，一天各500日圓，雨鞋有男女與兒童的尺寸。租借時要出示有照片的身分證件。纜車站有投幣置物櫃，但沒有更衣室。

10月到11月是因為裝備不足出事、發生山難的高峰期。2026年10月2日旭岳初冠雪，姿見站早上9點是零下1℃、風速每秒9公尺。那天的散策路有些地方結冰，有些被雪蓋住看不到路。遊客中心建議，下雪時只在姿見站前一帶散步，裝備不夠就折返。

## 旭岳姿見の池散策路怎麼走

姿見の池散策路繞一圈，纜車官網寫約1小時、1.7公里。旭岳遊客中心的地圖寫得寬一點，是1小時到1小時30分。大雪山國立公園連絡協議會把這一帶列為最容易的等級1，路線不只一條，30分鐘到1小時都能走完。遊客中心地圖上各段的時間如下。

| 區段 | 約幾分鐘 |
|---|---|
| 姿見站到第1展望台 | 5分鐘 |
| 第1展望台到第3展望台 | 10分鐘 |
| 第3展望台到第4展望台 | 10分鐘 |
| 第4展望台到姿見展望台 | 15分鐘 |
| 姿見展望台回姿見站 | 20分鐘 |

沿路會經過噴氣孔冒著白煙的地獄谷、舊火口形成的姿見の池，還有鏡池與すり鉢池合稱的夫婦池，以及満月沼。這一帶也有機會看到花栗鼠與ギンザンマシコ、ノゴマ這些野鳥。展望台大多設有長椅，只有第2展望台沒有。時間不夠時可以走地圖上約10分鐘的中道，從第2展望台附近接回東側的路，不必繞到姿見の池。路上有岩石地與不少階梯，東側往姿見站的下坡段差特別陡。

姿見の池旁邊是旭岳的5合目，往山頂的登山道從這裡分出去。池邊的旭岳石室可容20人，是緊急時才用的避難小屋。從姿見站往山頂，見旭岳登山。

姿見一帶屬於特別保護地區，不能帶植物進來，也不能採集。寵物不能搭纜車，導盲犬與輔助犬可以。沒有許可的空拍機也不能帶上車，纜車公司還呼籲不要在散策路飛空拍機。旭岳最後一處沖水廁所在姿見站，開放時間跟著纜車營業時間走，出發散策前在站內上好廁所。

| 項目 | 內容 |
|---|---|
| 日文名 | 姿見の池 |
| 開放期間 | 6月～10月中旬 |
| 一圈 | 約1.7公里，1小時～1小時30分 |
| 難度 | 大雪山等級1，最容易 |
| 廁所 | 姿見站，依纜車營業時間開放 |

### 高山植物與紅葉的時期

旭岳的春天從5月下旬開始，山麓的濕地開出水芭蕉與エゾノリュウキンカ。山上這時還是雪地，2026年春季檢修完在5月23日恢復運行，當天散策路還埋在雪裡。官方那天的建議是條件好時穿租來的雨鞋，走到第1展望台看看。

6月上旬到8月中旬是高山植物的花期，キバナシャクナゲ與チングルマ成片開花。花在7月下旬達到高峰，遊客中心的地圖也寫7月最盛。愛奴語把這一帶叫作カムイミンタラ，纜車官網譯成「神々の遊ぶ庭」，意思是眾神遊玩的庭園。

旭岳的紅葉號稱日本最早，9月中旬到下旬從姿見一帶開始轉紅，再一天天往下移到旭岳溫泉。主角是ナナカマド的紅與ダケカンバ的黃。以2026年為例，9月17日標高約1,600公尺的散策路正是最好看的時候，到了9月30日紅葉已經下到山麓。遊客中心說最美的時期通常落在9月中旬到下旬，但每年前後差很多，9月也可能遇上初冠雪。想知道當下的狀況，可以問遊客中心的工作人員。

散策路到10月中旬就不開放，冬天的旭岳換成雪景。這裡的雪輕到被稱為Silky Snow，天氣好時能看到鑽石塵、日柱與霧凇，晴天從姿見站一帶望出去視野開闊。積雪期遊客中心出租雪鞋，一天1,000日圓，可以穿著在周邊散步。

## 旭岳纜車站的食堂與賣店

旭岳溫泉一帶能吃東西的地方很少，遊客中心列出的只有三處。分別是纜車山麓站2樓的食堂、1樓的賣店，以及ラビスタ大雪山1樓的便利商店Yamazaki Shop。食堂夏天最受歡迎的是東川產蔬菜煮的咖哩，也有炸豬排拉麵與燉內臟拉麵。山麓站1樓的賣店賣輕食、點心、飲料與伴手禮。纜車站的賣店另有啤酒、點心這類纜車限定的原創商品，飲食區賣香腸與冰淇淋。

上到姿見站，站內賣東川產馬鈴薯與旭川笹豚做的手工可樂餅，還有用旭岳源水沖的有機咖啡。旭岳一帶沒有銀行、郵局與ATM，最近的ATM開車要30到40分鐘，買吃的現金在出發前備好。

## 錯過旭岳纜車末班會怎樣

下行末班就是當天營業時間的最後一刻。錯過下行末班，過去曾有人被其他人報警，被當成山難處理。營業時間外要請纜車緊急運行，除了車資還要另付運行費，用到雪上車也要收使用費。

上行末班比下行末班早。散策路開放期的尾聲，2026年10月1日起下行末班是17:00，上行末班是16:40。搭16:40那班上去，約16:50到姿見站，只剩10分鐘左右就是下行末班，走不了散策路。散策路一圈約1小時到1小時30分，想繞完一圈，最好在下行末班前1小時30分以上就到姿見站。

10月21日起散策路已經過了開放期，營業時間改成9:00到16:00，上行末班是15:40。這時搭15:40那班上去，約15:50到姿見站，離16:00的下行末班只剩10分鐘左右，只夠在站前看一眼。

搭いで湯號回旭川，從旭岳發車的末班是16:55，到旭川站是18:33，前一班是14:55。10月21日以後搭16:00的下行末班，約16:10回到山麓，接得上16:55那班巴士。冬季的下行末班是15:40，一樣來得及。下行末班17:00的日子，約17:10才回到山麓，已經趕不上16:55的末班巴士。纜車發車時間可能依狀況微調，要接巴士、飛機或JR的話，回程別抓得太緊。回旭川的いで湯號時刻，見旭岳交通。

錯過16:55的末班巴士，旭岳溫泉沒有計程車招呼站，也沒有租車公司。要搭計程車，必須事先向計程車公司預約。
