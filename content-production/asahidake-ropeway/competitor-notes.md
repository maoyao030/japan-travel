## 各篇的順序

1. 好運日本行：海拔數字 → 「搭纜車就能到」→ 夏秋冬景色各一句 → 帶到姿見池、溫泉、遊客中心 → 重點條列 → 照片 → Q&A（外語、Wi-Fi、置物櫃、廁所）→ 基本資訊欄（時間、票價、電話、刷卡）。
2. japantravel.co：基本資訊（季節營業時間與班距 → 票價表 → 聯絡與停車）→ 纜車介紹（國立公園、四季、特殊需求）→ 各季亮點 → 實用攻略（最佳時間、步道分級、搭乘技巧、穿著、餐飲設施、無障礙）→ 交通 → FAQ → 總結。
3. look2up：導言（天氣狀況、為什麼照去）→ 交通（巴士、開車）→ 沿路風景 → 山麓站餐廳、買票、票價、班次 → 搭乘 → 姿見站大廳地圖、步道長度與建議方向 → 各景點 → 下山、伴手禮 → 往住宿。
4. ETtoday：開頭設問 → 位置與車程 → 纜車（營業時間、容量、票價、高低差）→ 站內伴手禮與廁所 → 步道總覽（長度、時間、木棧道、繩索範圍）→ 步道第一段植被 → 第二段池子倒影 → 第三段近火山 → 小景點。
5. geotravelnotes：旭岳是什麼（最高峰、國立公園）→ 停車與旺季早到 → 票價與班次 → 纜車構造、車程 → 姿見站工作人員說明 → 站內賣店 → 步道總覽（環狀、長度、時間、方向）→ 依步道順序講各展望台與池 → 往登山道的岔路提醒 → 回站。

## 開頭怎麼寫

- 共同手法：先一個數字讓讀者知道「很高」（海拔、標高差），立刻接「但搭纜車十分鐘就到」，把門檻放下來。
- 攻略型（japantravel.co）開頭第二段就預告整篇會講哪些（時間、票價、交通、步道），讀者一進來就知道這頁能答什麼。
- 遊記型開頭會先交代當天狀況（天氣、季節），本站不寫親身經歷，不採用。
- 本站現在的開頭已經是「纜車從幾公尺到幾公尺、多久 → 姿見池散策路多長、何時開放 → 營業時間會變、停駛期」，和攻略型順序一致；可以保留，只檢查第二段是否太早塞進停駛日期。

## 關鍵問題怎麼回答

1. **營業時間、班距與停駛期**：攻略型先講「依季節不同」，再列季節對應的時段，最後才提檢修停駛；遊記型只說「出發前查官網」。讀者先想知道的是「我去的那個月幾點開、幾點收」，其次班距，最後停駛期。用表格（月份 × 時段）是最清楚的，japantravel.co 也用表。
2. **票價、預約、刷卡**：所有競品票價都緊接在營業時間後面；先大人來回，再單程、兒童；預約與刷卡多半放在基本資訊欄或 FAQ。japantravel.co 用票價表。
3. **姿見池散策路**：一律「總覽先行」：環狀、多長、走多久 → 路況（木棧道、岩石、階梯）→ 方向建議 → 再照步道順序講沿路的池與展望台。遊記型最後才提岔路往山頂。
4. **要穿什麼**：只有攻略型獨立成段，依季節分；遊記型把鞋子與登山杖夾在步道段的提醒裡。讀者先問「穿什麼鞋」，再問「山上冷不冷」，最後「哪裡租」。
5. **季節看什麼**：攻略型照季節依序（多半從夏或從冬開始），遊記型散在各段。照月份由春到冬排最直覺。
6. **天氣與即時影像**：只有 japantravel.co 提到看官網天氣與攝影機，而且只一句。競品幾乎沒寫，這是本站的優勢節，可以照「打開哪個頁面 → 看到什麼 → 怎麼解讀」寫。
7. **紅葉季人多**：只有 japantravel.co 給避峰建議（平日、清晨），geotravelnotes 提「停車場旺季要早到」。順序是「哪幾天最擠 → 早班幾點開 → 停車」。
8. **末班**：競品幾乎都沒寫纜車末班與巴士銜接，只有巴士回程末班散在交通段。這也是本站獨有的節。

## 段落與句子的習慣

- 攻略型句子短、資訊句一句一個數字，大量用條列與粗體；遊記型句子長、逗號串很多、口語多。
- 稱呼讀者：攻略型用「您」或不稱呼，遊記型用「我們」「朋友們」。本站維持不稱呼或少用「你」。
- 數字放的位置：營業時間與票價都放在該段的第一兩句，不先鋪景色。
- 轉場：攻略靠小標與條列切換，遊記靠「接著」「出了站」等動線詞。步道段用「沿路依序」的動線轉場讀起來最順。
- 共同缺點：同一頁數字前後不一、把官網的提醒原樣塞進段落。本站要避免一段裡堆兩三個「可能」。

## 給作者的順序建議

標題照 `draft-tagged.md`，不改；只排每節裡的資訊順序。

- **旭岳纜車的營業時間與停駛期**：①先給表（讀者找自己的月份）；②再講班距；③最後停駛期與強風停駛、怎麼查當天。現在稿子先講月曆代號 A～G 才給表，代號可以放到表後一句帶過。內連句「旭岳一日遊或住一晚」放在開頭或段尾都可。
- **旭岳纜車票價與買票**：①票價表；②哪種票划算（來回 vs 單程）、小孩怎麼算；③不用預約、可刷卡；④上行單程停賣的提醒最後。基本資訊欄放節尾。
- **紅葉季週末的排隊**：①哪幾天最擠；②那幾天幾點開、搭早班；③開車的停車場會滿。現在順序已經符合。
- **出發前看旭岳即時影像與山上天氣**：①官網首頁看運行狀態與姿見站天氣；②想看畫面去哪個攝影機、多久更新；③風大會停、到了山麓去哪裡看公告。現在順序已符合，單日實況例子可以縮短。
- **旭岳纜車姿見站的服裝與雨鞋租借**：①穿什麼鞋與外套（先給答案）；②為什麼（比山麓高、雪期長）；③在哪裡租、多少錢；④10～11 月的風險。現在稿子先講雪期再講鞋，可把「穿登山鞋或厚底鞋」提到第一句。
- **旭岳姿見池散策路怎麼走？**：①一圈多長、走多久；②各段時間表；③沿路依序看到什麼；④路況（階梯、岩石、陡下坡）與抄近路；⑤規則與廁所；⑥往山頂的岔路一句帶過接內連。現在稿子在第一段就講國立公園分級，可往後移。
- **高山植物與紅葉的時期**：照月份由春到冬（5 月下旬 → 6～8 月 → 9 月 → 冬季），現在已符合；每季第一句先給月份。
- **旭岳纜車站的食堂與賣店**：①山麓站有什麼（食堂、賣店）；②姿見站有什麼；③周邊沒 ATM、先備現金。現在先講「能吃的地方很少」再列，可以保留，因為那是讀者要的結論。
- **旭岳纜車的末班與回程巴士銜接**：①下山末班就是營業結束時間、錯過的後果；②上山末班比較早、上去還能做什麼；③要接 16:55 巴士最晚搭哪班（分期間）；④錯過巴士的備案與內連。現在順序已符合；季節分段可以考慮先夏後冬，跟營業時間表的順序一致。

## 他們有、我們缺的

- 免費 Wi-Fi（好運日本行的 Q&A 說纜車站也有）：官方現行頁只寫遊客中心館內有，纜車官網沒寫，查不到不寫。
- 散策路建議走的方向（順時針或從第 1 展望台開始）：官方沒有寫建議方向，不寫。
- 姿見站工作人員出發前說明天氣、路況、熊出沒：沒找到官方說明，不寫；熊歸登山頁。
- 千島櫻（6 月中旬）、雲海、樹冰：事實表沒有，不在本輪 mustAnswer 範圍，不補。
- 纜車構造（三線交走式）、嬰兒車、輪椅：讀者需求低，不補。
- 從旭川或札幌的車程、巴士班次與車資：歸 `asahidake-transport`，本頁用內連帶過。
