## 3. 開頭怎麼寫

- A、C：先給地理座標（旭川旁、機場旁），再列兩三個「為什麼有名」的理由，最後一句邀讀者來待一天。
- B：用行程情境開場，讀者正在往旭岳或美瑛的路上，東川是順路停的地方，接著一句說本文介紹什麼。
- C：用問句開場（你聽過嗎），接著用一兩個反常的事實（沒有鐵路、沒有自來水）製造好奇。
- D：個人情感開場，資訊少。
- E：沒有開場段，直接進第一家店。

給作者的觀察：讀者熟悉的開頭是「在哪裡（離旭川、機場多近）→ 特別在哪（水、寫真、咖啡店）→ 適合怎麼去或待多久」。本站線上稿開頭第一段講位置與景點清單、第二段講交通，順序和競品接近；「沒有自來水」競品都放在很前面當鉤子，本站放在第一個 H2。

## 4. 關鍵問題怎麼回答

- **東川是什麼樣的地方**：先位置與距離（機場、旭川），再水（地下水、沒有自來水），再寫真之町，有的加人口增加與移住。水的段落會講到「用這個水做的東西」（米、豆腐、咖啡）。沒有表格。
- **從旭川、機場怎麼去、町內怎麼移動**：先說沒有鐵路、只能開車或巴士 → 從哪上車、系統號、在道草館下車 → 車程 → 車資。機場那側另起一句講溫泉巴士或計程車。班次與末班車沒有一篇寫。町內移動只有「從道草館走幾分鐘」「開車幾分鐘」，A 提到町營巴士一天幾班與計程車。沒有表格，全部散文或資訊框。
- **東川町景點**：道草館幾乎都排在景點的第一個，介紹順序是「它是什麼（服務中心）→ 免費地圖兩種 → 霜淇淋 → 農產與米 → 廁所」。工房類一律先講地點與距離，再講體驗或商品，最後公休。キトウシ、源水、忠別湖只有 D 提到公園與活動。
- **東川町美食**：一家一節，順序是「店的來歷或空間（倉庫、廢校）→ 招牌品項 → 一句建議（會賣完、早點去）→ 資訊框（地址、時間、公休）」。B、C 在段首就提醒「很多店會賣完、公休各不同」。豆腐與飯糰都被寫成「要早去」。
- **要排幾小時**：只在結尾一句（A 一天、B 半天）。
- **住哪裡**：A、E 各寫一兩間，C 只講旭岳溫泉；沒有比較市區和旭岳溫泉。
- **幾月去、祭典與冬天**：D 照季節串；其他篇只零星提到攝影比賽、冬天雪景、冰祭。
- **依旅客類型**：沒有一篇寫。B 預設自駕，D 預設搭巴士。

## 5. 段落與句子的習慣

- 句子偏長，用逗號一路接；常見轉場是「除了…之外」「此外」「最特別的是」「順道」。本站要避開逗號長句，但可以借「順道」「如果…就…」這類把地點串成動線的轉場。
- 稱呼讀者多半不直接叫「你」，用「不妨」「推薦」「建議早點去」這類建議語氣；B 用祈使句。
- 數字集中在資訊框與車資句，散文裡只放車程分鐘數；店家時間不放進正文句子，放框裡。
- 一家店一段，每段兩到四句，第一句講「這家是什麼」，不是講時間。
- 交通都用「從 A 到 B，搭 X，約 N 分鐘」的固定句型，起點先講。

## 6. 給作者的順序建議（標題照大綱，不改）

- **開頭兩段**：位置與距離 → 水與寫真（一兩句）→ 景點與咖啡店在哪 → 怎麼去最快、要注意什麼（班次少、店會賣完）。可以把「沒有自來水」這個鉤子提早到第一段，但第一個 H2 仍要寫細節。
- **東川是什麼樣的地方？**：先水（沒有自來水、地下水），接著「用這個水做的東西」，最後寫真之町與木雕招牌。現狀順序已經對。
- **從旭川、旭川機場到東川**：先一句「沒有鐵路，最近是旭川站」→ 搭巴士：乘車處、系統、下車站 → 車程 → 車資 → IC 卡 → 時刻表。開車與租車放最後，讀者多半搭巴士。
- **搭Ideyu號在道草館下車**：先說誰會搭（從機場來、或往旭岳順路停）→ 乘車處（旭川站⑨、機場②）→ 時刻表 → 車資 → 中途下車要等多久 → 售票機與不等誤點。
- **在東川町內怎麼移動**：先「市中心走得到」→ 自行車（讀者最常用）→ 共享電動自行車 → 町營巴士（要預約、門檻高，放後面）→ 循環巴士。計程車一句。
- **東川町景點，從道草館開始**：道草館先講「它是什麼、為什麼先來」→ 免費地圖 → 特產區與霜淇淋 → 基本資訊欄。競品都把地圖放很前面，可以維持。
- **Sentopyua與織田收藏**：先「是什麼、在哪」→ 看什麼（椅子）→ 附近的咖啡 → 時間在資訊欄。
- **Kitoushi森林公園與展望閣**：先「在哪、多遠」→ 能做什麼（展望閣、溫泉）→ 怎麼去（不開車的走法）→ 資訊欄。目前「怎麼去」在第三段，可提早到第一段尾。
- **往旭岳路上的大雪旭岳源水與忠別湖**：先「在往旭岳的路上」→ 源水能做什麼（取水）→ 不開車怎麼到 → 忠別湖 → 再往上是旭岳。
- **工藝街道與北之住設計社**：先北之住設計社是什麼（廢校、多遠）→ 園區有什麼 → 公休（週三）。注意 F152 改名。
- **東川町美食，咖啡店、麵包與豆腐**：段首先一句提醒「公休各不同、熱門的會賣完」（B、C 都這樣開），再一家一家：店是什麼 → 招牌 → 早去或公休提醒；時間放表格。
- **用大雪山的水釀的酒與啤酒**：先「有幾家、哪幾種酒」→ 每家：能不能參觀 → 商店時間與公休。
- **選物店與伴手禮**：先「吃的伴手禮在道草館一次買齊」→ 再選物店。
- **東川要排幾小時？**：競品只給結論一句；本站先給結論（半天或一天），再說差在哪幾個點，最後講星期幾去。
- **住東川市區還是旭岳溫泉？**：先依讀者隔天要做什麼分（上旭岳就住旭岳溫泉）→ 市區適合誰 → 表格 → 小木屋細節 → 住宿稅。
- **幾月去東川，夏天的寫真節與冬天的冰祭**：照季節排，夏天先、冬天後，每個活動「名稱 → 什麼時候 → 有什麼」。冰祭改用 2027 年日期（F151）。
- **東川的排法，依旅客類型**：競品沒有，照本站現狀。每型先講出發點與交通，再講停哪裡，最後回程。
