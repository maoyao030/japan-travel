## 2. 各篇的順序

**A WAmazing**
- 開頭：大雪山與旭岳的位置 → 溫泉特色 → 一句預告「以下介紹」。
- 溫泉介紹（泉質、源泉數、溫泉街規模小）。
- 周邊景點（纜車、姿見池、國立公園）。
- 住宿推薦 4 間：每間「特色定位 → 溫泉 → 餐 → 其他服務」，地址與交通集中在每間最後的資訊區塊。
- 交通（以巴士為主，分機場出發、旭川站出發）。
- 結語與「資訊可能變動」聲明。

**B 日旅清單**
- 開頭先給判斷（值得住一晚），再講住旭岳溫泉與住旭川的選擇原則。
- 區域比較表 → 全部旅館的總表 → 逐間介紹 → 按旅客類型推薦 → 不建議這樣住 → 行程搭配 → 常見問題。
- 每間：一句定位（最大優勢、再講取捨）→ 條列（交通、附近景點、適合誰、亮點、訂房前注意）。

**C FUN! JAPAN**
- 開頭：大雪山四季景色 → 一句帶出「精選幾間」。
- 每間：小標題是「特色短句＋飯店名」（例如離纜車幾分鐘）→ 一兩段特色 → 固定的名稱、地址、交通條列。

**D REI 體感日本**
- 開頭：推薦給喜歡山的人，從旭川出發約多久。
- 交通：位置屬東川町 → 巴士從哪搭、多久、哪站下 → 時刻表連結 → 拉比斯塔接送。
- 旅館分佈地圖，說明哪幾間已停業。
- 逐間介紹，依離纜車由近到遠排：位置與視野 → 房數 → 溫泉 → 餐 → 官網。
- 纜車站與四季景色。

**E 忘路之遠近**
- 開頭一句交代行程。
- 交通與接送（接送要先預約、冬季狀況、巴士在哪站下）。
- 入住當天的動線（寄行李、上纜車、回來）。
- 外觀與大廳 → 房間 → 溫泉 → 晚餐 → 早餐 → 地址與聯絡。

## 3. 開頭怎麼寫

- A、C、D 都先寫景色或位置，再一句帶到「以下介紹幾間」，旅館數量放在第二、三句。
- B 開頭直接下判斷（要不要住、住哪一區），再補理由。
- 本站現行開頭（只有 7 間、Deer Valley 停業、靠 Ideyu 號一天 4 班、晚餐跟住宿一起訂、山下領現金）比競品更直接，競品都沒在開頭講交通班次少與吃飯問題；這是我們的優勢，保留。
- 共同點：沒有競品在開頭提「停業」，D 是放在旅館分佈那段才說。本站把停業放第一段，讀者看到的數字跟訂房網站搜到的對不上時才不會困惑，可以保留但不要比「能住幾間」更搶前。

## 4. 關鍵問題怎麼回答

- **①有哪些住宿**：A、C 只挑 4 間大飯店；D 是唯一列全的，用地圖加編號，再說哪幾間停業。B 用總表（欄位：名稱、區域、最近車站與步行時間、適合誰、賣點、訂房前注意）。讀者習慣「先看全部有幾間 → 一張總表 → 逐間」。
- **②離纜車多遠、哪站下**：C 把「離纜車幾分鐘」放進小標題；D 依離纜車由近到遠排順序。下車站在 A、C 都放在每間最後的交通條列，D 放在文章前段一次講完。順序：先講離纜車近不近，再講哪站下。
- **③要不要訂含餐**：B 一句建議「晚上能吃的地方少，訂含晚餐」，放在交通之後；A、D 只在各旅館裡描述餐點內容，沒有說周邊沒得吃。順序：先給建議（訂含晚餐）→ 理由（周邊只有幾處）→ 例外（自炊、純住宿）。
- **④搭巴士與接送**：A、D 都是「從哪裡搭 → 車程 → 哪站下 → 時刻表連結」，接著才講旅館接送。E 先講接送要預約、要提前幾天打電話，再講沒有接送時搭公車。D、E 都把接送寫成「免費，但要事先預約」，先講好處再講條件。沒有競品列時刻表，只給連結。
- **⑤訂房管道**：競品多半只在每間結尾放訂房按鈕或平台連結，沒有比較官網與平台；B 有「訂房前注意」欄。本站這節（哪幾間平台找得到、哪幾間只能電話或日語）是競品沒有的。
- **⑥天人峽**：繁中競品幾乎沒寫。日文與平台結果都先講「現在只剩一間、其他已歇業」，再講溫泉與瀑布。

表格：B 用兩張大表；A、C、D 用條列資訊區塊，不用表。

## 5. 段落與句子的習慣

- 編輯站（A、B、C）句子中等長，一句一個資訊，數字（分鐘、間數）放在句中，不另成句。B 常用「若…可…」條件句帶出替代方案。
- 稱呼讀者：A 用「各位」「大家」，B 用「你」，C 用「您」。本站照寫作 Skill 的導覽編輯口吻，不用「各位」。
- 轉場：A 用「以下」「以上介紹了」，B 用「不過」「相比之下」轉優缺點。本站不需要預告句，直接進下一件事。
- 旅館介紹的開頭：C 和 B 都先用一句話講這間的定位（離纜車最近、自炊型、小宿），再講細節；本站現行 H3 有幾段是先講「屬於哪個集團」「哪年開業」，定位句晚出現。
- 部落客（D、E）會講住了才知道的小事（接送要先打電話、房卡插了才有電），這類我們沒有也不寫。

## 6. 給作者的順序建議

標題照現行 `draft-tagged.md`，不改。

**開頭兩段**
1. 先講能住幾間、分在哪兩區（旭岳溫泉 7、天人峽 1），停業的一句帶過。
2. 再講交通與吃飯這兩個會影響選擇的限制（Ideyu 號一天 4 班、晚餐跟住宿一起訂、山上沒有 ATM）。

**H2 旭岳溫泉住宿的含餐與周邊用餐**
1. 建議先出現（訂含晚餐），理由緊接著（周邊只有三處能吃）。
2. 再講例外：K's House 自炊要在山下買食材、しきしま莊晚到就沒晚餐、大雪山山莊只有 1 泊 2 食。
3. 現金與不能刷卡放最後。

**H2 旭岳溫泉住宿有哪幾間？**
1. 表格前一句講幾間、Deer Valley 停業（訂房網站還搜得到）。
2. 表格說明（冬季營業怎麼查的）放表格前一句就好。
3. 表格欄位順序符合讀者：名稱 → 區域 → 下車站 → 冬季 → 訂房管道，現在的順序可以留。

**各 H3（各旅館）**
1. 第一句講這間的定位：離纜車近不近、大飯店還是小宿或青年旅館、適合誰（C、B 的做法）。
2. 接著是下車站與走到纜車的距離。
3. 再講溫泉、餐或房型的特色；開業年、集團名這類往後放或刪。
4. 拉比斯塔這節：先講巴士站與便利商店，接著是冬季免費接送（運行月份、週末為主、要先預約），自駕放最後（E、D 都是先接送後開車）。

**H2 旭岳旁的天人峽溫泉，御宿Shikishima莊**
1. 先講現在只剩這一間（其他已歇業）。
2. 再講怎麼去（沒有公車直達、源水公園前接送要預約）。
3. 最後才是房間、餐食時間與羽衣瀑布。

**H2 搭Ideyu號到旭岳溫泉各旅館**
1. 先一句講一天幾班、從哪搭、不等飛機。
2. 再講各旅館在哪站下（讀者最想知道的），然後才是時刻表。
3. 末班車提醒放在時刻表後；しきしま莊接送放最後。

**H2 旭岳溫泉住宿的訂房管道**
1. 先講平台訂得到的 5 間，再講只能直接跟旅館訂的。
2. 每間的特殊規定（只收網路、只收日語、表單到一週前）緊接在該間後面。
3. 拉比斯塔的冬季接送也是在訂房時一起預約，若作者需要可在這裡一句帶到，細節留在 H3。
