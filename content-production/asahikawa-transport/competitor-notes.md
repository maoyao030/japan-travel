## 各篇的順序

**Funliday 機場巴士**
1. 開頭：廉航讓旭川成了新入口 → 小機場人少 → 本文會講什麼
2. 路線總覽（機場專用巴士與一般公車兩種，一張表比較路線、車程、車資、業者）
3. 車程與車資
4. 時刻（說明跟著航班走，給時刻表連結）
5. 買票與乘車處（售票機在哪 → 乘車處編號）
6. 結語、延伸閱讀（計程車、租車另開文章）

**Funliday 計程車**
1. 開頭：拿新千歲對照，旭川機場小、入境快 → 交通選項有哪些
2. 路線與時間（先說路很單純）
3. 車資（車型與價格範圍 → 夜間加成、定額計程車）
4. 上車處與預約（航廈出口 → 服務台 → 排班處 → 怎麼預約）
5. 適合誰（帶小孩、長輩、行李多）→ 自由行改搭巴士或租車

**FunTime**
1. 開頭：交通是新手最擔心的事 → 本文整理
2. 各機場一段：一句說這個機場適合誰、在哪 → 每種交通「從哪搭、多久、多少錢、時刻連結」
3. 各種周遊券
4. 租車

**札幌觀光協會**
1. 一段總說，跳轉選單（鐵路、巴士、飛機）
2. 鐵路：一段為什麼搭 JR → 每個目的地一小節，固定欄位：車名、時間、車資（車票＋指定席分開）、兒童、價格會變 → 其他特急一行 → 折扣票
3. 巴士：一段強調便宜、不用轉車 → 每個目的地固定欄位：車名、時間、單程、兒童、要不要預約、在哪上車、電話與訂位連結
4. 飛機

**バスとりっぷ（輔助）**
1. 開頭：旭川常跟札幌排在一起
2. JR 與高速巴士的總覽（條列）
3. 特急：快、班次多 → 訂票小技巧 → 固定欄位（路線、車資、時間、轉乘）
4. 高速巴士：班次 → 跟特急比 → 在哪上車 → 同樣欄位
5. 普通車：班次少 → 價錢時間跟巴士差不多 → 在哪轉
6. 旭川站到動物園、札幌當天來回

## 開頭怎麼寫

- Funliday 兩篇都從「為什麼會從旭川機場進出」起頭（廉航、小機場人少），再預告本文內容，回答讀者核心問題要讀到第二節以後。
- 札幌觀光協會只寫一段功能性總說，馬上進資料。
- 日文比較文從「旭川常跟札幌排在一起」帶出要比較交通。
- 共通點：沒有一篇在開頭就給「搭什麼、多久、多少錢」；本站現在的開頭第一段就答了，這是優勢，保留。

## 關鍵問題怎麼回答

1. **札幌、新千歲到旭川**：競品一律「JR 特急 → 高速巴士 →（普通車）」由快到慢排，每種交通用同一組欄位：時間、車資、要不要轉車，接著才是班次與在哪上車。比較結論放在最後，給「要快選特急、要省選巴士」的取捨，不替讀者選。新千歲到旭川，中文競品只寫「先到札幌再轉」，直達巴士幾乎沒人寫。
2. **旭川機場到旭川車站**：先說有哪幾種車（機場專用巴士、一般公車）→ 車程與車資 → 時刻怎麼排（跟著航班）→ 在哪買票、在哪上車。乘車處放在最後。用一張小表並列兩種車。計程車另成一篇，順序是時間 → 車資 → 去哪搭、怎麼叫 → 適合誰。
3. **台灣能不能直飛旭川**：競品沒有正面回答，只提到廉航讓旭川變成入口。
4. **旭川站前乘車處**：中文競品沒有一篇寫出乘車處編號；只有「搭公車約 40 分到動物園」之類。這是本站獨有的資料。
5. **回札幌、新千歲**：競品只寫去程，回程一句「反方向相同」或不寫。

## 段落與句子的習慣

- Funliday：中等長度，口語，常用驚嘆號與粗體，稱「大家」「你」；用「前面提到」回指；提醒事項獨立一小段。
- 札幌觀光協會：幾乎沒有句子，全是「欄位：數值」；提醒（價格會變、要預約）放在欄位下一行小字。
- 日文比較文：每種交通先一兩句判斷（快、班次多），再列欄位，註解放最下面。
- 數字的位置：各篇都把時間和車資放在同一行或同一句，先時間後車資。
- 轉場：Funliday 用「另外」「但如果」帶出替代方案；札幌觀光協會不轉場，靠標題切。

## 給作者的順序建議

標題照現在的 `draft-tagged.md`，不改；以下只排每一節裡的資訊順序。

- **開頭兩段**：維持「先答機場到車站搭什麼、多久、多少錢，再答札幌、新千歲」。12 月車資調整放在車資那句之後，一句就好。
- **從札幌、新千歲機場到旭川，JR 特急與高速巴士（H2 導言）**：先一句兩者怎麼選（快的是特急、省的是巴士，差多少錢與時間），再一句班次多不用遷就；新千歲的兩條路放最後。
- **札幌到旭川的特急Kamui號與Lilac號**：時間 → 車資 → 全車指定席 → 班次（第一班、末班）→ 台灣旅客買不到 Eki-net 折扣。彩繪車頭放最後（現在就是，順序對）。
- **札幌到旭川的高速旭川號**：照競品欄位順序：時間（夏冬）→ 車資（單程、來回）→ 班次 → 在哪上車 → 要不要預約 → 怎麼付錢 → 車上設備。三家共同營運的句子可以挪到後面或拿掉主詞位置，讀者第一個想知道的是多久、多少錢。
- **從新千歲機場到旭川**：先比兩條路（JR 經札幌、直達巴士）各要多久，再講巴士的班次表、車資與預約；「沒預約能不能上車」與「趕不上末班改搭 JR」放最後。
- **飛到旭川機場，怎麼進旭川市區？（H2 導言）**：先列有哪幾種車與各自多久，再說哪些配合班機、哪些不配合。
- **台灣能直飛旭川嗎？**：第一句直接答「沒有定期航班」，接包機，再接替代路線（現在就是）。
- **旭川機場到旭川車站的機場巴士**：時間 → 車資（含 12 月調整）→ 班次跟著航班、時刻表 → 班機晚到巴士會等（新事實 F180）→ IC 卡與買票 → 行李。計程車段落照競品順序：時間或車資 → 冬季加成 → 怎麼叫（預約、叫車 App，F181）。
- **旭川機場的巴士站與售票機**：先乘車處位置與編號，再售票機（現在就是）。
- **從旭川機場直接去美瑛、旭岳與動物園**：先一句「不用先進市區、在 2 號上車」，再各目的地多久，再「不配合班機」的提醒；78 號動物園直達車依「哪天開 → 時刻 → 車資」排。
- **到了旭川車站，站前巴士乘車處怎麼找？（H2 導言）**：先說 Bus Touch 在哪（出站方向），再說各號怎麼分兩排，最後是室內等車與問路的地方。
- **往旭山動物園、旭岳、東川、層雲峽各在哪一號搭？**：表格先（競品沒有，讀者最想要），表後每地一兩句加連結句；順序照表格。
- **往美瑛、富良野的富良野巴士**：乘車處 → 經過哪裡 → 班次 → 怎麼搭與付錢。
- **旭川電氣軌道巴士總合案內所**：在哪 → 幾點開 → 能買什麼。
- **從旭川往稚內與上川、網走方向**：稚內一句帶過加連結 → 上川、網走的班次。
- **從旭川回札幌、新千歲機場**：競品不寫回程，本站寫回程本身就是差異；照去程同樣的欄位順序，但只寫跟去程不同的地方（乘車處、首班、到札幌時間），相同的一句「跟去程相同」帶過。
- **旭川到新千歲機場的Taisetsu Liner**：班次與時刻表先 → 到機場哪個航廈、國際線怎麼走 → 預約建議 → 沒車時改搭 JR。

## 他們有、我們缺的

- **計程車怎麼叫**：Funliday 有一整篇講上車處與預約。本站只有車資與「建議預約」。已回官方查到 F181（GO、DiDi、Uber 叫車 App 與上車處），可以補一句。
- **班機誤點時機場巴士會不會等**：競品只說「跟著航班」。已回官方查到 F180（往市區的車在班機晚到時延後發車）。
- **札幌到旭川的普通車**：日文比較文列了普通車（轉車、較慢）。大綱與 mustAnswer 沒有，本站事實表也沒有，不加。
- **租車、JR 北海道周遊券**：競品常附。大綱沒有這兩節，不擴充（研究記錄「查到但不寫」已列）。
- **札幌端巴士總站位置**：札幌觀光協會提醒札幌站巴士總站曾因工程搬遷。本站已有 F158（札幌站前 2 號、中央巴士札幌總站 3 號），夠用。
