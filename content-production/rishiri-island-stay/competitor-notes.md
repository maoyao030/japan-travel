## 2. 各篇的順序

**誌麟姊姊**
- 沒有開場段，直接進第一家。
- 每家：粗體店名 → 一句標語 → 位置與特色 → 作者感想 → 照片 → 資料框（官網、地址、電話、期間、費用、Mapcode）。
- 旅館那家的順序：旺季價格與難訂 → 免費接送（港口、登山口）→ 租車租單車 → 設施 → 晚餐 → 登山客的飯糰便當。
- 兩處露營場用比較寫：一個靠登山口但採買不便，一個離市區近、補給方便。

**niigata.tw**
- 先寫前一天的行程，最後才到住宿。
- 住宿：位置（離岬多近）→ 接駁 → 房間（一兩句）→ 溫泉 → 餐食（篇幅最長）→ 夕陽。沒有價格、沒有訂房管道。

**O2 Travel**
- 到店小故事開場 → 門口看板的服務（登山報名、碼頭接送時段）→ 單車租借 → 房型 → 活動 → 登山接送與裝備租借 → 公共空間與廚房 → 費用與官網訂房 → 預告下篇。

**FUN! JAPAN**
- 開場先講島在哪、一個大家認得的連結點，再一句島上住宿不多，然後「推薦給你」。
- 每家：氣氛與房間 → 交通便利（離港口幾分鐘）→ 特色（景觀、餐食）→ 價格放敘述末尾 → 最後資料框（名稱、地址、交通）。

**tahokkaido（稚內，參考結構）**
- 開場一個實用事實（住宿集中在車站附近），接一句「看你這趟的目的決定」。
- 依類型分（商務、背包、海邊民宿），每類一句「適合…的人」→ 逐家（位置交通先、設施後、缺點、作者提醒、訂房按鈕）→ FAQ → 總結。

## 3. 開頭怎麼寫

- 編輯站：先定位（島在哪、為什麼有名），一句帶到住宿少，再進清單。
- 部落客：直接進店家，或用到店的小故事開場。
- 稚內那篇：一個讀者馬上用得到的事實（住宿集中在哪）＋「依目的選」，最接近本站的選區題。
- 沒有一篇在開頭講冬天。

## 4. 關鍵問題怎麼回答

**mustAnswer①「39 家住宿怎麼選區」**
- 中文競品沒有正面回答。最接近的是逐家介紹時，第一個資訊都是「離港口（或岬、市區）走幾分鐘」，第二個是「有沒有接送、接送到哪」。
- 讀者的隱含順序：先知道住在哪一港附近 → 離港多遠、要不要接送 → 登山的人能不能送登山口、早餐怎麼辦 → 吃飯方不方便。
- 露營場用「兩處比較」寫：一處靠登山口、一處靠市區補給，讀者靠取捨選。
- 沒人用表格；資訊都在每家最後的資料框（地址、電話、期間、官網）。

**mustAnswer②「冬季休館的有哪些」**
- 競品沒寫。最多是露營場資料框裡的開放期間，暗示冬天沒有開。
- 遊記類的交通文（Funliday 兩篇，查到但不是住宿文）只在 FAQ 一句帶過「冬天有些民宿、餐廳休息」。本站的表與全年營業名單是獨有資料，應該放前面、講清楚。

**訂房管道**
- 部落客寫「官網訂」或「電話」，放在每家最後；編輯站用訂房按鈕。沒有人說哪些家只能打電話。

## 5. 段落與句子的習慣

- 部落客句子短、口語、多感嘆，以「你」「大家」稱呼讀者；本站不學感嘆與自嘲，只學「每家先給位置與接送」。
- 編輯站中長句，用「您」，價格放每家敘述最後。
- 數字位置：步行分鐘數緊跟店名後面；期間、費用、電話集中在資料框；不在段落中間堆數字。
- 轉場：「如果你要登山…」「想看夕陽的話…」這類條件句開頭，接一家住宿。本站可用「要登山就…」「從禮文島過來…」這種條件開頭，符合現在稿子的寫法。

## 6. 給作者的順序建議

標題照現在 `draft-tagged.md`，不改。

- **開頭段**：先一句住宿分在哪四區、哪一區最多人住，接著「看你這趟要不要登山、從哪個港上島」決定；冬天少一截放第二段。現在的稿子順序已接近，但「清單共收39筆，34筆是…5筆是露營場」的規格可以後移或縮短，讀者第一個想知道的是住哪區。
- **H2 怎麼選區**：表格之後，先講「要登山 → 鴛泊」，再「從禮文或想玩西岸 → 沓形」，最後「不開車住鬼脇、仙法志 → 巴士」。計程車、租車家數放最後或併進不開車那段。
- **H3 鴛泊**：每家先給「離渡輪站多遠」，接著「接送到哪」（競品每家都把這兩項放最前）；登山客的早餐便當、登山口接送接在後面；Peshi 岬日出放最後。
- **H3 沓形**：先講住沓形的理由（船、觀光巴士從沓形出發），再逐家：位置與接送 → 特色 → 營業期間（アイランドイン 2027 年 5 月開、12/1 開放訂房，讀者現在用得到）。ホテル利尻接送要照 F195 改（沒有沓形渡輪站、事前預約）。
- **H3 鬼脇與仙法志**：先「不開車也能住、但跟著巴士走」，再列住宿，最後吃飯（仙法志只有一家食堂）。民宿はまだ的價格依住宿頁規則刪。
- **H3 露營場**：先一句「都只在夏天開」，表格，然後照誌麟姊姊那種取捨寫：靠登山口（北麓）對比靠市區補給（ゆ～に）、免費但採買不便（沼浦）。施工公告今年已用不到。
- **H2 冬季休館與全年營業**：先講「12 月到 2 月表上全部不開」這個結論，再表格，最後一句查核日期。
- **H3 全年營業**：清單之後，接「年底年初更少」→「停航多住一晚也找這些」→ 溫泉。可以把 F198 的接送放進清單（哪幾家接渡輪站），冬天讀者最需要。
- **H2 訂房管道與住宿稅**：先講「哪些家在 Trip.com、Agoda 訂得到（F193、F194）、哪些家官網能線上訂（F197）、其餘打電話」，再寫接送要在訂房時寫船班航班，住宿稅放最後。

- **每家離港口幾分鐘與接送範圍**：競品每家都寫。事實表原本只有鴛泊幾家；已用官方補 F195、F198、F199（全年營業各家的接送）。
- **訂房管道**：競品寫「官網／電話」。已補 F193（Agoda 上架）、F194（Trip.com 部分）、F197（官網線上訂房）。
- **含餐（晚餐、登山便當）**：競品篇幅最多的是餐食。本站只在影響選擇時寫（登山便當 F87、仙法志吃飯 F147），沒有另補。
- **旺季要多早訂**：競品都說要早訂，沒有官方或三個獨立來源，不寫。
- **沓形新開的素泊住宿**：只見於 Jalan，不在觀光協會清單，不寫。
