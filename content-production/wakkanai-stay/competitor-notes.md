## 2. 各篇的順序

**A**
1. 開頭：住宿集中在哪、住的人多半為了什麼（搭船去離島、去宗谷岬）、類型比位置重要
2. 價格趨勢（我們不寫價格，跳過）
3. 怎麼選：市區商務旅館 → 青年旅館與 Guest House → 郊外海景民宿
4. 6 家推薦：每家「亮點（位置與交通 → 設施 → 服務）→ 缺點 → 旅客回饋 → 入住建議 → 訂房鈕 → 評分、電話、住址、官網」
5. 常見問題（第 1 題就是車站到渡輪站多遠、哪家早餐最早）
6. 總結

**B**（單館）
1. 開頭：自駕抵達的經過、為什麼選這家
2. 位置與走路時間 → 為什麼選（位置、品牌）→ 評分 → 免費宵夜拉麵 → 溫泉 → 房間 → 備品 → 早餐 → 停車 → 附近商店街

**C**（攻略的住宿一節）
1. 一句總覽（都在車站旁）
2. 每家：一段描述（離車站幾分、房型、溫泉或廚房、早餐、適合誰）→ 粗體資訊欄（名稱、地址、交通、官網）

**D**（單館）
1. 開頭：開車到稚內的經過 → 為什麼選這家 → 到渡輪站走幾分、附近景點 → 大廳 → 景觀 → 房間 → 浴室 → 早餐 → 附近走得到的景點 → 資訊欄

## 3. 開頭怎麼寫

- A：第一句講住宿集中在車站周邊，第二句講讀者來稚內多半為了什麼，接著給一個選擇原則。直接從讀者的行程起頭，不鋪陳城市介紹。
- B、D：用自己的旅程起頭（本站不用第一人稱，不學）。
- C：用對比加反問帶出整篇（住宿節沒有開頭）。
- 共通：住宿頁的開頭都很快講到「住車站附近」與「搭船」，這兩件事是讀者最先想知道的。

## 4. 關鍵問題怎麼回答

**mustAnswer①有哪些住宿、各在哪一區、怎麼訂**
- A：先分類型（商務、青旅、郊外），再一家一家講。每家第一個資訊都是位置與離車站幾分，訂房放在最後（按鈕）。沒有表格。
- C：每家先一段描述，最後才是地址、交通、官網的資訊欄。
- 競品都沒有整理「訂房管道」，也沒有分區表。這是本站獨有的資料，表格放前面是對的。
- 競品每家的順序固定是：位置與走幾分 → 最有特色的設施（溫泉、廚房）→ 早餐 → 缺點或適合誰 → 訂房。

**mustAnswer②搭早船該住哪一區**
- A：放在常見問題第 1 題，先給車站到渡輪站走幾分，再講哪家早餐最早可以吃。
- D：在位置那段順帶講到渡輪站走幾分。
- 共通：讀者想知道的順序是「走到渡輪站要多久」→「早上來不來得及吃早餐」→「行李多要不要叫車」。競品都沒有算報到時間，也沒有寫送站服務；本站有（F36、F409），是我們的優勢。

## 5. 段落與句子的習慣

- 句子短到中等，一句講一件事；A 每段常用「適合…的人」收尾。
- A、C 稱讀者「你」；B、D 用「我們」（第一人稱，本站不學）。
- 數字（走幾分、幾點開）放在句子裡，緊接在地點後面，不另外拉成清單。
- 轉場常用「另外」「如果…就…」；單館文用照片說明當小標，一格一個主題。
- 缺點寫得很直接（房間小、要爬樓梯、洗衣機要排），跟優點放在一起。本站對旅館的評價要照「評論常提到」的規則，客觀條件（只收現金、只能打電話、晚上沒餐廳）可以直接寫。

## 6. 給作者的順序建議

標題照現在的 `draft-tagged.md` 不改，只排每節的資訊順序。

- **開頭**：先回答住哪裡（車站周邊）→ 搭早船住站前、渡輪站走幾分 → 其他區給誰。現稿已經是這個順序，保留。
- **H2 搭早班渡輪的住宿區域與走到渡輪站的時間**：
  1. 第一班幾點、幾點前要報到（現稿有）
  2. 站前各家走到渡輪站幾分（可加サフィール 15 分，F427）
  3. 早上能不能先吃早餐：Dormy Inn 早餐 5:30 開，是配合渡輪提早的（F425）。競品把這點當搭早船的第二個答案，現稿缺。
  4. 不想走或行李多：冰雪莊清晨送站、請櫃台叫車（F409、F427）
  5. 南稚內離得遠，要叫車（現稿有）
- **H2 稚內住宿推薦，各區飯店與離車站的距離**：表格放最前面（競品沒有，是本站的強項）；表格後的引言一兩句講各區給誰。
- **H3 各館**：每家照「位置與走幾分 → 最有特色的一件事 → 會卡住的條件（只收現金、只能打電話、晚上沒餐廳）→ 怎麼訂」。評分放在特色之後、訂房之前，或拿掉；競品把評分放在最後的資訊欄。
  - Dormy Inn：走 3 分 → 溫泉與露天浴池看得到什麼 → 早餐（含 5:30 開）→ 宵夜拉麵（F426，可一句帶過）→ 評分。
  - サフィール：走 3 分 → 到渡輪站 15 分、門口有機場巴士、免費停車（F427）→ 評分 → 訂房專線的時間限制。
- **H3 野寒布與宗谷岬的住宿**：先講能不能住（季節）再講位置與餐：みのり約 11 月底到 4 月底休業（F184，重查後可寫）、Tom Soya 冬季休業到 2027 年 4 月下旬，放在各自那段的前面，讀者冬天排行程先知道排不排得進。
- **H2 稚內住宿的訂房管道**：先講平台訂不到的幾家（只能打電話）→ 冬天營業與查核日期 → 平台頁面不一定能訂。競品沒有這一節，順序照讀者「我能不能在網路上訂」的疑問走。
- **H3 住宿稅**：先講每晚會多付多少（合計表的概念：道稅＋市稅）→ 什麼時候開始 → 由旅館代收。市稅已定案（F180 更正），不用再寫「預定」。
