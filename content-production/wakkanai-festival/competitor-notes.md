## 各篇的順序

1. 樂吃購（活動一節）
   - 每項活動：一句定位小標（例如「代表性大型祭典」）→ 一段氣氛描寫（有什麼表演、晚上有煙火）→ 日文原名 → 「舉辦時期：○月（預定）」一行。
   - 四項的排序：南極祭（夏）→ Night & Light（秋）→ 雪樂園（冬）→ 犬橇大會（冬）。沒有白夜祭、北門神社祭、冰雪廣場。
   - 完全沒有交通、會場怎麼去、費用。
2. 北海道生活（犬橇觀賽記）
   - 開場：冬天北海道除了常見景點還有什麼 → 比賽時期、場地、從哪年開始、規模（選手數、狗數、觀眾數）→ 作者為什麼去 → 賽前場邊 → 比賽規則（幾隻狗、幾公里、計時）→ 為什麼在稚內辦（《南極物語》）→ 選手技巧、風雪 → 冠軍 → 第二天的附帶活動（體驗搭雪橇抽籤、狗狗短跑、時裝秀）→ 收尾叫讀者明年去。
3. WAmazing（清單）
   - 每個祭典：粗體中文名（日文原名）→ 地點 → 日期 → 交通 → 官網。
4. Walkerplus（煙火頁）
   - 日期 → 時間 → 會場 → 發數 → 雨天順延 → 交通（車站走幾分）→ 當天資訊請問主辦。

## 開頭怎麼寫

- 樂吃購整篇開頭先推「最北」與招牌景點、美食，用驚嘆號；活動那一節沒有導言，直接進第一項。
- 北海道生活用「冬天北海道不是只有雪祭」這種反差開場，再立刻給時期和地點。
- 共通點：開頭一兩句就交代「什麼時候」。沒有一篇先講歷史。

## 關鍵問題怎麼回答

- **南極祭日期與煙火**：樂吃購是「兩天、有兩種舞、晚上約 2,500 發煙火」→ 時期一行。Walkerplus 是日期 → 煙火幾點到幾點 → 在哪放 → 下雨延哪天 → 車站走幾分。讀者查煙火最先找的是**哪一晚、幾點、在哪**，中文文章都沒寫這三樣（本站有 F261 可以補上）。
- **2 月犬橇大會**：樂吃購只有氣氛描寫加「2 月下旬」。北海道生活是時期 → 場地 → 規模 → 比賽怎麼比 → 為什麼在稚內 → 附帶活動。沒有人寫會場在郊外、沒車怎麼去、接駁車起點。
- **白夜祭、北門神社祭**：中文競品都沒寫（搜不到中文介紹）。日文報導寫法是先講「夏至、站前、啤酒」→ 日期；北門神社祭先講日期與攤位數 → 神轎 → 海上祈願。
- 表格：沒有一篇用全年月曆表；樂吃購與 WAmazing 用的是「每項一行時期」的條列。

## 段落與句子的習慣

- 樂吃購：每項一段約 4～5 句，句子長、形容詞多（熱鬧、繽紛、夢幻），用「不妨」「當然不能錯過」叫讀者；數字只有煙火發數，日期獨立放在段落後的資料行。
- 北海道生活：一段一兩句，口語、驚嘆號多，稱讀者「朋友」；數字（選手、狗數、觀眾）集中在開頭交代規模。
- WAmazing／Walkerplus：欄位式，數字全放在欄位，不寫進句子。
- 轉場：樂吃購直接用編號 ①②③ 換項，不寫轉場句。
- 本站不學的：氣氛形容詞、驚嘆號、「不容錯過」。可以學的：日期與時間放在一段的最前面，讀者第一眼就看到。

## 給作者的順序建議

標題照現在的 `draft-tagged.md`，只排每節內的順序。

- **H1 開頭兩段**：先回答「稚內有哪些祭典、什麼時候」：夏天南極祭（8 月第一個週末、煙火）→ 冬天犬橇大會（2 月底、免費）→ 其他兩個夏季祭典一句帶過。南極與樺太犬的淵源可以壓成半句或移到後面，競品都沒先講歷史。
- **稚內祭典與活動月曆**：表格先（讀者掃月份）→ 表後一句講 2 月最集中、哪兩個日期每年固定。現在表前那段「日期每年固定的是…」可以縮短或移到表後。
- **稚內港南極祭的日期與煙火**：日期（8 月第一個週六、週日）→ **煙火是第二晚 20:30 起、北防波堤穹頂公園**（F261）→ 下雨延哪天 → 兩天各有什麼（第一天上午慰靈祭、晚上舞蹈遊行；兩天站前物產祭；第二天白天副港划船賽，F262～F264）→ 交通（穹頂離車站近、封路與巴士改道）→ 住宿內連句。原本「煙火幾點放到案內所問」那句改掉。
- **稚內為什麼辦南極祭？**：維持短段；可補第一天在稚內公園樺太犬供養塔前的慰靈祭，把由來和祭典本身接起來。
- **稚內冬季的犬橇大會**：日期、時間、免費 → 會場在郊外大沼 → 開車多久與停車 → 沒車：接駁車起點 Fureai公園 → 巴士怎麼到公園。讀者第一個想知道「哪天、要不要錢」，第二個是「沒車去得了嗎」。2027 年預定辦物產祭、餐車祭（F265）可放在日期之後一句。
- **犬橇大會與太郎、次郎**：照現在。
- **冰雪廣場與雪樂園**：每項先日期與地點 → 能玩什麼 → 費用 → 交通。冰雪廣場「走路到得了」放第一段最後，當作沒車的人的選擇。Snow Attack 那句照 F165 更正。
- **白夜祭與北門神社例大祭**：每項先日期與地點 → 主要內容 → 小細節（日落時間、電影節、神轎路線）。
- **Night & Light 與和平馬拉松**：期間與時間 → 點亮哪裡 → 啤酒花園 → 馬拉松一兩句。
