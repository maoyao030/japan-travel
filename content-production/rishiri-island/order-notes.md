- **利尻島一日遊可行嗎？**：改最多。一句答可不可行 → 船班時刻表 → 用船班接觀光巴士 A 路線（含路線名、票價、停哪裡）→ 下午接 B 路線 → 5 月的接法 → 預約方式 → 路線巴士一日券。競品只寫「要算好船班」，時刻表是本站獨有的，從原本的段落中間移到開頭第二句之後（筆記第 4 節「一日遊」）。
- **利尻島和禮文島怎麼一起排？**：有直航船、船程 → 天數 → 禮文島主頁連結句（筆記「有沒有直航→多久→停哪→先去哪」）。
- **禮文島與利尻島之間的船程**：船程與班數 → 時刻表 → 沓形航線與臨時船 → 寄行李。與競品同序，不動。
