## 各篇的順序

**1. Funliday 十大景點**
- 開頭：島的位置與暱稱 → 列出本文會講什麼
- 前往禮文島（稚內港走路、訂票、季節班次）
- 景點逐一：每個景點「是什麼 → 特色 → 位置或時間 → 小提醒」，桃岩展望台是「從港口走到入口要多久 → 登頂多久 → 難不難 → 植物」
- 常見問題五題（在哪、怎麼去、季節）

**2. Funliday 稚內船票與交通**
- 船票 → 島上交通三種（租車、巴士一日券、觀光巴士）→ 景點
- 景點順序「特色 → 到達方式 → 所需時間 → 難度或季節 → 條列地址時間」

**3. 北海道 Labo 桃岩展望台路線**
- 開頭：這條路為什麼值得走 → 起終點 → 全長與總時間 → 沿路看得到什麼 → 預告注意事項
- 第 1 節 港口到展望台：路線圖 → 從渡輪站走多久 → 季節巴士可以省一段 → 入口在哪 → 路況與指標
- 第 2 節 展望台到金梅之谷：到了看到什麼 → 植物 → 標高與天氣 → 木棧道
- 第 3 節 金梅之谷到知床：上坡 → 固有種的花 → 景色 → 燈塔與下坡 → 終點巴士
- 結尾：推薦與官方步道網站連結

**4. 痞客邦實走**
- 島的地形與花季 → 7 條步道與長度範圍 → 為什麼選桃岩 → 從哪頭走比較輕鬆 → 怎麼到登山口（原本想搭巴士、改搭計程車）→ 登山口的廁所 → 上坡與天氣 → 展望台與稜線 → 下坡 → 到知床、搭車回港

**5. nippon.com 離島系列**
- 島的位置、花季、海膽 → 走路最能看島 → 7 條步道 → 桃岩展望台步道（花、坡度、兩端都有巴士站、看得到利尻山）→ 其他步道各一句 → 8 小時步道（距離、最高點、難、作者走了多久）→ 住哪裡

## 開頭怎麼寫

- 編輯站（1、2、5）都先講島的位置與「花之浮島」，再說這篇要帶讀者做什麼；沒有人一開頭就講步道開放期間或封閉。
- 步道專文（3）先講這條路值得走的理由，馬上接起終點、全長與總時間，數字在第一段就出現。
- 實走文（4）先給全島概況（花季月份、步道條數與長短範圍），再收斂到為什麼選這條。
- 共通點：第一段給「能不能走、要走多久」的感覺，季節或花期放在第一或第二段；沒有人把封閉日期放進開頭。

## 關鍵問題怎麼回答

**各步道時間與起訖點巴士**
- 競品幾乎只寫桃岩展望台步道。順序一律是「從渡輪站走到入口多久 → 登上展望台多久 → 難不難」，再補「終點知床有巴士回港」。
- 3 和 4 都談到「從哪一頭出發比較輕鬆」，以及登山口可以搭巴士或計程車省一段上坡。
- 其他步道（巡岬、8 小時、禮文林道、禮文瀑布、禮文岳、久種湖）競品多半一句帶過，只給長度或難度；沒有任何一篇把 7 條排成表格。
- 起訖點巴士：只有 3、4、5 提到桃岩登山口與知床的巴士站，都沒有車資；沒人比較一日券與單買。

**群生地開放期間**
- 五篇都沒寫禮文敦盛草群生地的開園日期。1 只在高山植物園一段提到敦盛草；花季多寫成「5～9 月」「6～8 月」這種大範圍，有的互相矛盾。

**冬季封閉**
- 五篇都沒寫步道冬季封閉；1 只在常見問題說 10 月到 4 月天候嚴苛、部分設施關閉。

**表格**
- 五篇都沒有表格，數字放在條列資訊框或標題括號裡（3 的「（2.8 公里／1 小時 20 分）」很好掃讀）。

## 段落與句子的習慣

- 編輯站句子中等長度，常用「大家」「你」，多驚嘆與「超級」「絕對」這類形容詞；本站不學語氣，只學順序。
- 步道專文照「走到哪裡 → 看到什麼」的時間順序推進，轉場是「過了…之後」「到了…」，讀者像跟著走一遍。
- 數字的位置：路段的距離與時間放在路段一開始（甚至在標題），景色描述放後面。
- 實用提醒（廁所、巴士班次少、強風濃霧）放在該路段的最後一句，或放在出發前的段落。
- 常見問題都只是把正文重講一次，本站大綱不設常見問題，照舊。

## 給作者的順序建議

標題照現在的 draft-tagged.md 不改，以下只排每節裡的資訊順序。

- **禮文島步道怎麼選？**
  1. 先依讀者有多少時間給答案（半天或當天來回 → 桃岩；想看敦盛草 → 巡岬或從濱中來回；一整天且有經驗 → 8 小時）。競品的讀者第一個想知道「我能走哪條」。
  2. 再講當天來回的船班與「整條走完都不用等巴士」。
  3. 地圖、沒有熊這類安心資訊放最後。
- **禮文島的花季**：先月份範圍（觀光季 5～9 月、花最多 6 月中到 8 月初）→ 三種固有種各在什麼時候 → 天氣與衣物。現在的順序已經對。
- **禮文島的禮文敦盛草群生地開放期間**：先今年的開園與閉園日 → 每天幾點到幾點、免費 → 怎麼去（濱中走 20 分）→ 錯過了怎麼辦（高山植物園，可補 5～9 月開、收費 F533）→ 花的小知識放最後。競品完全沒有這節，是本站獨有資料，放前面不要被小知識搶走。
- **禮文島步道的冬季封閉**：先 10 月的兩階段封閉 → 10 月下旬還能走哪裡 → 春天什麼時候開（改用 F531 的 2026 年順序，取代不採用的 F496）。
- **禮文島7條步道的時間與起訖點巴士**：先表格前一兩句說哪些起訖點有巴士站 → 表格 → 表格後算車資與一日券。競品沒有人給比較表，表格留著。
- **桃岩展望台步道**：照競品 3、4 的動線排：從渡輪站怎麼到登山口、多久 → 登山口到展望台（巡山員小屋、鋪面）→ 展望台看到什麼、強風濃霧 → 往金梅之谷、元地燈塔到知床 → 從知床怎麼回渡輪站。現在的稿子把「全長、天然紀念物、金梅之谷、雲海」放在路怎麼走之前，讀者要先讀完景點介紹才知道怎麼出發，建議把「怎麼到登山口」往前。
- **巡岬步道／8 小時步道／禮文林道／禮文岳步道／禮文瀑布步道／久種湖畔步道**：每條都用同一個順序骨架會太像量產頁；建議只有「起點怎麼到」與「難在哪裡」兩件事放前面，景色放後面。8 小時步道先講難（體力、訊號、無村落）再講路線；久種湖畔先講輕鬆可以只走一段。
- **禮文島步道的規則**：出發前要做的（裝備、雨具、先確認廁所 F532、清鞋底）放前面，走路時的（不踏出步道、不採植物）其次，露營與寵物最後。
- **禮文島的花導覽**：先說導覽是日文、夏季（6～8 月）、半日約 4 小時（F534）→ 四家名單 → 電話；補一句 2026 年度已結束。

## 他們有、我們缺的

- **從哪一頭出發比較輕鬆**（4 有寫，從香深那頭坐車上登山口可省上坡）：桃岩展望台步道的方向建議，事實表只有起伏圖方向，沒有官方說哪頭輕鬆。沒查到官方說法，不寫。
- **計程車到登山口**（4）：島上計程車公司與車資，事實表沒有，歸交通頁。
- **登山口與步道上的廁所**（4）：只查到步道規則要讀者事先確認廁所位置（F532）；各登山口有沒有廁所沒有官方清單，不寫。
- **行李寄放**（billyistravelling 提到先把行李放旅館）：香深渡輪站置物櫃沒查到官方資料，歸交通頁。
