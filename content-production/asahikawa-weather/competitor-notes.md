# 旭川天氣 競品筆記（重寫前，2026-11-02）

只記資訊順序與句子習慣，不拿事實、不抄句子。競品的數字彼此不一致（年均溫寫約 8°C、冬天「約零下 1 到 13 度」、「最低零下 20 度」各說各話），本頁數字一律用 `reference-review.md`。

## 各篇的順序

1. UpToGo（11 月旭川）
   - 開頭：台灣人想看雪 → 北海道各月雪況不同 → 直接拋出讀者會問的問題
   - 盆地氣候特徵（年均溫、日夜溫差、比札幌函館冷）
   - 先給答案「會下雪，但積不積看旬別」
   - 初雪時間 → 初期是濕雪會融 → 下旬才積雪
   - 上、中、下旬三段，各寫「氣溫狀態」「雪況景緻」
   - 和北海道其他城市比較的表格
   - 穿著：上身洋蔥式（內、中、外三層）→ 下身（牛仔褲不夠）→ 鞋與防滑（結冰路面、當地買鞋底防滑套）→ 配件（帽、耳、圍巾、手套）
   - 11 月去的優缺點 → 周邊行程 → FAQ（看得到雪嗎、自駕、要不要買雪靴、交通會不會停）
2. FUN! JAPAN（旭川冬天）
   - 開頭：先承認冬天冷，再翻轉說冷但好玩，列出雪像、冰雕、點燈、雪上運動
   - 冬天做什麼 → 冬まつり（會場、交通、時間）
   - 最後才是天氣：一句溫度範圍 → 穿著（鞋最先，接襪子、手套、圍巾、蓋耳朵的帽子，最後內層）
3. tsunagu Japan（北海道逐月）
   - 開頭：一個冬天的畫面 → 反問其他月份呢 → 預告逐月介紹
   - 1 月到 12 月各一個標題，每月固定：溫度範圍 → 穿著建議 → 當月活動
   - 結尾一段總結冬天怎麼穿與夏天的好處
4. Funliday（札幌冬天穿搭）
   - 開頭：北海道冬天很美 → 但冷，穿對很重要 → 預告幫你準備
   - 12、1、2 月各一塊，每塊：平均氣溫、高低溫、雪量的數字標籤 → 穿著
   - 通用的外套、褲子、鞋子建議 → 男女穿搭清單（外套 → 上衣 → 褲子 → 鞋 → 配件）

## 開頭怎麼寫

- 四篇都先講讀者的心情或期待（想看雪、冬天很美、冷但好玩），再帶到天氣；只有 UpToGo 在第二段就把讀者的問題直接寫出來並馬上回答。
- 數字很少出現在開頭第一段；UpToGo 第一個數字（年均溫）在第一個標題底下。
- 本頁現在的開頭用零下 41.0°C 紀錄起頭，競品沒有人用紀錄開場。讀者搜「旭川天氣」最先想知道的是「去的那個月有多冷、要怎麼穿」，紀錄可以往後放進冬天那一節（作者決定，標題不動）。

## 關鍵問題怎麼回答

- **各月氣溫與雨雪**：競品不是整年表格（tsunagu 逐月段落、Funliday 只給冬天三個月的數字塊），UpToGo 的表格是城市比較不是月份。順序都是「平均或高低溫 → 會不會下雪、雪多深 → 穿什麼」。本頁的 12 個月表格是競品沒有的，是本站獨有的資料，可以照現在放在第一個 H2。
- **冬天有多冷、雪多深、怎麼穿**：先溫度（多半給範圍），接著講路面（結冰、滑）→ 鞋，再講身體的層次與配件。FUN! JAPAN 與 UpToGo 都把鞋或防滑放在很前面；UpToGo 把「室內暖氣強，所以要好穿脫的洋蔥式」放在穿著的第一句當理由。
- **夏天熱不熱**：tsunagu 只用一兩句帶過夏天涼爽、早晚涼；競品都沒寫近年高溫紀錄。順序是「白天溫度 → 早晚差 → 帶一件外套」。
- **鑽石塵**：四篇都沒寫。是本站獨有的內容。
- **冬季活動與交通受天氣影響**：UpToGo 放在 FAQ 最後一題，順序是「11 月不太會大規模停 → 1、2 月暴風雪可能停 JR、封高速、航班取消 → 出發前看預報與交通動態」。FUN! JAPAN 的冬まつり段落只講交通怎麼去，沒講天氣影響。
- **春秋與初雪**：UpToGo 用旬別（上、中、下旬）講秋冬交界，順序是「初雪什麼時候 → 會不會積 → 什麼時候開始不融」。tsunagu 春天講融雪泥濘與溫差、秋天講紅葉到初雪。

## 段落與句子的習慣

- 稱呼讀者用「您」或「你」「大家」，常用「建議」「務必」「一定要」的提醒句；本站不學強調語氣，但「建議」放在數字後面一句的節奏可以參考。
- 句子：UpToGo、Funliday 偏長、逗號多；tsunagu 段落短、一段講一件事。
- 數字放法：溫度多寫成範圍（「約 2 到 5 度」）放在一段的第一句，接著馬上講體感或該怎麼辦。很少一段塞三個以上的數字。
- 轉場：常用「不過」「因此」「到了○月」接季節變化；月份或旬別本身就是轉場。
- 穿著常用條列（內層、中層、外層；上身、下身、鞋、配件）。

## 給作者的順序建議

標題照現在的 `draft-tagged.md`，不改。

- **開頭（H1 下）**：先回答讀者最想知道的「冬天多冷、雪多深、夏天怎樣」，再提零下 41.0°C 紀錄（或把紀錄留在冬天那一節）。平年值是什麼、出發前看預報，放開頭第二段可以。
- **旭川天氣，各月平均氣溫與雨雪**：①一句講全年的溫差與雪季長度 → ②表格 → ③表格怎麼讀（全年最深積雪那一列）→ ④雨最多的季節與冬天日照短。現在的順序已經接近，表格前的引言不要放太多數字。
- **旭川冬天溫度與積雪**：①多冷（白天也在冰點下）→ ②雪多深、下多久 → ③紀錄與都市化放後面。動物園休園與內連句放最後。
- **旭川冬天怎麼穿**：競品的順序是「先講為什麼要這樣穿 → 鞋與防滑 → 身體層次 → 配件」。建議①用早上的溫度定基準 → ②鞋（防水、防滑、鞋筒高，因為地上一整季有雪）→ ③外套與內層 → ④帽子手套（戶外待很久）→ ⑤風不大但清晨更冷 → ⑥3 月也是冬天。現在鞋放在段尾，可以往前移。
- **旭川冬天早上的鑽石塵**：①是什麼 → ②什麼條件、什麼時候 → ③怎麼挑日子出門。現在的順序可以留。
- **暴風雪對冬季活動與交通的影響**：照 UpToGo FAQ 的節奏，①平常風不大 → ②遇到暴風雪預報活動會改（冬まつり例子）→ ③飛機與 JR 怎麼查。現在的順序可以留。
- **旭川夏天的氣溫**：①白天溫度與早晚差 → ②怎麼穿 → ③近年變熱 → ④雨具。現在近年紀錄那段數字很多（96 天、37 天、63.0 天、10.9 天、25.3°C、4.0 天、5.4 天），可以刪到只留讀者用得到的幾個。
- **旭川春秋的氣溫與初雪**：春天①4 月還是冬天 → ②櫻花 → ③5 月回暖；秋天①9 到 10 月降溫 → ②紅葉 → ③初雪、積雪、根雪 → ④11 月就照冬天準備。現在秋天那段紅葉插在初雪前面，可以照時間順序排（紅葉 10/23 在初雪 10/19 之後，作者決定照日期還是照讀者先想知道的）。

## 他們有、我們缺的

- **室內暖氣強，要穿好穿脫的層次**：UpToGo 放在穿著第一句。沒有找到官方來源，事實表沒有，不寫。
- **鞋底防滑套可以在當地便利商店或土產店買**：UpToGo 有，還寫了價格。沒有找到旭川或北海道給旅客的官方頁，不寫。
- **結冰路面怎麼走（小步、整個腳底著地、斑馬線特別滑）**：競品沒寫細，但讀者會在意。官方資料只找到札幌市、函館市與北海道勞動局給居民的宣導 PDF，不是旭川也不是給旅客；適合以後的共用教學頁，這頁不加。
- **牛仔褲不夠暖、要加保暖褲**：UpToGo、Funliday 都有，屬穿著判斷；沒有官方來源，不寫。
- **11 月上、中、下旬的雪況差別**：UpToGo 有。我們有初雪 10/19、積雪 11/4、根雪 11/24（F477）與 11 月冰點下 20.2 天（F470），作者可以用這幾筆把 11 月講清楚，不需要新事實。
- **冬まつり 2027 年的日期**：FUN! JAPAN 寫冬まつり很多。官網已公布第 68 屆 2027-02-06～02-11（F490），日期歸 `asahikawa` 頁。
