# 旭川天氣 資訊順序筆記（重寫，2026-11-02）

照 `competitor-notes.md` 排順序，事實只用 `reference-review.md`。標題沿用網站上的版本，一字不改。

## 開頭（H1 下）

- 順序：盆地的身分與冬冷夏熱 → 冬天多冷（12～3 月冰點下、清晨近零下 12°C）→ 雪多深 → 怎麼穿的結論（照早上零下 10°C 以下準備、鞋要能走雪地）→ 夏天一句 → 第二段平年值與出發前看預報。
- 依據：筆記「開頭」一點，讀者最先想知道去的那個月多冷、怎麼穿；競品沒有人用紀錄開場，所以零下 41.0°C 從第一句移到冬天那一節。

## 旭川天氣，各月平均氣溫與雨雪

- 順序：一句溫差與雪季長度 → 表格 → 全年最深積雪怎麼讀 → 雨最多的季節與冬天日照短 → 連回主頁。
- 依據：筆記建議表格前的引言不要放太多數字，拿掉年均溫與全年降雪（都在表格全年列）。表格照原位，是本站獨有的資料。

## 旭川冬天溫度與積雪

- 順序：多冷（白天也在冰點下）→ 雪多深、下多久 → 零下 41.0°C 紀錄與都市化 → 動物園冬季時間與兩句連結句。
- 依據：筆記「①多冷 → ②雪多深 → ③紀錄放後面，動物園與內連放最後」。

## 旭川冬天怎麼穿

- 順序：用早上溫度定基準 → 鞋（防水、防滑、鞋筒高）→ 外套與內層 → 帽子手套（戶外待很久）→ 風不大但清晨更冷 → 3 月也是冬天。
- 依據：筆記「先講為什麼 → 鞋與防滑 → 身體層次 → 配件」，鞋從段尾移到第二段。室內暖氣、防滑套、結冰路面怎麼走沒有官方來源，不寫。

## 旭川冬天早上的鑽石塵

- 順序不變：是什麼 → 什麼條件、什麼時候 → 怎麼挑日子出門。競品沒寫，本站獨有。

## 暴風雪對冬季活動與交通的影響

- 順序不變：平常風不大 → 暴風雪預報時活動會改（2026 年冬祭例子）→ 飛機 → JR 怎麼查 → 連到交通頁。照 UpToGo FAQ 的節奏。

## 旭川夏天的氣溫

- 順序：白天溫度與早晚差 → 熱帶夜 0 天 → 怎麼穿 → 近年變熱 → 雨具。
- 依據：筆記建議近年紀錄的數字刪到讀者用得到的。刪掉 2021 年 35°C 以上 10 天、2025 年 30°C 以上 37 天（與 1928 並列）、30°C 平年 10.9 天、2025 年 7 月月均 25.3°C，留 37.9°C 最高紀錄、2025 年 25°C 以上 96 天對平年 63.0 天，以及平年 7、8 月 30°C 以上天數（決定短袖帶幾件）。

## 旭川春秋的氣溫與初雪

- 春天：4 月還是冬天 → 櫻花 → 5 月回暖（拆成兩段）。
- 秋天：9～10 月降溫 → 初雪 10/19 → 紅葉 10/23、落葉 11/2 → 11 月單獨一段講積雪 11/4、根雪 11/24、早上冰點下天數 → 11 月照冬天準備。
- 依據：筆記建議照時間順序；原稿紅葉插在初雪前面，改成照日期排。11 月用 UpToGo 的旬別思路，只用 F477、F470、F120 講「初雪後要兩週左右才積得住、下旬就不融」。
