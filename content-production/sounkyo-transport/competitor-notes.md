## 開頭怎麼寫

- 來一球叭噗：先一句點出層雲峽在哪、有什麼季節亮點，緊接著丟出「沒有 JR 車站」這個讀者最容易誤會的事，再列可行的方式；第二段給判斷標準（只逛溫泉街就搭大眾交通、要跑外圍才自駕），最後預告會講哪些出發地。
- Funliday、FunTime：沒有引言，標題下直接進條列或表格。
- WAmazing：開頭第一句就是「有直達巴士」，口氣平實。
- 共通點：讀者最想先知道的是「能不能直達、沒有火車要怎麼辦」，其次才是車程與車資。本站現在的開頭（不通鐵路、上川轉巴士 → 直達一天幾班、多久、多少錢 → 回程收得早）方向一致。

## 關鍵問題怎麼回答

- **① 旭川到層雲峽**：競品順序幾乎一致：搭車地點（站名、幾號乘車處、怎麼走過去）→ 下車站 → 車程 → 車資 → 一天幾班或時刻表 → 末班提醒。來一球叭噗用表格放票價與車程；Sophie 用截圖放時刻表。沒有一篇手打完整時刻表。
- **② 札幌、新千歲**：來一球叭噗先講兩條轉乘路線的差別（經旭川轉直達巴士、經上川轉巴士），再說札幌當天來回很趕，最後推一日遊或住一晚。機場分旭川機場、新千歲機場兩節，各自「先到旭川站，再接上面的巴士」。
- **③ JR 到上川轉巴士**：Sophie 順序是 出站往哪邊走 → 巴士站在哪 → 車程與車資 → 火車錯過一班要等很久。來一球叭噗另起一節「適合搭 JR 的人」，先說誰適合，再給搭車方式。
- **④ 網路票**：五篇正文都沒寫。只有來一球叭噗留言區提到可以線上付款。這是本站獨有的內容，應放前面、寫細。
- **⑤ 冬天自駕**：競品只給各地開車多久的表（來一球叭噗），或一句車程；冬胎、封路、查路況都沒寫。自駕表的順序是 出發地 → 距離 → 時間。
- **⑥ 阿寒湖、北見**：來一球叭噗的 Sunrise 號一節順序是 路線與營運公司 → 搭車處 → 票價 → 班次 → 車程 → 預約方式，用表格。
- **⑦ 回旭川末班**：來一球叭噗只提醒「旭川往層雲峽的末班」，回程末班沒有任何一篇寫清楚。本站獨有。
- **⑧ 大雪湖、銀泉台、高原溫泉**：只有 WAmazing 在瀑布段提到往大雪湖方向的巴士與瀧見台下車；銀泉台、高原溫泉沒有競品寫交通。本站獨有。

## 段落與句子的習慣

- 句子中等長，資訊用逗號串成一串，概數前面習慣加「約」。表格裡只放短詞。
- 稱呼讀者多用「旅客」「大家」「自由行的人」，部落客才用「你」；本站照自己的規則，不用第一人稱、不寫成去過。
- 轉場靠條件句分流：「如果從○○出發」「想省轉車的話」「搭 JR 的人」——每節先說這節是給誰的，再給做法。這一點值得學。
- 數字放在句子後半：先講在哪上車、坐到哪，再講多久、多少錢。
- Sophie 的地標式指路（出站往右手邊走一小段）讀者很受用，但本站沒有站內方向的事實，不學內容，只學「上車處在前、車程在後」的順序。
- 常見問題一節（來一球叭噗）本站規則不設，不學。

## 給作者的順序建議

標題照現在的 `draft-tagged.md`，只建議每節裡先講什麼。

- **開頭兩段**：照現在：不通鐵路 → 兩種走法（直達巴士、JR 轉上川）→ 一天幾班、多久、多少錢 → 回程收得早。可以在第一段就說「只逛溫泉街與黑岳搭巴士就夠」這類判斷，前提是有事實撐。
- **旭川到層雲峽的道北巴士**：1. 在哪上車（Bus Touch 8 號）、坐到哪下（終點「層雲峡」、走到纜車 5 分）。2. 車程、車資、一天幾班，然後才放時刻表。3. 當天來回怎麼排、末班一句，最後是行李。內連句（層雲峽值得去嗎、旭川交通）放在讀者還在決定的位置，不要夾在時刻表中間。
- **道北巴士網路票怎麼買、怎麼用？**：1. 一句說它是什麼、跟付現金比有什麼差（價格一樣、先付清、不用註冊）。2. 怎麼買（日文按鈕對照表、信用卡、收信信箱）。3. 搭車當天怎麼用（整理券 → 叫出票券 → 給司機看）。4. 例外（單程、多人同班、改班次、手機沒電）。競品都沒寫，順序照讀者實際操作走。
- **札幌到層雲峽，經旭川或上川轉巴士**：1. 先說兩條路的差別與適合誰（不想轉兩次就經上川直通オホーツク；班次多就經旭川）。2. 早上、下午各一個能接上的組合。3. 開車一句、旅館接駁一句帶過連到住宿頁。
- **搭 JR 到上川站轉巴士**：1. 先說這條是給誰的（手上有 JR 票、或剛好沒有直達車的時段）。2. 上川巴士站在哪、車程與車資。3. 轉乘表。4. 好接與不好接的班次、最晚的組合。5. 回札幌的銜接。
- **從新千歲機場或旭川機場出發**：照競品「先到旭川站，再接上面的巴士」：機場 → 旭川站的方式一句 → 接道北巴士一句 → 計程車。新千歲到旭川的細節歸旭川交通，不展開 F221 的增班。
- **開車去層雲峽，冬天的路況與封路**：1. 各地距離與時間（競品也是先給這個）。2. 冬胎（10 月下旬就積雪）。3. 臨時封路與查路況。讀者第一個想知道的是「多久」，第二才是「冬天能不能開」。
- **到了層雲峽，往大雪湖、銀泉台與高原溫泉**：先講現在（11 月起）三處都去不了或沒有公車，再講夏秋的季節安排。大雪湖班 10/31 已結束，時態改成已結束、隔年再看。
- **層雲峽到阿寒湖、北見的Sunrise號**：照來一球叭噗的順序：路線與營運公司 → 一定要預約 → 時刻表 → 車資與車程 → 怎麼買票、在哪上車 → 不能搭的區段與誤點。現在稿子大致如此，可把「一定要先預約」再往前提。
- **從層雲峽回旭川的末班車**：先給答案（直達末班 17:00），再給錯過後的走法與表，最後兩句內連。競品沒有，維持現在的順序。
