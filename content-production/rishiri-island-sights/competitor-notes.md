## 2. 各篇的順序

**A（Funliday 10選）**
1. 開頭讚美山海與季節活動，預告會寫景點、美食、交通、行程。
2. 怎麼去利尻島（渡輪、機票）。
3. 姬沼 → Otatomari 沼 → 白色戀人展望台 → 神居海岸公園 → 仙法志御崎公園 → 沓形岬 → 夕陽之丘 → Peshi 岬 → 兩家店。
4. 常見問題 6 題，接著一長串推廣區塊。
- 每個景點內部：先寫看得到什麼（倒影、海豹、包裝由來），再一句怎麼去（哪站下車、走幾分鐘），最後條列地址、開放時間、交通。

**B（FUN! JAPAN）**
1. 島在哪、名字由來、從稚內船程多久。
2. 島的介紹：人口、國立公園、利尻山、登山與花季。
3. 觀光巴士：誰營運、為什麼要預約 → 兩條路線各經過哪裡、多少錢 → 哪幾個月跑 → 提醒看官網。
4. 滑雪。
5. 相關資訊條列。

**C（方格子全攻略）**
1. 情感開頭，列出讀者會來的理由。
2. 最佳季節。
3. 交通：先登島（飛機或船）、再島上移動（租車、機車、自行車、公車、計程車）。
4. 季節活動。
5. 必去景點 10 個：一句定位 → 作者經驗 → 注意事項。
6. 吃、住、打工度假、給第一次去的人、附錄計程車。

## 3. 開頭怎麼寫

- A：先描繪島的山海與能做的事，再預告整篇內容，景點本身到第三節才出現。
- B：直接用地理資訊起頭（島在哪、離港多遠），沒有勾子。
- C：用「為什麼想去」起頭，把讀者分成想吃海膽、想爬山、想放空幾種人。
- 三篇的開頭都沒回答「沒車到得了嗎」「幾月開」，這兩件事散在後面。本站開頭直接回答這兩題，是和競品最大的差別，順序保留。

## 4. 關鍵問題怎麼回答

**開放期間**
- A：每個景點的資訊條列裡放一行開放月份，沒有總表；冬季開放與夏季開放混在同一格式，讀者要自己比。
- B：只講觀光巴士哪幾個月跑，景點開放不談。
- C：用「冬天很多店休、船班變少」一句總結，沒有逐點。
- 讀者期待的順序：先一句「大多 5 月到 10 月」→ 例外（全年的溫泉、博物館）→ 逐點表格。沒有一篇用表格，本站的總表是加分。

**沒車怎麼去**
- A：放在每個景點底下，寫法固定是「搭公車在○○站下車，走約幾分鐘」。
- B：先講觀光巴士（兩條路線、價格、季節），路線巴士不談。
- C：交通一節先講租車、再講自行車、公車當備用、最後計程車難叫。
- 讀者期待的順序：先說「觀光巴士一趟繞完主要景點」→ 再說路線巴士（哪幾個景點有站牌、一天幾班）→ 最後是計程車與自行車補位。三篇都沒列路線巴士時刻，本站的時刻表是獨有資料，放在說明繞法之後。

## 5. 段落與句子的習慣

- A：句子長，用頓號串很多子句；口吻熱絡，有驚嘆號與括號裡的玩笑。數字集中在條列，正文少。
- B：中等句長，用「您」，給建議時用「務必」「不要錯過」。數字放正文裡（票價、距離、時間）。
- C：短句、口語、表情符號，第一人稱經驗多；數字放在注意事項裡。
- 共同點：景點段落都先講「看得到什麼」，再講交通。轉場多直接換下一個景點，不寫過渡句。
- 本站不學：驚嘆號、第一人稱經驗、「您」、推廣區塊。可以學：景點段第一句先給畫面（看得到什麼），交通放第二句。

## 6. 給作者的順序建議

標題照現在的 `draft-tagged.md`，不改。

- **開頭（H1 下）**：維持先回答沒車與開放期間；第二段的觀光巴士運行日期可以縮到一句，細節留給後面兩個 H2。
- **利尻島景點有哪些？**：先一句分類（沼、岬、湧水、資料館、溫泉）→ 沒車只有半天最好排哪三處 → 總表。兩個町的分法可以挪到表格前一句或刪短，讀者先想知道「哪些值得去」。
- **各景點 H3**：競品一致是「看得到什麼 → 怎麼去 → 開放期間與設施」。目前姬沼、Otatomari 沼、仙法志御崎公園都是先講由來或周長，可改成先一句畫面（新增 F201、F202、F204 的湖面倒影、熔岩奇岩、透明海水），再接站牌與開放期間。Peshi 岬先講在港邊、看得到什麼（F203），再講步道危險。沓形岬公園現在只有位置與電話，用 F200 先講看夕陽、看得到禮文島，再講展望台要先問。
- **白色戀人之丘與包裝那節**：A 是先講包裝由來再講展望台。本站兩節分開，維持現在順序即可。
- **利尻島景點沒車怎麼去？**：照讀者期待，觀光巴士 → 路線巴士（站牌、班次、付款）→ 時刻表與繞法 → 逐點表 → 計程車與自行車。B 路線也經過仙法志御崎公園與 Otatomari 沼（官方コース一覧），寫 B 路線時可一併提。
- **利尻島景點的開放期間**：先總結（大多 5～10 月）→ 表 → 不自己開車哪幾個月最好排 → 冬天還能去哪。現在順序已經符合，不用動。
