# 利尻島景點，開放期間與沒車怎麼去

搭渡輪抵達鴛泊港、手上沒有車，利尻島的沼、岬角與展望台還是看得到，只是要照巴士時刻排。這些景點散在標高1,721公尺、別名「利尻富士」的利尻山山腳與海岸，路線巴士繞島一圈約1小時45分到2小時15分。

利尻島景點大多只在5月到10月開放，姬沼的步道、Otatomari沼與仙法志御崎公園都是。這三處都有路線巴士站牌，定期觀光巴士利尻A路線也一趟繞完，2026年在5月3日到5日與5月20日到9月30日行駛。

還沒決定要不要排利尻島，可以先看利尻島值得去嗎。

## 利尻島景點有哪些？

利尻島景點有看山的沼與展望台、海岸的岬角與奇岩、湧水、資料館，還有可以收尾的溫泉。島分屬兩個町，北邊與東側的鴛泊、鬼脇是利尻富士町，西側與南側的沓形、仙法志是利尻町。渡輪靠岸的鴛泊港旁就是Peshi岬。甘露泉水與Pon山則要從鴛泊這一側的登山口往上走。

只有半天又沒開車，姬沼、Otatomari沼與仙法志御崎公園最好排。路線巴士與觀光巴士利尻A路線都到得了。

### 姬沼

姬沼原本是三個沼，大正時代攔住湧水才合成一個，名字取自當年放養的姬鱒。沼的周圍有一圈約1公里的步道，只在5月到10月開放。停車場裡有公廁，沼前有商店。從姬沼還有一條探勝步道通往Pon山。路線巴士的站名是姬沼口（姫沼口），從站牌走到沼邊的路線與時間，下車前用Google地圖查好，排回程班次時一起算進去。

| 設施 | 停車場公廁、沼前商店 |

### Pon 山

爬Pon山從北麓野營場出發，也就是利尻山鴛泊登山口所在的地方，單程約1小時。往返約2到3小時，途中會經過甘露泉水。從鴛泊渡輪站走到北麓野營場是3.6公里、約60分鐘。從溫泉（温泉）巴士站走過去近一些，2.2公里、約40分鐘。北麓野營場10月17日到隔年5月14日冬季封閉，這段期間打算走Pon山，出發前到鴛泊渡輪站的觀光案內所確認。

也可以從姬沼那頭沿探勝步道走上來，姬沼口有路線巴士站牌。姬沼往Pon山的探勝步道中途設有攜帶式廁所用的隔間，裡面沒有衛生紙。攜帶式廁所在哪裡買，見利尻山登山。

### Otatomari 沼

島上最大的湖沼是Otatomari沼，周長約1公里，繞著看一圈大約30分鐘。沼在島的東南、鬼脇一帶，路線巴士設有Otatomari沼站。

沼畔的利尻富士町休憩所（利尻富士町レストハウス）只在觀光季營業，8:00到17:00。伴手禮店利尻龜一（利尻亀一）從4月中旬開到10月下旬，9:00到17:00營業，搭觀光巴士在Otatomari沼下車時可以順便逛。

### 白色戀人之丘

白色戀人之丘就是沼浦展望台，從鴛泊渡輪站開車約35分鐘，有可以停10台車的免費停車場。在這裡求婚、拍下照片，帶到利尻富士町觀光協會，就能領到石屋製菓認可的「求婚證明書」。

展望台和Otatomari沼同在鬼脇的沼浦，從沼浦露營場入口旁的坡道往上，可以望見Otatomari沼後方的利尻山。11月上旬到隔年4月下旬封閉。沒有自己的車，可以搭路線巴士到Otatomari沼站，再用Google地圖確認能不能走上坡道，或直接搭計程車。

### 白色戀人包裝上的利尻山

北海道點心「白色戀人」包裝上的那座山就是利尻山，石屋製菓選它，是因為積雪的樣子讓人聯想到歐洲的阿爾卑斯山。2026年12月起包裝逐步換新，利尻山改成更抽象的插畫，這個冬天買到的新舊包裝都有可能。

### 南濱濕原

南濱濕原長滿水苔，是島上最大的高層濕原，約1公里的步道走一圈大約30到40分鐘。濕原在鬼脇的南濱，路線巴士也有南濱（南浜）站，不開車可以用Google地圖查從站牌走過去的路線。

### 仙法志御崎公園

仙法志御崎公園在利尻島最南端，5月到10月開放，園內有公廁。園內有海豹池，餵斑海豹的時間約在6月到9月的8:00到17:00，飼料一份100日圓，在隔壁的Misaki物產（みさき物産）買。視狀況海豹也可能不在，5月和10月造訪時公園開著，但不一定餵得到。

### 人面岩、寢熊岩與北之嚴島辯天宮

人面岩、寢熊岩與北之嚴島辯天宮都在西海岸的仙法志，三處常一起看。辯天宮位在仙法志的久連，路線巴士也有「久連」站，沒車可以用Google地圖查從這站走過去的路線，或搭計程車。

### 甘露泉水

甘露泉水入選日本名水百選，位在利尻山鴛泊登山路線的3合目附近。開車可以停在利尻北麓野營場，不過野營場10月17日到隔年5月14日冬季封閉。排Pon山時會順路經過，要繼續登上利尻山頂，路線與時間見利尻山登山。

### 麗峰湧水

麗峰湧水在西海岸仙法志的道道108號旁，湧出的地下水可以自己裝走。所在地是仙法志的神磯，路線巴士也有「神磯」站。

### Peshi 岬

鴛泊港旁那座約90公尺高的岩山就是Peshi岬，5月到10月開放，是島上看日出的好地方。住在鴛泊，清晨可以上去看。步道又窄又陡，天氣不好的日子上去很危險。

### 夕日之丘展望台

鴛泊一帶的夕日之丘展望台，從停車場沿坡道往上走約5分鐘就到，5月到10月開放，下雪後關閉。沒車的話搭計程車前往。

### 富士野園地

鴛泊一帶的富士野園地長滿一大片萱草，花期在6月下旬到7月中旬，園地5月到10月開放。這幾週島上的海岸與濕原也會被萱草染成一片橘色，想看花就排在這段時間。

### 野塚展望台

野塚展望台在鴛泊的野塚，道路對面的野塚駐輪駐車公園是利尻島自行車道的起點，也是看利尻山的地點之一。路線巴士也有「野塚」站。觀光巴士利尻A路線會經過這裡，但只從車窗看。自行車道11月上旬到隔年4月下旬冬季封閉。

### 沓形岬公園

沓形岬公園在沓形的富士見町，和利尻Fureai溫泉在同一區。想登上園內的展望台，出發前打電話問利尻町觀光案內所0163-84-2349，或在鴛泊渡輪站的觀光案內所確認能不能上去。

### Kamui Terrace

Kamui Terrace在沓形的神居，是面海的觀景台，也是看夕陽的好去處，有公廁，參觀約20分鐘。開放期間大約是4月到11月，11月中旬到3月左右冬季封閉。

### 見返台園地

見返台園地在利尻山標高約500公尺的5合目，往返展望台約30到50分鐘。5月中旬到10月中旬可以上去，冬天積雪封路。5月中旬開放後，山麓還有殘雪，可以在這裡玩雪。

見返台也是沓形路線的登山口。島上的住宿幾乎都有登山口接送，但只送自己這一區，鴛泊的住宿不會送到見返台，住沓形這一側比較有機會。

### 利尻島鄉土資料館

利尻島鄉土資料館用的是1913年建成的舊鬼脇村公所，參觀約30分鐘。5月到10月開館，時間是9:00到17:00，週二與假日隔天休館，7月與8月無休。11月到隔年4月閉館。資料館在鬼脇，觀光巴士利尻B路線8月到9月會停，路線巴士也有「鬼脇」站。

### 利尻町立博物館

利尻町立博物館9:00到17:00開館，16:30停止入館，門票200日圓，高中生以下免費。週一、假日隔天與年底年初休館，另有臨時休館日，出發前看官網的開館日曆。博物館和仙法志御崎公園同在仙法志，觀光巴士利尻B路線6月到7月會停。

### 利尻 Art & Visitor Center

鴛泊的利尻Art & Visitor Center在5月1日到10月15日開館，時間是9:00到17:00，16:30停止入館。5月與10月每週一休館。館內附設介紹利尻山登山的利尻山遊客中心。打算登山，出發前一天可以到這裡看看路線介紹。

### 利尻富士溫泉與利尻 Fureai 溫泉

利尻富士溫泉保養設施從中午營業到21:00，最後入場20:30，大人500日圓。旁邊的足湯6月到10月底免費，水溫約35°C。

沓形的利尻Fureai溫泉全年營業，13:00到21:00，露天風呂只在5月到10月開放。11月到隔年4月，利尻富士溫泉每週三休館，這天想泡湯就改去Fureai溫泉。

## 利尻島景點沒車怎麼去？

利尻島的主要景點，不開車也能逛。5月到9月有定期觀光巴士，10月以後靠路線巴士與計程車。環島巴士與觀光巴士見利尻島交通。

觀光巴士利尻A路線從鴛泊渡輪站出發，一趟繞過姬沼、Otatomari沼、仙法志御崎公園與利尻空港，野塚展望台從車窗看，大人3,500日圓。6月1日到9月30日是9:05出發、12:15回到鴛泊，5月3日到5日與5月20日到31日提早到8:35出發、11:45回來。利尻B路線只在6月1日到9月30日行駛，13:45從沓形渡輪站出發，16:15到鴛泊渡輪站，大人3,300日圓。B路線6月到7月停利尻町立博物館，8月到9月改停利尻島鄉土資料館。

從稚內搭船到鴛泊，要自己移動到沓形才搭得上B路線。夏天鴛泊13:00開的經沓形路線巴士13:40停沓形渡輪站，車資860日圓。時刻表上的「沓形」是下一站的市區站牌，要在沓形渡輪站下車才接得上13:45的B路線。上午搭A路線、下午接B路線，一天就能把兩條繞完。

觀光巴士是預約制，乘車日前2個月開放預約，可以打電話或用巴士訂票網站Hassha Orai Net（発車オーライネット）訂。鴛泊渡輪站1樓的觀光案內所也能預約與買票。

路線巴士分成鴛泊出發經鬼脇繞島的「鬼脇経由」，以及反方向經沓形繞回鴛泊的「沓形経由」。6月1日到9月30日的夏季各5班，10月1日到隔年5月31日的冬季各4班，每年1月1日到3日全部停駛。車資付現金或PayPay，車上換零錢只收千圓鈔，坐滿一圈以上再買2,500日圓的一日券，它也不能用在觀光巴士。沓形、鴛泊、仙法志、鬼脇市區以外的路段可以舉手攔車、跟司機說要下車，但彎道、隧道與視線差的地方司機可能拒絕。

三處有站牌的景點，照兩種繞法整理成時刻表，夏季是6月1日到9月30日，冬季是10月1日到隔年5月31日。

## 利尻島景點的開放期間

利尻島景點大多在5月到10月開放，11月以後陸續封閉，多數要等到隔年4月下旬或5月才重新開放。

| 景點或設施 | 開放期間或冬季封閉 |
|---|---|
| 姬沼 | 5月～10月，11月～4月封閉 |
| Otatomari沼 | 5月～10月 |
| 白色戀人之丘 | 11月上旬～4月下旬封閉 |
| 仙法志御崎公園 | 5月～10月 |
| Peshi岬 | 5月～10月 |
| 夕日之丘展望台 | 5月～10月，下雪後關閉 |
| 富士野園地 | 5月～10月，萱草6月下旬～7月中旬 |
| 見返台園地 | 5月中旬～10月中旬 |
| Kamui Terrace | 4月～11月左右，11月中旬～3月左右封閉 |
| 利尻北麓野營場（甘露泉水、Pon山的停車處） | 10月17日～5月14日冬季封閉 |
| 利尻島自行車道 | 11月上旬～4月下旬封閉 |
| 利尻島鄉土資料館 | 5月～10月，11月～4月閉館 |
| 利尻Art & Visitor Center | 5月1日～10月15日，5月與10月週一休館 |
| 利尻町立博物館 | 週一、假日隔天、年末年始休館，另有臨時休館 |
| 利尻富士溫泉 | 11月～4月每週三休館 |
| 利尻Fureai溫泉 | 全年，露天風呂5月～10月 |
| 仙法志御崎公園的餵海豹 | 6月～9月左右 |
| 定期觀光巴士利尻A路線 | 2026年5月3日～5日、5月20日～9月30日 |
| 定期觀光巴士利尻B路線 | 6月1日～9月30日 |

這些景點全部都開著的時段是5月中旬到10月中旬，見返台園地與北麓野營場開得最晚，利尻Art & Visitor Center與見返台園地關得最早。不自己開車，6月到9月最好排，觀光巴士A、B兩條都在跑，兩條都只到9月30日。RISHIRI ACTIVITY的自行車租借2026年也在9月30日結束。10月景點多半還開著，但這兩樣都停了，移動改靠路線巴士與計程車。

11月到隔年4月，沼與展望台大多封閉。這段時間還能去的有利尻町立博物館、全年營業的利尻Fureai溫泉，以及週三以外的利尻富士溫泉。
