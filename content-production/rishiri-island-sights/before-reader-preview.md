# 利尻島景點，開放期間與沒車怎麼去

利尻島位在日本最北的國立公園範圍內，島上的利尻山標高1,721公尺，是別名「利尻富士」的獨立峰。沼、岬角與展望台散布在山腳與海岸，搭路線巴士繞島一圈約1小時45分。

利尻島景點大多只在5月到10月開放，姬沼的步道11月到隔年4月封閉，Otatomari沼與仙法志御崎公園也只開5月到10月。不開車也去得了，路線巴士在這三處都設有站牌，6月到9月還有繞行這三處的定期觀光巴士。

還沒決定要不要排利尻島，可以先看利尻島值得去嗎。

## 利尻島景點有哪些？

利尻島景點有看山的沼與展望台、海岸的岬角與奇岩、湧水、資料館，還有可以收尾的溫泉。島分屬兩個町，北邊與東側的鴛泊、鬼脇屬於利尻富士町，西側與南側的沓形、仙法志屬於利尻町。渡輪抵達的鴛泊港旁就是Peshi岬，甘露泉水與Pon山也從鴛泊這一側的登山口出發。

只有半天又沒開車，姬沼、Otatomari沼、仙法志御崎公園最好排。三處都有路線巴士站牌，夏天的觀光巴士利尻A路線也一次繞完。

### 姬沼

姬沼是大正時代攔住湧水、把當時的三個沼合成一個而成的沼，名字來自當年放養的姬鱒。沼的周圍有一圈約1公里的步道，停車場裡有公廁，沼前有商店。

步道5月到10月開放，11月到隔年4月封閉。姬沼和Pon山之間另有一條探勝步道，中途設有攜帶式廁所隔間，不提供衛生紙。

| 項目 | 內容 |
|---|---|
| 日文名 | 姫沼 |
| 開放期間 | 5月～10月 |
| 步道 | 周圍約1公里 |
| 沒車怎麼去 | 路線巴士「姫沼口」站，從鴛泊渡輪站360日圓；觀光巴士利尻A路線 |
| 設施 | 停車場公廁、沼前商店 |

### Pon 山

Pon山從利尻山鴛泊登山口的北麓野營場出發，單程約1小時就能登上，往返約2到3小時，途中會經過甘露泉水。沒車的話，從鴛泊渡輪站走到北麓野營場是3.6公里、約60分鐘，從「溫泉」巴士站走過去是2.2公里、約40分鐘。

步道上沒有一般廁所，姬沼往Pon山的探勝步道中途只有攜帶式廁所隔間。從姬沼那頭走上來也可以，姬沼口有路線巴士站牌。

### Otatomari 沼

Otatomari沼周長約1公里，是利尻島最大的湖沼，繞著看一圈大約30分鐘。開放期間是5月到10月，路線巴士設有「オタトマリ沼」站，觀光巴士利尻A路線也會停。

沼畔的利尻富士町レストハウス只在觀光季營業，時間是8:00到17:00。伴手禮店利尻亀一4月中旬到10月下旬營業，9:00到17:00開門，搭觀光巴士停靠時可以順便逛。

| 項目 | 內容 |
|---|---|
| 日文名 | オタトマリ沼 |
| 開放期間 | 5月～10月 |
| 參觀時間 | 約30分鐘 |
| 沒車怎麼去 | 路線巴士「オタトマリ沼」站、觀光巴士利尻A路線 |
| 沼畔設施 | レストハウス 8:00～17:00（觀光季）、利尻亀一 9:00～17:00（4月中旬～10月下旬） |

### 白色戀人之丘

白色戀人之丘就是沼浦展望台，免費停車場可以停10台車，從鴛泊渡輪站開車約35分鐘。在這裡求婚並拍下照片，帶著照片到利尻富士町觀光協會，可以領到石屋製菓認可的「求婚證明書」。

展望台11月上旬到隔年4月下旬封閉。不開車的話，可以搭計程車前往，島上的計程車行鴛泊與沓形各有一家，清晨不營業。

| 封閉期間 | 11月上旬～4月下旬 |
| 停車場 | 免費10台 |
| 怎麼去 | 鴛泊渡輪站開車約35分鐘 |

### 白色戀人包裝上的利尻山

北海道點心「白色戀人」包裝上的那座山就是利尻山，石屋製菓說選它是因為積雪的樣子像歐洲阿爾卑斯山，拿來象徵西點。2026年12月起包裝會逐步換新，利尻山留在包裝上，但改成更抽象的插畫。這個冬天買到的，可能是舊包裝，也可能是新的。

### 南濱濕原

南濱濕原是島上最大的高層濕原，長滿水苔，約1公里的步道走一圈大約30到40分鐘。

### 仙法志御崎公園

仙法志御崎公園在利尻島的最南端，是有公廁的自然公園，5月到10月開放。園內有海豹池，飼料在園內的物產店買，可以餵斑海豹。

| 項目 | 內容 |
|---|---|
| 日文名 | 仙法志御崎公園 |
| 開放期間 | 5月～10月 |
| 沒車怎麼去 | 路線巴士「御崎公園」站、觀光巴士利尻A路線 |
| 看點 | 餵斑海豹，飼料在園內物產店買 |

### 人面岩、寢熊岩與北之嚴島弁天宮

人面岩、寢熊岩與北之嚴島弁天宮都在西海岸的仙法志，三處常被排在一起看，現場沒有停車場。

### 甘露泉水

甘露泉水是日本名水百選的湧水，位在利尻山鴛泊登山路線的3合目附近。開車的話停在利尻北麓野營場，但野營場10月17日到隔年5月14日冬季封閉。排Pon山時會順路經過，要繼續登上利尻山頂，路線與時間見利尻山登山。

### 麗峰湧水

麗峰湧水在西海岸仙法志的道道108號旁，湧出的伏流水可以自由取用帶走。

### Peshi 岬

Peshi岬是鴛泊港旁一座約90公尺高的岩山，也是看日出的名所，5月到10月開放。住在鴛泊想看日出，可以排在清晨上去。步道又窄又陡，天氣不好的日子上去很危險，這種時候就別勉強。

### 夕日之丘展望台

夕日之丘展望台從停車場沿坡道往上走約5分鐘，5月到10月開放，下雪後就關閉。

### 富士野園地

富士野園地是萱草的大群落，6月下旬到7月中旬開花，園地本身5月到10月開放。這段花期裡，島上的海岸與濕原也會被萱草染成一片橘色，想看花就排在這幾週。

### 野塚展望台

野塚展望台是利尻島自行車道的起點，也是看利尻山的地點之一。觀光巴士利尻A路線經過這裡，只從車窗看。自行車道11月上旬到隔年4月下旬冬季封閉。

### 沓形岬公園

沓形岬公園的展望台因為階梯破損，2025年8月起暫停進入，停車場、廁所與露營場照常使用。打算登上展望台，造訪前可以在鴛泊渡輪站的觀光案內所確認是否已重新開放。

### Kamui Terrace

Kamui Terrace是沓形面海的觀景台，也是看夕陽的地點，大約4月到11月開放，11月中旬到3月左右封閉。

### 見返台園地

見返台園地在利尻山的5合目，標高約500公尺，往返展望台約30到50分鐘。5月中旬到10月中旬可以上去，冬天因積雪封路。5月山麓還有殘雪，在這裡可以玩雪。

沓形路線的登山口就在見返台，島上幾乎所有住宿都提供登山口接送，但不跨區接送，住沓形一側比較有機會請住宿送上來。

### 利尻島鄉土資料館

利尻島鄉土資料館用的是1913年建成的舊鬼脇村公所，參觀約30分鐘。開館期間是5月到10月的9:00到17:00，週二與假日隔天休館，7月和8月無休，11月到隔年4月閉館。

### 利尻町立博物館

利尻町立博物館開館時間是9:00到17:00，16:30停止入館，門票200日圓，高中生以下免費。週一、假日隔天與年末年始休館。

### 利尻 Art & Visitor Center

鴛泊的利尻Art & Visitor Center在5月1日到10月15日開館，時間是9:00到17:00。館內附設介紹利尻山登山的利尻山遊客中心。打算登山，可以在出發前一天到這裡看路線介紹。

### 利尻富士溫泉與利尻 Fureai 溫泉

利尻富士溫泉保養設施從中午營業到21:00，20:30截止受理，大人500日圓。旁邊的足湯6月到10月底免費使用，水溫約35°C，也就是源泉原本的溫度。

沓形的利尻Fureai溫泉全年營業，時間是13:00到21:00，露天風呂只在5月到10月開放。11月到隔年4月的週三利尻富士溫泉休館，這天想泡湯就改去Fureai溫泉。

## 利尻島景點沒車怎麼去？

沒車也看得到利尻島的主要景點，6月到9月搭定期觀光巴士最省事，其他時間靠路線巴士、計程車或自行車。

觀光巴士利尻A路線在6月1日到9月30日從鴛泊渡輪站9:05出發，12:15回到鴛泊，大人3,500日圓。一趟繞姬沼、Otatomari沼、仙法志御崎公園與利尻空港，野塚展望台從車窗看。利尻B路線13:45從沓形渡輪站出發，16:15抵達鴛泊渡輪站，大人3,300日圓。B路線6月到7月停利尻町立博物館，8月到9月改停利尻島鄉土資料館。從稚內搭船到鴛泊的旅客，得自己移動到沓形才能搭B路線，住沓形的話這條最順。

觀光巴士是預約制，乘車日前2個月開始受理，可以打電話或用「発車オーライネット」訂。鴛泊渡輪站的觀光案內所也受理預約與售票。2026年的運行期間是5月3日到5日，以及5月20日到9月30日。

路線巴士分成從鴛泊經鬼脇繞島一圈的A路線，以及經沓形反方向繞回鴛泊的B路線，6月到9月各5班，10月到隔年5月各4班。繞島一圈約1小時45分，每年1月1日到3日全部停駛。一日券大人2,500日圓，在利尻營業所窗口或車上買，當天不限次數搭乘，但不能用在觀光巴士。從鴛泊渡輪站沿路坐一整圈的單程車資最高2,550日圓，坐滿一圈以上就是一日券划算。只去姬沼來回是720日圓，買單程票比較省。

在沓形、鴛泊、仙法志、鬼脇市區以外的路段，路線巴士可以在路邊舉手攔車，下車時口頭告訴司機。斑馬線前後、彎道、隧道和視線不好的地方，司機可能拒絕上下車，攔車要站在巴士前進方向道路左側的安全處。

| 景點 | 沒車怎麼去 |
|---|---|
| 姬沼 | 路線巴士「姫沼口」站、觀光巴士利尻A路線 |
| Otatomari沼 | 路線巴士「オタトマリ沼」站、觀光巴士利尻A路線 |
| 仙法志御崎公園 | 路線巴士「御崎公園」站、觀光巴士利尻A路線 |
| 野塚展望台 | 觀光巴士利尻A路線從車窗看 |
| 利尻町立博物館 | 觀光巴士利尻B路線，6月～7月停靠 |
| 利尻島鄉土資料館 | 觀光巴士利尻B路線，8月～9月停靠 |
| Pon山、甘露泉水 | 鴛泊渡輪站走到北麓野營場約60分鐘，從「溫泉」巴士站約40分鐘 |
| Peshi岬 | 在鴛泊港旁 |
| 見返台園地 | 沓形一側住宿的登山口接送 |

其他景點搭計程車或騎自行車前往，計程車行鴛泊與沓形各一家，清晨不營業。RISHIRI ACTIVITY在鴛泊與沓形都有租車點。電動自行車5、6、9、10月一天4,000日圓起，7月和8月是5,500日圓起。這家只收線上付款，不收現金，借車要上傳護照，2026年營業到9月30日。

環島巴士與觀光巴士見利尻島交通。

## 利尻島景點的開放期間

利尻島景點大多在5月到10月開放，11月以後陸續封閉，多數要等到隔年4月下旬或5月才重新開放。

| 景點或設施 | 開放期間或冬季封閉 |
|---|---|
| 姬沼 | 5月～10月，11月～4月封閉 |
| Otatomari沼 | 5月～10月 |
| 白色戀人之丘 | 11月上旬～4月下旬封閉 |
| 仙法志御崎公園 | 5月～10月 |
| Peshi岬 | 5月～10月 |
| 夕日之丘展望台 | 5月～10月，下雪後關閉 |
| 富士野園地 | 5月～10月，萱草6月下旬～7月中旬 |
| 見返台園地 | 5月中旬～10月中旬 |
| Kamui Terrace | 4月～11月左右，11月中旬～3月左右封閉 |
| 利尻北麓野營場（甘露泉水、Pon山的停車處） | 10月17日～5月14日冬季封閉 |
| 利尻島自行車道 | 11月上旬～4月下旬封閉 |
| 利尻島鄉土資料館 | 5月～10月，11月～4月閉館 |
| 利尻Art & Visitor Center | 5月1日～10月15日 |
| 利尻町立博物館 | 週一、假日隔天、年末年始休館 |
| 利尻富士溫泉 | 11月～4月每週三休館 |
| 利尻Fureai溫泉 | 全年，露天風呂5月～10月 |
| 定期觀光巴士 | 2026年5月3日～5日、5月20日～9月30日 |

列出的景點全部開放的時段是5月中旬到10月中旬，見返台園地與北麓野營場開得最晚、關得最早。沒車的話6月到9月最好排，觀光巴士只跑到9月30日。RISHIRI ACTIVITY的自行車租借，2026年也在9月30日結束。10月造訪時景點多半還開著，但觀光巴士與這家的自行車租借都已結束，移動改靠路線巴士和計程車。

11月到隔年4月沼與展望台大多封閉，還能去的是利尻町立博物館與全年營業的利尻Fureai溫泉。博物館的休館日只有週一、假日隔天與年末年始。
