## 各篇的順序

**Mimi韓**：值得去嗎 → 花期 → 交通停車 → 花田路線 → 美食伴手禮 → 周邊順遊 → FAQ。花期在交通前面，先讓讀者決定什麼時候去，再決定怎麼去。

**波比**：基本資訊框 → 農場介紹（花季總覽、免門票） → 花田逐區（花人之田、倖之花田、彩色花田） → 美食必買 → 交通 → 附近景點。交通放很後面，花田介紹在前面。

**滿分**：交通停車 → 農場外的哈密瓜店 → 園區環境（抵達、時間） → 導覽地圖（免門票、設施） → 彩色花田 → 薰衣草 → 咖啡伴手禮 → FAQ。交通開頭，照著自駕動線走。

**Claire**：交通（JR、慢車號、自駕） → 園區（入園、花況、時間、拍照、美食商店） → 資訊框。交通最前面，篇幅最長。

## 開頭怎麼寫

- Mimi韓：感官描寫開場（紫色波浪、香氣），然後預告內容架構，用第一人稱帶入。
- 波比：直接下推薦結論（「大推薦！」），馬上給花季重點（7 月中下旬），不講故事。
- 滿分：第一人稱遊記（「北海道旅行的第一站，我們來到…」），先講心情再講景點。
- Claire：感性開場（「此生必看的景點之一」），順帶提交通方便。

共同點：四篇都在前兩段就提到免門票，但沒有任何一篇把「免門票」當第一句話。

## 關鍵問題怎麼回答

### 門票
四篇都寫「免門票」「免費」，但都不是獨立段落，而是一兩句帶過。Mimi韓在「值得去嗎」段落裡寫，波比在介紹段落裡寫，滿分在導覽地圖段落寫，Claire 在園區段落一句帶過。沒有人和桃園富田花園農場做比較。

### 開放時間
沒有任何一篇列出完整的季節營業時間表。波比資訊框寫「約08:30–17:00 (會依季節微調)」，滿分寫「當日營業時間9:00~17:00」，Mimi韓完全沒提，Claire 只說「依季節而定，請參考官網」。這是我們可以明確勝過競品的地方。

### 花期
順序一致：先給結論（7 月中旬最漂亮） → 各品種或各花田的見頃 → 提醒 8 月就收割。Mimi韓建議鎖定 7/15～7/25，波比用圖片版花期表，Claire 只說遇到滿開很幸運。

### 交通
兩種排法：(1) Mimi韓、滿分、Claire 把交通放在花期或門票之後；(2) 波比把交通放最後。交通內部順序分兩派：自駕優先（滿分、Mimi韓的 FAQ）或 JR 優先（Claire、波比）。慢車號的描述競品之間不一致（停靠站、運行日各說各話）。

### 必買必吃
四篇都是薰衣草霜淇淋放第一，然後是哈密瓜（切片或麵包），最後是伴手禮商店。Mimi韓有提到價格（霜淇淋約 400、哈密瓜約 500），波比和滿分沒有價格。

### 規則
只有我們這頁會獨立寫規則。四篇都沒有提到禁止事項（不能帶外食、禁寵物、禁三腳架等），也沒提到哈密瓜之家是不同的店。

## 段落與句子的習慣

- 句子偏短到中等，常用逗號串接，不寫長複句。
- 語氣口語，大量使用「超」「爆」「真的」「必」「一定要」。
- 稱呼讀者用「大家」「你」，有時用「旅人」。
- 轉場靠小標題和照片，段落之間幾乎不用過渡句。
- 數字直接嵌在句子裡（「步行約 25 分鐘」「約 400 日圓」），不另外做表格。
- 沒有任何一篇在正文用表格列時刻或價格。

## 給作者的順序建議

以下是大綱每個標題底下，讀者最先想知道什麼。標題照大綱不改。

### H2 中富良野富田農場要門票嗎？
1. 先一句回答：不用門票、停車也免費。
2. 再帶一句和桃園富田花園農場的區別（競品都沒提，我們有 mustAnswer 0 要回答）。
3. 連到中富良野主頁。

### H2 開放時間，每天看官網首頁
1. 先說全年無休，但每天開放時間不同。
2. 給季節時間表（這是競品都沒有的，放在這裡讀者馬上看到）。
3. 即時影像連結（出發前看花況）。

### H2 薰衣草幾月開
1. 先給結論：7 月上旬到中旬最漂亮。
2. 各花田的見頃按時間早到晚排。
3. 提醒 8 月就開始收割。
4. 彩色花田 H3：彩りの畑的見頃，再帶花人の畑四季都有花。

### H2 從中富良野站走到富田農場
1. 先講最簡單的走法：中富良野站走 25 分。
2. 然後是薰衣草花田站走 7 分（但只有夏季臨時列車停）。
3. 計程車選項（5 分、15 分）。
4. 開車 H3：免費停車 → 500 輛 → 旺季塞車與接駁巴士。

### H2 在中富良野富田農場逛什麼
1. 先講整體：12 片花田、80 種花。
2. 逐一介紹設施（展望台、花人の舎、香水之舍、蒸餾之舍、ギャラリーフルール），按讀者走的動線排。
3. 必買 H3：薰衣草霜淇淋放第一（競品全部這樣），然後哈密瓜、麵包、咖哩、伴手禮。
4. 規則 H3：先講最常犯的（不能帶外食、不能進花田），再講哈密瓜之家是不同的店。

### H2 從中富良野富田農場往薰衣草東區
1. 先講東區是什麼（日本最大級薰衣草田）。
2. 怎麼去（開車 7 分，沒有公共交通）。
3. 薰衣草巴士。

### H2 冬天去中富良野富田農場
1. 先回答：可以去，全年無休。
2. 看什麼：溫室薰衣草、ギャラリーフルール。
3. 吃什麼：冬季在花人の舎 1 樓ルネ，薰衣草霜淇淋全年都有。
4. 注意：多數商店冬季關閉、雪深。

## 他們有、我們缺的

1. **停留時間建議**：Mimi韓暗示需要半天，滿分建議早點來，波比說旺季要排隊買東西預留 20 分鐘。我們的 F152 記了官方不公布所要時間，大綱 gap 1 也寫了不寫官方數字，改用花田配置讓讀者判斷。不追加。
2. **哈密瓜麵包限購**：Mimi韓寫「每人限購三個」。官方餐點頁只寫「數量限定」沒寫每人限購，可能是旺季臨時措施或作者誤解。不追加。
3. **周邊景點與一日遊行程**：Mimi韓和波比都有順遊建議。這由中富良野主頁和大綱 links 處理，不在本頁寫。
4. **具體營業時間**：競品都沒有完整的季節表，我們有（F44、F153），這是我們的優勢。
