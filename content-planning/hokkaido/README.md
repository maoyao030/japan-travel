## 不成頁的題目

| 題目 | 處理 | 理由 |

| 宗谷岬住宿 | 排除 | 官方住宿清單在宗谷岬只看到民宿宗谷岬一家；研究時確認，若只有一家就寫進稚內住宿頁。 |
| 宗谷岬天氣 | 排除 | 宗谷岬沒有自己的氣象廳平年值，和稚內天氣頁共用。 |
| 利尻昆布 | 排除 | 搜尋結果幾乎都是染髮劑。 |
| 整理券巴士教學 | 延後 | 讀者是去過日本自由行的人，整理券屬於一般常識；等其他地區也需要時再評估。 |

宗谷岬的景點、美食與祭典內容少，寫在宗谷岬主頁裡。
